# RepeatCut / 柄合わせ裁断 (2026-11-28)

`index.html` をブラウザで開き、残り長さ・縦リピート・先端の柄位置と、必要片のID/裁断長/開始柄位置（タブ区切り）を入力して計算する。登録・外部API・通信なし。

## ターゲットと選定理由
壁紙DIY利用者、内装施工店、補修・端材活用担当。国内の[Arms](https://grand-arms.shop/howto) は柄・ステップ柄によるロスの計算を案内し、[アウンワークス](https://www.aunworks.jp/product/165187) は縦リピートを含む購入量計算を提供。海外の[A2Z Tools](https://a2z.tools/wallpaper-roll-calculator) は端材活用、[TrimLayout](https://trimlayout.com/wallpaper-calculator/) は柄位置と切断順の計算を扱う。既存サービスは需要の間接証拠であり、市場規模・支払意思は未検証。

## 差別化仮説
購入量ではなく、実測済みの単一残反で裁断順と採用片を同時に厳密最適化する。最大14枚、整数mm。最大枚数→最大必要片長→最小消費長の辞書式目的。施工順はIDで保持し、裁断順だけを変更。状態（使用済み集合・最後の片）の最小終了位置を動的計画法で保持する。同じ状態の終了柄位置は一定なので、短い終了位置が長いものを支配する。入力順比較、累積切断位置、残り長・次の柄位置、JSON出力。既存273アプリ名と関連コミット3語を確認し、MotifCircuit（縫製の合印整合性）、MAKINOKORI（フィラメント割付）、HAGIREZA（布の配置）等のREADME冒頭も確認。全ソース照合は未実施。

## テスト結果
`node test.js`：独立全列挙300ケースと不変条件、固定8アサーション全合格。14枚の上限を確認。サンプル10,800mmでは入力順3枚に対し最適4枚、消費10,600mm、柄合わせ端材600mm、残り200mm。`python browser_test.py`：Chromiumで同一HTMLをインライン読込（環境のfile URL制限）、初期計算、JSONダウンロード、不正入力、編集時の旧結果無効化、リセット、390px幅、JS例外・HTTP要求0件を確認。PythonテストはPlaywrightと/usr/bin/chromiumを使用。

## 制限
全片は同幅・同方向・同品番・同ロットを想定。切りしろを裁断長に含め、開始柄位置は生地の切断開始点を指定する。横柄・反転・欠陥・刃幅・伸縮・複数ロールの同時最適化は対象外。現物で確認してから切断すること。実施工・販売実績は未検証。
