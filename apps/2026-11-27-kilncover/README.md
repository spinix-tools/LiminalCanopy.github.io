# KilnCover — 試験片カバレッジ

対象：陶芸工房・美術大学・釉薬試験担当者。2026-11-27制作。

## 選定理由・差別化仮説
- 国内：京都美術工芸大学では200種以上の釉薬調合と試験片の番号管理を実施（https://www.kyobi.ac.jp/contents/faculty/arts_crafts/22284/）。岐阜県セラミックス研究所には約15万点の釉薬サンプル（https://www.ceram.rd.pref.gifu.lg.jp/library.html）。試験片作成・管理の実需を示すが、アプリの購買意欲は未検証。
- 海外：Glazyはブレンド生成（https://help.glazy.org/guide/blends）、Test Tile Trackerは実験記録（https://www.testtiletracker.com/）、Glazimoは因子試験・記録（https://apps.apple.com/mz/app/glazimo-glaze-tests/id6816692071）。NIST ACTSは汎用の組合せ試験（https://csrc.nist.gov/projects/automated-combinatorial-testing-for-software/faqs）。
- 本作は承認済み候補と既試験を入力し、限られた追加枚数で未確認の2因子ペアを多く埋める計画を生成。一般的なカバリングアレイの考え方を陶芸向けに簡略化したもの。独占性・収益性は未確認。
- 重複調査：会話内の直近10案、mainとの比較300ファイル（51ディレクトリ）、glaze/pairwise/釉薬/テストピースのコミット検索（各0件）。全履歴・全ソースの網羅照合は未実施。

## 起動と使用
index.htmlをブラウザで開く。サンプルを編集、または表計算からTSVを貼付。ID、状態（済/候補）、2〜6因子の列を指定。最大500行。追加上限を入力して計算し、計画と残りの組合せを確認。JSON出力・印刷可。計画後の値は実施済みではなく予定。再試験が必要な場合は候補に戻す。

## 検証結果
- `node test.cjs`：独立参照計算との500生成ケース、固定6チェック（重複・不正上限・因子名・上限0・追加・500行6因子）合格。
- `python browser_test.py`：Chromiumでサンプル、JSON実ダウンロード、上限0、入力変更で旧結果無効化、不正入力、390px表示、JS例外・HTTP要求0件を確認。file URLは環境ポリシーにより拒否されたため同一HTMLのインライン読込で実施。印刷実機未検証。
- 初期サンプル：12候補（うち既試験2件）、全16ペア、既試験6ペア、追加4件で16ペアを計画上カバー。

## 制限
貪欲法の近似解。最少枚数・最大カバレッジの厳密最適性、統計的有効性、3因子以上の相互作用、再現性、焼成や食品安全性を保証しない。承認済みの条件のみ入力。外部API、登録、通信、永続保存なし。個人情報・秘密情報は入力不要。
