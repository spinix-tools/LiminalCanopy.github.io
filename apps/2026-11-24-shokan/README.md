# 焦間 / SHOKAN — 2026-11-24

固定倍率のマクロ撮影で、採用可能な撮影済みレール位置を入力し、深度合成の抜けと最少追加撮影位置（本モデル内）を求める、オフライン単一HTML。`index.html` をブラウザで開く。アカウント・サーバー・外部ライブラリ不要。

## 対象・選定理由
日本・海外の鉱物、昆虫標本、模型、小物の商品撮影を行うマクロ撮影者。国内メーカーのOM SYSTEMは深度合成撮影を製品技術として紹介している。国内向けApp Storeにも被写界深度計算アプリが存在。海外のGera Toolsは撮影間隔・枚数の計算、Helicon Remoteは自動ブラケット撮影に対応する。需要の存在を示す間接材料であり、本アプリの有料需要や市場規模は未確認。

- OM SYSTEM: https://www.omsystem.com/ja-jp/technology/computational/focus_stacking/
- 国内向けSharpStop: https://apps.apple.com/jp/app/sharpstop-%E8%A2%AB%E5%86%99%E7%95%8C%E6%B7%B1%E5%BA%A6%E8%A8%88%E7%AE%97/id6814971826
- Gera Tools: https://geratools.com/macro-focus-stacking-interval
- Helicon Remote: https://www.heliconsoft.com/helicon-remote-features/

## 差別化仮説・使い方
計画時の理論枚数よりも、撮影後の実測位置・不採用コマの除外を起点に、追加撮影を減らす。対象奥行き、実測シャープ幅、余裕率、採用済み位置を入力。カバー率・不足区間・追加位置が更新される。撮影・確認後に「採用」。空の位置リストから新規計画も可能。CSV、印刷、端末保存あり。サンプルは5 mmに対し6枚採用済み、余裕込み72%、追加3枚。日本語版のみ。英語化・撮影者5〜10人の再撮影枚数比較が次の需要検証案。

## 計算と限界
整数µmで座標を扱い、実測幅の半分と余裕率で縮小した半幅をそれぞれ切り捨てる。既存区間を併合し、左端の未カバー点を覆う最も右の追加中心を選ぶ貪欲法で、対象内の0.001 mm格子・一定対称幅のモデルで追加枚数を最小化する。最大1500枚、対象奥行き最大100 mm。倍率変化、非対称な被写界深度、レールのバックラッシュ・可動端・実機分解能、実画像の品質、合成結果は未評価。入力幅はユーザーが同一撮影条件で測定する。実際の位置合わせと試写が必要。写真・個人情報を取得・送信しない。追加課金なし。
