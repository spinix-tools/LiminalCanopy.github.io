# 択点 / TAKUTEN

四択問題の正答位置と誤答肢の利用状況を、匿名回答だけで点検する無料オフラインWebアプリ。

## 対象・選定理由
学校教員、塾講師、企業研修の小テスト制作者。文部科学省は2026年8月3日、令和8年度全国学力・学習状況調査の全国データに基づく分析結果を公表している（市場規模や本アプリへの支払需要の証拠ではない）。
- 国内近接競合: [Marubatsu AI](https://marubatsu.com/ja)（作問・配布・採点・集計）
- 海外近接競合: [ZipGrade](https://zipgrade.com/)（採点・項目分析）、[ExamQR](https://app.examqr.com/analysis)（CTT/IRT・誤答分析）
- 根拠: [文部科学省の2026年度結果公表](https://www.mext.go.jp/a_menu/shotou/gakuryoku-chousa/sonota/1419141_00008.htm)

**差別化仮説**: 作問前の正答位置チェック → 匿名の選択状況 → 設問メモ → 監査CSVを、登録なし・通信なし・明示保存でつなぐ。競合より優位と証明したわけではなく、顧客需要・収益性は未検証。従来の字幕・端材計画・CSV保全・班編成・工事見積等とは異なる教育評価領域を選んだ。

## このGitHubディレクトリで動く機能
- `index.html` 単一ファイルで起動。正答キー編集・設問追加削除、匿名回答貼付（A〜D、欠答 `-`）、正答位置の偏り・正答率・欠答・各選択肢の件数・確認メモ
- しきい値による注意喚起：正答率90%以上/30%以下、回答20件以上で未選択の誤答肢、キーの集中・連続
- 36件の架空サンプル、CSV出力、JSON入出力、印刷、明示的なブラウザ保存/復元/削除
- 外部CDN/API・有料サービスなし、氏名やID等の入力を意図しない

**動かし方:** `index.html` をダウンロードしてブラウザで開く。ネット接続なし。コードはHTML中にすべて含まれる。

## テストと制限
- GitHub版：JavaScriptの構文解析成功、DOM模擬操作 **17/17 成功**（表示・編集・不正入力・明示保存等）。GitHub保存後の再取得・内容照合を実施。実ブラウザ直接起動は未検証。
- ローカル完全版（同じ製品の別実装）：Node.js単体 **21/21**、固定シードランダム **600系列**、Chromium操作 **34/34**。ブラウザ検証は管理環境の制限で `set_content` によるインライン起動、端末保存はメモリ模擬。
- **差異:** ローカル完全版には、同点を除外する「当該問以外の得点による上下群差」もある。GitHub版にはその指標は未実装。別実装なのでローカル完全版の操作テスト結果をGitHub版の結果と混同しない。
- 本アプリは教育測定や試験問題の妥当性を自動判定しない。匿名データでも入力・保存前に内容を確認すること。
