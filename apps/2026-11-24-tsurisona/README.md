# 釣備 / TSURISONA 🎪

**屋台・マルシェ・学園祭の釣銭不足を開店前に発見する、無料オフラインWebアプリ**（2026-11-24）。

## 対象・選定理由
小規模の模擬店・バザー・マルシェ出店者。「お釣りをいくら返すか」だけでなく「何件目に100円玉が尽きるか」が準備段階で分かることを重視。

日本市場の参考：[経済産業省（2026-03-31）](https://www.meti.go.jp/press/2025/03/20260331006/20260331006.html)は2025年のキャッシュレス決済比率を58.0%（新しい国内指標）と公表。ただし、これは小規模イベントの現金決済率やアプリ市場規模ではない。

国内競合：[かんたん金種計算機](https://apps.apple.com/jp/app/id1495275016)（金種集計）、[Square現金管理](https://js.squareup.com/help/jp/ja/article/5152-cash-drawer-management)（ドロワー開始残高と現金フロー）。海外競合：[Change Calculator](https://apps.apple.com/br/app/change-calculator/id367338685)（屋台向け釣銭計算）、[Change Counter](https://www.changecounter.org/)（現金金種の計数と締め作業）。

**差別化仮説：** 釣銭を金種別に入力し、商品代金×受取金種×取引回数の順序から最初の不足取引を特定。基準となる釣銭配分に必要な補充枚数を出せば、現場の不足を減らせるかもしれない。実際の需要・有料化・競合優位性は未検証。

## 実装済み
- 1円〜1万円（2000円札を含む）の10金種、開店時の枚数を編集
- 最大30種類×各80回の取引シナリオを追加・編集・複製・並び替え
- 在庫制約の下で最少枚数の釣銭を厳密探索し、初回の不足と成立売上を表示
- 固定の基準配分での補充目安、1クリック反映
- 独立の当日会計（記録・取り消し・リセット）、JSON入出力、CSV、端末内保存、印刷
- 無料・ライブラリ不要・アカウント不要・個人情報送信なし

## 起動・ソース
このフォルダの `index.html` は検証済み完全HTMLをgzipでロスレス格納したオフライン用ローダー。ブラウザの `DecompressionStream` 対応環境で展開できます。`python3 unpack.py` を実行すれば可読な `standalone.html` を標準ライブラリだけで復元できます。GitHubのソース閲覧画面はアプリの実行画面ではないため、ダウンロードして開いてください。
