# 字幕余白 / JIMAKU YOHAKU

**日本語字幕の読みやすさを点検し、縦型動画のUI占有範囲を見ながらSRT/VTTを整える、登録不要・端末内処理のWebアプリ。**

## ターゲットと選定理由

- **対象**：YouTube Shorts・Reels・TikTok向けに日本語字幕を制作する個人クリエイター、学校、店舗の広報担当者。
- **日本の需要の参考指標**：サイバーエージェント／デジタルインファクトが**2026-03-09**に発表した調査では、2025年の国内縦型動画広告市場は**2,049億円（前年比155.9%）**と推計。広告費市場の数字であり、本アプリに支払い需要があるという証明ではない。出典：https://www.cyberagent.co.jp/news/detail/id=33050
- **海外の関連需要**：Wistiaの**2025-03-26**公表資料では、ブランドの動画制作AI利用者の6割超が字幕AIを利用済み、または利用予定と報告。動画字幕ワークフローが活発という傍証であり、本アプリ固有の需要は未検証。出典：https://www.prnewswire.com/news-releases/wistias-2025-state-of-video-report-shows-use-of-ai-in-video-production-more-than-doubled-over-last-year-302411243.html

## 競合調査と差別化仮説

- **日本語で利用可能**：Editsub（SRT/VTT編集・翻訳）、SubTailor（日本語UI・行再分割・CPSチェック） https://editsub.com/ja https://subtailor.com/ja/about/
- **海外**：Subtitld（QA・波形タイムライン）、SRT Creator（QA・一括修正）、Schedulin（Shortsのセーフエリア表示） https://subtitld.org/ https://www.srtcreator.com/ https://www.schedulin.app/free-tools/youtube-shorts-safe-zone-checker
- **仮説**：強力な字幕エディターや単独のセーフエリアチェックは既にある。**日本語の禁則文字を意識した行再分割、読速・時刻重複チェック、複数縦型サービスのUI占有範囲プレビューを、1つの無料・オフライン可能な編集導線に集約**すると、小規模な制作現場の書き出し前チェックが速くなる可能性がある。
- **反証条件**：クリエイターが既存編集ソフト内のQAで十分と判断する、実プラットフォームで字幕位置が再現されない、時短が確認できない場合は差別化仮説を棄却・修正する。

## 実装済み（MVP）

- SRT / WebVTT のファイル取込・貼り付け、字幕の追加・削除・時刻・原稿編集、HTMLや動画ファイルなしでの操作
- 日本語の書記素（結合絵文字を含む）単位の文字数、CPS・行数・最大行字数・空欄・時間逆転・重複・短すぎる表示・狭い間隔のチェック
- **句読点・禁則文字を考慮**した最大4行の自動再分割、実行不能な長文は切り捨てず残し警告
- 重複区間の終了時刻短縮、全字幕の時間移動、問題箇所のみのフィルター
- Shorts／Reels／TikTok／縦型共通／横型の**参考セーフエリア**と字幕の上下位置調整。ローカル動画のプレビュー（字幕を焼き込まない）。位置パラメータはSRT/VTTには含まれない
- SRT・VTT・JSONプロジェクト・BOM付き診断CSVのダウンロード。localStorage自動保存、サンプル、端末データ削除
- 外部ライブラリ、外部API、認証、外部送信、追加課金なし（動画/字幕ともブラウザ内）

## 使用方法

`index.html`を現代的なブラウザで開く。ビルド不要。**字幕ファイルを開く**または**テキスト貼り付け** → 基準を調整 → 指摘を確認 → 必要に応じて一括調整 → 出力。横型プレビューは目安。データはブラウザの保存領域にのみ置くため、バックアップはJSON出力を推奨。

## テスト（2026-11-18）

```bash
node --test engine.test.cjs
python browser_test.py   # Playwright と Chromium が必要
```

- **Node.js単体テスト：40/40 合格**（SRT/VTTパーサ、書記素、QA、再分割、時間調整、CSV、安全側の入力拒否など）。
- **Playwright Chromium DOM操作テスト：33/33 合格**（取込・貼り付け、編集、時刻移動、行再分割、重複修正、ファイル出力、XSS無害化、デスクトップ/モバイルUI）。
- **制約**：このテスト環境では localhost への Chromium ナビゲーションが管理者によってブロックされたため、ブラウザ試験は**実ファイルのHTML/CSS/JSをabout:blankに直接挿入**して実施。`localStorage` はテスト用の模擬ストレージで復元を検証。`file://`直開き・実サーバー配信でのE2E、実端末での保存持続性、動画映像の実再生とSRT互換性全般は未検証。
- アプリのセーフエリア数値は**2026-11-18時点の編集用仮定値**で公式保証ではない（サービスや端末・UI表示状況で変化）。特に字幕をSRT/VTTで書き出しても配置座標は保存されない。音声認識、翻訳、焼き込み、言語解析による意味単位の分割は非対応。
