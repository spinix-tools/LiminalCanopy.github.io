# SpoolRelay / フィラメント使い切り計画

## 対象・選定理由
家庭の3Dプリンタ利用者、小規模造形工房。スプール残量の合計が足りても、途中交換をしない個別ジョブの割付に失敗する問題を扱う。日本語市場では temoto.app の残量計算 (https://temoto.app/filament-calc/) と Filament Genius (https://filamentgenius.app/ja/)、海外では Spoolroom (https://spoolroom.app/) と Spoolr (https://spoolr.net/) を2026-11-28に調査。残量・在庫管理や印刷前の確認機能は既に充実。利用者数・検索量・収益性は未検証。

## 差別化仮説
複数ジョブを一括で、同一互換グループの残スプールへ割付。完了件数最大→使用量最大→使用本数最小の辞書式最適化。比較用の降順先着割付も表示。競合に同様の機能がないことは未確認。入力は端末内のみ、アカウント・API不要。

## 使用方法
index.html をブラウザで開く。名前,互換グループ,整数g の形式でスプール最大8本・ジョブ最大12件を入力。予備量は各スプールに適用。入力変更後に再計算。結果のJSON保存が可能。各ジョブは途中交換なし・単一スプールで実行する前提。探索200,000ノードで打ち切る場合は暫定解と明示。素材・色・径・温度等の互換性は入力者の責任。実機造形、測量誤差、多色造形、スライサー連携は未検証。

## テスト
`node test.cjs`：固定9アサーション、独立全列挙300ケース合格。`python test_browser.py`：Chromiumでサンプル、JSONダウンロード、旧結果無効化、不正入力、入力HTML非実行、予備量、390px表示、JS例外・外部HTTP要求なしを確認。環境のfile URL制限により同一HTMLをset_contentで読み込んだ。サンプルでは残量85/75g、予備5g、ジョブ70/50/30gで単純割付2件→最適3件、150g使用。
