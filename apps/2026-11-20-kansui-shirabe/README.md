# 換水しらべ / KANSUI SHIRABE

淡水アクアリウム向け、**2案の定期換水をNO₃予測・手間・使用水量で比較**するオフラインWebアプリ。2026-11-20制作。前回までのカード確率・字幕・棚割・郵便・焙煎・野鳥・シフト・裁断・Wi-Fi・室内音響アプリとは対象と実装が異なる。

## ターゲット・選定理由

日本の水槽ユーザー、特に換水間隔や使用水量を見直したい淡水魚・水草飼育者。J-Net21（中小機構）のアクアショップ解説は、観賞魚飼育の存在と水換えアドバイスの重要性に触れる。一方、富士経済の2025年市場データの紹介（2026-07-28更新）では国内水槽・周辺器具市場は2022年以降縮小傾向で、国内需要の成長を仮定しない。海外では米国APPAが2025-09-24に発表した報告で、淡水魚飼育世帯約1,000万、海水魚飼育世帯約200万と紹介。これは飼育人口の周辺指標であり、本アプリの支払意欲や需要を直接証明しない。

## 競合・差別化仮説

- 国内: [Aqua Navi 水槽計算ツール](https://aqua-navi.jp/Aqua_Navi/tools/) は単発・連続換水による硝酸塩変化を計算。[ハッピーフィッシュプロジェクト アクア計算ツール](https://happyfish-animal.com/aqua-tools/) も水換え量を算出する。
- 海外: [FishFits Water Change Calculator](https://fishfits.com/calculators/water-change/) は換水量・水道水NO₃・毎週の増加量・定常値を扱い、高機能。[AquariumToolbox](https://aquariumtoolbox.com/calculators/water-change) も換水間隔・定常ピークを扱う。

**差別化は「既存にはない硝酸塩計算」ではなく**、同じ水槽での **A/B換水計画を42日等の時間軸に重ね、換水前ピーク、使用水量、目安超過日数、正味変化±30%の感度帯、定常換水率の逆算、14日の換水カレンダー**を一体化する点。使い勝手・優位性・収益性は未検証。

## 機能・起動方法

1. `index.html` をブラウザで開く（`style.css`、`engine.js`、`app.js`を同じフォルダに置く）。サーバー、APIキー、ライブラリ、登録は不要。
2. 水槽の実水量、現在/換水用水のNO₃、1日正味増減、任意の管理目安と予測日数を設定。
3. A/Bの換水間隔・1回の割合・初回換水日を設定し、ライン・比較表・換水カレンダーを確認。
4. 2測定値と測定日数から換水のない期間の正味変化を推定可能。定常ピークの目安を満たす換水率を逆算し、適用可能。
5. JSON入出力、CSV時系列、SVG画像、印刷、明示操作によるlocalStorage保存/削除に対応。入力の外部送信なし。ブラウザ外へ出すのはユーザーが明示的に書き出したファイルだけ。

## 計算モデルと制限

日ごとに `換水直前 = max(0, 前日換水後 + 日次正味増減)`、換水日は `換水後 = 直前×(1−換水率) + 補給水NO₃×換水率`。定常的な増加が正なら `定常換水前ピーク = 補給水NO₃ + (日増加量×間隔)/換水率`。逆算は定常時の目安で、**初回の超過解消は保証しない**。予測帯は日次増減±30%の単なる感度分析で信頼区間ではない。最高値・目安超過日数は毎日の換水直前で評価。初日の値はグラフにも含める。

NO₃（硝酸塩としてのppm）とNO₃-N（窒素換算ppm）は異なる。魚種・水槽立上げ状態・生体の健康・NH₃、NO₂⁻、pH、水温、硬度、塩素処理、植物や給餌量の変動はこのモデルでは判定できない。**生体の安全性や換水の最適解の保証はない**。実測値と飼育管理の専門資料を優先する。
