# 値札あわせ / NEFUDA AWASE

出店当日の「値札を大量に作り直す」を少し減らす、**A4値札の面付け・印刷補正ツール**。日本語／完全フロントエンドMVP（2026-11-17）。

## ターゲットと選定理由

- 対象：マルシェ、ハンドメイドイベント、小規模小売の出店者。商品数が多く、値札を少量ずつ自宅プリンターで準備する人。
- 市場の存在：Creemaの公式案内は全国約30万人の作家・デザイナーが出店すると説明（2026-11-17閲覧）。ただし**値札印刷への需要・課金意思を示す数値ではない**。
- 困りごとの仮説：会場の前夜に複数種類の値札をまとめて刷る際、テンプレート操作より「商品名・価格・枚数→一括配置」とプリンター位置ずれ修正を優先する利用者がいる。

### 差別化仮説

**価格札という限定用途で、商品名・価格・必要枚数の即時入力、連続印刷ページ、全体オフセット＋列/行ごとの「累積送り補正」、100mm実測線つき試し刷りを一つの画面に集約。** 専用ラベル用紙やアカウントを必要としない軽量版という立ち位置。Averyやラベル屋さんが既に高機能のため、競争優位・成長可能性は未検証。

## 実装済み機能

- 商品の追加・編集・削除、価格・補足・必要枚数の登録。初回はサンプル商品3種類入り。
- A4 3プリセット（8/12/24面）と列数・行数・札サイズ・間隔・余白のカスタム設定。
- 位置補正：左右/上下の一律シフト、列/行ごとに加算する送り補正（mm）。A4はみ出し判定時には印刷不可。
- 札を枚数分並べ、複数ページに分割、ページ送りプレビュー、ガイド線のON/OFF。
- 100mm基準線と配置座標付きの試し刷りモード。ブラウザの`window.print()`で印刷。
- 日本語/英語ヘッダーのCSV読み書きと、JSONでの全設定バックアップ・復元。localStorageによる自動保存（利用可能な環境のみ）。
- 入力値のDOMへの表示は`textContent`（HTMLとして実行しない）、CSVエクスポート時の表計算式文字列をエスケープ。

## ローカル実行

同一フォルダーに`index.html`、`engine.js`、`app.js`を置いて`index.html`を開く。厳格なブラウザポリシーで`file://`が制限される場合は、フォルダー内で`python -m http.server 8000`を実行して`http://localhost:8000`へアクセス。ネットワーク・追加API・ビルド不要。データはアプリから外部送信されない。**共有端末では端末のブラウザ内の保存データを管理すること。**

印刷はA4縦、倍率100%／実際のサイズ、余白なし（利用可能なら）、ヘッダー・フッターなしを指定。最初に普通紙で試し刷りし、物理定規で100mm線と印字位置を確認する。**ブラウザとプリンター固有の余白・倍率制限があるため、寸法精度は保証しない。** 印刷データに含まれる「税込」等は自由入力の表示文字列で、税率計算機能ではない。

## テスト結果（2026-11-17）

- `node --test engine.test.cjs`：**18/18件合格**（配置・補正・はみ出し・枚数分のページ割当・CSVパーサー・式注入対策など）。
- `python browser_test.py`：**18/18操作項目合格**（商品操作、用紙変更、送り補正、ページ移動、試し刷り、CSV/JSON入出力、プレビューのHTML安全表示、印刷ボタン、デスクトップ・モバイル）。Chromiumを使用。
- **試験環境の制限**：ブラウザによる`http://127.0.0.1/`へのアクセスが管理者によってブロックされたため、HTMLとJSをChromiumに直接読み込んで操作試験を実施。`localStorage`は模擬ストレージで保存／再初期化を検証。実URL配信・実端末での保存永続性・実際のプリンター印字位置は未検証。
- モバイル幅390pxで横方向はみ出しなし。試験画像`desktop.png`・`mobile.png`はローカルの検証結果。

## 制約と次の検証

デザインは単色の簡易値札（文字の自動改行はブラウザ依存）。長文はクリップされる可能性がある。自動縮小、バーコード、複数ラベル用紙規格、税計算、クラウド同期は未実装。異なるプリンター3機種で実寸誤差を記録し、利用者5人に「プリセットで十分か・列送り補正が必要か」を確認することが次の検証。ソフトの機能が実装済みであることと需要の実証を混同しない。

## ソース・権限

アプリ本体は`index.html`, `engine.js`, `app.js`。テストは`engine.test.cjs`と`browser_test.py`。外部ライブラリ・有料API・Cookie解析・トラッキング・ユーザー識別子の送信なし。`hourly-app-lab/apps/2026-11-17-nefuda-awase/`に保存する想定。`main`を変更しない。
