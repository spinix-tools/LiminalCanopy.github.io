# コンロ譜 / KONROFU

夕食の提供時刻から、**調理する人・コンロ・オーブン・炊飯器の占有**を逆算するオフライン調理段取りWebアプリ。2026-11-19制作。

## 想定ユーザーと選定
複数の料理を一度に作る家庭の自炊担当者、料理初心者、作り置きの段取りに悩む人。タニタの2026-03-12国内調査は料理初心者の「節約・時短」志向を報告。Antwayの2026-05-14調査（2,000人）では料理が最も負担に感じる家事の首位（28.1%）。ただし調理段取りアプリ単独への支払い意思を示す数字ではない。

## 競合と差別化仮説
国内: ParaChef（AI統合レシピ・段取り）、ダンドリキッチン（並行調理）、そろいごはん（完成時刻から逆算）。海外: Simmer（調理タイムライン）、Cook's Clock（台所設備も考慮）、Mise（作業工程の競合解消）。**完成時刻の逆算自体には新規性なし。** 差別化仮説は、「手も使う」加熱工程の**二重資源占有**とコンロ・作業者の増員比較を、外部登録不要の日本語一画面で編集・可視化できる点。実ユーザー検証・商業性は未検証。

## 実装
- 12工程のサンプル、料理・工程・時間・設備・手の占有・前工程の編集、追加、削除
- 有向依存関係の検査（循環・異料理間の不正参照を拒否）
- 資源制約を守る逆算ヒューリスティック、SVGなしのアクセシブルなタイムライン
- 調理開始時刻、全体調理時間、完成後待ち時間、コンロ+1・調理者+1の仮想比較
- JSONの書出し/読込み、CSV、印刷、localStorageへの保存
- Vanilla JavaScriptのみ。ログイン、API、課金、外部送信なし。フォントのみGoogle Fontsを参照（オフライン時は代替フォント）。

## 動かし方
全ファイルを同じフォルダに置き、index.htmlをブラウザで開く。オンライン接続不要。Node.js v20+ がある場合は \`node --test engine.test.cjs\` でテスト可能。

## テスト
- スケジューラの自己試験: assertions PASS（GitHub保存直前の実行時）
- 同梱の Node.js テスト：実行環境で確認すること（実行後に結果を更新する）
- 重要制限：探索は最適解を保証しない。調理時間は利用者入力であり食品の安全性・加熱温度・保存・保温を判断しない。複数資源を同時に使うタスクは単位期間ずっと占有する単純化モデル。実料理・実機印刷での検証は未実施。
