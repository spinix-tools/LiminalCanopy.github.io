# BridgeAudit / ステンシル破断検査

2026-11-27 MVP。対象：ステンシル型紙を設計するDIY制作者、看板・印刷・加工業者。日本の加工業者がブリッジの配置・耐久性の問題を解説しており、海外にも自動ブリッジ生成・警告ツールが複数ある。生成ではなく、既存の型紙の局所破断による脱落面積を全候補で比較する検査に特化する。実需要・検索数・収益性・競合の全機能は未検証。

## 使い方
index.html をブラウザで開く。24×24の格子をクリックして素材／穴を切り替えるか、文字マスクを貼り付ける。外周は固定素材。1×1または3×3セルの局所破断を、外周につながる内部素材セルを中心に全数検査。4近傍の幅優先探索で、破断前は外周に接続し、破断後に残存するが接続を失ったセルを数える。既存孤立と除去セルは別集計。上位30件または任意の有効位置を選択して可視化する。JSONは全危険位置を出力し、PNGは元の二値マスク（24×24）を保存する。

## 検証
- `node test.cjs`：固定6件、独立した反復伝播参照計算との400比較（200盤面×2破断範囲）合格。
- `python browser_test.py`：Chromiumで編集、位置選択、入力エラー、JSON/PNGダウンロード、390px幅、JS例外・外部HTTP要求ゼロを確認。環境のfile URL制限のため同一HTMLをインラインで実行。
- サンプル：片側ブリッジは1セル破断で危険位置6件、最大新規脱落40セル。両側ブリッジは1×1・3×3とも新規脱落0セル。
- 重複確認：直近の会話、mainとの差分300ファイルに含まれる51アプリディレクトリ、stencil/ステンシル/bridge/型紙のコミット検索（該当なし）。全履歴・全ソースの網羅確認ではない。
