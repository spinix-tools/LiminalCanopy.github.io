# 面余 / MENYO — カセット小ロット録音の面替え計画
2026-11-24制作。`index.html` をブラウザで開き、曲順と在庫を入力し「全候補を比較」。登録・通信・外部ライブラリ不要。

## 競合・差別化仮説
日本語圏のFoundは順次A/B割当・残量表示・コピー、海外のMixtape Makerは曲順編集・残量・Jカード、MixTape Calculatorは順次割当・最適収録・曲間指定を提供。基本の時間計算は既存。面余は曲順を固定し、面替え禁止/希望、A/B別の録音可能時間の下限、各在庫本数、追加秒・予備を用いて、**同じマスターが収まる在庫本数を最大化**する。競合の全機能・独占性は未確認。既存199ディレクトリと関連9件のREADME冒頭を確認した範囲で用途重複なし（全ソース比較ではない）。

## 機能・計算
2〜40曲、1〜20在庫グループ（各1〜999本）。曲の後の `!` は面替え禁止、`*` は希望。全39以下の境界を列挙し、適合本数、希望位置、適合在庫の最小余裕（0本なら最も近い在庫の最大側不足の最小化）、面長差、曲番号の順で順位付け。曲間は同一面の曲間のみ。追加秒は全曲、予備は各面に加算。各在庫判定、手動候補比較、開始時刻表、CSV、印刷を実装。バーは各面の在庫最大容量との比。サンプル（架空）では5曲目後の2/12本から4曲目後の10/12本へ改善、最小余裕25秒（予備10秒控除後）。2本は不足のまま。

## 制限
単一の共通マスターを前提。録音可能時間はユーザー入力の下限であり、実際の録音速度、磁気テープの劣化、音質、実測誤差、楽曲利用権は検証しない。音声生成・外部送信・個人情報収集・有料APIなし。テープへの録音や印刷実物、市場需要・収益性は未検証。
