# DotFit — 点字ラベル寸法検査

## 対象と選定理由
点訳済みのラベルを作る印刷・加工担当者、教材制作者、個人の試作利用者。国内のTOPPANインフォメディアは点字加工ラベルを提供し、当事者の触読テストを推奨している。海外ではBraille3DやLyraMakerが点字ラベルの3Dモデル生成、BraillifyがSVG/PNG/STL生成、shapeCrafterが語群を分割しない点字折返しを提供する。2026-11-27に公開ページを確認。市場規模、購入意向、収益性は未検証。

## 差別化仮説
点訳・造形ではなく、既に確認済みの点配列を縮小せず、複数の既製ラベル寸法と一括照合する。候補ごとに群を分割しない最少行数を動的計画法で求め、同じ行数では空きセル数の二乗和を最小化する。収まる候補から面積最小、次いで行数・幅・入力順で選ぶ。候補なしも明示。外接矩形を全セルに確保する保守的な寸法モデルで、点が少ないセルも同じ幅で扱う。競合に同等機能がないとは断定しない。

## 操作
index.htmlをブラウザで開く。1行1ラベル（Unicode 6点点字のみ、空白は語群区切りとして正規化）、1行1候補寸法（幅 x 高さ mm）を入力。点径、セル内間隔、セル送り、行送り、余白を調整して「寸法を検査」。最大60ラベル・各300セル・30候補。結果は点配置見本・候補別判定・JSONで確認できる。初期例は架空の配列であり、正しい点訳文ではない。

## 検証
- `node test.cjs`：5語群の長さ1〜3、容量1〜12の2,916ケースで独立全分割列挙と一致。固定12アサーション合格（不正文字、8点点字、寸法境界、候補選択、点座標等）。
- `python browser_test.py`（Playwrightと/usr/bin/chromium）：同一HTMLをインライン読み込みして、初期3件、入力変更時の旧結果無効化、不正入力、候補なし、リセット、JSON実ダウンロード、390px幅、HTTP要求・JS例外0件を確認。環境のfile://制限により直接ファイル起動は未検証。
- 重複確認：会話の直近作品、mainとの比較に含まれる51アプリディレクトリ、およびbraille/tactile/emboss/点字のコミット検索（該当なし）。全履歴・全ソースの網羅照合ではない。

## 制限・プライバシー
初期寸法は計算例であり規格推奨値ではない。点訳、点の高さ・形状、材料、触読性、正式規格への適合、加工・印刷は未検証。点字利用者・専門家による実物確認が必要。SVGは画面プレビューで加工データではない。外部依存・通信・API課金・登録・永続保存なし。入力はブラウザ内のみ。日本語UI。
