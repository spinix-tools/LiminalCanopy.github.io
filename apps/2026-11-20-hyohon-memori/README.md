# 標本メモリ / HYOHON MEMORI

**匿名集計だけで、アンケートの属性偏りとウェイトバックの副作用を把握するWebアプリ**（2026-11-20）。ソースは `index.html`・`style.css`・`engine.js`・`app.js`。ファイルを同じフォルダに置き `index.html` を開くだけ。外部API、CDN、Cookie追跡、アカウント、OpenAI API、有料サービスなし。

## 対象・市場選定・競合

対象：小規模NPO、自治体広報、教育機関、個人リサーチャー、社内アンケート担当。日本ではマクロミルが2025年2月12日の発表でセルフ調査「Questant」の調査対象スクリーニング機能拡充を報告し、約2,500万人の調査パネル、QuickCrossによるクロス集計を紹介している。国内では集計・属性管理ニーズの存在を示すが、このMVPへの有料需要を示すものではない。海外のQualtricsは既にレーキング（IPF）、セルベース、静的重みづけを提供し、製品競合として強い。

- 国内参照：[マクロミル・Questant 2025-02-12発表](https://www.macromill.com/press/release/20250212.html)、[QuickCrossウエイトバック解説](https://www.youtube.com/watch?v=uUYFXb3fGyY)。
- 海外競合：[Qualtrics 回答の重み設定](https://www.qualtrics.com/ja/support/survey-platform/data-and-analysis-module/response-weighting/)。近接する無料・オープンソースのR統計パッケージなども代替。
- **差別化仮説：** 既存の高機能調査プラットフォームではなく「個票をアップロードせず、匿名2次元クロス集計だけで、補正前→1軸→2軸の変化と Kish 実効サンプル数、空セル・極端な重み・目標非収束を同時に示す」軽量説明ツール。競合より優れていると実証されたわけではない。

## 機能

- 2〜5×2〜5の属性クロス集計に回答数・肯定数、各軸の目標百分率を入力。行列の追加／末尾削除、ラベル編集。
- 反復比例フィッティング（IPF / raking）で2軸の周辺構成に合わせる。1軸のみの結果も比較。観測のないセルを仮想回答で埋めない。
- 回収構成・補正後・目標のバー表示、加重肯定率、重み最大値、Kish の実効サンプル数（ESS）、収束残差と反復数。
- 入力矛盾、ゼロ回答の目標セル、両軸の実現不可能な目標、極端な重み、空セルを表示。
- CSVとJSONをローカルへ保存、JSON復元、localStorage自動保存、印刷。
- 氏名・メールアドレス・個票は不要。分析は完全ブラウザ内で実行。サンプルの目標比率・回答数は架空。

## 検証

`node --test engine.test.cjs` / `node --check engine.js` / `node --check app.js` / `python browser_test.py`。2026-11-20の結果：**Node.js単体テスト32/32合格**（250件のランダムな正値セルの周辺制約検証を含む）、**Chromium操作チェック32/32合格**、`node --check` 2ファイル合格、PC/モバイル画面保存。管理環境が `file://` ナビゲーションを拒否したため、ブラウザ試験では**同一のHTML/CSS/JSをページ内へ読み込んで実施**。通常の `file://` 直接起動、端末保存の持続性、印刷実機での出力、実調査データへの適用精度は未検証。

**統計上の限界：** 目標割合の根拠をアプリは検証しない。任意抽出・募集経路・非回答などの選択バイアスは属性への校正だけでは解消しない。IPFは観測済み属性セルに一定ウェイトをかけるもの。サンプルが母集団を代表する保証はなく、Kish ESS はあくまで重みの偏りの目安であり、推測統計の信頼区間・有意差を提供しない。属性は差別的プロファイリングのためでなく、適切な分布の診断に用いること。実務公開前に統計専門家の確認を推奨。
