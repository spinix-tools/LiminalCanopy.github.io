# 戻せる？ / MODOSERU

**バックアップ事故シミュレーター（無料・登録不要・オフライン）**。データをどこに何通り複製したかではなく、同じ機器・保管場所・認証群が同時に使えなくなったとき、**期限内かつ復元テスト済みのコピーが残るか**を点検します。

## 対象と市場・競合（2026-11-21確認）

- **対象：** 小規模事業者、制作会社、写真・動画クリエイター、個人で自前のバックアップを管理する人。現物・ファイルは投入せず保存構成のラベルと数値のみ入力。
- **日本：** IPA「情報セキュリティ10大脅威 2026」（2026-01-29）組織向け1位が11年連続で「ランサム攻撃による被害」。これは潜在需要の背景であり、本アプリの直接需要を証明する統計ではありません。[IPA一次資料](https://www.ipa.go.jp/pressrelease/2025/press20260129.html)
- **海外：** Veeamの2026-04-14発表では、調査で復旧の速さに自信を示すセキュリティ担当者90%に対し、ランサムウェア被害組織でデータを完全回復できた割合は28%と報告。調査対象は大企業中心であり、小規模事業者への外挿不可。[Veeam調査](https://www.veeam.com/company/press-release/veeam-report-reveals-a-market-wide-shift-from-recovery-confidence-to-proven-data-resilience-amid-ransomware-threats-and-ai-adoption.html)
- **競合：** [HIXOR Backup 3-2-1 Planner](https://hixor.jp/en/tools/backup-planner/) は3-2-1の不足と提案をブラウザ内で計算。[Backblazeの3-2-1解説](https://www.backblaze.com/learning-center/3-2-1-backup-strategy)は運用の基本を案内。[Duplicati](https://github.com/duplicati/duplicati)は実バックアップの実行・復元を担うOSS。競合は存在し、「バックアップ点検」一般は独占的な新領域ではありません。
- **選定理由・差別化仮説：** 3-2-1の**枚数**を数える画面とは別に、機器、拠点、認証群、全オンライン書込可コピーの一斉改変の**相関故障**を列挙し、データごとに **RPO（何時間前までを許容）＋復元テスト有無＋復元時間の概算**をクロス診断する。特に「コピーは残るが古い／未検証」を、喪失や回復可能と区別することに価値を見込む。市場適合・収益性・競争優位は未検証。

## MVPでできること

1. データ資産（名前・GB・許容遡り時間）とコピー（保管場所・機器・認証群・経過時間・ネット接続・変更保護・実機検証・復元速度）の追加・編集・削除。
2. 全ユニーク機器、全拠点、全認証群、オンライン書込可能コピーの一斉改変を自動列挙。`復元候補あり / 期限超過 / 復元未検証 / 全コピー喪失` の4種類で全ケースと詳細を表示。
3. 手当て候補、復旧時間の概算、診断表CSV、JSON設定の保存・読込、ブラウザ内設定保存、印刷。
4. 依存パッケージ・認証・API・外部通信なし。ローカルなHTML/CSS/JavaScriptのみ。パスワードや実データは入力不要。

**起動：** 同梱の `index.html` を対応ブラウザで開く。インターネット接続不要（ただしブラウザのローカルファイル制限は環境依存）。各ファイルを同じディレクトリに置く。

**試験：** `node --test engine.test.cjs`。Chromium/Playwrightが使える場合は `python browser_test.py`（要Python playwright・Chromium実行体）。

## 検証（2026-11-21）

- `node --test engine.test.cjs` : **34/34合格**。例示データ、コピーロスト条件、RPO境界、未検証コピー、CSV式注入対策、上限・形式検査、500ランダム構成の不変条件。
- Chromiumで**28/28 UI操作チェック合格**：編集、判定連動、追加・削除、シナリオ選択、JSON書き出し・読込、CSV、印刷呼出、保存ロジック、モバイル幅。JavaScript例外なし。実行環境の管理制限で `file://` はブロックされたため、**同一ソースをHTMLへインライン埋込み、localStorageをメモリモック**して試験。通常ブラウザでのファイル直接起動と永続保存は未検証。
- 出力画像：`desktop.png` / `mobile.png`。

## 安全上・計算上の限界

これは**想定事故を比較する教材・計画ツール**であり、実際の復旧可能性、完全性、安全性、対策水準を検証しません。変更保護は入力どおり有効と仮定し、実機復元テストは利用者の自己申告です。攻撃者の権限昇格、バックアップソフトの脆弱性、破損や互換性、暗号鍵消失、実測帯域、データ依存・復旧順序、保険・規制適合、確率や費用はモデル化しません。復元時間は `GB × 1000 / MBps / 3600` の単純近似。必ず実機での復元演習と専門家による確認が必要です。

**データ方針：** 設定はブラウザのローカル領域のみ。アプリのHTML/JSに外部通信コード・解析タグ・課金コード・秘密鍵なし。設定JSONの共有には内容への配慮が必要です。
