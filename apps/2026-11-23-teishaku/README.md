# 停尺 / TEISHAKU — 鉄道模型の編成・ホーム長検算

**2026-11-23 制作。** ホームの長さを測り、手持ちのN/HOゲージ編成が収まるかをオフラインで試せる日本語Webアプリ。サーバー・登録・APIキー・課金なし。

## ターゲット・選定理由

小型レイアウトを作る鉄道模型愛好家、模型クラブ、展示担当。車長の異なる複数車両と、端部で使えない区間を持つ複数ホームを一度に照合することで、ホーム延長や増結前の寸法確認を助けることを狙います。

- **国内の需要の手掛かり**：2026-06-30のNEXER調査は、鉄道に興味を持つ回答者138人の模型購入傾向・予算面の課題を掲載。標本に選択バイアスがあるため日本全体のアプリ市場規模・有料需要ではありません。 https://prtimes.jp/main/html/rd/p/000002668.000044800.html
- **国内の実際の設計例**：KATOのレイアウトプランは6両対応ホームの延長による長編成対応を例示。ホーム有効長は具体的なレイアウト条件です。 https://www.katomodels.com/unitrackplan/plan_N2_46
- **海外の動向**：車長・側線収容計算の個人用Webツールやブラウザ型レイアウト設計サービスが存在します。これは課題が既知である状況証拠ですが、ヒット確率や有料需要の証明ではありません。

## 競合と差別化仮説

- **国内向け:** [Trackplanner 日本語版](https://trackplanner.io/ja) はKATO/TOMIXの線路品番、自動接続、3D・基本検算まで扱う強力な競合。
- **海外:** [ToolHuts Train Length & Siding Capacity Calculator](https://toolhuts.com/model-railroad/train-length-calculator) は機関車・貨車・側線の長さ比較。[ModelRailCalc](https://modelrailcalc.com/calculators/) は線路設計の多様な計算を提供。
- **差別化仮説:** 線路CADやメーカー部品表ではなく、**車両1両ずつの実測長、両端の停止余裕、ホームごとの使用不可区間を入力し、複数ホームへ同時照合**する「寸法の見落としを防ぐ」単機能の速さ。既存ツールと機能は一部重複し、競合優位・実需要・継続率は未検証。

## 実装・操作

1. **GitHub版:** `index.html` 単独で起動。モダンブラウザで開くだけ。**可読な単一ファイルのコンパクト実装**です。
2. 縮尺（日本型N、N、HOなど）、連結間隔、前後余裕、車両ごとの長さ（模型mm）を設定。編成の追加・複製・順序変更・編集・削除。
3. ホーム名と全長、両端使用不可区間を設定（最大12線）。実寸比のSVG図と収容可否、不足mm、後尾削減両数、指定車両の追加可能両数を確認。
4. Undo、JSON保存/復元、UTF-8 CSV検算表、SVG図保存、印刷、ブラウザ内localStorage保存に対応。外部通信・SDK・個人情報収集なし。

## 計算の前提

編成長 = 車両実測長合計 + 連結間隔×(両数−1)。停止必要長 = 編成長 + 前後余裕。ホーム有効長 = max(0, 全長−左端不可−右端不可)。差 = ホーム有効長−停止必要長。差が0以上で「収容可」。後尾削減は現在の順序で末尾から順に車両を外す場合の数で、連結可能性は未判断。初期値はデモ用の仮寸法で、メーカー公称寸法ではありません。

曲線での張り出し、建築限界、車輪・連結器の干渉、扉位置、分岐器、停止位置誤差は対象外。**現物での確認が必須です。**
