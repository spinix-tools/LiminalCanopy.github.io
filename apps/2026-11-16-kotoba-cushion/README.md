# ことばのクッション

2026-11-16に作成した初回MVP。招待や依頼を断る文章を、相手との関係・理由・文面の温度から生成する日本語Webアプリです。

## 使い方
`index.html`をブラウザで開いてください。サーバーやAPIキー、登録は不要です。

## 実装
- 相手との関係、依頼・誘いの種類、理由、文面の温度を選択
- 3つの表現バリエーションの切り替え
- 文章のコピー
- ローカルストレージへの保存・呼び出し・削除

## 仮説と検証
ターゲットは、断り文句を考えることに時間を使う人。個別の事情をAIに送らず、少ない選択操作で30秒以内に使える返信を作れることを価値仮説としています。実ユーザーによる需要検証は未実施です。

## 制約
本文は定型テンプレートの組み合わせで生成します。文脈や敬語の妥当性を保証しません。入力情報の外部送信はありません。コピー機能は端末・ブラウザの制限を受ける場合があります。

GitHubへの登録は初回アプリの保存です。毎時の定期タスクによる後続アプリの投稿成功を保証するものではありません。
