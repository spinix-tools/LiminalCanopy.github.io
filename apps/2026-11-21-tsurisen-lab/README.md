# 釣銭設計室 / TSURISEN LAB

2026-11-21 | 無料・ブラウザ完結の出店前「釣り銭」リスク試算MVP

## 対象と採用理由
- **ターゲット:** 学園祭・地域バザー・小規模マルシェ・個人作家の現金販売担当者。準備金の金種内訳に迷う人。
- **日本の状況:** 経済産業省は2026年3月31日に2025年のキャッシュレス決済比率を**58.0%（国内指標・金額ベース）**と発表した。現金取引が残る環境は想定されるが、これは小規模出店の現金比率やアプリ需要を示す調査ではない。[出典](https://www.meti.go.jp/press/2025/03/20260331006/20260331006.html)
- **国内競合:** iOS「[かんたん金種計算機](https://apps.apple.com/jp/app/id1495275016)」は金種別の入力・合計・保存。「[お釣り 電卓](https://apps.apple.com/jp/app/id367338685)」は受取金額から釣り銭を表示する。
- **海外競合／需要の兆候:** [MakeChange](https://www.varo.industries/blog/posts/makechange-cash-change-calculator) はクラフトフェアでの釣り銭計算を支援。[Booth Season（2026年11月9日更新）](https://boothseason.com/how-much-cash-to-bring-to-a-vendor-event/) は市場出店に持ち込む釣り銭の金額・金種について実務記事を掲載。いずれも利用者数や支払意欲を証明しない。
- **差別化仮説:** **販売価格×予定個数×支払い方の比率×手持ち金種**から、釣り銭不足のシナリオ割合を試算。金種別の増額案を予算上限内で作り、共通乱数でA/B比較する。単なるお釣り計算、金種集計、POSと役割を分ける。

## 実装済み
1. 商品（価格・予定個数）編集・追加・削除、支払い方4種類の割合設定、金種10種を手持ちと比較案で個別編集。
2. 有限の紙幣・硬貨在庫で**最少枚数の釣り銭組合せを探索**。貪欲法だけでは解けない組合せも探索し、受け取ったお金はその取引で利用可能とする。
3. 20～400回の決定的なモンテカルロ試算。順序のシャッフル、任意の支払い方選択、釣銭不能時の取引不成立、会計残高の追跡を行い、現在／比較案で**同じ乱数条件**を用いる。
4. 「1回以上不足」割合・平均不足取引数・90パーセンタイル不足件数・先頭20件の見本ログ・金額比較。
5. 予算内の**簡易補強案**作成、JSON読込／出力、CSV準備表、印刷、localStorage保存。

**重要な前提:** 1商品の販売を1取引とし、複数商品をまとめ買いする行動・キャッシュレス購入・客の紙幣選択の実分布・途中両替・売り逃し後の再購入・税計算は再現しない。「確率」は**設定した仮想モデル内の割合**であり、実際の発生確率の推定値ではない。釣り銭不足時はその売上を成立しなかったものとする。複数の同価値解では枚数が少ない組合せを使用し、将来の最適準備金を保証しない。最適化案も経験則であり数学的最適解ではない。

## 実行
依存ライブラリ不要。`index.html`を開いて操作するか、`python -m http.server 8000` で公開してアクセスする。処理はすべて端末内。追加の有料サービス・外部API・個人情報送信なし。端末内の設定保存にはブラウザの localStorage を使用する。

## テスト（2026-11-21）
- `node --test engine.test.cjs` → **20/20合格**。釣り銭在庫限界、非貪欲組合せ、入力エラー、会計保存則300シナリオ、金種ランダム500件、再現性・補強案予算のチェック。
- `python browser_test.py` → **25/25合格**。Chromiumで商品編集・削除、金種表示、試算、補強案、JSON/CSV出力、JSON復元、モバイル結果・はみ出し等を確認。スクリーンショット `desktop.png` / `mobile.png` あり。
- `node --check engine.js app.js` → 合格。なお管理環境のブラウザで `file://` および `http://` のページ遷移が管理ポリシーで拒否されたため、Playwrightは**同一の本番HTML/CSS/JSをページへインライン展開**して検証。通常の直接起動・localStorage永続性・実機印刷は**未検証**。商用利用前に現場テストが必要。

## 制約・プライバシー
JSONは自分で選んだファイルだけを読み込み、最大200KBとする。価格や商品名は端末内に保存されるが、送信されない。共有端末なら「サンプルへ戻す」を実行。実資金は必ず現物を数えて管理すること。MIT License。
