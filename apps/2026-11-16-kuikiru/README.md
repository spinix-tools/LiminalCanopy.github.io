# くいきる / KUIKIRU — 使える備蓄を試算する

2026年11月16日制作。対象は家庭の在宅避難準備に取り組む世帯。水・食事・加熱の制約を入力し、停電・断水で食べられる食数と日ごとの配分を可視化する。

## 選定理由・競合・差別化仮説
農林水産省と政府広報は家庭での食料備蓄を最低3日から1週間、水を一人一日約3L（飲用・調理）と案内している。食品の個数は足りていても、電気・水・加熱手段がなければ利用できない可能性がある。[農林水産省](https://www.maff.go.jp/j/syokuiku/plan/4_plan/togo/html/part8.html)・[政府広報（2026-02-13）](https://www.gov-online.go.jp/useful/202407/video-286084.html)。

日本の競合：[Sonamet](https://sonamet.web.app/)、[ノコリス](https://restock.altive.co.jp/ja/)は備蓄量・賞味期限の管理に強い。海外の[KitReady](https://kitready.app/)は世帯の備え全体、[MyPlann](https://www.myplann.com/)は水・燃料・食品の複合評価に対応する。今回の差別化仮説は、食品単位の調理条件から **日ごとの配分結果と食べられない理由** を短い日本語操作で示すこと。世界初の概念ではなく、需要・収益性は未検証。

## 主な実装
- 人数、日数、保有水量、調理に回せる水、加熱可能食数を入力して即時計算
- 食品の登録・編集・増減・削除（食数、調理条件、期限）
- 調理不要を優先した日ごとの配分。水・食事がともに目安を満たす連続日数
- 期限超過食品の除外、バックアップJSONの輸出・復元、印刷
- APIキー・アカウント・クラウド保存・追加課金なし

## 安全上の限界
水は目安3L/人/日（飲用＋調理）、調理水はその内数。1人1日3食・1食1加熱枠とした簡略的な決定的配分で、最適化、栄養・衛生・食品安全・生活用水・特別な配慮は保証しない。賞味期限と消費期限は異なる。調理器具は換気・火災・一酸化炭素中毒に注意。行政機関の公式ツールではない。

## 検証
フル版の計算エンジンは Node.js 14/14件、ChromiumのUI操作は11/11項目が合格。ブラウザのナビゲーションが制限された環境でHTMLとスクリプトを注入し、保存機構はモックで検査。実端末の永続化、静的サイト実配信、印刷は未検証。READMEとテストの原本はZIPにも付属。

## 利用
`index.html` と `engine.js`、`app.js` を同じフォルダで開く。静的ファイルだけで利用可能。
