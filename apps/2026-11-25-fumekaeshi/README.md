# 譜返し / FUMEKAESHI

既存の紙の楽譜を、演奏中に交換できる境界で1〜3面の独立した譜面セットに分ける計画ツール。index.html をブラウザで開く。ネット接続・登録不要。

## 対象・選定理由（2026-11-25調査）
- 日本：電子楽譜カノンは自動譜めくり・ペダル等を提供。Piascoreにも遠隔ページめくりがある。譜めくりの課題への既存投資を示すが、紙の利用者数や支払意思は不明。
  - https://www.canon-score.com/usage/app
  - https://help.piascore.com/hc/ja/categories/360000036252-Piascore
- 海外：2012年の譜めくり技術調査は演奏中・練習中の課題を指摘。LilyPondは休止区間を使う最適改ページを実装済み。最新の市場規模は未確認。
  - https://doi.org/10.3233/WOR-2012-1242
  - https://lilypond.org/doc/v2.24/Documentation/notation/page-breaking
- 対象は紙のパート譜を使う演奏者・伴奏者・楽団。差別化仮説は既存ページを再組版せず、3面展開の予算と実測交換時間で、交換セットを計画すること。独占的な新規性や需要は未証明。
- 直近の制作履歴、mainとの比較で返された差分のディレクトリ、譜めくり/page turn/楽譜/譜面のコミット検索を確認。全既存アプリの網羅的照合は未実施。

## 使い方・仕様
境界ごとの交換可能秒（0〜60、小数1桁）を入力。最大120ページ、必要時間0.1〜60秒、3面セット上限0〜20。通常の2面配置と比較し、時間不足の交換回数→不足秒の合計→交換回数→3面組数の辞書式最小化をメモ化DPで行う。時間は0.1秒の整数。準備表のCSV・印刷対応。入力変更で旧結果を無効化。最後のページ後は交換なし。サンプル8ページは2,2,2,2から3,2,3へ変更し、不足3回→0回、合計5.5秒→0秒。
