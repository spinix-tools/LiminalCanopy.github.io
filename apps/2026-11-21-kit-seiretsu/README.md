# キット整列 / KIT SEIRETSU

> 同じ日に重なるイベントの備品不足を先回りで検出する、登録不要・オフラインの持ち出し準備室。

- **対象**: 部活・学校行事・NPO・地域イベント・小規模スタジオなどで共用備品を複数案件に持ち出す担当者。
- **選定日**: 2026-11-21 (JST)。既存アプリ群の木取り・展示札・写真・箱詰め・行列・停電・製パン・字幕・異本・アンケート集計とは別領域。
- **価格・個人情報**: 外部 API / 有料サービス / ログイン / 追跡 / 送信機能なし。データはブラウザの `localStorage` と手動ダウンロードにのみ存在。氏名・連絡先は入力しないでください。

**差別化仮説:** 高機能な資産管理や利用者ログではなく、**共通在庫 × キット構成 × 日付重複**に絞り、短時間で不足品と追加必要数を計算し、持ち出し確認まで端末内で完結させる。なお競合もキットや予約に対応しているため、優位性や有料需要は未検証。まず地域イベント運営者5組で、準備時間と不足品発見数を紙/表計算と比較する。

## 起動・使い方

1. ZIPを解凍。ネット接続なしで `index.html` を開く（動作しないブラウザでは任意の静的ファイルサーバーに配置）。
2. 「備品・キット」で共通在庫とキットの構成数を登録。
3. 「予定と不足」で各予定の期間（**両端日を含む**）、使用キット数を登録。同日に重なる需要が在庫を超えると警告。
4. 「出庫チェック」で実物確認の進捗を記録。チェックを入れても在庫不足は解消されない。
5. 「出力・保存」でピーク需要を満たすための追加数をCSV出力、JSONバックアップ/復元。

**備品の追加必要数** = `max(0, 日別の最大同時必要数 - 現有数)` 。予定期間は最大90日、開始・終了は同日可。予定の期間途中の出庫/返却時刻、故障率、物理的に持ち出せる時間、同一備品の割当優先順位は考慮しない。**本ツールは予測・持ち出しチェック用であり、正式な貸出台帳や在庫引当システムではない。**

## 実装した機能

- 備品・キット・イベントの新規/編集/削除（参照中の削除は禁止）
- 日別需要集計、競合の品目・日付表示、予定単位の不足警告
- ピーク同時需要に基づく調達・借用品目と追加個数の抽出
- 予定別出庫チェックシート、進捗表示、印刷
- CSV 3種（不足・追加・出庫）と JSON バックアップ/復元
- 自動ローカル保存・安全側の入力検証・インポート制限・HTML/CSV式注入対策
- デモデータ、デスクトップ/モバイルのレスポンシブ画面

## 検証（同梱ソース上で実施）

- `node --check engine.js && node --check app.js`：構文検査合格
- `node --test engine.test.cjs`：**18/18**。日付境界、参照整合性、重複・不足、チェックと割付の分離、CSV安全化、JSON往復など
- うち **250件の決定的ランダム条件**について、計算結果を別実装の全日・全品目総当たりと比較（合格）
- `python browser_test.py`：**33/33**。Chromiumで予定/備品/キットCRUD、CSV、JSON復元、チェックと警告、XSS、画面描画・モバイルなどを検査

**ブラウザ検証の制限:** この管理環境のChromiumは `file://`・`http://localhost` 等のナビゲーションを拒否したため、同一の本番HTML/CSS/JSをインライン展開し、`localStorage` を模擬して検証。実ファイル直接起動、ブラウザ標準の保存永続性、印刷実機での精度、複数端末同期は未検証。ブラウザAPIの本番動作を包括的に保証するものではない。
