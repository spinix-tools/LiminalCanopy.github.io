# TickLens — 目盛りラベル監査

2026-11-28 / MVP。`index.html` をブラウザで開き、昇順の目盛り値と検査する幅を指定。「検査する」で現在の表示を監査し、提案を適用・JSON保存できる。依存なし、通信なし、登録不要。

## ターゲット・市場・差別化仮説
ダッシュボード開発者、研究者、資料作成者。国内のMatplotlib解説では軸ラベルの任意設定が紹介され、海外のD3は単位と精度を揃える書式機能、Quickplotterは目盛り数・フォント調整、AnyToolは短縮ラベルのグラフ生成を提供。目盛りを削らず、日本語の万・億と英語K・Mを含む候補について同名・文字の重なり・丸め誤差を複数画面幅で同時に監査することが差別化仮説。需要規模・支払意思・競合全機能は未検証。次は既存グラフの作成者に操作評価を依頼する（未実施）。

## モデル・制約
2〜30目盛り、2〜6画面幅（240〜1600px）。固定単位（元単位/K/M/万/億/基準値との差分）×小数0〜8桁の最大54候補。Canvasの実測文字幅、左右40pxの余白、4pxの間隔で全ペアの水平重なり・はみ出しを計数。誤差率は最大絶対丸め誤差÷最小目盛り間隔×100。条件を満たす候補のうち最大文字幅が最小の形式を提案。同点なら基準値なし、桁数、誤差率の順。差分形式には基準値注記が必須。倍精度の固定書式・水平線形軸のみ。実チャートや他フォントへの適合、対数軸、文字回転、端数処理の他実装との一致は保証しない。個人情報や秘密情報を入力しないこと。
