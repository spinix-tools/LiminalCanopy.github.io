# 釉巡 / YUUGURI — 釉薬試験片の配合探索計画

2026-11-24制作。`index.html` をブラウザで開く。外部ライブラリ・API・登録・課金不要。データは端末内のみ（保存は任意）。

## ターゲット・市場・競合
陶芸家、小規模工房、陶芸教室。既調製の3種類の液状釉薬で、残量が少ないときにどの配合の試験片を追加するか計画する。
- 国内：京都美術工芸大学の2022-10-17の記事では陶芸分野の学生が200種以上の釉薬調合を試験。岐阜県セラミックス研究所の釉薬カラーライブラリーは約15万点のサンプルを保有。これは試験文化の間接指標であり、本アプリの需要規模ではない。 https://www.kyobi.ac.jp/contents/faculty/arts_crafts/22284/ / https://www.ceram.rd.pref.gifu.lg.jp/library.html
- 国内競合：陶芸手帖は調合・焼成・工程の記録、釉式Yushikiは化学組成計算・比較・対照付き再試験を提供。 https://www.tougeitecho.jp/ / https://apps.apple.com/jp/app/釉式yushiki/id6787324042
- 海外：Glazyは三角ブレンドや計量・試験法を提供し、Potter's Kitも各試験片の重量と必要総量を計算。GlazeIQは三角グリッドの記録も提供。 https://help.glazy.org/testing/triaxials / https://help.glazy.org/testing/blending / https://potterskit.com/triaxial-blend / https://glaze-iq.com/
- 差別化仮説：既試験点と各原液の固形分濃度・残量・予備・試験数制限から、新規試験候補を距離優先で選び、計量表を作る。通常の全格子生成や記録ツールと異なる作業に絞る。独占的機能・実需要・支払意思・市場規模は未確認。調査日2026-11-24。
- 次の市場検証：工房・教室5組程度に、手計算との所要時間・計画の採用率を比較してもらう（未実施）。

## 機能・計算モデル
2〜10分割（6〜66点）。既試験登録、最大40点の自動提案・手動選択、原液必要量、比率の丸め誤差、CSV、印刷、端末保存。目標乾燥分に対し濃度で割って液状重量へ変換、0.1g刻み切り上げ。予備を除いた残量を0.1g刻み切り捨て。距離は目標配合比の各成分差の最大値（百分率ポイント）。既試験・選択点に最も近い点への距離が最大の実行可能点を順次選択、同距離では原液総量の少ない点を優先。既試験なしでは中心に近い点から開始。貪欲法であり大域最適性・最大試験件数は保証しない。試験結果の色や釉薬の化学反応・安全性・焼成条件・測定誤差・沈降・計量ロスは判定しない。原液の種類・焼成条件が変わったら既試験点を解除すること。
