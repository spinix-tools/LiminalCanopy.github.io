# 溝境 / GrooveBoundary
2026-11-26制作。自主制作レーベル、ミュージシャン、レコード入稿担当者向け。`index.html` をブラウザで開く。登録・通信・外部API・音源アップロード不要。

## 機能とモデル
2〜40曲、2/4面、目標尺、曲間秒、曲ごとの前半希望・次曲と分離禁止を入力。順序を保った全合法境界を列挙（最大9,139通り）。超過秒合計→希望曲が指定時刻を超える演奏秒→面間尺差の辞書式最小化。曲間は同一面内のみ加算。時間だけの案（超過→尺差）も比較。上位10候補、面別バー、JSON、印刷、入力検証。時間指標は実際の溝半径・歪み・カッティング可否を予測しない。目標は工場の指定を入力する。分離禁止はハード制約、前半希望はソフト制約。曲名は架空名・番号でよく、永続保存・収集・送信なし。
