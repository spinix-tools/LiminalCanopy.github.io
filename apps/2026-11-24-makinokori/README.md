# 巻残 / MAKINOKORI

余りフィラメントと複数の単色プリント予定を、途中の巻交換なしで割り当てるブラウザ完結MVP（2026-11-24）。`index.html` を開き、サンプルの各行を編集して計算します。

## ターゲット・市場・選定理由
家庭用FDM機の利用者、学校・メイカースペース、小規模工房。日本AM協会の[2025-06-03告知](https://jsam.or.jp/news/2025-06-03-5133/)には一般向け3Dプリンターや素材を扱うJapan RepRap Festival 2025が掲載されている。日本語圏の競合は[Filament Genius](https://filamentgenius.app/ja/)（在庫・スライサー連携）と[Gyroid](https://gyroid.app/ja/)（残量・コスト・保守記録）。海外の[Spoolroom](https://spoolroom.app/)（重量とスライス済みファイルの照合）、[3D Print Cost Lab](https://3dprintcostlab.com/tools/spool-remaining)（残量・予備・単一予定の判定）も同じ課題の存在を示す。イベント・競合の存在は需要の間接指標であり、市場規模や課金需要、ヒット確率を実証しない。

## 差別化仮説・機能
最大4巻・8予定を対象に、総重量−空重量−予備重量を容量として、互換グループが一致する巻への不可分割の割り当てを全探索（枝刈り・対称性削減）する。優先度合計→件数→使用gの順で最大化。先着順との比較、巻別の残量バー、未割り当て理由、CSV、印刷、端末への明示保存を実装。サンプルでは先着3件から最適4件になる。日本語UI、通信・アカウント・外部依存なし。競合の全機能を操作検証したわけではなく独占性は未確認。既存apps一覧と関連5件のREADMEを確認したが全既存ソース比較は未実施。木取り等と最適化手法は近いが、3Dプリントの優先度・重量・互換性・途中交換禁止に特化する。

## 検証・制約
Node.js 15単体テスト、独立全探索との1,000ランダム照合（目的値・容量・互換性・割り当て整合性）に合格。Chromiumでサンプル、先着比較、編集、再計算、入力拒否、保存・復元、CSV、初期化、HTML文字列の安全表示、390px幅を確認。JS例外・外部リクエストなし。管理環境のナビゲーション制限によりHTMLをインライン実行、端末保存はメモリ模擬。印刷実機、ファイルURL・GitHub上の直接起動、実際の造形は未検証。互換性は利用者指定。整数gのみ、単色・1件1巻、サポート等を含む見積り必須。巻端や測定誤差、複数素材・途中交換・プリンタ接続は対象外。印刷完了や材料節約を保証しない。

再現: 配布ZIP内で `node test.cjs`、PlaywrightとChromiumが導入された環境で `python browser_test.py`。テストは配布ZIPに同梱。
