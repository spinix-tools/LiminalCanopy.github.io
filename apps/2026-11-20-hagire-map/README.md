# はぎれ地図 / HAGIRE MAP

**縫い代と布の方向を考慮し、手元の端切れから裁断計画を作る、無料・ローカル完結のWeb MVP。**

## ターゲットと選定理由

布小物の個人制作者、ワークショップ主催者、小ロットのハンドメイド販売者。端切れがあっても「何が何枚切り出せるか」の判断に手間がかかる。GMOペパボ公式の2025年11月13日発表では minne の2025年のカテゴリー成長が報告され、同社サービス紹介では登録作家・ブランド数97万以上（2026年4月14日時点の比較記載）。海外でも Etsy の2025年年次報告（2026年2月19日公表）が、2025年末のアクティブセラー560万人を報告。これらは作り手市場の存在を示すが、裁断ツールの利用需要・支払意欲を直接証明しない。

## 競合と差別化仮説

- 日本の **Cutting Planner** / **CutRun** は1D/2D板取り・刃厚・木目方向など高機能。CutRunはCSVと複数原板に対応。
- 海外の **CutMath** / **2D Cut** はブラウザでの切断最適化、木目・切りしろ・端材や保存などを備える。端材管理自体は新規機能ではない。
- **仮説：** 製材・工場向けの万能ツールではなく、縫い代込みの仕上がり寸法、布の色/素材の完全一致、柄方向の回転禁止、**端切れ優先の割当**、使った布から生まれた余りを**次回在庫へ確定**する一連の作業を日本語で簡単に扱うと、布小物制作者の作業時間を短縮できる。

## 実装機能

- 端切れ・新品の布を複数枚登録（幅/高さmm、素材名、枚数）。
- パーツ登録（完成寸法、1辺あたりの縫い代、枚数、90°回転可否）。
- 素材名が一致する布にのみ配置。端切れ優先で長方形を配置し、8種のヒューリスティック（4順序×2分割方向）を比較。裁断間隔を確保する。
- 使用布別のSVG図面、実際の裁断寸法、未配置リスト、使用布ベースの面積利用率を表示。
- 裁断完了ボタンで未使用布＋各辺50mm以上の余りを次回の在庫に引き継ぎ。ワンクリックUndo。
- CSV裁断リスト、SVG図面、JSON保存・復元、ブラウザ内自動保存、印刷、スマートフォンUI。
- 外部通信なし。課金なし。名前・連絡先等の入力不要。

**重要な限界：** 長方形のみ。最小在庫使用数・最小廃材の厳密な最適性は保証しない。端材図は切断できる自由長方形の近似で、実物の歪み・布耳・柄合わせ・曲線型紙・カット工程は未考慮。使用率は「使用した布の面積に対する縫い代込みのパーツ面積」。裁断後の残布に裁断間隔で使えない細い領域があり、在庫更新では各辺50mm未満の端材を除外する。端末保存は同一ブラウザの localStorage に限る。

## 使い方

1. `index.html` をブラウザで開く。サーバー、ビルド、アカウント登録は不要。
2. 布・パーツを編集し「配置を計算」。同じ素材名を使う（完全一致）。
3. 印刷/CSV/SVGを出力し、実物と計画を照合。実際に裁断した後のみ在庫確定。
4. JSONを適宜バックアップ。個人のデータは外部に送信しない。

## テスト

- `node --test engine.test.cjs` — エンジン単体テスト、500ケースのシード固定乱択幾何検査。
- `python browser_test.py` — Chromium + Playwright で画面操作・ダウンロード・読込・保存・在庫確定・Undo・レスポンシブ画面を確認。
- `node --check engine.js && node --check app.js` — 構文検査。

結果はこの実行で検証した内容に更新する。
