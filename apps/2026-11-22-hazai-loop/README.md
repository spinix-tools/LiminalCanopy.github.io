# 端材ループ / HAZAI LOOP

端材と長尺材の切断計画をブラウザ内で作り、計画の確定時だけ在庫を更新するMVPです。

## 対象と差別化仮説
木工教室・DIY・小規模什器製作者。2025年5月の国内ホームセンターDIY用品・素材売上は683億円（経産省速報の報道。ただしアプリ市場規模ではない）。
競合：国内 [Cutting Planner](https://tubakurosoft.com/)、[板取りくん](https://apps.apple.com/jp/app/id6759824247)、海外 [CutOptim](https://cutoptim.com/)、[OptiCut](https://wooddesigner.org/opticut-software/) は既に木取り・端材在庫に対応します。新規性は木取り自体ではなく、軽量な「プレビュー→明示確定→端材登録→直前の取消」の一画面運用にあります。需要・収益性は未検証。

## 機能と実装範囲
`index.html` を直接開くと単体で利用できます。材料・部材の編集、材種区分、切りしろ・両端余白、未配置警告、切断図、端材登録、直前の確定取消、JSON入出力、CSV、印刷、端末保存。ログイン・APIキー・通信・有料依存なし。

## 検証と限界
このGitHubの単一HTML版はソース構文を確認できる形で公開しています。**Node.js 19/19・Chromium 39/39の自動テストは、ユーザーに同梱提供した分割版／完全版に対する結果であり、この軽量版のブラウザ自動テスト結果ではありません。** この版はより単純な貪欲配置法で、厳密な最適解は保証しません。

実物の刃厚、材の傷・歪み、固定余長、斜め切断、設備安全を評価しません。計画確定は台帳更新であり物理的切断完了ではありません。実使用時は現物確認が必要です。MIT License。
