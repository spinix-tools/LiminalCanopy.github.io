# 窓つゆ時報 / TSUYUDOKEI

**窓の結露と表面の湿潤条件を、1日の時間推移で「現状A / 対策B」比較する、完全ローカルのWebアプリ。**

## ターゲットと選定理由（2026-11-20調査）

- **対象:** 冬に窓の結露が気になる家庭、賃貸住宅の入居者、小規模な住まいの修繕検討者。特に「内窓を付けるか、まず湿度を変えるか」を比較したい人。
- **日本の状況:** 環境省は[先進的窓リノベ2026事業](https://www.env.go.jp/earth/earth/ondanka/building_insulation/window_00004.html)を案内し、断熱窓の改修を支援している。これは窓改善への社会的関心の背景であり、アプリ需要の直接証拠ではない。[YKK APの結露予測](https://www.ykkap.co.jp/consumer/reform/window/ketsurosimulation/simulation.php)には室内外温湿度と改修前後の窓種を使った予測が既にある。
- **海外の状況:** 米国[ENERGY STAR](https://www.energystar.gov/products/res_windows_doors_skylights)は高断熱窓でも結露し得ること、窓面の通風・室内湿度を管理することを説明。[InfyCalculator](https://infycalculator.com/calculator/window-condensation-risk-calculator)はU値と露点から表面温度、許容湿度を算出。[Home Moisture Lab](https://homemoisturelab.com/)は部屋別の露点や湿度の比較に対応している。既存の類似計算サービスがあり、単なる「露点計算」は独自機能ではない。
- **選定仮説:** 一時点の判定だけでは「夜間の何時間が危ないか」「内窓＋湿度調整の組合せでどこまで変わるか」を説明しにくい。**2時間刻みの12条件をA/Bに同時適用して危険時間を比較し、その時間帯の表面湿度80%を下回る室内湿度の計算上の上限を示す**、という一連の検討体験を差別化仮説とした。実利用者数・費用対効果・有料化可能性は未検証。

## 実装したMVP

1. 2時間ごとの12枠について、室温・外気温・室内相対湿度を直接編集。寒波／穏やかな冬のプリセットから開始できる。
2. A/Bそれぞれで窓のU値（定型5種／自由入力）、室内側熱抵抗（通常／カーテン相当）、湿度の差分（%pt）を指定。
3. Magnus近似の露点、窓内側表面温度、表面相対湿度を推定。**100%を超える結露条件、80%を超える湿潤目安を別々に**2時間単位で集計。
4. A/Bの24時間リスク折れ線SVGグラフ、湿潤時間差、最悪時刻、各時刻の表面RHを表示。80%に達しないための室内湿度上限と追加低減量を逆算。
5. CSV結果のダウンロード・温湿度CSV復元、JSON設定のダウンロード・復元、端末内`localStorage`自動保存、印刷、スマホ幅レイアウト。初期データは架空。サインイン・外部通信・課金は不要。

## 使い方と実行

`index.html`をブラウザで開く。同じディレクトリに`style.css`、`engine.js`、`app.js`を置く。デモ条件を変え、表の温湿度を実測値で置き換え、対策BのU値や湿度補正を編集する。条件変更時に自動反映され、ボタンでも再計算できる。

ローカルHTTPサーバーで試す場合は `python -m http.server 8000`。静的ページだけで動作し、パッケージのインストールは不要。CSV読み込みは自身で書き出したCSVの形式（`time,outside_C,inside_C,base_RH_pct`を含むヘッダーと00:00〜22:00の12行）に対応。

## 計算モデルの限界

- 水蒸気飽和圧はMagnusの簡易式（氷点下も水面基準の近似）。`dew = 243.12×γ/(17.62−γ)`、`γ = ln(RH/100)+17.62×T/(243.12+T)`。
- 基準室内側表面熱抵抗を0.13 m²K/Wとし、U値から基準のその他熱抵抗を `1/U−0.13` と推定。指定した室内側熱抵抗を足して `T_surface = T_in − (T_in−T_out) × R_si / (1/U−0.13+R_si)` を計算。室内の水蒸気量が窓面まで同じと仮定して `RH_surface = RH_room × p_sat(T_in)/p_sat(T_surface)`。
- 各2時間枠の条件が一定と仮定した「条件該当時間」であり、連続実測の結露時間ではない。表面RH100%以上は「水滴生成の熱力学的条件」で、凝縮量・持続時間は計算しない。80%はユーザーの観察用の閾値であり、**カビ発生・危険性の診断基準ではない**。
- 窓枠・熱橋・日射・放射・風・結露水の蒸発・季節変動・経時的な湿度変化、実際のU値・サッシ施工状態は扱わない。カーテン設定は抵抗変化を粗く表すのみ。高断熱窓でも窓枠が結露する場合がある。建築設計・施工・健康診断、消防安全の根拠にしない。
- 米国[EPAの湿度に関する一般的推奨](https://www.epa.gov/mold/brief-guide-mold-moisture-and-your-home)は室内RH 60%未満、可能なら30〜50%という目安であり、本アプリの「窓表面RH80%」とは対象が違う。両者を混同しない。
