# 余白ラベル / YOHAKU LABEL

**小ロット作家のための「端数のラベル×使いかけシート」配置ツール。** 2026-11-21制作、MIT License。HTML / CSS / JavaScriptのみ、外部API・アカウント・課金・データ送信なし。

## ターゲットと選定理由

ハンドメイドの作品販売者、クラフトイベント出店者、小規模ショップ。作品の種類ごとに必要枚数が違い、印刷済みシートの空き面を再利用したい場面を対象とする。

- **日本の需要代理指標:** Creema公式サイトは**2026年1月時点**で約30万人のクリエイター・2,000万点の出品を公表。minneは**2025年11月13日**に2025年の検索・購入トレンドを公開。販売人口の広がりは示すが「ラベルツールへの支払い意向」を示すものではない。
  - https://www.creema.jp/page/about
  - https://prtimes.jp/main/html/rd/p/000005113.000000136.html
- **国内競合:** エーワン「ラベル屋さん」は無料でWeb作成・印刷、5,000点以上のテンプレート、エーワン製品の品番指定による位置合わせに対応。競合機能は十分に成熟している。
  - https://www.a-one.co.jp/download/
- **海外競合:** Avery Design & PrintはCSV・Excel差し込み、個別ラベル編集、既存ラベルを印刷範囲から除外する機能がある。単なる「余り位置をスキップ」だけでは新規性にならない。
  - https://www.avery.com/help/article/create-and-print-labels-and-other-projects-in-design-and-print-online
  - https://www.avery.ca/en/help/template-support/how-to-preview-and-print-in-design-print-online-html.html
- **差別化仮説:** ブランド用紙・会員登録なしで、**異なる品目の数量配分＋使いかけの1枚目の任意位置スキップ＋自動ページ分割＋原寸SVG＋全枚印刷**を一画面で行う。ニッチな現場作業の時間節約が採用理由になるかを検証したい。

## 実装済みMVP

1. A4 / US Letter、縦横、ラベル寸法、左右上下余白、セル間隔をmmで設定。
2. 最大60品目・計2,400ラベルを追加・削除・編集。品名、補足、色、必要枚数を指定。
3. 品目ごとの連続配置 / ラウンドロビン交互配置。グリッドを計算し最小シート数へ割り当て。
4. 1枚目の使用済み位置を `1-3,7` 形式またはクリックで指定。使用済み位置には印刷しない。
5. ページごとのリアルタイムSVGプレビュー、必要枚数・必要シート数・未使用位置数。
6. 表示中の1ページを原寸SVGで保存、全ページのブラウザ印刷、配置CSV、プロジェクトJSON保存/復元、端末内localStorage保存。
7. 値の検証（収まらない寸法・範囲外のスキップ位置・不正枚数など）、モバイル画面。

### 起動・テスト

`index.html` をブラウザで開く（ビルド不要、オフライン利用可能）。`node --test engine.test.cjs`、`python browser_test.py`（Playwright・Chromiumが必要）。

テスト日: **2026-11-21**。**Node.js 21/21ケース合格（うち乱択500条件の枚数保存則等）、Chromium 34/34確認項目合格**。Chromiumは運用環境で `file://` とローカルHTTPへの直接アクセスが制限されたため、同一ソースをDOMにインライン展開して操作検証した。外部リクエスト0件、JavaScript例外0件。デスクトップ・モバイルのスクリーンショットを同梱。

### 重要な制限

- 用紙への配置は**指定した矩形グリッドの理論計算**。市販ラベルの専用型番やプリンターの給紙誤差・余白・色差を自動校正しない。まず普通紙で100%印刷して位置合わせすること。
- 端数枚の再利用は**1枚目のみ**。後続シートの個別穴あき配置や不定形裁断は対象外。
- SVGは単色帯・2行程度の品名・補足テキスト用の簡易デザイン。高度なデザイン・QRコード・食品表示や化粧品法定表示の適法性判断は行わない。
- ブラウザの `file://` 直接起動、実機プリント位置、印刷色、永続保存、実売・収益性は未検証。
