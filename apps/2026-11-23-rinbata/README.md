# 輪畑 / RINBATA 🌱

連作の注意候補を「区画×年」の作付履歴から見える化する、完全オフライン・ログイン不要のWebアプリ。

## ターゲット・選定理由
家庭菜園、学校菜園、共同菜園、プランター利用者。農林水産省は同じ場所に異なる科の野菜を栽培する輪作を説明する。タキイ種苗の2026年3月4日発表「家庭菜園に関する調査」は20〜69歳400人の意識調査であり、本アプリの有料需要や市場規模を示すものではない。

## 日本と海外の競合
国内：野菜栽培図鑑（科情報・栽培履歴）、菜園プランナー（レイアウト・連作・日誌）。海外：GrowVeg Garden Planner（輪作警告・継続計画、7日試用と有料プラン）。

## 差別化仮説
「栽培全般」ではなく、**実施済み履歴と予定を区別し、同じ科を避けたい理由を年次・区画ごとに表示**。注意年数0〜6年を利用者が設定でき、JSON/CSVで持ち出せる。ヒット可能性・収益性は未検証。

## 機能
18作物・季節・区画登録、作付追加/編集/削除、年別マップ、同科履歴と同季重複の警告、候補地比較、Undo、JSONインポート/エクスポート、CSV、印刷、端末保存、レスポンシブ。外部API・課金・個人情報収集なし。

## 動作とテスト（2026-11-23）
- 完全版 `index.html`：Node.js 単体 22/22合格、固定シード3,000ケース合格。
- Chromium操作：28/28チェック合格（登録・編集・Undo・インポート/エクスポート含む）。
- GitHub版は完全版をgzipにロスレス格納した起動HTML。最新Chrome/Edge/Safari等の `DecompressionStream` 対応ブラウザで動作し、`python unpack.py` で可読HTMLに復元できる。
- 環境制約：直接file://起動がブロックされたため、**Chromiumはインライン実行**。端末保存はメモリスタブで検証。実菜園での農学的精度は未検証。

**注意**：初期「2年」はデモ用の仮設定で、栽培上の推奨値ではない。菌、品種、土壌、環境、土替え等は評価しない。「記録上の注意なし」は安全保証ではない。予定を実施履歴とはみなさない。
