# SpoolRelay — フィラメント割付 (2026-11-27)

## 対象・選定理由
3Dプリンター利用者、学校・メイカースペース、小規模造形工房。使いかけの複数スプールと複数の造形ジョブを、途中交換なしで組み合わせたいという課題を対象とする。国内のRaise3D代理店は長時間造形中の交換が失敗要因となる場合を説明し、MaterialPASSは教育・事業者向けの材料調達を提供。海外のSpoolman（在庫・実績）、Spoolroom（単一造形と在庫の照合）、3D Print Cost Lab（重量・予備量計算）は関連需要の証拠。ただし市場規模・購入意向は未測定。

## 差別化仮説・操作
在庫記録ではなく、計量済みの最大8本・12ジョブを一括最適化する。ブラウザで index.html を開き、タブ区切りでID・適合キー・整数g・優先度等を入力し「割付を計算」。使用可能量=max(0,総重量−空重量−誤差−予備量)。必要量=ceil(見積g×(100+上乗せ率)/100)。適合キーは素材・色・径・銘柄などの互換条件を利用者が定義する。各ジョブは分割不可。部分集合DPで割付件数最大→優先度合計最大→使用本数最小を厳密に求める。単純な先着順割付との比較、未割付理由、JSON保存、印刷を提供。サンプルは単純法2/4件、最適3/4件（優先度合計19）。外部依存なし、通信・登録・永続保存なし。

## 検証・限界
`node test.cjs`: 独立の全列挙との500生成ケースの照合と8固定アサーション合格（最大8本/12件を含む）。`python browser_test.py`: Chromiumで同一HTMLのインライン読み込み、初期表示、JSON実ダウンロード、編集時の無効化、再計算、不正入力、リセット、390px幅、JS例外・HTTP要求なしを確認。環境制限でfile://直接起動のブラウザ試験は未実施。印刷実機・造形成功・材料の物理互換性・実需要は未検証。予備量は安全保証ではない。購入費最小化、途中交換、複数素材造形は対象外。

## 重複確認
会話内の直近制作案、専用ブランチとmainの比較で返された51アプリディレクトリ、filament/spool/フィラメント/3D printer/巻きのコミット検索で明確な重複なし。比較APIの返却範囲外の全ソースは未照合。
