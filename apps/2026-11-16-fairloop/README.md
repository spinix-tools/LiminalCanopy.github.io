# 時差フェア / FAIRLOOP

**2026-11-16 ｜ ブラウザ完結の国際定例会議プランナー（試作MVP）**

海外の同僚・取引先との定例会議で、特定の地域だけが毎週早朝や深夜を引き受けないよう、**参加者ごとの累積負担**を表示しながら開始時刻を提案します。単一の `index.html` を開けば、登録・サーバー・APIキーなしで計算できます。

## ターゲットと選定理由

日本から米国・欧州などの少人数チームに参加するフリーランサー、海外営業、共同研究チーム。日本のテレワーク一般がそのまま国際チーム市場を意味するわけではありませんが、国際会議の時差調整は具体的な反復的課題です。

- 日本側の参考：ザイマックス総研「大都市圏オフィスワーカー調査2025」（2025-11-21）は首都圏の在宅勤務利用を報告。国際会議需要の直接証拠ではありません。<https://soken.xymax.co.jp/report/2511-worker_survey_2025.html>
- 海外含む競合：Google Calendarは2026-09-25にウェブ版の3タイムゾーン表示を発表。<https://workspaceupdates.googleblog.com/2026/09/view-up-to-three-time-zones-in-google-Calendar-on-the-web.html>
- 既存の専用競合：WhenWorks4Uは時差・DST込みの候補推薦とICS、UnisonTimeは食事・休日への配慮、Timemozは負担点と公平ローテーションも提供。**公平な時刻推薦自体は新規性を主張できません。** <https://whenworks4u.com/> / <https://unisontime.com/> / <https://timemoz.com/en/meeting-planner>

## 差別化仮説

日本時間の定例日を固定した運用に絞り、①2〜6人それぞれの勤務時間、②4/6/8週間の**累積負担**と地域間の最大差、③**毎週同じJST時刻に固定する案**との比較を、日本語の1ページにまとめることで、会議の運用者が「最小負担か偏りの少なさか」を説明しやすくなるのではないか。類似サービスがあるため、差別化も事業価値も**未検証の仮説**です。

## 実装済みの機能

- 17地域のIANAタイムゾーン、2〜6人の名前・勤務開始/終了・土日の扱いを設定
- 日本時間の指定日を起点に、毎週同じ曜日の4/6/8回について30分刻みの48候補を走査
- 勤務時間内0点、その他の時間帯2/5/9点、土日（勤務日設定がない場合）+8点、各30分の負担を合計
- **負担最小**と、総負担・人ごとの偏りを折衷する**公平重視**の2モード（後者は幅100のビーム探索による近似であり最適性保証なし）
- 各参加者の現地日付・時刻、会議ごとの負担、期間累積負担の棒グラフ、JST固定案との比較
- 提案をICS（UTC時刻・改行折り畳み）、CSV（数式インジェクション対策付き）で保存、テキストコピー
- ブラウザのlocalStorageへの条件保存を試みる（制限環境では保存なしで利用可能）

## 動かし方

`index.html` をデスクトップまたはスマホのモダンブラウザで開き、参加者の勤務時間と開催日を設定。提案を確認してICS/CSVで書き出します。実行時にネットワーク要求は発生せず、サーバー・APIキー・料金は不要です。ページをGitHub上で表示しただけでは実行されないので、ローカルでHTMLを開くか静的ホスティングに配置してください。

## 対応しないこと・注意

祝日・食事休憩・実カレンダーの空き時間・参加者の同意・シフト勤務・不公平感の主観差は考慮しません。深夜など不適切な候補も提示され得ます。**計算結果は合意済みの予定ではありません。** また日付は常にJSTを起点に固定し、別地域では前日になることがあります。会議日そのものの変更や非同期連絡も検討してください。

既存の別アプリ「ことばのクッション」（断り文句支援）、「まにあう帖」（期限管理）とは問題領域と操作目的が異なります。過去の他のディレクトリは上書きしません。
