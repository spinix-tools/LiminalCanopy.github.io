# 現組 / GENKUMI — フィルム現像バッチ計画 (2026-11-25)

`index.html` をブラウザで開く。インストール・外部通信・アカウント・有料API不要。匿名ロールIDのみで利用できる。

## 対象・市場・選定理由
自家現像者、小規模暗室、写真教室。FilmFocusの2026-08-09公表調査（2025年11–12月、自己選択式、有効1,337件）はラボのみ67%、併用25%、自家現像のみ8%と報告。海外ではCineStillが複数本対応のPatersonタンクを販売。こうした利用・設備は周辺需要の根拠だが、世界市場規模や本ツールへの支払意思は不明。
- 国内: https://www.film-photo.net/articles/film-survey-2025-result
- 海外: https://cinestillfilm.com/collections/paterson/products/paterson-multi-reel-developing-tank-3

## 競合・差別化仮説
- 日本語対応の現像リファレンス: https://35mm.org/ja
- 海外の薬品利用・残容量管理: https://thebostonfilm.com/tools/chemistry-tracker/ 、 https://www.analog.cafe/app/chem-log
- 現像手順・記録: https://apps.apple.com/au/app/developfilm-darkroom-lab/id6749870154
既存機能は時間参照、記録、薬品管理等。本MVPは確認済みの同時処理グループ・占有単位・優先フラグを使い、限られたバッチ回数で優先本数→総本数→最少回数を厳密に最適化する。競合全機能・需要・収益性は未検証。204既存ディレクトリと関連7件のREADME冒頭を確認。露光段取り・露光しらべ等とは用途が異なる（全ソースの重複検査は未実施）。

## 使い方・モデル
最大12本。CSV風の4列（ID,グループ,占有単位,優先0/1）を入力。容量1〜30、最大回数0〜12。部分集合DPで各集合を収容する最少バッチ数を求め、優先本数、総本数、少ない回数の辞書式順に選ぶ。比較は入力順で連続した同グループのみをまとめ、容量超過を飛ばす。推奨・保留・全処理最少回数・CSV・印刷を提供。サンプルでは2回で2本→6本、優先0→2本。架空条件であり、現像品質・薬品節約額ではない。

## 検証
`node test.cjs`：固定10アサーション、独立割当全探索250条件、12本境界に合格。`python browser_test.py`：ChromiumのHTMLインライン実行（file://は環境ポリシーで拒否）、入力変更・再計算・CSV実ダウンロード・不正入力・リセット・390px表示に合格、JS例外/外部HTTP要求0。ブラウザテストはPlaywrightと/usr/bin/chromiumを使用。

## 制限
加算可能な抽象容量モデル。グループの適合性、タンクの実際の混載、薬品量、温度、現像時間、洗浄、作業時間、安全性を判定しない。メーカー指示と実機を確認すること。複数タンクや期限の日時、現像液の寿命は対象外。入力を外部送信・永続保存しない。
