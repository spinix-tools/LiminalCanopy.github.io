# 巻割 / SpoolFit

2026-11-26 MVP。3Dプリンター利用者・小規模工房向けの、途中交換なしの残量配分計画。`index.html` をブラウザで開く。登録・外部API・外部ライブラリ不要。入力は素材グループと重量・任意IDのみで、送信・永続保存なし。

## 市場と仮説
日本： [temoto.app](https://temoto.app/filament-calc/) は重量から残量・費用を計算。[Gyroid](https://apps.apple.com/jp/app/gyroid-3d%E3%83%97%E3%83%AA%E3%83%B3%E3%83%88%E7%AE%A1%E7%90%86/id6805195681) は残量・履歴管理。海外：[Spoolroom](https://spoolroom.app/) はスライスファイルと在庫の照合、[SpoolVault](https://www.spoolvault.com/) は残量・プロジェクト管理、[Prusa SpoolJoin](https://help.prusa3d.com/article/spooljoin-mmu2s_134252) は途中の自動切替を提供。残量不足対策への需要の間接証拠だが、利用者数・検索量・売上は未確認。
差別化仮説：一括の印刷ジョブを、交換なし・互換グループ別に割り当て、先着順との差を示す。競合の全機能は未確認。集客仮説は「フィラメント 余り 使い切り」「leftover filament print planner」。

## 仕様
最大6本・12ジョブ。使用可能g=max(0,総重量−空重量−誤差−残す重量)、必要g=ceil(見積g×(100+上乗せ率)/100)+追加g。1ジョブ1本、完全一致する互換グループのみ。分枝限定で件数→見積gを辞書式最大化。20万ノードを上限に、未証明の場合は暫定案と明示。サンプルは容量50/50/35g、先着順4/5件、最適5/5件（135g）。JSON出力・印刷ボタンあり。CSV風入力は引用符やカンマ入りID非対応、整数g限定。物理的供給、適合性、実際の消費・収益性は未検証。多色同時印刷や途中交換は対象外。
