# 撮りしろ / TORISHIRO — 背景紙と画角の撮影準備室

小物・ハンドメイド作品・ネットショップの商品撮影を、レンズ・被写体・背景紙・室内奥行の**3条件**で同時確認する、完全ローカルの日本語WebアプリMVP。制作日：2026-11-19。

## 実行方法

`index.html` を最新の Chrome / Edge / Firefox / Safari などで開く。`style.css`, `engine.js`, `app.js` を同じフォルダに置く。`npm install` やビルド、ログイン、サーバー、ネット接続、外部API、外部ライブラリ、課金、写真アップロードは不要。計画名は任意で実名の入力は不要、外部通信・トラッキングは実装していない。設定の保存先はブラウザ内の `localStorage` のみ。

## ターゲットと選定理由

- **ターゲット:** 日本のハンドメイド作家、小規模ECの商品撮影担当、レンタルスタジオ利用者。スマホ/カメラを買い換えるより前に、限られた奥行・購入予定の背景紙・手元の焦点距離を机上で検討したい人。
- **国内の周辺需要:** カメラ映像機器工業会（CIPA）は2026年11月2日にデジタルカメラ・交換レンズの**2026年9月**統計を公開（https://www.cipa.jp/j/news/index.html ）。BCN総研が2026年3月13日に公表した記事では、CIPAに基づく**2025年国内向けデジタルカメラ出荷は約99.6万台**（https://ri.bcnretail.com/post/2026031302 ）。これはカメラ供給側の周辺指標であり、**本アプリ需要・支払い意向を示すものではない**。
- **海外の課題と需要の傍証:** Product/studio shooting のため PhotoRobot が被写界深度計算、VT Photo Workplace が撮影距離・室内・背景紙サイズの計算を提供している。競合製品の存在は課題の存在を示唆するが、市場規模の推定はできない。

## 実装機能

- センサー5種、縦/横構図、焦点距離8–500mm、撮影距離、商品幅・高さ・奥行、上下左右の位置ずれ、安全余白、背景紙と離隔、部屋の奥行・カメラ後方余白をリアルタイム編集。
- **3条件**の合否、被写体前面と背景紙面の画角、必要撮影距離、警告理由を計算。正面投影と上面視野のSVGダイアグラムを表示。
- 24–135mmの9種類のレンズを、現在距離の合否＋**距離区間の成立可否**で比較し、ボタンで適用。
- 初期化、端末内自動保存、設定JSONの保存・読み込み（最大50KB／基本的スキーマ検査）、Excel向けBOM付きCSV、SVG図面、ブラウザ印刷。数式インジェクション対策のCSVエスケープ。

### 計算上の定義

画角は直線投影（rectilinear）かつ薄レンズ近似として `FOV幅 = センサー幅 × カメラからの距離 ÷ 焦点距離` を使用。被写体の見切れは `被写体中心距離 − 奥行/2` の保守的な前面距離で判定。背景紙の端が写るかは `被写体中心距離 + 背景紙までの距離` で投影したフレームの幅・高さと背景紙サイズを比較。左右/上下ずれは被写体側のみ考慮。必要室内奥行は `撮影距離 + 商品から背景紙までの離隔 + カメラ後方余白`。3条件の距離区間は見切れによる下限、背景紙と室内奥行による上限の共通部分。**数値は光学・物理の簡易推定であって、安全上の判断や実機撮影を保証しない**。

最短撮影距離、レンズ歪曲・ブリージング、マクロ倍率、レンズの主点、背景紙カーブ、床・スタンド幅、カメラ高さ・照明・反射、画面外での物体干渉、セットの安全固定はモデル外。
