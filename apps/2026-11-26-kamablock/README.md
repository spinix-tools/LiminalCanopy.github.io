# 窯区 / KAMABLOCK

釉薬試験片の区画別割当と基準片比較を行う日本語Web MVP。`index.html` をブラウザで開く（外部依存、通信、アカウント、課金なし）。試験条件を1行ずつ、区画を「名称,容量」で入力し、反復数とシードを指定。印刷した配置IDを試験片に対応させ、焼成後に任意の共通尺度0〜100の評価を入力し、CSV保存する。入力変更・再計算で測定値は消えるため先にCSV保存する。

## 対象・選定理由（2026-11-26調査）
陶芸工房、釉薬開発者、陶芸教室。瀬戸窯業試験場は約15万点の試験片を保有し、2026-07-22の記事で約2万件の試験片データ整備を報告。京都美術工芸大学では200種以上の調合を扱う教育事例がある。海外のGlazyとCeramics Monthlyは窯内の熱仕事の不均一性を説明する。需要の間接指標であり、市場規模・支払意思は未検証。

- 国内: https://lib.aibsc.jp/ceramic/2488/ ; https://www.kyobi.ac.jp/contents/faculty/arts_crafts/22284/
- 海外: https://help.glazy.org/concepts/temperature ; https://ceramicartsnetwork.org/ceramics-monthly/ceramics-monthly-article/techno-file-temp-vs.-heatwork
- 競合: https://help.glazy.org/support （調合・共有）、https://apps.apple.com/be/app/glazimo-glaze-tests/id6816692071 （試験格子・比較）、https://apps.apple.com/jp/app/glaze-test-tiles/id6837682714 （試験片記録・写真比較）。公開機能説明に基づく比較。

## 差別化仮説
記録・調合計算の前段で、区画ごとの基準片を予約し、同一条件の反復を異なる区画に分散する。最大20条件・8区画・各区画21枚、最大160試験片+8基準片。最大流で配置数を厳密最大化し、容量不足なら部分案を明示する。シードは配置順の再現用で、均等な確率の実験計画やペア共起の最適化は保証しない。測定後は同区画の基準との差の平均・範囲・比較数を表示し、未入力は除外。基準片は同一条件で準備する。競合に同等機能がないことは未証明。まず工房5件で設計時間と記録漏れを従来手法と比較する仮説。

## 検証
`node test.cjs`：固定9/9、独立全列挙240/240、容量・反復・基準片制約、最大160試験片、欠測とゼロ、CSV数式対策を確認。`python browser_test.py`：Chromiumで入力、基準差、CSVダウンロード、不足、不正入力、初期化、旧結果無効化、安全な文字表示、390px幅、JS例外・外部HTTP要求0件を確認。管理環境でfile://が禁止されていたためHTMLをインライン読み込み。テストにはNode.js、後者にはPython・Playwright・Chromiumが必要。

区画容量は利用者が安全な配置を確認済みであることを前提とする。物理的配置・熱分布・焼成制御・化学配合・食品接触安全性・統計的有意性は扱わない。実窯・実需要・収益性は未検証。自動保存やCSV再読込は未実装。個人情報を入力する必要はない。
