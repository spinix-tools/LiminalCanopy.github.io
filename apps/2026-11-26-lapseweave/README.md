# 時紡 / LapseWeave
2026-11-26 | 区間別タイムラプス撮影計画。index.html をブラウザで開く。登録・通信・外部API・課金不要。

## 対象・選定理由
風景・建築・自然観察のタイムラプス制作者。国内ではソニーの撮影ガイド（2026-07-30更新）が撮影間隔・回数と電池・カードの準備を扱う。海外では PhotoPills が間隔・動画長・容量計算、USCalc が容量・電池計画を提供。国内のポチカツ道具箱にも同種の計算機がある。これらは課題の実在を示す間接証拠で、利用意向・市場規模・収益性は未検証。

## 差別化仮説
単一区間の計算に対し、複数区間で最短・希望・最長間隔を指定し、完成動画の総フレーム数を厳密に維持して画の密度を配分する。撮影時刻CSVで編集・現場計画に連携。競合の全機能は未調査。既存235ディレクトリ名と写真関連README（rokoshirabe、roko-dandori等）を確認し、長時間露光の校正・時間割とは異なる用途を選択。全ソースの網羅比較は未実施。

## モデル・使い方
最大12区間、総10,000枚。区間長D秒、最短m、希望p、最長M（m≤p≤M）から枚数nの範囲をceil(D/M)〜floor(D/m)とする。総枚数を目標に固定し、容量（1GB=1000MB）・撮影可能枚数を上限にする。目的関数はΣ(n−D/p)^2/(D/p)。下限から限界費用が最小の区間に1枚ずつ加える。分離凸の整数配分なのでこの目的に対し最適（浮動小数誤差を除く）。区間は半開区間、時刻0からD/n間隔で撮影。境界を重複させない。サンプル240枚、24fps、6GB、区間配分53/134/53枚。入力変更後は再計算。CSV・印刷対応。
