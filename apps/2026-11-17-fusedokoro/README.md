# ふせどころ / FUSEDOKORO

**画像をブラウザ内で不透明に黒塗りし、出力したPNGそのものを再検査する日本語Webアプリ。** 2026-11-17 制作。追加課金・外部API・画像送信・ログイン・個人情報収集なし。MIT License。

## ターゲットと選定理由
- SNS投稿者、学校・自治体・小規模組織の広報担当、サポート・QA担当者が、画面キャプチャの個人情報を公開前に手動で伏せる際の利用を想定。
- 2025年の国内SNS利用者が広範に存在すること、個人情報の公開前確認の必要性から、操作の容易さと**出力物の確認**には需要の余地があると仮定。ただし本アプリ固有の有料需要・継続利用意向は未検証。
- 日本の競合：[SeekerLab 画像マスキング](https://tools.seekerlab.jp/image-mask/)、[ramda lab 画像の個人情報を塗りつぶす](https://lab.ramda.io/image-redact/)、[ANYSWEB IMG LAB](https://anysweb.jp/ja/redact-image/) 。海外：[SensHide](https://senshide.com/)、[PrivaCanvas](https://www.privacanvas.com/)、[Popshot](https://www.popshot.app/blur-screenshot)。いずれもブラウザ内のマスキングを提供し、ramda lab は画素・メタデータ検査も実施済み。単なる「ローカルで黒塗り」は独自性とは言えない。
- **差別化仮説**：画像上の余白付き範囲選択 → マスク座標1px調整 → 手動公開前チェック → **出力PNGを再読込して全指定画素と既知メタデータチャンクを検査** → 検証レポートJSON、という監査可能な軽いワークフローを単一画面に集めることで、見た目の加工だけでは不安な利用者が選ぶ可能性がある。競合に同等機能があり、優位性は実利用テストで反証可能。

## 操作と実装機能
1. `index.html` をブラウザで開く（`engine.js` と `app.js` は同じフォルダ）。「サンプルを試す」でも確認可能。
2. PNG/JPEG/WebPを選択、ドロップ、または貼り付け。**画像はネットワーク送信されない**。最大20MB・2,400万画素。
3. マウスまたはタッチで隠したい領域をドラッグ。余白px設定、カテゴリー選択、領域一覧、選択して座標調整、Undo/Redo、全解除、仕上がり表示、100%ズームでの確認に対応。
4. 目視確認2項目をチェックすると「検証してPNGを書き出す」が有効。元画像を白背景に描画してマスクを単色で焼き込み、新規PNGとして出力。
5. **書出PNGを実際に再デコード**し、指定マスク内の各ピクセルがRGBA `[20,30,42,255]` と一致するか全件検査。PNGチャンクから `eXIf` / `tEXt` / `iTXt` / `zTXt` を検査。結果を画面に表示し、検証レポートJSONを保存できる。マスク被覆率は重複領域を1度だけ数える。

## テスト（実行済）
- `node --test engine.test.cjs`: **26/26合格**。矩形の端・逆方向ドラッグ・余白・重複被覆率・画素の完全一致・PNGチャンク検出。
- `python browser_test.py`: **39/39合格**。Chromiumで範囲指定・Undo/Redo・座標編集・UI・画像読込・PNGダウンロード・再読込後の出力画像ピクセル実測・監査JSON・モバイル表示を確認。テストはデスクトップ/モバイル画面画像も作成。
- 制限：実行環境のファイルURLナビゲーションが `ERR_BLOCKED_BY_ADMINISTRATOR` となるため、Chromium試験ではHTMLからCSPメタタグとJS参照を外し、同一の実JSコードを直接挿入して操作試験。**通常のブラウザによるファイル実行・GitHub Pages配信環境での動作確認、CSPの動的挙動、実スマホ操作は未検証**。

## 安全と限界
- 単色に上書きした**指定ピクセルについてのみ**検証できる。見落とした領域、画像外部の情報、文脈からの推測、ブラウザ拡張機能のアクセス等は検知できず、総合的な匿名化・法令適合を保証しない。ぼかし・モザイクは採用しない。
- 書き出しで元画像のEXIF情報をコピーしない。チェック対象はPNGの既知のメタデータチャンクであり、すべての付帯情報を網羅するものではない。元ファイルの削除は行わない。
- 元画像は表示中メモリだけに保持し、localStorage・Cookie・外部通信をアプリコードから行わない。デモは架空のデータ。
