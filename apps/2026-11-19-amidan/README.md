# あみ段 / AMIDAN
袖の増減目カレンダー · 2026-11-19 · MITライセンス

## ターゲット
編み物をする日本語ユーザー（初中級者・手芸教室・作品設計者）。ゲージを測定してから袖など**平編みパーツの左右対称の増減目段**を設計したい人向け。

- 日本：ITmedia（2026-03-08）の取材によると新宿オカダヤ本店の2025年毛糸売上は2023年比約6倍。これは特定店舗の事例で、アプリ需要の証拠ではない。https://www.itmedia.co.jp/business/articles/2603/08/news004.html
- 日本：フェリシモ（2025年夏発表）は特定のかぎ針編みキットの2025年7月受注を前年比444%と報告。https://prtimes.jp/main/html/rd/p/000004010.000012759.html
- 海外：Craft Industry Alliance（2026-05-26）による米国のブランド顧客調査の紹介では回答3,076人で、上級者ほど衣類制作や支出が増える傾向。標本の代表性は限定的。https://craftindustryalliance.org/yarn-industry-consumer-survey-results-2026/

## 実装機能
目・段ゲージ、開始/終了幅、長さ、模様の繰り返し、余り目、奇数/偶数/全段、前後余白。左右各1目の増減を行う段の均等配分、全段の目数計算、予定と現実の幅の差・模様破綻警告、SVG図、進捗カウンター、任意イベント段を完了として記録、端末内自動保存、JSON入出力、全段CSV、印刷。

## 使用方法と制約
index.htmlをダブルクリックしてブラウザで開く（ビルド不要）。外部API・有料サービス・通信・アカウント・個人情報収集は不要。localStorageに設定と進捗のみ保存。JSONは自分の設定が入るので共有前に確認する。
平編みの両端で各1目を増減するモデルのみ対象。目数は指定の模様条件と左右対称性のため丸められ、実寸が希望寸法に一致する保証はない。模様の位置・個々の技法・袖山・伸縮・ゲージ誤差は別途検討。段不足時はエラーを表示。医療用・安全用の用途ではない。

## 検証
Node.js計算単体テスト、Chromium画面操作試験、モバイル幅とファイル出力の確認を行う。実行結果は別途記録。通常環境での直接ファイル起動・印刷実機・実物の編み地との照合は未検証。
