# 本輪 / HONRIN — 本の交換会を「輪」でマッチング

制作日: 2026-11-24（JST） / MIT / 追加API・登録・課金なし

## ターゲットと選定理由
地域のブックスワップ、読書サークル、学校・企業の読書交流会の主催者。**1人1冊持ち寄る対面交換**では、1対1の交換が成立しなくても3〜4人の循環交換なら成立しうる。匿名コードだけで、本の移動先と引渡し確認表を作ることに特化。

## 日本・海外の実例と競合（2026-11-24確認）
- 日本：草津市は2026-09-01更新の公式案内で「本の交換会 in エコライフフェア」を紹介。1人2冊まで交換できる催し。 https://www.city.kusatsu.shiga.jp/kosodate/dokusyo/event/1004honnokoukankai.html
- 日本：POPEYE Webの2025-04-03記事は、2023年開始の「BOOK SWAP MEETING」を全国各地で開催していると説明。 https://popeyemagazine.jp/post-246131/
- 海外：BookSwapは蔵書登録・希望リスト・交換依頼・チャットを提供。 https://www.bookswapapp.com/
- 海外：Second Chapter Book Swapは相互マッチ方式。 https://secondchapterbookswap.com/
- 海外：PaperBackSwapは郵送・クレジット制の本交換サービス。 https://www.paperbackswap.com/

需要の実例ではあるものの、これらの情報から本アプリの潜在ユーザー数・支払意思・収益性は推定できない。

## 差別化仮説（未検証）
会員制・発送・相互マッチ中心の汎用交換サービスと異なり、**会場で匿名コードのみ、最大4人の交換サイクルを厳密最適化し、1枚の引渡し表へ整理する**。1回の催事運営に価値があるのではないか。ただし同等機能を持つ競合が存在する可能性を排除できない。

## MVPの機能
- 最大14人。各人1冊の本タイトルと希望先（第1〜3希望）。追加・削除・編集・Undo・サンプル。
- 2〜4人の循環交換を列挙、参加者が複数の輪で重複しないように**総交換冊数→希望順位合計→グループ数**の優先順でビットマスクDPにより厳密最適化。
- 交換の方向（提供者→受取者）、本のタイトル、希望順位、引渡し確認を表示。計画編集時には古い確認状態を解除。
- 引渡しCSV、JSONバックアップ・復元、localStorage保存、印刷。タイトルはHTMLエスケープ、CSVの式注入対策。
- 外部API、画像、Google Analytics、CDN、外部へのデータ送信なし。

## 起動と復元
リポジトリ内の `index.html` と `payload.js` を同一ディレクトリに置き開く。ブラウザ標準の `DecompressionStream('gzip')` が必要。ソースを直接確認するにはPython 3で `python3 unpack.py` を実行、SHA-256が一致する場合に限り単独で起動できる `standalone.html` を復元する。開発用の編集しやすい原本 `index.html` + `engine.js`、自動テスト・画面画像は同時配布したZIPに収録。
