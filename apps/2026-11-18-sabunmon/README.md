# 差分門 / SABUNMON

**商品マスタCSVを公開・一括取込する前にレビューする、小さなローカルWebアプリ。** 2026-11-18制作。日本語、MITライセンス。

## ターゲット・選定理由
小規模EC運営者、雑貨店の通販担当者、複数の委託先から商品CSVを受け取るスタッフ。価格の桁誤り、在庫0への変化、廃番に見える行の消失を更新前に見つけたい人向け。

日本では経済産業省が**2026-10-21**に公表した調査によると、2025年のBtoC-EC市場は27.6兆円、物販系は約15.8兆円。海外ではEMARKETERが**2025-05-22**の記事で世界の2025年EC売上を約6.419兆米ドルと予測した。**これらは関連市場の規模であり、当アプリの需要・支払意思を直接証明しない。**

## 国内・海外の競合と差別化仮説
- 国内：[KantanTools CSV差分比較](https://kantantools.net/tools/csv-diff/) はブラウザ内でキー列による追加・削除・変更検知とCSV出力を提供。
- 国内：[CSVToolkits](https://csvtoolkits.com/) は文字コード判別・日本語クリーニング・CSV差分を提供。
- 海外：[csvdiff.app](https://www.csvdiff.app/) はキー照合、セル別マージ、差分の解決、エクスポートを既に提供。
- 海外：[DiffResolver](https://www.diffresolver.com/diff-csv/) はキー列対応・空白／大小文字無視とローカル処理を提供。

**仮説：** CSV差分の発見自体は既存技術。差分を「価格変動・在庫切れ・商品消失・値不正」という業務上のレビュー理由に翻訳し、**高リスク変更は自動承認せず、承認した商品だけを反映した更新案CSVを作れること**を小規模EC向けに一画面で統合すれば、汎用CSV比較より更新事故の見逃しを減らせる可能性がある。実利用者による比較・需要・収益性は未検証。

## 完成した機能
- CSVファイル（UTF-8 / Shift_JIS）読込と直接貼り付け、架空の商品デモ。
- 一意の商品コード（SKU）で順序が異なる行を突合。全角数値・円記号・3桁区切りの数値を診断時のみ正規化。**商品コードの先頭0は保持**。空・重複キー、重複見出し、列不一致、壊れた引用符を拒否。
- 追加・削除・変更の検出。価格の閾値以上の増減、在庫0・半減超、価格0、新規登録、数値不正に注意表示。新しい価格・在庫の形式が不正なら変更承認を禁止。
- SKU・商品名検索、分類別フィルター、個別承認、重大リスク以外の一括承認。
- 承認済みの変更だけを採用し未承認分を旧値に戻した **更新案CSV**、変更履歴CSV、変更前バックアップCSVをローカルダウンロード。
- CSSによるスマホ対応。すべてブラウザ内で動作しログイン・外部通信・分析SDK・保存APIなし。CSVの内容や承認状態はlocalStorageにも保存しない。

## 実行方法
同じフォルダの `index.html` / `style.css` / `engine.js` / `app.js` を置き、`index.html` を開く。初期画面には架空のデモCSVが入り、すぐ試せる。実データ利用時は双方のCSVを貼り付けるかファイル選択 → 商品コード・価格・在庫列を確認 → 比較 → 個別承認 → 更新案CSVを保存。

## 制限と安全上の注意
- CSVは**カンマ区切り・ヘッダー付き・UTF-8またはShift_JIS**、1ファイル最大3MB、最大1万データ行。TSV、Excel (.xlsx)、異なる列名の自動マッピング、独自文字コード自動判別は未対応。CSVの列名集合は同一である必要があり、列順は変更可。
- 確認・承認は**商品行単位**。変更された1セルだけを承認する機能ではない。CSVの差分以外（仕入価格、税率、ECプラットフォーム固有の制約）については検証しない。変更理由の正しさ、公開・取込結果、データ品質や収益への効果を保証しない。
- CSVを取り込む**外部システムは自動操作しない**。生成したCSVをそのまま適用せず、バックアップと取込前プレビューを確認する。フォーミュラを含むセルは値の意味を保つため更新案では書き換えず、**Excelなどで開く際はCSV数式注入に注意**。監査レポートでは数式起動を避けるため値の先頭に引用符を付加する。
- 個人情報・秘密情報を扱う意図のないツールであり、ユーザー情報を外部へ送信・保存しない。ユーザー入力を含むダウンロードファイルは各自で保管する。
