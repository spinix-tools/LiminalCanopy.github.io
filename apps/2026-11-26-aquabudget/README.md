# 水配 / AquaBudget
2026-11-26 MVP — 複数水槽に共通の交換水を配分するローカルWebアプリ。

## 対象・選定理由
複数の水槽を管理するアクアリウム愛好家・小規模店舗。交換水の準備量が限られ、各水槽にどれだけ配分できるか比較したい場面を想定。日本語の水換え計算機と海外の換水計画ツールの存在を需要の間接指標とした（検索量・売上・実利用者数は未調査）。

## 競合と差別化仮説（2026-11-26 閲覧）
- 日本語: Aqua Navi https://aqua-navi.jp/Aqua_Navi/tools/ 、AquaLab https://tools.goat-lab.net/ja/aqualab/ — 水量・希釈計算。
- 海外: AquariumCalcs https://aquariumcalcs.com/water-chemistry/nitrate-water-change-calculator/ 、AquariumHQ https://aquariumhq.app/tools/water-change-schedule-calculator — 単一水槽の必要換水量・定常濃度計算。
- 本作は同じ交換水を使える最大12水槽の総在庫・各換水上限を同時に扱う。目標達成数最大化、超過質量最小化、使用水量最小化の辞書式目的を動的計画法で厳密に解く（離散刻み、最大300単位）。先着順と比較、CSV/JSON出力。市場全体での独自性・収益性は未確認。
- 重複調査: 直近の会話履歴、mainとの比較で取得した51アプリディレクトリ、aquarium / 換水 / 硝酸塩 / 水槽 のコミット検索（各0件）。全既存ソースの照合ではない。

## 起動・検証
`index.html` をブラウザで開く。外部依存・API・登録・データ送信なし。Node.js 22で `node test.cjs`（固定17アサーション、独立全列挙500ケース、最大規模2アサーションが合格）。`python browser_test.py`（Python PlaywrightとChromiumが必要）で同一HTMLのインライン読み込み、CSV/JSON実ダウンロード、編集、追加削除、不正入力、文字列安全表示、390px幅、JS例外・HTTP要求0件を確認。環境ポリシーで file:// の直接読み込みは検証不可。印刷実機・他ブラウザ未検証。

## 前提・限界
全水槽で同一の適合する交換水を用い、排水後の補水1回・完全混合、濃度一定、体積整数L・濃度0.1mg/L刻みを仮定。超過質量は目標濃度を上回る分の合計で、危険度ではない。目標達成数優先なので高濃度の水槽が後回しになることもある。飼育上の安全性・優先順位を判断するアプリではない。水温、塩素、pH、硬度、塩分、アンモニア、測定誤差、生体・実水槽での効果は未検証。目標・上限は別途確認すること。
