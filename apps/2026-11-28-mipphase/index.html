TEXTURE QA / LOCAL TOOL

MipPhase / アトラス混色監査

同じ間隔でも、縮小格子との位置関係で混色リスクは変わる。配置を変える前に確認。

01 — 入力

独自JSONまたはTexturePacker JSON（hash / array）。座標は左上原点、格納矩形。2のべき乗のアトラスのみ。

最大100矩形・4096×4096。画素の色ではなく、別スプライトの元画素がサンプルに寄与し得る範囲を判定。

02 — 結果

監査待ち

青緑：元の矩形 / 橙：混色候補の矩形 / 破線：選択Mipの読取元範囲（最初の候補）

03 — 格子位相の比較

モデル：2×2ボックス縮小、CLAMP_TO_EDGE、UV矩形は半開区間。Nearest / Bilinear単一Mip。圧縮、透過色、押し出し、異方性、トライリニア、実GPU描画は未検査。混色候補ゼロは画質保証ではありません。
