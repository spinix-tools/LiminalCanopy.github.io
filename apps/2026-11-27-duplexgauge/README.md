# DuplexGauge / 表裏位置合わせ

## 対象・選定理由
小規模印刷、ZINE、教材・カード制作。両面の位置ずれを定規で測って、単純な移動で足りるか、回転・倍率・せん断を含む変形が必要かを比較する。実需要・収益性は未検証。

## 市場調査（2026-11-27）
- 日本: [キヤノン 印字位置調整](https://oip.manual.canon/USRMA-0803-zz-SS-jaJP/contents/SS252_maintenance_161inziitiwochouseisuru.html)、[リコー 印刷位置調整 FAQ](https://faq.ricoh.jp/app/answers/detail/a_id/2224/p/1822)。メーカーが表裏の位置調整を案内している。
- 海外: [PrintableTestPage](https://printabletestpage.com/duplex-test-page/) は印刷用グリッド・見当確認、[PrintTest.org](https://printtest.org/duplex-printer-test-page/) は透過確認、[ManualDuplex](https://manualduplex.com/test-page/) は給紙方向の試験。
- 差別化仮説: 4点×2枚の測定から無補正・平行移動・アフィン変形を比較し、別の未補正用紙でも予測許容差を満たす最も単純なモデルを選ぶ。逆変換した裏面SVGを提供。競合の全機能・同等機能の不存在は未確認。直近のRisoTrapは二色版の重ね代、今回は表裏の位置合わせ。専用ブランチ比較300ファイル（51ディレクトリ）と関連5語のコミット検索では明確な重複なし。全既存ソース未照合。

## 利用法
index.htmlをブラウザーで開く。A4/Letter/A5、長辺/短辺を選び、表・裏SVGを同条件で2枚に原寸印刷。表正立の透過視点で裏−表のdx,dy（右・下が正）をA/B/C/D順に測り入力。許容差を設定し計算。裏面用逆変換行列、補正テストSVG、JSONを出力。外部通信なし。

## 計算と限界
測定1の4点を最小二乗でアフィン近似。補正予測残差は測定差−モデルの推定差。測定2は独立した未補正の紙で、実補正後の測定ではない。表の位置を基準とし、相対変形が再現する近似を仮定。双方の最大残差が許容値以内なら単純な順で選択、失敗時は最小の最大残差を持つ逆変換可能な候補。裏面座標へ反転共役。物理的再現性・印刷精度・印刷可能領域・ドライバー適合・実機印刷は未検証。原稿を自動変換する機能はなく、行列とテストSVGのみ。必ず再試し刷りする。

## テスト
- `node test.cjs`: 300個の合成アフィン変換の復元・両とじ方向の逆変換、固定9チェック合格。
- `python browser_test.py`: Chromiumで初期計算、SVG3種・JSONのダウンロード、入力無効化、エラー、リセット、とじ変更、390px幅、JSエラー/HTTP要求0件を確認。同一HTMLをインライン読み込み（file:// は環境で禁止）。
- サンプル測定2最大差: 補正なし2.102 mm、移動0.762 mm、アフィン0.141 mm（予測）。許容0.3 mmでアフィン推奨。
