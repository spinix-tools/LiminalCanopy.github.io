# BlendGrid / 配合目盛りラボ

陶芸工房・教室・材料の試験配合を行う制作者向け。index.html をブラウザで開く（外部通信・登録・依存ライブラリなし）。2材料の直線、3材料の三角配合を選択し、分割数・試料質量・秤の刻み・許容誤差を入力する。全試料の計量表、重複、材料消失、最大誤差、現在量以上の最小合格質量を表示し、CSV保存・印刷ができる。

## 市場・差別化（2026-11-27）
- 日本：陶芸シンリュウは粉末釉薬のテスト焼成を案内 https://www.shinryushop.jp/glaze/powder.html 。高橋粘土店は多種の基礎釉を販売 https://clayart.co.jp/otoriyose_yuyaku.html 。専門工房の反復試験という用途を想定。
- 海外：Glazyの試験調合ガイド https://help.glazy.org/testing/mixing-tests 、ブレンド機能 https://help.glazy.org/support 、Karen's Kiln https://karenkiln.com/ は配合・試験管理の関連競合。
- 仮説：化学組成や焼成色の予測ではなく、秤の表示刻みにより理想配合が失われる問題を、全試料の同一質量を保ちながら検査・修正する。日本語の小規模工房向け入口から国際展開を検討。実需要、競合の同等機能の有無、収益性は未検証。
- 重複確認：直近の会話履歴、専用ブランチの比較で得られた51ディレクトリ、glaze/釉薬/blend/陶芸のコミット検索（各0件）。全既存コードは未確認。

## 計算と制限
整数目盛りで最大剰余法を用い、各試料の総質量を固定し絶対配分誤差の和を最小化する。同率はA/B/C順。合格条件は最大成分誤差が許容内、正の理想成分の消失なし、全試料が異なる配合。現在量から分割数-1目盛り先まで順に探索（分割数の倍数で理想比を厳密表現可能）。この決定的丸め方式での最小合格量であり、他の丸め方式は探索しない。最大91試料、10000目盛り。実際の秤の精度・材料の適合性・化学・焼成・食品接触安全性は評価しない。架空サンプルの数値は実材料の推奨配合ではない。
