# 指替 / YUBIGAE — 多用途キーマップ交換ラボ
2026-11-24制作。`index.html`をブラウザで開く。外部ライブラリ、サーバー、アカウント不要。

## 対象・選定理由
自作キーボード・配列設計愛好者、日英両言語を使う開発者。2026-09-23のTOKYO KEYBOARD EXPOには80以上のブランドが参加（[AKIBA PC Hotline! 9/28](https://akiba-pc.watch.impress.co.jp/docs/news/news/2143484.html)）。海外にも継続的な[キーボード交流イベント](https://kbd.news/meetup/switch/)が存在する。これらは関心層の傍証で、製品需要・支払意思ではない。

## 競合・差別化仮説
国内：[KeyFlow Analyzer](https://keyflow.koyasi777.com/)、[KeyMap-Tool](https://keymap-tool.com/)は配列・運指分析。海外：[Oxeylyzer](https://github.com/o-x-e-y/oxeylyzer)は分析・比較・固定キー付き生成、[Kühlmak](https://github.com/fxkuehl/kuehlmak)は多目的最適化。固定・最適化自体は既存。指替は日英・コードの複数コーパスに対し、各用途の許容悪化を設定し、1交換だけの候補を最悪改善または平均改善順に比較する小さな移行支援ツール。独占的新規性は未確認。既存195ディレクトリ名・関連候補7 README冒頭を確認（全ソース未比較）。

## 操作・モデル
3つの英字サンプル、現在の26文字配列、固定キー、許容悪化率、順位基準を設定し計算。上位30件を表示、適合案を適用し再計算・Undo・全件CSV出力。英字以外は隣接を切る。コストは1打鍵の位置・指コストと隣接の加算を英字数で割る。各用途等重み。1交換を最大325通り全探索し、各用途の改善率が許容悪化の下限以上の候補を優先。複数交換全体の最適性、実際の速度・疲労・健康、IME・記号・修飾キーは対象外。外部送信・永続保存・キー監視なし。秘密や個人情報を含まない例文を使用すること。

## テスト結果
- `node test.cjs`：固定アサーション、独立逐次モデル200件、20条件の全4,620候補の値・適合・順位照合に合格。
- `python browser_test.py`：Chromium（インラインHTML、file://は環境でブロック）で交換・Undo・CSV（232行）・不正配列・全固定・390px幅を確認。JS例外・外部HTTP要求0件。PlaywrightとChromiumは既存環境を利用。
- 初期サンプル：231候補、68適合。A↔K、ローマ字+2.60%、英語+2.42%、コード+1.57%、平均+2.20%。モデル上の改善であり実測ではない。
- 実利用者の評価・収益性は未検証。次は個人情報を収集せず、公開の合成サンプルで比較ニーズを検証する。
