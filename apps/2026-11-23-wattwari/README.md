# ワット割 / WATTWARI ⚡

**2026-11-23 / 小規模イベントの同時使用電力・時間帯別の計画MVP**

## ターゲットと需要仮説
学園祭・自治会・地域イベントの事務担当者。機器ごとの稼働時間がずれるため、総定格Wだけでは「何時にどの仮の系統が混むのか」が伝わらない、という仮説を検証する。

日本のNITEは2025-08-12、タップ・コンセントの表示定格を超えないことを注意喚起しています（[NITE](https://www.nite.go.jp/jiko/chuikanki/mailmagazin/2025fy/vol482_250812.html)）。これは当アプリの規格適合を証明しません。

近接競合：国内の[SS.Sound 電源容量シミュレーター](https://ss-sound.jp/power-simulator.html)は合計W・機材割当の概算が可能。海外の[PowerSense](https://squaresmile.de/powersense)や[LVA Power Planner](https://www.lvapowerplanner.com/)は本格的なイベント向け電源計画を提供します（2026-11-23調査）。

**差別化仮説：** 30分刻みの時間×仮の系統ヒートマップを、登録不要で現場前の打ち合わせ用に提供する。実需要・課金意向・予測精度は未確認。

## GitHub版で操作可能な機能
- 1～8系統（名称・定格W）、最大48機器（定格W・台数・開始終了・割当・固定）を登録
- 各系統の30分ごとの同時W・定格超過・80%注意目安・未割当を表示
- 固定機器を維持した貪欲な暫定自動割当。定格を超える候補は未割当へ
- JSONの書出・読込、CSV出力、印刷、ブラウザ内保存、サンプル初期化
- 単一HTML、外部API・ライブラリ不要、個人情報送信・追加課金なし

## 重要な制限
このディレクトリの `index.html` は軽量で操作可能な実装です。ZIP配布の完全版とは別コードで、完全版の「系統現地確認フラグ・メモ付き管理」など一部機能はGitHub版では簡略化されています。完全版のNode.js単体テスト **18/18**（ランダム700条件）、Chromium操作テスト **29/29** は**GitHub版へのテスト結果ではありません**。GitHub版の実ブラウザ起動・動作は未検証です。

デモの定格は架空値。回路独立性、上流共用、コード・タップの容量、起動電流、力率、保護装置、水濡れ、配線工事の安全性は判定しません。表示が定格内でも使用の安全性・法令適合は保証せず、会場管理者・有資格者の最終確認が必要です。

**非重複:** これまでのイベント進行遅延修正やリユース食器在庫と異なる、電気負荷の時間別配分が対象です。
