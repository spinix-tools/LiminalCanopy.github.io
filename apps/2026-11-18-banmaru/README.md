# ばんまる / BANMARU — 偏りを見せる当番表

制作日: 2026-11-18。日本語・登録不要・端末内完結の当番ローテーションMVP。

## ターゲットと選定理由
PTAの見守り当番、自治会の清掃、少年スポーツ・地域イベントのボランティア調整担当。名古屋市の2025-12-19公表のPTA調査では「参加しやすいこと」を求める回答が41.6%、役員就任理由に「仕方なく」が32.5%含まれる。全国PTA連絡協議会が2026-08-30公表の2026年度調査では「役員・委員のなり手不足」が65.9%。**これは関連する運営課題の証拠であり、本アプリへの有料需要を証明しない。**

## 日本・海外の競合と差別化仮説
- 日本: [tohban](https://tohban.net/) — 回答収集、過去実績を含む自動割当。[Toban-maker](https://www.toban-maker.jp/) — 不可日・連続当番回避、通知。[toban.app](https://toban.app/) — 無料・登録不要・印刷にも対応。
- 海外: [YourVolunteers](https://yourvolunteers.com/) — クラウドで希望・実績・競合管理。[Volunteer Shift Scheduler](https://marisstella.app/volunteer-shift-scheduler/) — ブラウザ内・登録不要で公平な割当や不足検出。**オフライン／登録不要だけでは新規性は弱い。**
- 仮説: **過去回数・役割制約・固定枠を守る当番割当と、「1人欠席」時の不足増分の比較を同じ画面で即時に行い、協議の前に根拠を見せる**ことが、小規模団体の意思決定で価値になる。利用者調査による検証は未実施。

## 動作・機能
ZIPを解凍し、`index.html`をChrome等で開く（依存パッケージ、通信、サーバ不要）。サンプルから開始可能。

参加者（匿名ID）、対応役割（`*`ですべて）、不可日、過去担当回数、今回上限、当番日・人数・固定IDを編集できる。自動計算は担当不可日、役割、同日重複、最小間隔、上限、固定を**必須制約**として守り、満たせない担当は未充足で明示。累計担当回数のばらつきを可視化し、1人の欠席時に不足枠がどう増えるか試算する。設定JSONの保存/読込、BOM付きCSV出力、印刷、ブラウザのlocalStorage保存に対応。CSV式インジェクション対策の先頭文字エスケープを実装。

**アルゴリズム:** 制約の強い枠を優先する貪欲法をシード変更で最大160回探索し、まず充足数、その次に累計担当回数の分散で候補を選択。最適化の完全性は保証しない。固定担当が欠席対象の場合は試算を停止し、固定解除を要求する。手動での編集後は再計算が必要。

## プライバシー・注意
個人情報を外部送信しない・API課金なし。端末内には入力内容を保存するため共用端末で実名を入れないことを推奨。公開CSV/JSONに実名を含めないこと。自動割当は本人同意、安全、保護者の負担、施設ルールなどを代替しない。
