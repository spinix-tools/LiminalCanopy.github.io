# 押し戻し / OSHIMODOSHI
小規模舞台・学園祭・地域イベント向け、固定の終演時刻を守るための**根拠のある時間回復シミュレーター**。このリポジトリには軽量な起動用HTMLとREADMEを収録。編集可能な完全版ソース・テストと画面画像は成果物ZIPで配布。

## ターゲット・選定理由
小規模イベントの司会、舞台進行、学園祭や地域ステージの担当者。遅れが生じても終演を守りたい場面がある。日本のイベント消費規模推計について[JACEの2025年版報告書（2026年6月発行）](https://www.jace.or.jp/activity/publications/)が存在するが、当アプリの市場規模・有料需要は未検証。

## 競合（2026-11-22時点）
国内：[GIGDECK](https://gigdeck.app/)（タイムテーブル・LIVE表示）、[TaiSuke](https://www.tai-suke.com/)（進行共有）、[eventio](https://www.eventio.pro/)（制作業務全般）。海外：[LASSO Rundown](https://www.lasso.io/rundown/)（複数端末同期・クルー連携）、[TimedFlow](https://www.timedflow.com/ja)（ステージタイマー・共有）。

## 差別化仮説
作表や同期より**遅延発生時の復旧判断**に特化。「固定枠」「各演目の最短尺」「短縮優先度」を守って削る量を提案し、回復不能なら残る超過時間を表示。優先度は先に短縮→通常→最後の順に、同優先度は元順に削る決定的な貪欲法で、最適公平配分ではない。

## 機能
最大40演目の編集・順序変更、時刻表、遅延シミュレーション、短縮案の採用・Undo、本番タイマー・実績ログ、CSV/JSON出力、JSON復元、印刷、端末保存。登録・外部API・課金不要。

## テスト（完全版ソース）
`node engine.test.cjs`：21/21合格（うち固定シードのランダム検査1,200ケース）。
`python browser_test.py`：Chromiumの33/33操作チェック合格。JavaScript例外・外部HTTP要求0。管理環境の制約でブラウザテストはHTMLのインライン挿入とlocalStorageメモリ模擬で実施。通常のfile://起動・永続保存・実業務適合は未検証。

## GitHubでの実装
`index.html` は検証済み完全版HTMLをgzip化して埋め込み、ブラウザ内で復元する**同一アプリの無通信ブートストラップ**（現代的な`DecompressionStream`対応ブラウザが必要）。完全版の編集可能な元コードとテストはZIPに同梱。アプリ本体は外部から読み込まず、広告・トラッキング・外部通信なし。
