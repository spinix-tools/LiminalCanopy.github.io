# 香盤つなぎ / KOBAN TSUNAGI 🎬

**2026-11-22 / 撮影順・拘束時間チェッカー。** 小規模な映像制作者、学校の映像班、地域の撮影サークル向け。

## 対象・選定理由・競合

- **日本**：矢野経済研究所の2026-10-02発表は、2025年度の動画コンテンツ関連主要5市場合計を **1兆1,474億円** と推計。動画制作サービスが牽引。ただし「香盤作成アプリの市場規模」ではない。[矢野経済研究所](https://www.yano.co.jp/press-release/show/press_id/4196)
- **日本の競合**：[CineOps](https://cine-ops.com/) は脚本PDF解析や香盤表・配車表などの資料作成に対応。
- **海外の競合**：[StudioBinder](https://www.studiobinder.com/film-scheduling-software/) はstripboard・撮影順や所要時間の編集、[Yamdu](https://support.yamdu.com/en/articles/58206-import-movie-magic-schedules-to-yamdu) は既存の撮影スケジュール取込を提供。関連市場は既に競争的。海外の規模・支払意思は未検証。

**差別化仮説**：プロダクション全体管理よりも、**短い単日撮影**における「出演者の到着・退出可能時間 × ロケ間移動 × 昼休憩」を局所的に診断し、登録や有料APIを使わずに並び替えを試せる。需要や収益性は仮説段階。

従来回の電力・栽培・ラベル・字幕・照度・音声・アクセシブルグラフ・手芸・釣銭・フォーム分岐とは別分野。

## 動くMVP

- 単日撮影の開始・終了・休憩・移動時間を設定
- 出演者の役コード・拘束可能時間、シーンの所要時間・ロケ地・必要な役コードを編集
- 移動・出演待ち・休憩を含む撮影タイムライン、出演時間違反・終了超過・休憩警告
- シーンの上下移動、改善候補の局所探索、元に戻す
- JSON読込・保存、CSV出力、印刷、ブラウザ内保存
- 外部スクリプト、外部API、トラッキング、ユーザー登録なし。実名入力不要

index.html をブラウザで開いて使用。すべてクライアント内で計算します。

## 検証結果と境界

**配布用マルチファイル版（別実装）**では、Node.js単体テスト **20/20**、固定シードのランダム500条件、Chromium操作 **34/34** が合格。初期サンプルは並べ替えで出演時間違反 3→0件、移動 5→2回、待機 55→0分。例外・外部HTTP通信は0件。実行環境がローカルURLへのアクセスを禁止したため、ブラウザ操作は同一ソースをインライン展開し、端末保存はメモリで代替して検証。

**このGitHub版は独立した軽量単一HTML版**です。保存後にソース再取得・JavaScript構文検査を行いましたが、上記20件・34件のテスト対象とは異なり、実ブラウザ操作・永続保存は未検証です。最適化はヒューリスティック（最適解保証なし）。運用上の安全、移動所要時間、労働法令の遵守を保証しません。
