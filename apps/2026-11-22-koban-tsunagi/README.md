# 香盤つなぎ / KOBAN TSUNAGI

**撮影順を見直すためのローカル完結型ミニ香盤チェックアプリ**（2026-11-22）。小規模な映像制作チーム、学校・地域の撮影活動、フリーランスの制作者向け。

## なぜ選んだか・市場と競合（調査日: 2026-11-22）

- **国内需要の間接指標**：矢野経済研究所の2026年10月2日付公表では、2025年度の動画コンテンツビジネス主要5市場合計を1兆1,474億円と推計し、動画制作サービス市場が成長を牽引。ただし**香盤ツールの市場規模や売上見込みを直接表す数字ではない**。[出典](https://www.yano.co.jp/press-release/show/press_id/4196)
- **日本の競合**：CineOpsは脚本PDF解析・香盤表・配車表など11種のプリプロ資料の生成をうたう。既存ツールの機能は強く、撮影管理全体で競うのは難しい。[公式](https://cine-ops.com/)
- **海外の競合・ニーズの存在**：StudioBinderはstripboard、撮影順変更、時間推定、レポート出力に対応し、YamduはMovie Magicの撮影スケジュール取込に対応。国際的にも撮影段取りツールの需要と競争があるが、**海外の市場規模・支払意思は今回未調査**。[StudioBinder](https://www.studiobinder.com/film-scheduling-software/) / [Yamdu](https://support.yamdu.com/en/articles/58206-import-movie-magic-schedules-to-yamdu)

**差別化仮説**：複雑な脚本解析やプロダクション管理を省き、「出演者の到着・退出可能時間 × ロケ移動 × 昼休憩」の衝突を1画面で可視化し、並べ替え候補を**外部通信・ユーザー登録・AI課金なし**で比較できる。小規模ワンデー撮影の直前チェックに絞る。需要と収益性は未検証。

過去の電源・栽培・ラベル・字幕・照射・音声ループ・アクセシブルグラフ・刺し子・釣銭・フォーム分岐とは異なる、**映像制作の時間割／拘束条件最適化**を対象とする。

## 機能

- シーン（最大40件）・ロケ地・所要分数・必要出演者の登録と順序変更
- 出演者（最大20件）の拘束可能時間、開始・終了・昼休憩・移動分数の設定
- 移動、出演待機、昼休憩を自動挿入するタイムラインと出演時間違反・終了超過・休憩警告
- 幅を制限した決定的ビーム探索で並べ替え候補を評価。**元より悪い案は採用しない**。前後比較とUndo
- ローカル保存（`localStorage`）、JSON読込／保存、CSV（BOM付き）書き出し、印刷
- 初期デモを内蔵。アカウント・外部ライブラリ・外部API・トラッキングなし

## 起動とテスト

`index.html` をブラウザで開く（`engine.js` と `app.js` と `style.css` を同じフォルダに置く）。ネット接続不要。

```sh
node --test engine.test.cjs
python browser_test.py
```

テスト実行時：**Node.jsの単体テスト20件合格**（うち1件でランダムな500条件を検証）。**Chromium操作チェック34件合格**。編集・順序変更・最適化・Undo・ダウンロード・JSON復元・XSS入力・モバイル幅などを確認し、JS例外と外部HTTP通信は0件。初期デモの探索では出演時間違反3→0件、ロケ移動5→2回、待機55→0分の候補を生成。計測ファイル `node-test-output.log` / `browser-test-output.log` に結果あり。

**検証上の制約**：管理ブラウザでは`file://`ナビゲーションが管理者ポリシーによりブロックされたため、ブラウザ操作テストは**同一HTML・CSS・JSをインラインに展開**して実行し、`localStorage`はメモリ実装で代替した。実際のファイル直開き・長期保存・本番撮影への適合性は未検証。探索はヒューリスティックで最適解や合法な拘束時間を保証しない。移動はロケ間で一律、休憩はシーン間のみ。キャストの出演時刻は単一ウィンドウ、複数日撮影や設備の二重使用は未対応。

## データとライセンス

データは端末のブラウザ内に保持し、JSON/CSVは利用者の端末へダウンロード。実名を入力する必要はなく、役名・記号の利用を推奨。**個人情報や秘密情報のサーバー収集を行わない**（ただし共有端末ではローカル保存データに注意）。MITライセンス。
