# 継ぎ音 / TSUGION

2026-11-21制作。ゲームBGM・環境音のループ開始／終了を比較・試聴し、16-bit PCM WAVと診断CSVに書き出す無料Webアプリ。ターゲットは日本の小規模インディーゲーム開発者・サウンド制作者。ファイルはサーバーへアップロードせず、ブラウザ内で処理。外部API・個人情報の収集・有料サービスなし。

## 日本・海外の調査と選定理由
JETROの2026年4月20日付報告によればTOKYO INDIE GAMES SUMMIT 2026には180超の出展タイトルと延べ12,978人の来場があった（これを本アプリの潜在需要数と解釈しない）。
https://www.jetro.go.jp/biznews/2026/04/1e0bc625a3fa33e1.html

国内のOtomusu（https://otomusu.com/en/tools/bgm-loop/）も音声範囲・クロスフェード・試聴を提供。海外のMubLoop（https://mubloop.com/）はゼロ交差やフェード、Audjust（https://www.audjust.com/tools/audio-loop-creator）は自動探索を提供。基本のループ作成は既存機能であり、独自性は未確定。

## 差別化仮説
日本語の画面で元の振幅段差・勾配差・RMS差、候補5件、補正後の段差・出力尺を並べ、診断結果をCSV保存できる監査ワークフロー。市場反応・収益性は未検証。

## 使い方
GitHubの index.html を単体で開く。デモ音・音声ファイル読み込み → 開始・終了・フェードを調整 → 候補探索 → 試聴 → WAV・CSV出力。音声30MB/90秒/2ch以下、読込形式はブラウザ依存。線形クロスフェードは末尾を冒頭に重ね、出力尺がフェード長だけ短くなる。クリック兆候を数値化するのみで、リズムや残響の自然さは保証しない。
