# 電源かさね / DENGEN KASANE

**小規模マルシェ・キッチンカー・学園祭・展示会ブースのための「時間帯別の電源負荷」事前計画Webアプリ**。依存ライブラリなし・完全ローカル。`index.html`をブラウザで開くだけ（`engine.js`, `app.js`, `style.css`を同一フォルダに配置）。サーバー・有料API・アカウント・個人情報収集なし。

## なぜこの案を選んだか / ターゲット

- **日本の具体的ニーズ**：橋本市「紀の川橋本SUMMERBALL2026」出店募集（2026-06-16更新）は、テントの合計2,500W・単体1,300W、キッチンカー単体1,500Wという上限と、超過による周囲の電源停止への注意を明記している。イベントごとに上限と機器の使用時間を擦り合わせる現実的な問題がある。 https://www.city.hashimoto.lg.jp/hashimototaikan/asobu/ibennto/summerball/2026/shuttenboshuu.html
- **国内の周辺競合**：SS.Sound「必要電源容量シミュレーター」は機器の合算・1.5倍の余裕・回路振分けに対応。 https://ss-sound.jp/power-simulator.html ／ 日本のiOSアプリ「デンゲンバン」は手持ち機器と上限の照合や回路分散を扱う。 https://apps.apple.com/jp/app/id6799537954
- **海外競合**：PowerSenseは音響・照明機器の電源系統バランスとケーブル検査、NADJ Power Plannerは機材・発電機・配電の計画を扱う。 https://squaresmile.de/powersense ／ https://www.nadj.org.uk/power-planner/
- **差別化仮説**：既存の「機器リストの合計W」や回路配置案に加え、**15分刻みの稼働重なり**を可視化。一定時間だけ使うポット等の作業開始時刻を±指定時間内でずらし、機器配線を変更せずに負荷超過枠を減らす候補を提示する。登録不要・日本語・CSV/JSON/相談メモ付き。市場規模、実需要、競合優位、収益性は未検証。

## MVPの実装

- 会場使用時間（同日内）、全体供給上限、計画上の予備率、1〜8系統の上限の編集
- 80件までの機器名、系統、台数、通常W、起動時想定W、稼働開始・終了、時刻移動可否と±許容幅の編集
- 15分刻み負荷表から、全体系統それぞれの上限超過、最大同時負荷、使用電力量（仮定）とSVGグラフを計算
- 柔軟機器の開始時刻を変える局所探索（**最適保証なし**）。固定機器は動かさず、移動幅・稼働時間は維持。変更前後の超過枠と移動案を確認して反映
- JSON保存／復元、Excel向けUTF-8 BOM付きCSV、主催者相談メモのコピー、印刷、端末内自動保存。外部通信・トラッキングなし

## 計算モデルと注意

稼働区間を `[開始, 終了)` とし、15分枠に通常消費電力×台数を積算。最初の枠のみ `max(通常W, 起動時想定W)×台数` とする**保守的な簡略モデル**。時刻シフトは超過枠数→超過ワット量等を順に減らすヒューリスティック。kWh値は枠内電力一定という仮定であり、測定値・料金予測ではない。**瞬間的な突入電流、負荷変動、電源力率・電圧降下、配線定格、分岐・漏電対策、複数回の再起動、地域規則、接地・防水は設計／判定対象外。**「超過なし」は安全確認・工事許可・会場承認を意味しない。主催者、機器メーカー、電気工事の有資格者に必ず確認。
