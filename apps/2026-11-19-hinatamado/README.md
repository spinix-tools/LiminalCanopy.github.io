# ひなた窓 / HINATA MADO ☀️

窓ぎわ・ベランダの鉢への晴天時の直射時間を、窓枠・庇・前方の壁・鉢の位置から概算する、無料・通信不要のWebアプリ。

**対象**：マンションの窓ぎわで植物を育てる人、日当たりを比較したい人。

**選定理由**：矢野経済研究所が2024-12-25に公表した調査によると、2023年度の国内ガーデニング・家庭菜園市場は2,321億円。都市型園芸は注目分野。海外でも日照推定サービスが複数存在し、需要は示唆される一方で有料化やユーザー獲得は未検証。

**競合**：国内「日照チェッカー」（地図・建物の影を計算）、海外「Sunpatch」（庭・バルコニーを2Dで日照計算）、「Shuny Shade」（季節別の日照時間と場所比較）。新しい太陽計算法を発明したという主張ではない。

**差別化仮説**：地図・カメラなしで、窓の幅と高さ、庇の張り出し、前方の壁、鉢2個の高さと窓からの距離をcm単位で入力し、10分刻みの日照タイムラインと各月21日の直射を比較できる。夏に庇が高い日射を遮ることも明示。

**使い方**：index.html を開く。東京・大阪・札幌・福岡の緯度経度プリセット、春分・夏至・冬至頃の切替、2つの鉢の比較、遮蔽理由、CSV書出、JSON入出力、印刷、任意の端末内保存を実装。

**モデル**：NOAAの近似太陽位置式＋光線と平面窓枠・水平庇の交差判定。植物を点とみなし、前方の壁は窓に平行な無限幅壁と仮定。各10分間の中央値で計算。雲・木・周囲の建物・窓ガラス・光量・夏時間は未考慮。法定日影判定や栽培保証には使用しない。

**検証**：Node.js 単体テスト18/18合格、ランダム入力100ケースを含む。Chromium画面操作25/25合格（インライン展開・localStorage模擬）。JavaScript構文検査合格。実際の測光・建築物での精度比較と通常ブラウザでの直接起動・保存永続性は未検証。

**サンプル**：東京・南窓・庇65cm・2026-11-19で鉢A 610分、鉢B 330分（モデル出力であり実測値ではない）。
