# きりしろ / KIRISHIRO — 端材・持ち帰り制約つき木材カット計画

**制作日:** 2026-11-19 JST  |  **カテゴリ:** DIY・木工 / オフラインWebアプリ

## 対象と選定理由
日本のDIY愛好者、賃貸住宅で家具を作る人、小規模な木工教室・作業場向け。木材を店で買う前に「手元の端材で何本作れるか」「短い車に積める規格材で予算内に作れるか」「店舗加工費を含めた出費はいくらか」を確認する。

日本DIY・ホームセンター協会の2025年（1〜12月）の会員26社売上集計は2兆6,719億円（業界全体とは集計対象が異なる）。東京商工リサーチは2026-10-04、国内ホームセンター市場を成熟期と表現した。どちらもDIY向けカット計算アプリの固有需要や成長を直接示すものではない。

- 日本DIY・ホームセンター協会（2025年年間調査）: https://www.diy.or.jp/members/tuunen-investigation/
- 東京商工リサーチ（2026-10-04）: https://www.tsr-net.co.jp/data/detail/1203285_1527.html

## 競合と差別化仮説
- **日本:** App Storeの「板取り木取り図 カットリスト最適化」は、定尺材の割付・刃幅・カット料金・端材記録(Pro)まで提供する。 https://apps.apple.com/jp/app/id6792293888
- **日本:** 「木取り計算 - 木材・ベニヤ合板のカット図面作成」は1D・2D、規格材、刃幅、購入リストに対応する。 https://apps.apple.com/jp/app/id6832567947
- **海外:** CutWizeは刃幅付き割付・端材在庫・複数形式を備える（有料DIYプランもある）。 https://cutwize.com/
- **海外:** Cutlistorはブラウザ型の1D/2D、在庫、価格・材料区分、CSV対応。 https://www.cutlistor.com/

**差別化は「木取り計算」という機能単体ではない。** 「日本のホームセンターでカットして持ち帰る」という行動に特化し、①既存端材を先に割り当てる、②購入する定尺材だけを持ち帰り長さで制限する、③店ごとに異なる1カット料金を入力して買い物メモと総額を算出する、④加工後に残材を次回の在庫へ反映する、の1画面導線を無料・登録なし・日本語・端末内完結で提供する。特許性・競合より高性能であること・ヒットは未検証の仮説。

## 使い方・実装範囲
`index.html`をブラウザで開く。`style.css`, `engine.js`, `app.js` は同じフォルダに置く。サンプルが自動表示される。単位は **mm / 円**。

- 部材名・切断長・数量、購入候補材の定尺・単価・本数上限、手元の端材を自由編集。
- 刃幅（kerf）、左右の端部余裕、店の1カット料金、残す端材の最低長、購入材の運搬上限を設定。
- 0/1部分和DPで1本ごとの部材集合を選ぶ反復ヒューリスティック。**端材優先**、購入材は単位部材長当たりの見積費用を重視。未配置部材を警告。最適本数・最安値は保証しない。
- 母材ごとの切断長・刃のロス・残材を可視化。費用、購入リスト、端材未使用時との参考比較を表示。
- **「加工完了」ボタンは実際の加工が終わったときだけ押す**。消費した端材を在庫から減らし、設定長以上の残材を加える。直後なら取り消せる。
- プロジェクトJSONの保存/復元、CSV加工表、SVG切断図面、ブラウザ印刷、localStorage自動保存。外部API・ライブラリ・送信なし。

## 計算・安全上の制約
1D（長さ）専用。同一断面・材質であること、直角切断であることを前提とする。節や割れ・曲がり・機械の安全条件・店舗の切断対応可否は検証できない。端部余裕は両端で確保するが端面処理そのものの刃厚は別途算入しない。正確な端面仕上げが必要なら余裕を多めに取る。**端材に0円、店舗カット代は購入した定尺材の切断回数だけ**適用する。部材が残り長さにちょうど一致する最終区間では切断不要とする。小さすぎる末端余裕では切断できないため配置しない。実物の寸法・費用は店舗と現物で必ず照合する。
