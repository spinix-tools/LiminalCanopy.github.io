# 骰子重ね / DICE MATCH
2026-11-25。TRPG・自作ボードゲームの判定設計者、ゲームマスター向け。index.html をブラウザで開く（登録、外部通信、追加API・有料サービス不要）。

## 選定理由・競合
- 日本：Role&Rollの[2025-11-04告知](https://r-r.arclight.co.jp/2025/11/04/%E3%80%8Ctrpg%E3%83%95%E3%83%AC%E3%83%83%E3%82%B7%E3%83%A5%E3%83%95%E3%82%A7%E3%82%B9-in-%E3%82%B2%E3%83%BC%E3%83%A0%E3%83%9E%E3%83%BC%E3%82%B1%E3%83%83%E3%83%882025%E7%A7%8B%E3%80%8D%E9%96%8B/)は同年11月22–23日のTRPG体験イベントを紹介。[BCDice](https://bcdice.org/)は100以上のシステムに対応、[ダイススペック](https://dicespec.app/)は期待値・分布分析を提供する。
- 海外：[AnyDice](https://www.anydice.com/docs/introduction/)、[Dicegraph](https://www.dicegraph.com/)、[dice.run](https://dice.run/)は判定・分布の解析を提供。実際の設計需要を示唆するが、利用者数や本製品の支払意思は未測定。
- 差別化仮説：式を指定して分析するだけでなく、現物のダイス在庫・個数・補正上限から全候補を逆探索し、全目標値の成功率差が最小になる式を提示する。候補比較とCSVで判定互換性の説明が可能。競合の完全調査・独占性・実需要は未検証。次は自作ゲーム設計者5人に代替式が必要な場面と許容差を聞く。
- 専用ブランチの205アプリ名と関連README6件を確認。「手札分け」はカード初手成立率であり、今回のダイス代替とは異なる。全ソースの精査は未実施。

## 機能・モデル
元の1〜4個、2〜100面、補正±20。代替はd4/d6/d8/d10/d12/d20の在庫各0〜4個、合計最大4個、補正上限±20。畳み込みによる整数の出目数と累積数を算出し、全整数Tで |P(元≥T)-P(代替≥T)| の最大値を最小化。最大8569候補、比の順位比較にBigInt使用。同値は個数・補正絶対値・式順。上位12件を選択、成功率曲線・任意T・CSV・印刷。公平独立な合計判定に限定し、出目個別条件、クリティカル、振り直し、実際のプレイ感は対象外。サンプルの1d20対d6のみでは4d6-3が最大差20.28pp、許容差10pp内は0件（68候補）。
