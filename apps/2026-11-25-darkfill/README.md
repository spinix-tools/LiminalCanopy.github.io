# 暗枠 / DARKFILL

天体写真のダークフレーム補充計画。2026-11-25 MVP。`index.html` をブラウザで開くだけ（依存関係・外部通信なし）。

## ターゲット・選定理由・競合
冷却CMOSなどで複数の露光設定を使い、再利用可能なダークを管理する天体写真愛好者。国内ではサイトロンジャパンの第6回天体写真コンテスト（2026年7月3日〜9月15日）が継続的な活動の一指標。ステラショットの日本語解説は同一露出・ISO等のダーク撮影を説明する。海外ではSirilがマスターダークのライブラリ利用、Ekosがダークライブラリの作成・選択（主にフォーカス等）、NINAの撮影シーケンスによるライブラリ作成事例もある。需要規模や支払意向は未検証。
- https://www.sightron.co.jp/photocon.html
- https://www.stellashot.com/products/stlshot/stories/photo/index-j.shtml
- https://siril.readthedocs.io/en/stable/preprocessing/calibration.html
- https://stellarmate.com/support/ekos/capture
- https://www.youtube.com/watch?v=6DYByR7pvL8

差別化仮説：撮影・画像処理ではなく、既存枚数、必要枚数、ライト枚数・優先度、露光時間、温度ごとの準備時間から、予算内で完全に充足する設定の組み合わせを選ぶ。入力順の貪欲案と比較し、CSV指示表を出力する。競合全機能との網羅比較や独自性の証明ではない。既存ブランチのmainとの差分300ファイルおよびdark/ダーク/天体/astroのコミット検索、直近の制作履歴を確認したが、全アプリとの完全照合は未実施。

## 操作とモデル
最大16条件、720分。各行は温度°C,露光秒,Gain/ISO,Offset,Bin,既存,目標,ライト枚数,優先度(1–5)。同一カメラ・読出しモードのみ。各未充足条件の追加枚数×(露光+読出し余裕)と、追加撮影する温度ごとに固定準備時間を1回計上する。部分補充は探索しない。最大65,536部分集合を探索し、優先度×ライト枚数合計、ライト枚数合計、所要時間最短の順に比較。既存充足済みは無費用で含む。選択条件を温度順で出力。サンプルでは60分予算で入力順160/690枚から最適案540/690枚、追加35枚、56分10秒（架空データ）。

## 検証
`node test.cjs`: サンプルと不正入力10アサーション、独立全列挙400条件の目的値・費用照合、16条件65,536候補すべて評価の境界試験に合格。`python browser-test.py`（PlaywrightとChromiumが必要、実行環境は `/usr/bin/chromium`）: HTMLインライン実行で初期表示、CSVダウンロード、入力変更で旧結果無効化、ゼロ予算、不正入力、リセット、390px幅の横溢れなし、JS例外・外部HTTP要求0を確認。印刷実出力・実機撮影は未検証。

## 制限
同一設定の利用可能な既存枚数は利用者が確認すること。温度の近似、画像品質、有効期限、冷却可能性、温度間の個別移行時間、カメラ操作、FITS読込み、部分補充は対象外。最適化結果は入力モデル内のもので、実際の校正品質を保証しない。追加API課金・有料サービス・個人情報収集なし。
