# 線究 / SENKYU — 小規模AV配線の事前検図

**2026-11-19 制作**。学校の配信担当、小規模イベントの音響・映像スタッフ、社内セミナー運営者が、機材・接続・必要ケーブル長を入力し、**「どの端子・ケーブルに注意が必要か」「その1本が抜けたらどの受信先が失われるか」**を一画面で確認する、登録不要の静的Webアプリ。

## 市場・競合の確認

- **日本の周辺需要:** 矢野経済研究所の **2026-10-02** 発表は、2025年度の国内動画コンテンツビジネス（制作・編集・配信など5市場）の規模を **1兆1,474億円**と推計。AV配線計画アプリの直接の市場規模や課金意思を示す数字ではない。https://www.yano.co.jp/press-release/show/press_id/4196
- **国内競合:** [Snapplot](https://snapplot.app/) は日本語のシステム図面、端子・プロトコルチェック、配線リストに対応。接続検証自体には既存需要と競争がある。
- **海外競合:** [EasySchematic](https://easyschematic.live/) は豊富な機材カタログと配線表、[WireFlow](https://wireflow.live/) は接続検証とケーブルリスト、[WireMapper](https://wiremapper.app/) はブラウザ作図とSVG/PDF、[CableDoc](https://github.com/fschpp/CabledocDesktop) は影響分析に対応。

**選定理由と差別化仮説:** プロ向け高機能CADと違い、会場の機材5〜15台で、見本からすぐ使える **日本語・単一画面の「配線距離＋手持ち長＋余長をチェック」「一本外した影響を確認」**を入口にする。競合にないと断定するものではなく、学校・小規模運営の準備時間短縮と再利用率で検証すべき仮説。

## MVPの機能

- 9種類の機材プリセットを配置。機材名・役割・端子名・信号種類（HDMI/SDI/XLR/LAN/USB）・入出力と座標を編集。図上のドラッグ移動にも対応。
- 接続の方向 OUT→IN、信号種別、端子の二重使用、欠落端子を検査。経路距離×(1+余長率)と手持ちケーブル長を比較し不足mを表示。
- 設定可能な距離ガイド超過を**注意（エラーとは別）**で表示。初期値は仮の編集用プリセットで規格上の限界ではない。
- 送信元から受信先への疎通を簡易探索。中継機器は **同一信号種類のIN→OUTをすべて通過**できると仮定。指定ケーブル1本の取り外しによる受信先の差分を表示。
- SVG配線図、Excel対策付きCSV、JSONプロジェクトの保存・読込、ブラウザ内自動保存、印刷、スマートフォン表示。

## 起動と検証

4ファイル `index.html`、`style.css`、`engine.js`、`app.js`を同一フォルダに置き、`index.html`を開く。サーバー・ビルド・APIキーは不要。外部JS、外部通信、分析タグ、ログイン、個人情報の収集なし。

```sh
node --test engine.test.cjs
python browser_test.py  # Playwright + /usr/bin/chromium
```

- **Node.js v22**: 純粋な接続検証・経路探索・ケーブル不足・安全なCSV/SVGなど **29/29テスト合格**。
- **Chromium**: 機材・端子の追加削除、配線編集、断線シミュレーション、JSON/CSV/SVG、JSON復元、モバイル幅など **37/37チェック合格**。描画済み画面 `desktop.png`、`mobile.png`。
- **検証制限:** この管理環境では `file://` への直接遷移が `ERR_BLOCKED_BY_ADMINISTRATOR` のため、**同一HTML/CSS/JSをChromiumへ注入して試験**。localStorageはメモリ内モック。直接ファイル起動、実URL配信、実端末の長期保存、印刷実機、物理ケーブル実験は未検証。

## 利用上の限界

**これは配線準備メモであり、安全認定・接続互換性保証ではない。** 端子の形状、映像解像度・フレームレート、方向性、電気仕様、変換器動作、HDCP、EDID、PoE、USB給電、LAN規格、音声レベル、ケーブル材質、実配線経路、電源、RF干渉等は検査しない。単純な同信号型中継モデルであり、スイッチャー・ミキサーの選択状態や多対多の物理機能を再現しない。距離ガイドは設計目安であり実規格から導出した推奨値ではない。現物の製品説明書と担当技術者の確認が必須。案件・会場名の入力に個人情報を含めないこと。

## 次の検証

3〜5件の学校・小規模配信案件で、表計算・Snapplot等と比べた**準備所要時間、ケーブル忘れ・誤接続の発見件数、修正漏れ**を確認。誤警告が多い・準備が短縮しないなら本差別化仮説を撤回し、用途を再選定する。
