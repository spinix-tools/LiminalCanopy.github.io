# 曲がりPASS / MAGARI PASS

**家具搬入のL字通路を2Dで事前検討する、完全ローカル動作のWeb MVP。**

- **対象**：引越し前の入居者、ソファ・冷蔵庫を買い替える人、小規模家具販売・配送の事前説明担当者。
- **選定理由**：総務省統計局「2025年住民基本台帳人口移動報告」（2026-02-03）では市区町村間の移動者が519万548人。これはアプリの利用需要・課金意欲ではなく関連市場の背景指標。IKEA日本の大型配送規約も、玄関・階段等の寸法で搬入できない場合があると注意喚起している。
- **国内の代替手段**：IKEA日本の搬入経路確認ガイドと配送相談。実測値の照合・業者判断が中心。
- **海外の競合**：ItemFits（ドア、角、階段等を寸法から計算）、WillMyFurnitureFit/WillItFitThrough（ドア・廊下のチェック）、movinghouse.app（間取りと家具の配置・動線検証）等。既存サービスにも経路判定があり、本作は新しい基礎発明を主張しない。
- **差別化仮説**：日本語・cm入力で「L字の曲がり角に実際の家具矩形を回転させながら」A=通常姿勢/B=横倒し姿勢を比較し、**途中姿勢をスライダーで検査できる**こと。登録・サーバー・API不要。正確性・利用率・収益性は未検証。

## MVPで実装済み

- 家具長さ・奥行・高さ・余裕幅、横/縦廊下の寸法、天井高、障害物（突起）を編集。
- 位置5/10/15cm格子・角度15°ステップで2D剛体経路をA*近似探索。通路の凹角と障害物は回転矩形と軸平行矩形のSAT（分離軸定理）で衝突判定し、隣接状態間も細分検査。
- 通常姿勢と横倒し姿勢を個別計算し、経路の有無・探索状態数、床占有寸法、移動距離目安、姿勢変更数を比較。
- SVG図面、経路上の家具位置をスライダー・ステップ・自動再生で確認。家具プリセット、JSON保存/読込、ブラウザ内保存、SVG書出し、印刷、スマートフォン対応。
- 既存案（野鳥、ボランティア、布裁断、Wi-Fi、残響、水槽、結露、種まき、電源、字幕）とは領域・計算機能が重ならない。

## 使用方法

`index.html`をローカルブラウザで開く（または静的Webサーバーで配信）。**外部通信・新規課金・秘密情報・個人情報の収集なし。** `engine.js`に計算を独立させ、外部依存ライブラリはありません。

## 検証（2026-11-20）

- `node --test engine.test.cjs`：**32/32合格**。境界、衝突、始点/終点、逆方向の姿勢、高さ制約、格子、100件のランダム条件を検証。見つけた全候補経路の全節点と節点間を再検査。
- `node --check engine.js && node --check app.js`：構文検査合格。
- `python browser_test.py`：Chromiumで**30/30操作チェック合格**（寸法変更、プリセット、姿勢A/B、突起表示、ファイル書出し、JSON復元、SVG、スマホ画面、JS例外）。
- ブラウザ管理制限により `file://` の直接遷移が不安定で、画面試験は**同一HTML/CSS/JSをインライン展開**した。実ブラウザでのファイル直開き・localStorage永続性はこの試験では未確認。エクスポートファイル実体とJSON復元は確認済み。

## 精度の限界と安全

これは**2Dの予備検査**です。角度15°・格子探索のため経路が見つからなくても搬入不能とは限りません。経路が見つかっても、安全な実搬入を証明しません。扱うのは床投影の長方形、単純なL字廊下、単一長方形突起だけです。ドア・階段・踊り場・家具の立体的な傾け方・運搬員・梱包・吊り上げ・床荷重・家具の重心・頭上障害・衝突の作業余裕は検証対象外。横倒し不可の家電・家具は姿勢Bを採用しないでください。図は寸法入力に従う概算図で、現場の安全判定は販売店・搬入業者へ相談してください。
