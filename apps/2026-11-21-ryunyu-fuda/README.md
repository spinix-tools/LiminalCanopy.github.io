# 流入札 / RYUNYU FUDA

**2026-11-21 JST · キャンペーンURLの一括生成・配信面ごとの集約検査 · 純粋な静的Web MVP**

## 対象・選定理由・日本／海外の需要シグナル

対象は小規模EC、自治体の広報、非営利イベント、独立したマーケティング担当者。SNS、チラシ、メルマガに同じキャンペーンを配る際、`utm_content` を指定しても標準的な `source / medium / campaign` 集計だけでは配信面の差を見分けられないことがある。URL配布前にこの**意図的な集約／意図しない完全重複**を説明できる軽量ツールを狙う。

- **国内市場の傍証：** 電通が2026-03-05に公表した「2025年 日本の広告費」ではインターネット広告費4兆459億円（前年比110.8%）、媒体費3兆3,093億円。市場の存在を示すものであり、本アプリの顧客数・売上・支払意欲の根拠ではない。<https://www.dentsu.co.jp/news/release/2026/0305-011003.html>
- **国内競合：** 株式会社ULTROの[UTMパラメータ生成ツール](https://ultro.co.jp/tools/utm-builder/)はGA4チャネル判定と複数リンク作成に対応。[ANEMAのUTM URLビルダー](https://anema.co.jp/url-builder/)は個別URL生成に対応。単純なURL生成自体は差別化にならない。
- **海外競合：** [UTM.io](https://web.utm.io/link-builder/) はテンプレート・ルール・一括URL生成などを提供する強力な競合。[MetricTidy](https://metrictidy.com/) は既存のURL群を端末内で監査し、欠落・重複・命名規則を点検する。本作のオフライン監査も新規性ではない。

**差別化仮説：** 「受け取ったリンクを監査する」のではなく**「これから配る1キャンペーンの配信面の設計」**に集中し、日本語で配信面カードを同時編集しながら、(1) 完全同一URLの誤配布、(2) `utm_content` は違っても基本レポートに集約される組合せ、(3) 大文字小文字による別集計、(4) 既存UTMの置換、を一画面で提示。ログインも送信もないため小さな作業に適するかもしれない。ただし競合にも同等・類似機能があり、**実利用需要、ヒット可能性、収益性は未検証**。

## 操作方法・完成機能

`index.html` を Chrome / Edge / Firefox 等で開く（`style.css`, `engine.js`, `app.js` を同じディレクトリに置く）。サーバー・ビルド・APIキー不要。

1. 共通の `utm_campaign` とリンク先URLを入力。既存の通常クエリとアンカーは意味上維持し、既存UTMだけ置き換えて新しいURLを作成。
2. 最大80個の配信面を追加・編集・削除。配信面ごとに source / medium / content / term と個別のリンク先を設定。タブ区切りの複数行を貼り付けて追加可能。
3. 5種のUTMを適切にエンコードし、http(s)チェック、必須値、命名揺れ、既存UTM、既存UTM重複、完全一致URL、基本レポートの集約、大小文字揺れを即時計算。`javascript:` や `file:`、資格情報付きURLは拒否。
4. 生成リンクのワンクリックコピー、警告別フィルタ、UTF-8 BOM付きの監査CSV、JSONバックアップ／復元、印刷。明示操作による端末内保存・消去。
5. 同じ「source / medium / campaign」でも**意図的に集計する**場合があるため、集約はエラーではなく「要確認」。完全同一の生成URLだけをエラー扱いする。フォームに入力した文字列をHTMLとして解釈しない。

**プライバシー：** fetch/XHR/外部ライブラリ/解析タグ/フォントCDNなし。全計算はブラウザ内。入力したURLを訪問しない。端末保存を押すまでlocalStorageへ保存しない（起動時、既存の明示保存がある場合は読み込む）。共有端末には機密URLや個人情報を入力しないでください。
