# 箱たしかめ / HAKO TASHIKAME

EC・フリマ・ハンドメイド商品の小規模発送者向け、箱詰めと送料のブラウザ内試算MVP。2026-11-20制作。

## ターゲットと選定理由

国内：国土交通省の2026-11-13公表資料では2025年度宅配便取扱個数が**51億6178万個**（前年比約2.5%増）。発送実務の規模は大きいが、この統計から本アプリの需要・課金意欲を推定することはできない。<https://www.mlit.go.jp/report/press/jidosha04_hh_000371.html>

海外：米国国勢調査局の2026-11-19公表資料では、2026年第3四半期EC小売売上（季節調整済）が**3,473億ドル**、全小売の**17.9%**。出荷業務が日常化する土壌を示す背景指標。<https://www.census.gov/retail/ecommerce.html>

## 競合と差別化仮説

- 日本：**BOX MASTER** は箱内配置分析と送料比較、**FreeSMAT** は梱包サイズ計算を提供。<https://box-master.net/> / <https://freesmat.com/>
- 海外：**BoxVolume** は3D梱包と複数箱分配、**BoxIntellect** は箱・重量・複数荷物最適化、**BoxPack 3D** は3D表示とレポートを提供。<https://boxvolume.com/en> / <https://boxintellect.pro/box-size-calculator/> / <https://boxpack3d.com/>

**差別化仮説（未検証）**：日本語・cm/kg入力、手持ち箱の内寸/外寸の分離、商品ごとの天地固定と緩衝材、**料金重視と箱数重視のA/B配置比較**、未割付警告、編集可能な配送料テーブル、出荷梱包表CSVを登録不要・ローカル完結で提供。3D梱包自体は新規ではない。価格支払意欲・競合優位は未検証。

## 実装済み機能

- 商品の追加・編集・削除と数量展開（最大40点、天地固定）
- 箱の内寸・外寸、箱重量、積載重量上限、資材費、送料階層の編集
- 緩衝材を各辺に両側分加え、直方体を回転・衝突判定・底面支持チェック付きで近似配置
- 候補箱を使う複数箱プラン、料金優先/箱数優先の比較、送料・未割付個数・容積充填率
- SVGによる疑似3D配置表示、商品別の凡例、箱切替
- JSON入出力、CSV梱包表出力、印刷、`localStorage`保存（端末内）
- 外部API、外部ライブラリ、課金、認証、トラッキングなし

## 実行方法

ファイルを同じフォルダに置き `index.html` をブラウザで開く。Webサーバーを使う場合は `python -m http.server 8000`。Node.js 18以降で `node --test engine.test.cjs`。Chromium + Playwright Python環境では `python browser_test.py`。

## 検証（2026-11-20）

- **Node.js 12/12テスト合格**。ランダム600ケース×2方針で箱外配置・重なり・支持・数量保存を検査。
- **Chromiumインライン展開で19/19項目合格**。商品編集、A/B表示、異常入力、JSON/CSV出力、JSON不正読込、スマホ表示など。デスクトップとモバイルのスクリーンショットを同梱。
- Chromium管理環境の `net::ERR_BLOCKED_BY_ADMINISTRATOR` によりHTTP直接遷移は拒否。**同一HTMLとJSをインライン展開**して画面を検証した。実ブラウザでの通常URL遷移、端末保存の永続性、プリンタ実機、実商品での梱包強度は未検証。

## 設計上の制約と注意

箱詰めは直方体と85%底面支持の**近似ヒューリスティクス**。最適解や実物の梱包可能性、破損防止を保証しない。総重量だけで荷重強度は判断できず、凹凸・破損防止の緩衝・組立順・運送会社固有の細則は対象外。送料は**架空のサンプル**なので契約運賃に置換が必要。送料と箱代のみを比較し、人件費・返品・梱包材の他費用は含めない。
