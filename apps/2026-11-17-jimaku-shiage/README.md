# 字幕しあげ / JIMAKU SHIAGE

字幕ファイルの「速すぎる」「長すぎる」「隣と重なる」を見つけ、1字幕ずつ調整して書き出せる、登録不要のブラウザ完結型MVP。2026-11-17 制作。

## 想定ターゲットと選定理由
日本語のショート動画を投稿する個人クリエイター、学校・自治体・小規模事業者の広報担当、動画編集者。国内では動画コンテンツ市場（主要5市場合計）が2025年度1兆1,474億円（2026-10-02公表、矢野経済研究所）と推計され、2025年の国内動画広告市場も8,855億円（サイバーエージェント、2026-03公表）と推計される。これらは字幕QAツール単体の需要・売上を直接示す数字ではない。

## 国内外競合と差別化仮説
- 日本: VrewはAI字幕生成とSRT書き出しを提供。CapCutは自動キャプション・手動編集・SRT取り込みなどを提供。
- 海外: Subtitle Editは字幕の読み速度、長さ、重複、間隔を診断可能。QuickVeedやCueCheckはブラウザ上でSRT/VTTのQAレポートを提供。つまり診断自体は新規性ではない。
- **仮説**: 認識AIを競わず、短い日本語UI・縦型/横型のプレビュー・日本語禁則を考慮した改行候補・次字幕を動かさない安全な延長/重複短縮・SRT/VTTの再出力を一つの無料画面にまとめることで、既存のAI字幕生成後に「最後の5分だけ確認したい」利用者に価値を提供できる。ユーザーテスト・有料転換率は未検証。

## MVP機能
- SRT/WebVTTのUTF-8貼り付け・ファイル読み込み。不正時刻や非対応の特殊VTTブロックは読み込みを停止（**黙って欠損させない**）。
- 表示速度（文字/秒）、行長、行数、表示時間、重複、字幕間隔、入力順の診断。各数値は変更可能で**公式配信基準ではない**。
- 日本語禁則を考慮した2行改行候補の提案（長文は勝手に削除しない）、次字幕との間隔を保持した延長、明示操作での重複短縮、手動タイムコード・本文修正、字幕追加/削除。
- ローカル動画を重ねてプレビュー（ファイルはアップロードしない）、動画がなくても時間スライダーで表示。SRT/VTT/診断CSV/編集JSONの出力。
- 端末内保存はユーザーが「保存」を押した時のみ。保存したデータはブラウザのサイトデータ削除で消える。動画自体は保存しない。

## 実行・テスト
`index.html`をブラウザで開く（同じ場所に`engine.js`と`app.js`が必要）。外部ライブラリ/API・ビルド工程なし。

- `node --test engine.test.cjs` → **36/36 合格**（パース、時刻、QA、書き出し、日本語改行、重複・延長など）。
- `python browser_test.py` → **32/32 合格**（Chromiumで画面操作、出力ダウンロード、JSON復元、XSS確認、モバイル横あふれ）。実行環境で`file://`ナビゲーションが制限され、HTML/JSをページに直接挿入して検証。`localStorage`は同環境で模擬、実端末の永続性と実公開URLの通信/配信は未検証。
- 画面画像 `desktop.png` / `mobile.png` はChromium操作時に撮影。

## 限界・リスク
校正指標は簡易ヒューリスティックであり、日本語意味理解、音声同期の自動修正、シーンカット検出、字幕制作規格への適合保証はない。VTTのNOTE・STYLE・REGIONや特殊な字幕識別子を保持しないため、非対応ブロックが見つかった場合は取り込みを停止する。ブラウザ内での動画再生は端末・コーデック依存。インポートした字幕には著作権や機密性がある可能性があるため端末共有時の保存に注意。

## プライバシーと費用
字幕/動画をサーバーへ送信しない。解析処理はブラウザ内で行う。アカウント登録、分析用外部送信、有料API、秘密情報・個人情報の入力要求なし。ライセンス: MIT。
