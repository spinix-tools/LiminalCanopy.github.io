# 釉配 / YUHAI
2026-11-25｜陶芸の三角配合試験を、残量と試験片数の制約下で計画する単独HTML。index.html をブラウザで開くだけ。登録・通信・外部API・追加課金・個人情報収集なし。

## ターゲット・市場・選定理由
陶芸教室、個人陶芸家、小規模工房。京都美術工芸大学の2022年実習紹介には200種以上の釉薬調合、岐阜県セラミックス研究所のライブラリーには約15万点の見本がある。試験作業の実在を示すが、アプリの利用意向・市場規模ではない。
国内競合：釉式Yushiki（ゼーゲル式・Stullチャート）。海外：Glazy（ライン・三角配合、BlendsはPatron向け）、Potter's Kit（三角配合の各片量・総必要量）、GlazeIQ（配合グリッド・写真記録）。既存ツールにも近接機能がある。
差別化仮説：全点を作る前提の必要量計算ではなく、残った調合済み原液と追加試験片数から、既測・必須点を保持して追加点を選ぶ。日本語、登録不要、工房でのオフライン使用。実需・収益性は未検証。初期検証は教室で手計算との所要時間比較を行うこと。

## 使い方・モデル
2〜10分割（6〜66点）、整数mL、1片の量は分割数の倍数。各原液の残量、残す量、追加片数を設定。点をクリックして未指定→必須→既測と切り替え、計算。既測点は同条件の結果とみなす。必須点を先に割り当て、残在庫に適合する候補から最近傍距離が最大の点を貪欲に選ぶ。同点なら残量に対する消費割合合計が小さい方、さらに同点ならID順。初点は中心寄り。距離は三成分の絶対差合計の半分（比率の百分率ポイント）。大域最適性・最大試験数は保証しない。既測点は在庫を消費しない。計量表・CSV・印刷に対応。
初期例：15候補中6点を追加、必要量A/B/C=55/35/30mL（全15点なら各100mL）、最大最近傍距離50pt。実際の色・品質の予測ではない。
調合済み原液の体積比のみ。沈降、濃度差、化学、焼成条件、食品接触安全性、計量誤差は対象外。固形分濃度が等しくなければ乾燥重量比にはならない。実際の調合・印刷は未検証。

## テスト
`node test.cjs`：固定10アサーション、乱数500条件で在庫・片数・重複・量保存・距離独立照合・候補終了条件を検証、全合格。`python browser_test.py`：Playwrightと/usr/bin/chromium（環境に応じ変更）、HTMLインライン実行（管理環境でfile://がブロックされたため）・CSV・既測切替・不正入力・リセット・66点・390px幅・JS例外/外部HTTP要求なし、合格。実機は未検証。
