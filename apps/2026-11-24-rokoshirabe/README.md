# 露光しらべ / ROKOSHIRABE (2026-11-24)

フィルム長時間露光の校正ツール。`index.html` をブラウザで開く。依存ライブラリ、登録、外部API、個人情報の入力・送信、有料サービスは不要。

## 対象・選定理由
日本・海外の白黒フィルム、ピンホール、大判写真愛好者。2026-08-25のデジカメWatchによれば、国内FilmFocusの2025年Web調査は有効回答1,337件、使用頻度を減らした層の理由の最多はコスト（62%）。英国Harmanは2024年に35mmフィルム製造関連設備への投資を報告。試写の無駄を抑える道具を選んだ。自己選択調査・企業投資は需要の間接指標で、校正ツールの需要や課金意思ではない。
- 国内調査: https://dc.watch.impress.co.jp/docs/news/2135076.html
- 海外: https://www.lloydsbank.com/business/resource-centre/case-studies/harman-technology.html

## 競合・差別化仮説
- 国内向け: FilmRecip（メーカー別補正・履歴） https://apps.apple.com/jp/app/id6809852097
- 海外: BentoUtils（補正・ブラケット） https://bentoutils.com/apps/film-reciprocity-calculator/
- 海外: 35mm.org（メーカー公表値の計算） https://35mm.org/ja/tools/reciprocity
既存計算器は公表済みの指数や表から露光を予測する。本MVPは同一処理条件の試写で許容できた実露光の範囲から、全試写に整合する指数の共通範囲を逆算する。矛盾の検出、外挿の警告、時間予算内での次の試写候補が差別化仮説。競合の全機能や独創性・需要・収益性は未検証。専用ブランチの既存アプリ一覧と関連7件のREADMEを確認した。星点帳（星像の伸び）、焦間（深度合成）とは目的が異なる。全既存ソースの重複検査は未実施。

## 使い方・モデル
1. 短時間の基準露光と比較し、同じ濃度と判断した露光時間の下限・上限を登録（最大20件）。初期値は架空。
2. T= t^p（秒、1<=p<=3、測光t>=2）を仮定し、各行の log(下限)/log(t) から log(上限)/log(t) の共通部分を計算。空集合なら予測を停止する。
3. 任意の測光時間で下限・幾何平均・上限を表示。試写範囲外は警告。次回は固定12候補のうち上限時間を守り、予測のEV幅が最大の未試写点を提示。同点なら短い測光を優先。
4. 試写CSV保存・印刷・ブラウザ内自動保存（可能な場合）。
モデルは単一幂乗・手入力区間のみ。信頼区間、実測誤差の確率モデル、濃度測定、色偏り、温度、現像差、フィルム銘柄別の公式補正は対象外。試写が矛盾した理由や最適露光を保証しない。

## 検証
Node.js: 固定11件、ランダム500モデル、独立した指数代入による20,000件の区間所属照合、次候補500件の照合が合格。架空例の指数1.27979〜1.32282、測光60秒の実露光188.65〜225秒。
Chromium: 入力・追加削除・矛盾・外挿・上限・CSV出力・初期化・390px表示を確認。JS例外・外部HTTP要求0件。file://が遮断されたため同じHTMLをインライン実行し、端末保存は模擬（永続性未検証）。実撮影・印刷実機・iOS/Safariは未検証。
ローカル配布ZIPには `test.cjs`（`node test.cjs`）、`browser_test.py`（Playwright/Chromium環境で実行）および画面画像を同梱。
