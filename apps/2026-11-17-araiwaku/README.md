# あらいわく / ARAIWAKU

**2026-11-17 制作｜洗濯前の「混ぜる・分ける・保留」を説明するローカルWebアプリ**

## 対象・選定理由

日本の一人暮らし、共働き家庭、古着愛好家など、洗濯のたびに色・洗濯表示・洗濯機容量の組み合わせを考える人。消費者庁は洗濯表示が国際規格に合わせて変更された経緯や2024年8月20日の改正を案内し、洗濯表示の認知度調査を公表している。記号の意味を調べる次の段階で、「**今日のこの衣類を何回に分けて洗うか**」を決める道具が使われると仮説を立てた。

## 競合・差別化仮説（2026年11月17日確認）

- **日本:** 「あ～らくせんたく」「洗濯ケアガイド - Rinse」「Sudsy!」は洗濯表示の読み取り・衣類記録・仕分けを提供。仕分け自体は既存の機能で、独占的な新規性はない。
- **海外:** LaundryMax はラベル読み取りから色・コースごとの仕分けを提供。RinseIndex は洗濯ロットと衣類のケア履歴を扱う。
- **本アプリの狭い仮説:** スキャンや会員登録を省き、**「混洗できない／要確認になる理由」を隠さず、色×コース×容量の制約内で洗濯機の回数を小さくする**。各分類が12点以下なら分枝限定法で最小回数を探索、13点以上はFFD近似と明記。CSV・JSONで持ち出せる完全ローカル設計。既存競合が同等機能を提供している可能性があり、差別化と収益性は未検証。

参照： [消費者庁（洗濯表示）](https://www.caa.go.jp/policies/policy/representation/household_goods/laundry_symbols.html) ／ [消費者庁（認知度調査）](https://www.caa.go.jp/policies/future/project/project_006/) ／ [あ～らくせんたく](https://apps.apple.com/jp/app/id1519966023) ／ [Rinse（日本）](https://apps.apple.com/jp/app/id6765633151) ／ [Sudsy!](https://apps.apple.com/jp/app/id6778044608) ／ [LaundryMax](https://laundrymax.app/) ／ [RinseIndex](https://apps.apple.com/us/app/id6826134395)

## 操作できる機能

- 衣類の追加・編集・削除、洗濯済み切替、サンプルデータ復元、任意の洗濯機容量（0.5〜20kg）
- 洗濯方法（標準/弱水流/手洗い/不可/未確認）、色、水温上限、乾燥表示、重量、色移りリスクの管理
- **色と洗濯コースで保守的に分割**した機械洗い候補。各候補の最低水温上限、重量・容量比、乾燥可否の注意。色移り注意は単独洗いに固定
- 手洗い／水洗い不可／表示未確認／容量超過を根拠つきで保留し、機械洗いに混ぜない
- CSV仕分け表、テキストメモのコピー、印刷、JSONバックアップ・検証つき復元、ブラウザ内保存

## 起動・テスト

`index.html`, `engine.js`, `app.js` を同じ場所に置き、`index.html` をブラウザで開く。`file://` で保存できないブラウザでは `python -m http.server 8000` を起動して `http://localhost:8000/` を利用。外部CDN・API・アクセス解析・課金・アカウント・個人情報送信はなし。

```bash
node --test engine.test.cjs
python browser_test.py  # Python playwright と /usr/bin/chromium が必要
```

**検証結果（2026-11-17）:** Node単体テスト **34/34成功**。Chromiumの追加・編集・削除・洗濯済み切替・容量変更・CSV/JSON出力・不正JSON拒否・HTML注入無効化・モバイル幅などの操作試験 **24/24成功**、ページスクリプト未捕捉エラー0。スクリーンショット `desktop.png` / `mobile.png` を収録。

**検証限界:** この実行環境では Chromium の `page.goto()` が管理者設定でブロックされたため、`set_content()` とスクリプト注入、メモリ上の `localStorage` 模擬で検証。**実端末での永続化、実衣類の洗濯結果、各洗濯機の容量定義、物理印刷は未検証**。パフォーマンス保証もない。

## 安全上の前提

手動入力に誤りがあれば仕分けも誤る。洗濯表示の画像認識はせず、素材・装飾・洗剤・水質・汚れ・色移りの化学的安全性は判定しない。同色・同一コースでも混洗安全を保証しない。ユーザーは**各衣類の正式な洗濯表示、付記、洗濯機・洗剤の説明を必ず優先**すること。「要確認」は自動推測で解消しない。最小回数は入力条件を満たす分類内の箱詰め計算であり、最適な洗濯品質を意味しない。
