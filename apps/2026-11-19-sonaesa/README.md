# そなえ差分 / SONAESA

家庭の防災備蓄を、**今日**と**指定した将来日**の二時点で比較する、無料・登録不要・ローカル動作の Web MVP（2026-11-19作成）。

## 対象・選定理由

- **ターゲット:** 自宅で備蓄を管理する家庭、マンション防災担当、少人数世帯。
- **日本の需要の根拠:** 東京都が2026年9月1日に紹介した調査では、携帯トイレを3日分以上備蓄する都民は約25%にとどまる。内閣府の防災資料は家庭の食料備蓄として最低3日～1週間分を呼びかけている。
- **海外の関連需要:** 米国FEMAのReady.govは家庭用キットに飲料水・保存食・衛生用品を挙げ、必要日数を家庭事情に合わせるよう案内している。関連需要は確認できるが、本アプリの利用意向・収益性は未検証。

## 競合と差別化仮説

国内の「月イチ備蓄」「備蓄ストック」「防災備蓄ノート」、海外のStowd・PrepStackには、期限管理、充足日数や買い足しなど既存の機能がある。したがって、**期限管理やオフラインを独自機能とは主張しない**。

本作は **任意の将来日付を指定して期限切れを除外 → 今日との差分を表示 → 入力した予算と購入パックの数量・価格から補充案を計算** する短い操作経路に集中する。これが使いやすさを改善するかはユーザーテストで反証できる仮説であり、既存製品の未対応を網羅的に証明したものではない。

## 実装機能

- 人数、目標日数、比較日、1日あたりの飲料水（L）・食事（食）・携帯トイレ（回）の必要量を設定。
- ロット単位で品名・分類・数量・期限・保管場所を追加、使用による数量減算、削除。サンプル付き。
- 賞味期限が比較日より前のロットを除外し、各カテゴリの必要量・不足量・備蓄日数と、最も少ないカテゴリの日数を算出。
- 予算と購入パックの容量・単価から、最短充足日数の小さいカテゴリを優先する簡易補充案。費用・購入後の充足日数を表示。
- 30日以内の期限リスト、JSONバックアップ・復元、CSV出力、印刷、ブラウザの localStorage 自動保存。
- 外部API、外部ライブラリ、アカウント、通信、個人情報収集、OpenAI APIは不要。HTML/CSS/JavaScriptのみ。

## 起動とテスト

`index.html` をブラウザで開く。CSS/JS は同フォルダに配置。ローカルストレージが制限されるブラウザではJSONを手動バックアップする。

```bash
node --test engine.test.cjs
python browser_test.py  # Playwright + Chromium 要。インライン配置とストレージ模擬で実施
```

- **Node.js: 25/25合格**（暦日、期限境界、需給算定、予算遵守の200ケース乱数試験、入力検証、CSV数式注入対策など）。
- **Chromium: 29/29操作アサーション合格**（フォーム変更、在庫追加/減算/削除、CSV/JSON、JSON復元、localStorage模擬再読み込み、デスクトップ・モバイル）。
- JS構文 `node --check engine.js app.js` 合格。
- **制限:** 実行環境のHTTPナビゲーションは `ERR_BLOCKED_BY_ADMINISTRATOR` のため、同じHTML/CSS/JSをインライン配置しlocalStorageをスタブ化して操作試験。`file://`での直接起動、永続保存の実ブラウザ・印刷実機・災害時の使用は未検証。

## モデルの限界

- 期限が空欄の品は無期限扱い。期限が比較日**当日**の品は有効として計算する。日数は指定日の開始時点の利用可能在庫を日次消費量で割った目安であり、災害期間中の期限到来・流通・保管条件を計算しない。
- 補充案はパック単位の貪欲法（最短備蓄日数優先）で、最適解・買い物の実在性・予算の価格正確性を保証しない。実在庫には自動反映しない。
- 医薬品、乳幼児・ペット用品、熱源、介護用品、特殊な食事制約、断水・停電への対策は別途必要。行政等の最新案内を優先すること。
