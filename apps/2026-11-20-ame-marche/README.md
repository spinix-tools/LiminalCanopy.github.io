# 雨マルシェ / AME MARCHE — 2026-11-20

個人ハンドメイド作家のための、晴雨リスクと在庫を含むマルシェ出店２案比較MVP。無料、ブラウザ内計算、外部API・追跡・個人情報収集なし。

## 誰の何を解くか
日本のマルシェ・ZINE即売会・ポップアップの個人出店者が、出店料が安い屋外Aと雨でも来客が見込める屋内Bなどを、同じ商品と雨確率で比較できるようにする。

## 主な機能
出店案A/B、天候別来客数、雨確率、1〜12商品の価格・原価・持込数・需要比率・残り損失、決済手数料、目標時給の編集。天候別利益、期待利益、1,600回の固定乱数シミュレーションによる10/50/90パーセンタイル・赤字率・時給達成率、雨確率感度図、JSON入出力、CSV出力、端末保存、印刷、レスポンシブ画面。

## 計算と注意
晴または雨の商品需要 = 来客数 × 購入率 × 商品重み（正規化）。販売は在庫まで。利益 = 売上 − 販売品の原価 − 決済手数料 − 売れ残り数×残り損失 − 出店固定費。残り損失は回収不能原価・廃棄費等で、再販可能なら0とする。製造原価の二重計上に注意。平均需要を用いた期待利益と乱数シミュレーションの平均は在庫上限制約により異なり得る。乱数はポアソン・正規近似で独立購買を仮定する。税・人件費の税務区分・需要相関・イベント中止等は未考慮。実際の利益を保証しない。
