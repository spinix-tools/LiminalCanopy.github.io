CrawlContract

robots.txt の変更を、期待するクロール方針と照合する。

01 / ルールを比較

同一オリジンのルールを貼り付け。空欄はルールなし。外部サイトへのアクセスは行いません。

02 / 期待する動作を登録

クローラー名 → パス（クエリ可） → allow / block / same（変更前の判定を維持）

03 / リリース判定

クローラー / パス期待変更前変更後契約
限定モデル：完全なクローラー互換性、HTTP状態、キャッシュ、索引登録、アクセス制御を保証しません。個人情報・秘密URLの入力は不要です。
