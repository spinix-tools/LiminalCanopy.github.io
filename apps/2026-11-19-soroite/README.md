# そろい手 / SOROITE 🃏

**Deck consistency studio — 日本語・オフライン・無料のTCG初手確率設計ツール。**

## ターゲットと選定理由

TCGプレイヤー、自作カードゲームの設計者、デッキ調整を教える人。「初動は必要、資源は適量、重いカードは引き過ぎたくない」という**下限と上限を同時に満たす**構築検証を支援する。日本玩具協会の2026年6月22日公表データでは、2025年度の国内「カードゲーム・トレーディングカード」市場は3,384億円（希望小売価格ベース）。市場の活動規模を示すが、本アプリへの需要・課金意欲の証明ではない。

## 競合と差別化仮説（2026年11月19日参照）

- **国内**: [DrawSim](https://tamamu.dev/apps/drawsim/) はカテゴリ別AND/OR複合確率、目標逆算、A/B比較、オフライン処理まで提供。[PokeDeckLab](https://poke-deck-lab.com/) はポケモンカード向けに1万試行のシミュレーションを案内。
- **海外**: [MathGyro](https://mathgyro.com/tcg-draw-probability-calculator/) は単一カード群の超幾何分布。[Flexslot](https://flexslot.gg/hypergeometric-calculator) も指定カード群の確率計算を提供。
- **仮説**: 下限だけではなく**複数カテゴリの「引きすぎ上限」**を同時に設定し、ターン経過で成功率が**一度上昇してから低下しうる**現象を可視化する。さらに、条件外カードとの**1枚置換による増減幅**をすぐに試せる。これらが通常の「1枚以上のヒット率」より構築判断に役立つかはユーザーテストが必要。

公式市場出典: [日本玩具協会・統計資料（2026-06-22）](https://www.toys.or.jp/toukei_siryou_data.html)。海外需要は公開計算ツールの存在から推察したにとどまり、海外の利用者数や支払意欲は未確認。

## 動くMVPの機能

- デッキ1〜200枚、初手、0〜12ターン、ドロー枚数を編集
- 互いに**重ならない**1〜4カードカテゴリごとの所属枚数／最低・最高枚数を設定
- 多変量超幾何分布（カテゴリごとの組合せ数を畳み込むDP）による**厳密な全条件成立確率**
- 初手・各ターンの曲線／表、同一枚数での**失敗時の全引き直し1回**の独立試行モデル
- デッキ総数を固定した「その他カードとの±1枚入れ替え」候補とワンクリック適用
- 実際に1回だけランダムに手札を引くデモ
- JSON入出力、CSV曲線出力、印刷、localStorage自動保存、スマートフォン対応

## 起動

`index.html`, `style.css`, `engine.js`, `app.js` を**同じフォルダ**に置き、`index.html` をブラウザで開く。ビルド不要。外部CDN・外部API・広告・解析・個人情報送信なし。

| デスクトップ／モバイル表示 | `desktop.png`, `mobile.png` を保存・目視確認 |

**環境上の制限:** ChromiumのHTTP/`file://`直接遷移は管理者ポリシーで `ERR_BLOCKED_BY_ADMINISTRATOR` となるため、**同じHTML/CSS/JSを `page.set_content` にインライン展開**し画面操作をテスト。localStorageはスタブで再読み込みを模擬した。ZIPを開いた通常ブラウザでの直起動／端末保存の永続性／実機印刷は未検証。

**モデル上の制限:** カテゴリ重複、サーチ、サイドボード、ゲーム固有のマリガン方式、ターン内のカード消費・追加ドロー・公開情報・戦略的プレイは扱わない。各ターンの成立率は**それまでに見た全カード**に条件が含まれる確率であり、実際に手札に残る確率ではない。全引き直し1回は失敗時に完全に山札を戻し同じ枚数を引く簡略ルールで、ゲーム別の公式ルールを再現しない。最適性や大会での勝率は保証しない。
