# 店ミリ / MISEMIRI — マルシェの卓上ブース設営プランナー

2026-11-19 制作。ミリ単位の机上レイアウトと搬入チェックをつなぐ、登録不要・外部API不要の静的Web MVP。

## ターゲット / 選定理由

ハンドメイド・同人・小規模物販マルシェに出店する個人作家と運営サポート担当者。「当日什器が机に収まらない」「会計場所がなくなる」「搬入の忘れ物が出る」を設営前に減らす。国内実需の隣接指標として、デザインフェスタ vol.64（2026年11月14・15日）公式情報は**1日約6,500ブース**を掲げる。ただしイベント規模は本アプリの利用意向・有料需要の証明ではない。

## 日本・海外競合調査（2026-11-19確認）

- 日本：**[BOOTHROOM](https://boothroom.me/ja/index.html)** は実寸の机にグッズを置く3Dブースシミュレーター。**[MiseFits](https://misefits.kokokikaku.com/)** は店舗・イベントの縮尺と什器配置、PDF/JSON出力に対応。**[卓上レイアウトノート](https://booth.pm/en/items/8819407)** はオフラインHTMLでA/B計画と持込一覧を作れる。
- 海外：**[Tradeshow](https://www.tradeshowapp.io/)** はアートフェア向け実寸配置・3Dブース・在庫/販売管理。**[StallnuTako](https://apps.apple.com/ca/app/stallnutako/id6813530748)** は露店・クラフト催事向け区画設計・チェックリスト・損益分岐試算に対応。
- 市場状況：**[デザインフェスタ公式](https://designfesta.com/about/)** の第64回案内、**[minne 2025年トレンド公表（2025-11-13）](https://group.gmo/news/article/9775/)**。既に高機能な競合が多いため、成功は未検証。

## 差別化仮説

**机上の実寸確認と当日の持参チェックを一画面に置き、会計帯・商品までの奥行目安・什器同士の必要な間隔を同時検査することで、実際の設営前作業の見落としを減らせる**と仮説を置く。レイアウト自体の新規性は主張しない。A/B比較・写真・3D・正確な安全性評価は未実装。

## 動作と主要機能

1. `index.html` をブラウザで開く。デモの5つの什器が表示される。外部ライブラリ・サーバーは不要。
2. 机の幅・奥行、余白、什器間隔、手前からの目安距離、右手前の会計スペースを変更する。
3. プリセットまたは自由名で品目追加。図面でドラッグ、矢印キーで10mm移動、右パネルから位置・寸法・分類・数量変更、回転・複製・削除。戻す（Undo）、自動仮配置あり。
4. 重なり、机からのはみ出し、会計スペース侵入、商品の奥行目安をリアルタイム警告。什器ごとに搬入済みをチェック。
5. ブラウザ端末内への自動保存（`localStorage`）、JSON保存・復元、BOM付きCSV明細、SVG実寸比図面、ブラウザ印刷。名前等の入力は外部送信しない。

## テスト結果 / 検証範囲

- `node --test engine.test.cjs` : **37 / 37 合格**。境界・衝突・クリアランス・会計・自動配置・CSV/SVGエスケープ・不正JSON・大規模100点配置を検証。
- `python browser_test.py` : **33 / 33 合格**（システムChromium + Playwright）。追加/編集/複製/回転/削除/Undo/キーボード移動/ドラッグ/警告/自動配置/3形式ダウンロード/JSON読込/不正JSON/モバイル横はみ出しを確認。`desktop.png`, `mobile.png` を保存。
- テスト環境では`file://`とローカルHTTPへのブラウザ遷移が管理者により遮断されるため、**同一のHTML・CSS・JSソースを `set_content` でインライン実行**した。通常ブラウザでのファイル直開き、実際のブラウザ保存持続性、実プリンタの印刷方向/縮尺、現物の設営は未検証。ブラウザの`localStorage`利用は試験環境で制限されたため、単体テストとJSON入出力を確認し、保存持続性は未評価。
- 自動配置は近似的なコーナー探索で最小空間を保証しない。寸法検証は上面の長方形近似。重量・荷重、転倒、火気、通行安全、現地規則は対象外。商品が顧客から届く距離は目安であって安全基準ではない。
