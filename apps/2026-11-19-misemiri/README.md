# 店ミリ / MISEMIRI — マルシェの卓上ブース設営プランナー

制作: 2026-11-19 / HTML・CSS・JavaScript / 登録不要・サーバー不要

## ターゲットと選定理由
ハンドメイド・同人イベントの出店者。机上で作品や什器が重ならずに置けるか、会計スペースと搬入のチェックを設営前に確認する。デザインフェスタ vol.64（2026-11-14/15）公式案内は各日約6,500ブースを掲げるが、本アプリの需要を直接示す数値ではない。

## 競合と差別化仮説
日本: BOOTHROOM（同人向け3D机上配置）、MiseFits（店舗実寸計画）、卓上レイアウトノート（オフラインHTML）。
海外: Tradeshow（アートフェアのブース設計）、StallnuTako（出店レイアウトと運営チェック）。
既存の配置機能そのものは新規ではない。**会計の専用帯・商品の手前距離・什器間隔の同時警告と、搬入の準備完了チェックを一画面に組み合わせる**ことで、当日の忘れ物と設営直しを減らせるかを試す。

## 機能
mm指定の天板と余白、什器の追加/編集/ドラッグ/回転/複製、間隔・はみ出し・会計帯の警告、面積率・搬入チェック、自動仮配置、JSON入出力、CSV・SVG・印刷、Undo、端末内保存。完全オフライン。JSONは端末外への手動バックアップに利用する。

## 検証
手元ソース: Node.js計算/境界テスト **37/37合格**、Chromium + Playwright 画面操作 **33/33合格**。ローカルfile://遷移は実行環境で遮断されたため同一HTML/CSS/JSをインライン展開して検証。端末保存の持続性・実プリンター出力・現物との照合は未検証。自動配置は近似アルゴリズム。重量/転倒/火気/会場規則は評価対象外。

## 起動
index.htmlをブラウザで開く。ビルド・APIキー・外部ライブラリ不要。外部への個人情報送信、API課金、有料サービスなし。MIT License。
