# 異本しおり / IHON SHIORI

**日本語の版・稿本を混ぜずに行単位で照合し、証拠資格を添えた点検メモを出力する、通信不要のWeb MVP。** 2026-11-20制作。MIT License。架空の原文を初期デモに使用。

## ターゲット・選定理由

日本文学・古典籍の研究者、大学生、アーカイブ担当者、文芸誌・独立出版の編集者。比較した箇所について、「どの版の何行か」「どの種別の資料か」「未確認か、原資料を再確認したか」を簡便に記録したい人向け。

国内では国文学研究資料館が **2026-07-28** に国書データベースの書誌登録 **100万作品突破**を報告し、同機関のDDH事業は2024～2033年度を対象にテキスト化・研究基盤の拡充を進めている。また **2026-10-01** に2026年のテキスト研究国際集会を案内。これはデジタル校訂の周辺活動・資料基盤の存在を示すが、本アプリの市場規模・課金需要を裏付けない。

- 日本市場・資料基盤: [国文学研究資料館 DDH（2026-07-28 / 2026-10-01）](https://www.nijl.ac.jp/ja/ddh/)
- 国内の実装状況: [TEI研究会 TEIviewer4EAJ（2026-03-20版）](https://tei.dhii.jp/teiviewer4eaj)
- 海外の競合: [CollateX](https://collatex.net/)（複数版本のトークン照合・異文グラフ等）、[Juxta Commons / TEI Wiki](https://wiki.tei-c.org/index.php/JuxtaCommons)（版本比較・視覚化・TEI出力）

## 差別化仮説

CollateXやJuxtaは本格的で、行対応・異文照合自体は既に存在する。国内TEIviewerも校異表示に対応する。**新規性は差分アルゴリズムではない。** 日本語・アカウント不要・通信不要で、**原本画像の転記／電子翻刻／校訂本文／翻訳**の区別、二版を保持した非破壊比較、機械判定と人間の確認状態の分離、独立した点検メモの出力までを一画面でつなぐことが、入門者の誤認と転記時の取り違えを減らすという仮説。競合に対する成果、継続率・収益性は未検証。

以前のアプリ群（字幕校正、商品CSV差分、資料の引用系譜、画像印刷の版ずれ、写真整理など）とは異なり、**同一作品の二つの本文版を混在させずに原文と確認判断を保存する文献照合作業**が対象。

## 実装機能

- A/Bの版名・資料種別・出典所在・本文を入力、UTF-8 TXTから読込。初期状態で架空の二稿を比較できる。
- 1行単位の動的計画法による順序付き近似照合（各160行・25,000文字まで）。一致／本文差／Aのみ／B追加／表記差候補を表示。
- NFKC＋句読点・空白除去による**表記差「候補」**の表示。原文そのものは改変せず両欄に保持し、機械的同一性を断定しない。
- 行番号、差異箇所の接頭・接尾ハイライト、絞り込み、差異ごとの未確認／差異を記録／原資料を再確認／保留と任意メモ、点検進捗。
- **CSV**（表計算ソフトの式注入を軽減）、**Markdown点検メモ**、**JSONプロジェクト**の出力・読込。利用者が明示的に操作した場合のみlocalStorageに端末保存。印刷表示。
- DOMはユーザー入力を`textContent`で描画。第三者ライブラリ・CDN・分析SDK・ネットワークAPI・OpenAI API・有料サービスは使用しない。

## 使用方法

このフォルダの `index.html` と `engine.js` を同じディレクトリに置き、`index.html` を開いてください。ファイル読込や端末保存がブラウザの制約で動作しない場合は、同じディレクトリで `python3 -m http.server 8000` を実行し `http://localhost:8000/` にアクセスします。デモ本文は著作権上の実在作品ではないオリジナル例文です。

## 検証（2026-11-20）

- `node --test engine.test.cjs`：**25/25 合格**。行の挿入・削除・置換、表記差候補、Unicode、CSV式注入対策、Markdown、入力上限、JSON検証と注記の不正引継ぎ防止、**ランダム450組**に対する原文順序・内容の保存を検査。
- `python browser_test.py`：**Chromium 21/21 項目合格**。差異表示、フィルター、点検状態、CSV/Markdown/JSONダウンロードと内容、本文変更、スマートフォン表示、JSエラーなしを確認。`desktop.png` / `mobile.png` は実ブラウザで撮影。
- ブラウザ試験は管理環境のネットワーク・ローカル遷移制限に合わせ、**`index.html` と `engine.js` の同一ソースを一時的にインライン展開して実施**。`file://`での直接起動、ブラウザ再起動後のlocalStorage永続性、実印刷、100以上の実史料に対する対応精度は未検証。

## 制約・検証すべき次の仮説

行対応は最短編集経路を近似する**自動提案**。段落移動・改行規則の変更・書写の錯簡・他の写本を参照した転写・異字の専門的同定には非対応。原文の行区切りの妥当性、資料画像と電子翻刻の一致、本文が後代に改変された事実等はアプリでは判定できない。表記差候補は削除された句読点自体が重要な場合もあるため、**同一認定しない**。実史料を扱う際は著作権・利用条件を確認すること。

5～10人の学生・校訂担当者に二つの短文を照合してもらい、「出典の取り違え」「未確認差分の見落とし」「記録にかかった時間」を既存の手作業・CollateX等と比較する。改善が見られなければ差別化仮説を撤回する。
