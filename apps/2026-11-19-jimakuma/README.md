# 字幕の間 / JIMAKU-MA

日本語SRT/VTT字幕の「読む時間・文字の詰まり・キュー重複」を見える化し、ブラウザ内で修正する軽量な字幕品質ワークベンチ。外部API、利用者登録、課金、音声アップロードは不要です。

## 対象と選定理由

動画編集者、企業の社内研修・商品動画担当者、字幕を納品前に見直す個人制作者。矢野経済研究所は**2026年10月2日**、2025年度国内動画コンテンツビジネス市場（主要5市場合計）を **1兆1,474億円**、動画制作サービス市場を **4,364億円** と推計。これはアプリ固有の利用需要を示す数字ではなく、周辺市場の状況です。

## 国内外の競合・差別化仮説（2026-11-19確認）

- **国内向け**：[Vrew](https://vrew.ai/ja/feature/srt-export/) はAI字幕制作、多国語字幕、SRT出力に対応。
- **海外**：[Subtitle Edit](https://www.nikse.dk/subtitleedit) は波形付きの多機能字幕編集・同期ツール。[Subtailor Subtitle Line Breaker](https://subtailor.com/subtitle-line-breaker/) はブラウザ内で改行・CPS検査・空き時間への延長も対応。単なるCPS検査やローカル処理は独自機能ではありません。
- **差別化仮説**：日本語を**全角換算**（半角英数0.5）で扱い、配信用の厳格参考値とSNS向け調整値を切り替えながら、**重複・速度・行幅と「次の字幕までの余白」**を一画面で編集できる、登録不要の小さなワークフローが、日本の小規模制作者に使いやすい可能性。利用意向や有料転換は未検証。
- **根拠**：[Netflix日本語タイムドテキストガイド](https://partnerhelp.netflixstudios.com/hc/en-us/articles/215767517-Japanese-Timed-Text-Style-Guide) は日本語字幕について全角13字/行、2行、1秒あたり最大4文字、最短0.5秒を掲げる。これはNetflixの納品形式・他の多数の規定を満たす保証ではありません。SNS向け8全角換算字/秒・18全角換算字/行・最短0.7秒は**本アプリ独自の編集用参考値**で公式規定ではありません。

## 実装機能

1. SRT / WEBVTTのファイル・貼り付けインポート（2MB、最大5000キュー）、UTF-8 BOM対応、エラー箇所の報告。
2. 日本語全角換算によるCPS、1行幅、最大行数、最短/最長表示、隣接キュー重複の検査。
3. キューごとの文章・開始/終了時間編集、文章の自動折り返し、2キューへの分割、次キュー前の空き時間への延長、キュー追加/削除、30回までのUndo。
4. 音声なしの再生タイムライン・テキストプレビュー、時間オフセット一括適用。
5. SRT / VTT / JSONダウンロード、JSON復元、localStorage自動保存、PC/モバイル画面。

## 起動

`index.html` を直接ブラウザで開く。`style.css`・`engine.js`・`app.js` を同じディレクトリに配置すること。サーバー・ビルド・外部フォントは不要。青緑の「サンプルを試す」を押すとテスト字幕を開けます。

## テスト

- `node --test engine.test.cjs` : **18 / 18 合格**。時刻、SRT/VTT解析・再出力、幅換算、速度・重複、改行、分割、延長、時刻シフト、300キューの往復を検証。
- `python browser_test.py` : **27 / 27 合格**（Chromium / Playwright）。サンプル、編集、プリセット、改行、分割/Undo、ダウンロード、JSON復元、プレビュー、端末保存の模擬、モバイル横はみ出し、コンソールエラーを確認。管理環境の直接`file://`遷移が遮断されたため、同一HTML/CSS/JSを`set_content`でインライン化。localStorageはモック。**一般ブラウザの直接ファイル起動・本物の永続化・実際の映像同期・字幕納品仕様適合は未確認。**
- `node --check engine.js && node --check app.js` : 構文検査合格。

## 制約とプライバシー

文字幅・自動改行は近似計算で、文意の区切り、字幕の安全領域や音声との同期を自動保証しません。WEBVTTの位置設定・音声話者や特殊タグはインポート時に一部失われます。変換・編集はブラウザ内で行い、通信APIを呼びません。ブラウザのlocalStorageに字幕テキストが保存されるので、共用端末では「初期化」し、必要ならブラウザ側のサイトデータも消去してください。
