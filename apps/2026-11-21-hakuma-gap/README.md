# 拍間 GAP / HAKUMA GAP

「音がある時」と「無音が続く時」で、自分の拍の先行・遅延がどう変わるかを可視化する、完全ローカルのタップ練習Webアプリ。

## ターゲットと選定理由

対象：ドラム、ピアノ、吹奏楽、アンサンブルの学習者／個人指導者。ピティナの2025年協会データは会員17,919名、イベント参加100,239組を報告しており、日本国内に音楽学習活動の継続的基盤があることを示す。ただし市場全体の利用者数でもアプリ購買需要の直接証拠でもない。

日本の競合 Metronoamee はタップタイミングをグラフとスコアで表示。海外の Gap Click by Benny Greb と Enyo Technologies の Rhythm Trainer は、クリックを無音化する練習を提供済み。**「無音メトロノーム」「タップ採点」単独では新規機能と主張しない。**

## 差別化仮説

音あり・無音・クリック復帰1拍を独立集計し、無音の「第何小節目」で早まり／遅れが進んだかを比較する。日本語の一画面で体験デモ、手動の入力遅延補正、誤タップと欠落の区別、再現可能なJSONと拍ごとCSVを登録不要で提供。セッションはローカル保存するためマイク・演奏音・個人名の収集を要しない。実市場需要・継続率・課金意向は未検証。

## 実装済み

- 40–220 BPM、2–7拍子、1–8小節のクリック／無音、1–8巡を設定
- Web Audio APIで先読みスケジューリングしたクリック、カウントイン、無音小節の画面表示
- クリック・SPACEによるタップ採録、最寄り拍への対応、重複・欠落・範囲外の識別
- ±200msの手動遅延補正、平均絶対ずれ／平均符号付きずれ、一致率
- 聞こえる拍・無音拍・復帰1拍別の集計、無音小節順の偏り分析と散布図
- 模擬タップで結果をすぐ試せるデモ、CSV、JSON、JSON復元、印刷、localStorage保存
- 外部JavaScript、会員登録、OpenAI API、課金サービス、外部送信なし

## 起動とテスト

index.htmlをブラウザで開く。ビルド不要。同じフォルダにengine.jsを置く。

- Node.js: node --test engine.test.cjs — **26/26 合格、追加で擬似乱数500設定の保存則検証に合格**
- UI擬似DOM統合試験：**13/13合格**（GitHub上の実際のindex.htmlのインラインJavaScriptを実行し、デモ・グラフ・エクスポート操作・保存・設定編集・クリア・開始／停止を模擬）
- Chromium: python browser_test.py を同梱。**実ブラウザでの実行は未検証**（実行環境にアプリHTMLのローカルコピーを用意できなかったため）。Web Audioの再生タイミング、ダウンロード、永続保存、印刷も実機未検証
- スマートフォンや各種Bluetooth機器ではWeb Audio再生と入力時刻のずれが異なる。手動補正は参考用で、自動レイテンシー校正や実演技能の測定精度を保証しない。
- 音が出ない場合でも視覚タップは可能。ブラウザがバックグラウンドになると処理と音声タイミングが変わる場合がある。
- 途中終了の未経過拍を低得点として扱わず、計測を破棄する。練習の経過表示と完走結果を区別する。
- サンプルタップは決定的な模擬データであり、実測ではない。
