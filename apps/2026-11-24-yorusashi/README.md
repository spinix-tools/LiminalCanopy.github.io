# 夜差し / YORUSASHI
2026-11-24制作。機械式腕時計の7日間の静置姿勢を計画する、登録不要のオフラインWebアプリ。index.htmlをブラウザで開く。追加API・有料サービス・マイク・個人情報収集なし。

## 対象・市場・競合
対象：機械式時計愛好者、複数の姿勢で歩度を実測できるユーザー。セイコーは姿勢、携帯時間、温度、巻き上げ量の影響と1週間程度での精度判断を説明している。日本時計協会の2025年国内腕時計市場推定は1兆2,919億円（前年比1%減、全方式）。同協会による日本メーカーの機械式完成品輸出数量は前年比18%増。スイス時計協会の2025年輸出総額は256億CHF（前年比1.7%減）。関連市場の指標でありアプリ需要・支払意思は未検証。

差別化仮説：測定器・記録アプリとは別に、曜日ごとに異なる着用時間と各姿勢の歩度上下限を入力し、7日間の朝夕の最悪ずれまたは最終ずれを全探索で最小化する。両目的の比較、固定姿勢との区間比較を無料・オフラインで提供。競合全機能の網羅確認はしていない。専用ブランチの既存アプリ一覧と関連8件のREADME冒頭を確認し、同用途は見つからなかった（全ソース未照合）。

## 実装と制限
各日を着用と静置に分け、歩度区間×時間/24を累積する。最大6^7=279,936通りを探索。主目的の同点は副目的で比較（許容誤差1e-9秒）、なお同点なら探索順。許容ずれは評価用で制約ではない。現在のずれも最大値に含む。上下限は利用者設定の決定論的区間で統計的信頼区間ではない。温度、巻き上げ、磁気、停止、実測誤差などは別途考慮が必要。分解や調整は行わない。安全に置ける姿勢のみ使う。CSV・印刷対応。

## テスト（2026-11-24）
`node test.cjs`：ランダム100条件、独立端点計算と78,615候補の照合、最適値一致、入力拒否4件、最大279,936候補の探索に合格。サンプルでは固定姿勢の最大ずれ46.25秒→推奨8.42秒、7日後の最悪ずれ46.25秒→7.58秒（架空入力）。Chromiumで同一HTMLをインライン実行し初期表示、目的切替、CSV、無効入力、リセット、390px幅を確認。JS例外・外部HTTP要求0件。環境のfile URL制限で直接ファイル遷移は未確認。実機での効果・需要・収益性は未検証。
