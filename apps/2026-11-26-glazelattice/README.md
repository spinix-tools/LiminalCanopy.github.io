# 釉格 / GlazeLattice
2026-11-26 | 湿式釉薬の三角調合・計量計画 MVP

**対象・選定理由:** 陶芸教室、個人工房、美術大学。京都美術工芸大学の2022年10月17日の記事は200種以上の釉薬調合実習を紹介。岐阜県セラミックス研究所の釉薬カラーライブラリーは約15万点を収録。海外のGlazyは三角ブレンド表と小規模テストの資料を提供する。直接の利用者数や支払意思は未検証。

**競合・差別化仮説:** 国内向けの釉式Yushikiは釉式・組成計算、Glazecalcは三角調合の計量表、Glazyはブレンド表、GlazeIQは三角グリッド・比重計算を提供。本MVPは既存の混合可能な湿式原液3種について、固形分濃度の差、秤の表示刻み、全試験の在庫消費を一体化し、調合比のずれを各試験で表示する。競合に同等機能がないと断定しない。教室での一括試験の準備時間・配合ミスの削減を検証したい。

**使い方:** index.htmlをブラウザで開く。3原液の固形分質量％と在庫、分割数、目標乾燥質量、刻み、許容誤差を設定して計量表を作成。6/10/21/66試験の三角配置を選択し、個別・一括表、CSV、印刷を利用。入力の変更で旧結果は非表示。外部依存・通信・永続保存なし。

**計算:** 各試験の目標乾燥質量D、目標比率w_i、固形分率f_iに対し理想湿質量D*w_i/f_iを求め、正の成分は最小1刻みを維持して最も近い表示刻みに丸める。実現比率は丸め後の乾燥質量を合計で割る。最大絶対比率誤差（pp）を判定。個別成分の丸めであり、全体比率や在庫を同時最適化するものではない。サンプル21試験の必要湿質量はA 175.00g、B 127.10g、C 100.20g、最大誤差0.28986pp。

**検証:** `node test.cjs` 8/8合格、固定乱数200計画・5,150試験の刻みと質量収支照合。`python browser-test.py`（Playwright、Chromium）で選択、CSV実保存、在庫不足、粗い刻み、66試験、不正入力、リセット、390px幅を確認。JS例外・HTTP要求0。file://は環境の管理ポリシーで拒否されたため、同一HTMLをインライン読み込み。実印刷・実釉薬・他ブラウザ未検証。混合適合性、焼成条件、発色、食品接触安全性、実際の秤の精度は対象外。

**重複調査:** 専用ブランチのmainとの差分300ファイル・51アプリディレクトリ、glaze/釉薬/陶芸/triaxialのコミット検索（0件）、直近の制作履歴を確認。全既存ソースの網羅比較は未実施。
