# ハコ余白 / HAKOYOH — 梱包を発送前に試す

**2026-11-19 / Hourly App Lab / MVP**

## 誰のため？
個人のフリマ出品者、ハンドメイド販売者、少人数ECチームが、複数商品のまとめ発送で「今ある箱に入るか」「緩衝材を加えたら入らないか」「見積送料と箱代はいくらか」を発送前に試すツール。

## なぜ選んだ？ 日本・海外の需要と競合
- 2026年10月21日公表の経済産業省「令和7年度電子商取引に関する市場調査」は、日本の**2025年CtoC-EC市場を2兆6,870億円**と推計。2026-10-22の業界記事で確認。これは梱包アプリ自体の需要・売上を示す数字ではない。
  - https://netshop.impress.co.jp/index.php/n/2026/10/22/16905
- ヤマト運輸は宅急便サイズを三辺外寸合計と実重量の双方で定める。発送前に箱の内寸と料金算定時の外寸を分けて見る価値がある。
  - https://www.kuronekoyamato.co.jp/ytc/customer/send/search/payment/size/
- 国内競合 **MercaFee** は送料最適化と梱包コストを提案。**TETRA** は3D箱詰めと箱選びを提供。海外の **BoxVolume** は3D梱包、複数種類の荷物と箱選定に対応。既存競合の機能水準は高く、独占的な新規性は主張できない。
  - https://www.mercafee.com/
  - https://apps.apple.com/jp/app/tetra-%E7%AE%B1%E8%A9%B0%E3%82%81-%E6%A2%B1%E5%8C%85%E3%82%B7%E3%83%9F%E3%83%A5%E3%83%AC%E3%83%BC%E3%82%BF%E3%83%BC/id6822309334
  - https://boxvolume.com/en

## 差別化仮説
**個人の「手元の箱」と「入力した送料」に絞る。** 箱の**内寸で配置可否**、**外寸＋箱重量＋予備重量で参考配送サイズ**、商品ごとに**緩衝材の両側余白**と**上下固定**を考慮。送料・材料費を自分で更新し、登録なし・完全ローカルでSVG図面と配置表を保存する。需要、支払意思、競合に対する優位性は未検証。

## 実装済み機能
- 商品20種・計60個、箱12種まで追加・削除・編集。寸法・数量・重量・上下固定、箱の内寸・外寸・耐荷重・料金・箱重量を扱う。
- 回転候補（最大6種類）と3つの並べ順を使った近似3D配置。箱の内部に収まり、商品同士が交差しない候補を探す。配置できる候補を入力費用順で表示。
- 箱ごとの参考配送サイズ、重量、費用、利用可能な空間の概算、未配置点数を表示。
- SVGの擬似3D配置図と段階表示、座標付き配置手順。CSV配置表、SVG図面、JSON設定のエクスポートとJSONインポート。
- ブラウザ内localStorageに保存。紙への印刷に対応。外部API・課金・ユーザー登録・秘密情報の収集なし。

## 使い方
`index.html`をブラウザで開く。商品と箱を編集し、緩衝余白・重量・参考送料を調整。候補を選び、図と手順を確認する。初期価格は**比較用サンプルであり、運送会社の実際の料金ではない**。

## 検証（この環境、2026-11-19）
- `node --test engine.test.cjs` → **12/12 合格**。寸法チェック、回転、境界・交差、余白、重量、料金順位、外寸/重量の参考サイズ、CSV/SVGエスケープなどを検査。
- 同テスト内の**乱数300ケース**で配置済み直方体の非重複・箱外へのはみ出しなし、配置数の整合を確認。
- `python browser_test.py` → **43/43 Chromiumアサーション合格**。追加削除・数値編集・候補切替・段階表示・JSON入出力・CSV/SVG保存・エラー処理・モバイル表示を検証。
- JavaScript構文検査：`node --check engine.js`, `node --check app.js` → 合格。
- **環境制限**：管理環境で `file://` とHTTP(S)直接遷移が遮断されたため、実際のHTML/CSS/JSの内容をChromiumへインライン投入してテスト。`localStorage`は模擬。通常ブラウザでの直接起動、保存永続性、実物梱包、実配送、実機印刷は未検証。

## 大切な注意
このアプリの3D配置は**近似探索**で、最適な詰め方の保証はありません。「未配置」は本当に物理的に入らない証明ではありません。SVGは擬似3Dの確認用です。緩衝材の圧縮、形状の歪み、商品保護、破損防止、箱の耐久性、サイズ区分、配送条件は現物と配送会社の最新規約で必ず確認してください。60〜200の参考サイズは一般宅急便表の目安であり、配送サービス選択や運賃照会はしていません。
