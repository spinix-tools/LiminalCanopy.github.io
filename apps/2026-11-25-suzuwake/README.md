# 鈴分け / SUZUWAKE
2026-11-25制作。学校・地域の小編成ハンドベル指導者向け、欠席時の担当再配分を比較する日本語Web MVP。

## 市場・競合・差別化
- 日本：[日本ハンドベル連盟](https://www.handbell.jp/festival) は2026年10月25日に第50回全国フェスティバルを開催日として掲載。過去には1日に約50チームが演奏した年もある。国内の専用自動割当ツールは今回の検索では確認できず。
- 海外：[Handbell Musicians of America](https://handbellmusicians.org/get-involved/become-a-member/) は団体・学校・個人向け会員制度を提供。[Martellato](https://apps.apple.com/gb/app/martellato/id6824465537) は担当表・欠席カバーを提供。[Bellsheet](https://saasmaster.net/extensions/bellsheet) は担当提案・衝突検出・欠席カバーを掲げる（調査時未公開）。
- 差別化仮説：欠席者の音だけ移す案と全員の再割当案を厳密探索で比較し、同時発音の超過数が最小になる条件で在席者の変更音数を最小化する。練習済みの担当をどこまで崩すべきか判断しやすくする。独占性、直接需要、収益性は未検証。次は指導者5人に欠席時の再配分時間を比較してもらう。
- 専用ブランチの202ディレクトリ名と音楽関連7件のREADME冒頭を確認。譜めくり・移調・音響・稽古割当とは用途が異なる。全ソース精査はしていない。

## 操作とモデル
`index.html` をブラウザで開く。3〜5人、最大8音・48時点。音名と現行担当、同時音、欠席者、1人の同時発音上限を入力して検算。休符は `-`。同一音の担当は固定。候補を全探索し、超過音数→在席者の変更音数の辞書式順で最小化。同点は入力順・担当番号順で決定。CSVと印刷に対応。例では通常0、欠席音だけ移すと2、全変更許可で0、在席者の変更音数1（64候補）。
持ち替え時間、ベル重量、技法、音域別技能、同音異名の統合、移動・複数欠席は対象外。衝突0は演奏可能性を保証しない。音の持続は手が塞がる時点にも記入する。外部ライブラリ・API・課金・送信・アカウントなし。個人名不要。
