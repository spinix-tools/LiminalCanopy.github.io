# 版合わせ / HANAWASE
2026-11-24 — 2色刷りの版ズレ耐性を検査する、ブラウザ完結のMVP。

## 対象・選定理由
リソグラフ・シルクスクリーンの小規模工房、ZINE作家、印刷教材制作者。隣接する色がずれて紙が見える問題に対し、重ね幅を増やすと欠けは減る一方、混色面積が増える。入稿前にその得失を比較したい人向け。

## 日本・海外の市場と競合（2026-11-24確認）
- 国内：レトロ印刷JAMは版ズレがランダムに起こることを説明（https://retroinsatsu.com/about/quality/）。理想科学は2023年の春のZINE祭りでリソグラフ体験に協力（https://www.riso.co.jp/release/20230428.html）。
- 海外：LA ART BOOK FAIR 2026ではRISO Studio Artsが実演ワークショップを案内（https://laabf2026.printedmatterartbookfairs.org/riso-studio-arts）。
- 競合：日本語対応ProDesignerは分版・重ね刷り確認（https://www.prodesigner.app/ja/tools/risograph/）。海外のrisoは位置ズレの再現・合成（https://github.com/jackbush/riso）、Ink Pressは分版・版ズレ・出力（https://aikizi.com/lab/ink-press）。トラッピング自体は既存の印刷技法。
- 差別化仮説：ランダムな見本の生成だけでなく、設定した整数平行移動を全探索し、接合欠けの許容値を満たす最小重ね幅と、外周を含む欠け・重なりの最大値を比較する。市場規模・利用意向・収益性・競合優位は未検証。
- 重複確認：既存192アプリ名と関連15件のREADMEの冒頭を確認。折順・折覧の面付け、橋守の型紙破損、刷り分けグラフの系列識別とは用途が異なる。全ソース比較は未実施。

## 操作
index.htmlをブラウザで開く。サンプル・ブラシ編集・A/BのPNG読み込み（各10MB以下）から80×56セルの二値版を用意し、セル幅、軸ごとのズレ（0〜5セル）、許容接合欠けを指定。全方向を検査し、幅とX/Yを変更して前後を比較。CSVと検査用二値PNGを保存できる。通信・外部API・登録・追加課金なし。入力はブラウザのメモリだけに保持し、永続保存しない。

## モデルと限界
固定Aと移動B。元Bのうち元Aからチェビシェフ距離r以内かつA外のセルを接合域とする。Aを元B領域に限定して距離tまで拡張（t=0..r）、Bを各軸-r..rに移動し、元のA∪Bに対する欠け・接合欠け・重なりを数える。許容値を満たす最小tを選ぶ。接合域外の欠けは残り得る。最大値の発生位置は指標ごとに異なる。設定範囲の整数移動のみ。回転、伸縮、網点、実際の混色、物理的な印刷精度、任意の原寸版出力は未対応。PNGは固定解像度に変形し二値化する検査用画像であり入稿用ではない。実印刷での検証なし。

## 検証
- `node test.cjs`: 固定6アサーション、乱数250図案・741幅を独立全探索と照合し合格。
- `python browser_test.py`: Chromiumで同一HTMLをインライン実行（file URLは環境ポリシーで拒否）。サンプル、最悪位置、CSV・2枚のPNG、入力制限、消去、PNG読み込み、編集、390px幅、HTTP要求・JS例外ゼロを確認。外部ライブラリはアプリに不要。テストのみNode.js、Python、Playwright、Chromium、Pillowを使用。
- サンプル：0.5mm/セル、相対移動各軸±3セル、49移動×4幅。接合欠け最大141→0、全欠け最大165→141、重なり最大131→338セル。選択幅1.50mm。実機の推奨値ではない。
