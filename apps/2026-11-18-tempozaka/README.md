# テンポ坂 / TEMPOZAKA

**作成日:** 2026-11-18（日本時間）　**種別:** 単一ページ・ブラウザ完結型MVP　**ライセンス:** MIT

## 誰の課題を解くか

独学のギター・ピアノ・ドラム練習者、音楽教室の講師、吹奏楽や合奏の個人練習者。曲の難所を「ゆっくり確認 → 徐々に加速 → 目標速度で反復 → 無音休憩」の順に練習したいが、メトロノームを毎回手で変更したくない人。

## 市場を調べて選んだ理由（公開情報）

- **日本:** クロス・マーケティングが2024-08-21に公表した20〜69歳向け調査では、楽器演奏経験ありは54.1%。対象とした調査の結果であり、アプリ市場の需要率ではない。[元資料](https://www.cross-m.co.jp/news/release/20240821)
- **日本:** ヤマハ音楽振興会は2025-07-02、2025年7月からのレッスン刷新とデジタル教材導入を発表。[発表](https://www.yamaha-mf.or.jp/newsroom/20250702-001/)
- **海外の競合:** [True Metronome の Tempo Trainer](https://truemetronome.app/features/tempo-trainer/) は段階的なBPM上昇を提供（ネイティブアプリのPro機能）。[Real Drum Metronome](https://www.realdrummetronome.com/lp/progressive-tempo) にもテンポ自動変更・カスタム段階がある。[Soundbrenner](https://www.soundbrenner.com/blogs/articles/practice-tracking) には練習記録・目標・セッション管理がある。**テンポ自動増加そのものは新規ではない。**

## 差別化仮説（要検証）

**日本語・登録不要・ローカル実行**で「曲単位の連続した練習ブロック」を作成できる点。小節単位の漸増・減速、拍子と2/3/4分割、無音休憩、見通しが立つ総時間とBPMグラフ、次ブロックへのスキップ、JSON持ち運び、CSV練習表をひとつの画面に統合する。個別機能には先行例があるため独占的な新規性は主張しない。楽器を演奏する人への利用テストで、再利用率と練習完了率が改善するか検証すべき。

## 実装済み機能

- 3種類のサンプルプラン。ブロックの追加・削除・入替・編集（最大16ブロック）
- BPM 30〜260、1〜48小節、2〜12拍/小節、1〜4分割、加減速、無音休憩
- Web Audio APIによるクリック音合成（1拍目強調）、カウントイン、再生/停止、ブロックスキップ、音量調整
- TAPテンポ計測、小節ごとの予定BPMグラフ、時間・進捗・拍の表示
- JSON読込/出力、小節単位のUTF-8 BOM付きCSV出力、明示操作でlocalStorageに保存
- 画面内のデータは通信せず、マイク・録音・アカウント・外部ライブラリを使用しない

## 使い方

`index.html`, `engine.js`, `app.js` を同じフォルダに置いて、`index.html` をChromeなどのモダンなブラウザで開く。サンプルを選ぶかブロックを編集し、**再生**を押す。自動音声再生制限により、最初の再生にはユーザー操作が必要。JSONを出力すれば別端末へ設定を移せる。

## テスト（この実行）

- `node --test engine.test.cjs`: **48/48 合格**。計算、加減速、拍タイミング、休憩、カウントイン、保存データ検証、上限・不正値、CSVなど。
- `python browser_test.py`: **49/49 合格**。Chromiumで編集、移動、サンプル切替、保存、JSON/CSVファイル出力、再読込、音声再生/停止/スキップ、モバイル表示とエラー監視。
- 制約: この実行のChromiumは `file://` とローカルHTTPナビゲーションが制限されたため、実HTML・CSSとJSをページへ直接読み込み、localStorageをモック。**実ファイルでの配信・保存持続性、物理スピーカーからの出音と音響精度、バックグラウンド/省電力時の再生は未検証**。WebAudio開始とスケジューラの状態遷移のみブラウザ上で確認。
- BPMは小節の先頭で線形補間した値へ更新する階段式。厳密な連続テンポランプ、楽譜の拍価解釈（複合拍子）、演奏の採点・録音は非対応。

## プライバシー・費用

外部API/アナリティクス/サーバー送信/有料サービスは使用せず、個人情報は要求しない。保存ボタンを押した場合のみプラン設定を端末内のlocalStorageへ保存。JSONファイルは利用者が明示的に取得する。追加のOpenAI API課金は発生しない。
