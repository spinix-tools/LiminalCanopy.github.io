# 転換秒 / TENKANBYO ↔

小劇場・学生劇団・地域演劇の舞台転換担当者が、各場面の小道具移動に何秒・何人かかるかを計算し、転換枠の超過を発見する、完全ローカルのWebアプリMVP。2026年11月23日制作、MIT License。

## 使い方・実装済み

index.html をブラウザで開き、場面と秒数上限・スタッフ人数、小道具の「開演前→各場面」の置き場所・持ち替え秒数、移動倍率を編集します。

- 5種類の場所の最短ルートから移動秒を算出。位置が変わった道具だけタスク化。
- 長いタスクを優先し、最も手の空いているスタッフに割り当てる近似計画。スタッフごとのガント風バー、所要秒、超過秒、1人増員時の試算、枠内に収めるスタッフ数目安を表示。
- 場面・道具の追加・削除・編集、Undo、JSON保存・復元、CSV書き出し、印刷、localStorage保存、モバイル対応。
- API・アカウント・外部通信・追加のOpenAI API課金・有料サービス・個人情報収集なし。すべての処理をブラウザ内で行います。

## 日本・海外の市場、競合と選定理由（2026-11-23調査）

日本劇団協議会は **2026年7月3日**、「演劇団体調査2025」分析報告を公表。2025年5月に全国800余の団体から回答があり、小規模団体を含む劇団運営の実態を調査しています。これは活動の存在を示す背景指標で、本アプリの市場規模や支払意向を意味しません。

- 日本の周辺市場：[演劇団体調査2025](https://gekidankyo.or.jp/news/news-3054/)
- 国内競合：[Stage Organizer](https://apps.apple.com/jp/app/stage-organizer/id6808857928) は場面ごとの小道具・動線を可視化。[GEKI TOCCA](https://geki.tocca.systems/) は制作タスクとスケジュールを統合。
- 海外競合：[Scenvori: Props Tracker](https://apps.apple.com/jp/app/scenvori-props-tracker/id6826084222) は小道具の場面間の連続性チェック・転換表・担当記録を提供。[Stage Write](https://www.stagewritesoftware.com/) は舞台図、移動、キューを管理。

**差別化仮説：** 所在・担当の記録だけでなく、「転換の上限秒 × 人数 × 作業秒」を即時に比較できる簡易な検算台として、導入障壁を減らすこと。個別機能の新規性や競合優位は確認されておらず、実際の需要・収益性は未検証です。

## 計算上の制限

作業秒＝ceil(場所間の最短経路・仮の歩行秒 × 移動倍率 / 100)＋持ち替え秒。スタッフ1人は1作業ずつ、異なるスタッフは並列として計算する貪欲アルゴリズムで、最適時間や最小人数の保証はありません。動線交錯、暗転、安全、重量物、演者による移動、複数人での運搬、器具の設置制約は未評価。実際の転換は現場リハーサルで検証してください。
