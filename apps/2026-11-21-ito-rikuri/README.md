# 糸りくり / ITO RIKURI

**手元に残った刺しゅう糸の長さを入力し、図案を描きながら糸不足を見つけ、買い足さずに作れる配色を試すオフラインWebアプリ。** 2026-11-21 JST制作。

## ターゲット・選定理由

ターゲットは、クロスステッチ初心者、少量の余り糸を使い切りたい手芸愛好者、地域手芸教室。2025-11-13にGMOペパボが発表したminneの2025年トレンドは手づくり・かぎ編みへの関心と実用品を報告。ただしクロスステッチ単体の需要、課金意向、アプリの成功確率を示すものではない。2025年7月開催の刺しゅうアートフェスティバルは初開催で延べ2,000名超と主催者が公表。海外のクロスステッチ専用制作・在庫アプリが成立していることは、このワークフローに継続的な課題があるとの示唆になる。

**差別化仮説**：多機能な写真変換・在庫台帳ではなく、小作品向けに **6本束の「実際の残りcm」を入力 → 1目描くごとに糸消費を算定 → 足りない色を在庫に余裕のある色に丸ごと置換 → 記号付き印刷図案を出す** 操作を短く統合する。糸をどれだけ使い切れるかを明示する。優位性・支払意欲・リテンションは未検証。

## 実装

- 4〜64目の任意グリッド（最大4096目）、最大12色。ペン、消しゴム、4近傍の連結領域塗りつぶし、ドラッグ描画、Undo/Redo。
- 各色の名前・表示色・残糸cmの編集、追加・削除。残り糸・必要糸・不足cmの即時計算。
- 糸残量で成立する全色置換候補を選出（RGB近似距離の近い順）。ワンクリック置換。
- 布のカウント（8〜28、主な値の選択式）、使用する糸の本数（1〜6）、ロス率（0〜150%）を設定。完成サイズcmを概算。
- 記号付きSVG図案、UTF-8 BOM付きCSV糸リスト、JSONバックアップ・復元、ブラウザ印刷、`localStorage` 保存。
- ログイン・外部通信・広告・有料サービス・APIキー・個人情報収集なし。依存ライブラリなし。

### 糸量計算

**単位は元の6本束の長さ(cm)**。1つのクロスステッチの糸消費は `((2√2 + 2) × 2.54 / 布count) × 使用本数 / 6 × (1 + ロス率/100)` cm としてモデル化。2本の表の斜め線＋裏の2本の移動を仮定し、末端・渡り・誤りによる損失を可変ロス率で見積もる（初期55%）。標準的な8m×6本の刺しゅう糸に適用可能な比較用近似。14ct・2本取り・ロス55%では1目約0.453cm（6本束換算）、8mあたり約1,767目。実際の糸長は布の厚み、針目の締め方、離れた点への移動、布裏の処理で大きく変わる。糸を購入する場合は余裕を持つこと。RGB距離も実糸の色一致を保証しない。

参考：[Floss Field 糸量の計算と前提](https://flossfield.com/cross-stitch/guides/how-much-floss/)、[The Craft Mat 概算式](https://thecraftmat.com/needlepoint/floss-calculator/)。両サイトの数値には仮定差があり、本アプリは後者の幾何モデルを使用。

## 動かし方

1. ZIPを展開し、このフォルダの `index.html` をデスクトップまたはスマートフォンのモダンブラウザで開く。ビルド不要。
2. 糸を選び、左のグリッドをクリック／ドラッグ。右側で必要cmと残糸を見比べる。
3. 糸が足りない場合は「図案の全マスを置換」を押して結果を再確認。保存はJSON、印刷はPDF保存も可能（ブラウザ依存）。
