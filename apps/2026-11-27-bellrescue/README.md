# BellRescue / ベル分担レスキュー

## 対象・選定理由（2026-11-27）
学校・地域の小規模ミュージックベルチーム、イベント担当者。欠席に伴う担当変更は再練習を発生させる。国内ではベルミントが少人数用楽譜に分担表を付属し、海外には欠席対応を扱う専用アプリがある。年末イベント前の用途を想定するが、検索量・売上・利用者数は未調査。

## 競合・差別化仮説
- 日本: [ベルミント（分担表付き楽譜）](https://bellmint.com/item/8on_xmasmedley)
- 海外: [Martellato（担当表・欠席カバー）](https://apps.apple.com/gb/app/martellato/id6824465537)、[Bellsheet（割当・衝突検査、調査時未公開と記載）](https://saasmaster.net/extensions/bellsheet)
- 本MVP: 既存担当を入力し、欠席者の音を引き継ぐ際の全変更音数を厳密最小化。同数なら参加者の発音回数の二乗和を最小化。競合との同等機能の不存在は未確認。
- 直近の制作履歴、mainとの差分300ファイル（51ディレクトリ）、handbell/bell/ハンドベル/ミュージックベルのコミット検索で明確な重複なし。全アプリ本文の照合は未実施。

## 使い方・仕様
index.htmlをブラウザで開く。担当欄は1行1人、`参加(1/0)|同時音数(1/2)|担当上限|音名`。発音欄は同時に鳴らす音を1行に並べる。最大6人・12音・120行。参加者に全音を重複なく割り当てる。集合DPで各参加者の合法な部分集合を列挙し最適解を復元する。欠席者の音は必ず変更されるため全変更数の最小化は参加者間の追加変更の最小化と等価。変更前後の担当表、移動リスト、発音グループ表、JSON、印刷を提供。入力変更時は結果を無効化する。

## テスト結果
- `node test.cjs`: 固定7ケース（最大規模を含む）、独立全列挙との240ケース照合が合格。
- `python browser_test.py`: Chromiumで初期サンプル（3音変更、うち参加者間1音、衝突0）、JSON実ダウンロード、不正入力、実現不能、結果無効化、リセット、390px幅、JS例外・HTTP要求0件を確認。環境制限によりfile URLではなくHTMLをインライン読み込み。
- 実演、印刷実物、他ブラウザ、需要・収益性は未検証。持替時間・持続音（利用者が各行に記入する場合を除く）・技法・音の重さはモデル外。異名同音は入力側で統一する。未使用音も割当対象。
- 外部依存・API・通信・個人情報収集なし。入力は端末内のみ。
