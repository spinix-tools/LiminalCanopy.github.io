# 電源段取り / DENGEN DANDORI ⚡

キャンプ・車中泊・小規模イベント・停電時の**ポータブル電源の使用順**を試す、完全ローカルで動く静的Webアプリ。単にWhを合計するのではなく、同時に使うAC機器のピークと、24時間の途中で予備電力量を使い切る可能性を分けて表示する。

## 対象・選定理由（調査日：2026-11-20）

- **対象：** 小型ポータブル電源を所有・購入検討する日本のキャンプ／車中泊／イベント担当者、防災備蓄を検討する家庭。海外でも同種の電源計画ニーズが存在すると考えられる。
- **国内の需要シグナル：** ミドリ安全の2026年防災意識調査（全国18〜79歳、1,000人、2026-08-07〜10）では「真夏の停電への対応を具体的に決めていない」が合計90.5%（住宅新報2026-09-04記事）。電源計画ツールの直接的な需要・支払意欲を示す調査ではない。[出典](https://sokuho.jutaku-s.com/news/id/105462)
- **国内競合：** [PowerBanks「防災用ポータブル電源診断」](https://powerbanks.jp/disaster-power-tool/)（2026-06-17公開、2026-10-22更新）では必要Whと同時使用ピークWを分けて計算。[ガジェスト「ポータブル電源容量計算」](https://gajest.com/tools/power-station-calculator/)は家電のW×時間を積算し、効率と余裕を考慮。
- **海外競合：** [Offgridculator](https://offgridculator.com/)には負荷スケジュール、インバーター、サージ、発電計画など詳細な機能がある。[OffGrid Power Planner](https://offgridpowerplanner.com/)はバッテリー・ソーラー・配線まで統合。[RuntimeStation](https://runtimestation.com/calculator)は起動サージ／稼働率を考慮した容量選定を提供。**機能そのものの先行例はある。**
- **差別化仮説：** 複数台のピークを避けるために「動かせる機器の開始時刻の範囲」を直接入力し、AC連続出力と電池予備容量に対する違反を削減する**半自動の段取り調整**を、A/B電源比較と一画面にまとめる。メーカーや商品推薦を介さず、端末内だけで使える。ユーザーテスト・SEO流入・収益性は未検証。
- **過去作との非重複：** 切手配分、コーヒー焙煎、野鳥記録、ボランティア当番、布裁断、Wi-Fi配置、室内音響、水槽水換え、窓結露、菜園播種と異なる「電源運用・使用時間の競合」領域。

## 操作方法と完成機能

1. ZIPを展開して `index.html` を開く（`style.css`, `engine.js`, `app.js` を同じフォルダーに置く）。CDN・サーバー・アカウントは不要。
2. 電源 **A/B** の容量Wh、AC連続出力W、変換効率、初期SOC、予備SOC、AC待機損失、太陽光入力の想定Wと時間帯を編集。
3. 機器の名称、台数、消費W、AC/DC、開始、使用分数を編集。自動移動可なら「最早開始〜最終開始」を指定。固定機器は動かさない。
4. **15分刻み**で24時間の残量／AC同時出力を計算。予備残量を下回るエネルギー不足Wh、AC定格超過分と超過時間を表示。
5. 「自動で段取りを改善」で、移動可能な機器を時間枠内でずらし、対象電源の不足Wh・AC超過を低減。直前の段取りはUndo可能。
6. JSON保存・読込、Excel向けBOM付きCSVレポート、SVGグラフ、印刷、`localStorage`保存。

## 計算と限界

- 15分スロットで、負荷W = Σ(機器W × 台数 × スロット重複率)。電池側の必要電力W = AC機器W / 効率 + (AC使用時の待機W) + DC機器W。
- 時間帯内のソーラー入力Wは一定と仮定。各スロット `次のWh = 現在Wh + (ソーラーW - 必要W) × 0.25` 。上限は定格容量、下限は確保したい予備Whで打ち切り、不足分を別計上する。定格超過時は**警告だけ**で電源遮断は仮定しない。
- 自動段取りは**座標降下型の近似探索**：`不足Wh ×100 + AC超過相当Wh ×25 + 開始時刻移動分 ×0.025` を低減する方向へ最大3巡。全体最適は保証しない。太陽光による充電見込みも概算。
- 突入電流、出力波形、DC端子の最大出力、充電器入力制約、実測デューティ、充電・放電効率の変動、寒冷・経年劣化、保護回路、安全配線、天候の変化はモデル化しない。**医療機器など人命に関わる用途の信頼性判定には使用しない**。メーカー仕様と専門家の指示が優先。

## 収集・費用

外部API、サーバー送信、アクセス解析、外部フォント、課金サービスなし。機器名と設定は任意入力であり、端末内ブラウザストレージにのみ保存し、JSONファイルはユーザー操作時だけ書き出す。秘密情報・個人情報の入力を求めない。
