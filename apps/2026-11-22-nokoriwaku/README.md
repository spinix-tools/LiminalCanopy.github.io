# のこり枠 / NOKORIWAKU 🏷️

A4ラベル用紙の印刷位置と空き枠を手元で確認する、オフラインのWebアプリ。2026-11-22作成。

## 対象と選定仮説
手作り食品・雑貨の小ロット販売、マルシェ・直売所、個人事務所。自宅で少数枚のラベルを作る際、用紙の残った枠・差込内容・プリンタの微調整を一度に扱う作業を短縮する。

### 日本・海外の競合（2026-11-22確認）
- 日本：[ラベル屋さん](https://www.labelyasan.com/guide/)はA-one製品向けの無料作成ソフトで豊富なテンプレートと[CSV差込](https://labelten.labelyasan.com/web/help/7_00-pouring_index.html)に対応。ジャム瓶のラベルも利用例。
- 海外：[Avery Design & Print](https://www.avery.ca/en/help/template-support/how-to-preview-and-print-in-design-print-online-html.html)は任意の印刷対象の選択が可能で、[位置調整](https://www.avery.com/help/article/make-a-printer-adjustment)も対応済み。
- 海外：[Etsy公式](https://help.etsy.com/hc/en-us/articles/360001968348-How-to-Download-and-Print-a-Shipping-Label)もラベル印刷手順を提供。

**差別化仮説**：既存競合にも枠の選択や位置調整はあるため、機能単体の独占ではない。「使わない枠のマーク→少量のラベル文字の割付→次の新品シートへの繰越→実寸SVG」の最短導線と、ログイン不要・オフラインを狙う。**市場規模・収益性は未検証**。

## GitHub版の機能
- 21/10/12/24面のA4プリセットと余白・間隔調整
- 使用済枠のタップ切替、複数ページへの連続割付
- 文字リスト編集、簡易CSV読込とひな形、JSON保存/復元
- mm位置補正、通常・校正用SVG、全ページの印刷プレビュー
- ブラウザ内保存。外部API・通信・個人情報収集なし

リポジトリの`index.html`をブラウザで開く単一ファイル版です。HTML・CSS・JavaScriptを含みます。

**注意**：用紙プリセットはメーカー個別商品の厳密な寸法ではありません。普通紙で試し刷りし、印刷設定はA4/実寸100%を確認してください。**一部が剥がれたラベル用紙の再給紙は危険なことがあります。用紙・プリンター両メーカーが許可していない場合は再給紙しないでください。** 食品表示などの法令適合も保証しません。

## 完全版と検証状況
このリポジトリの単一HTMLは、操作可能な**軽量独立実装**です。一方、同時に提供したZIPには、分割した可読ソース（`engine.js`など）、境界値テスト、拡張CSVパーサ、縦横倍率補正、文字省略検出を備えた**完全版**が収録されています。**GitHub版とZIP版はソースが同一ではありません**。

ZIP完全版の検証：Node.js **32/32合格**、固定シードの割付検証 **600系列合格**、Chromium UI **39/39チェック合格**、テスト環境での外部HTTP通信・JS例外 **0件**。GitHub単一HTML版は保存と再取得の検証対象ですが、ブラウザ操作自体の同一テストは未実施です。

Chromiumの管理環境では任意のURLとfile://への直接移動がブロックされたため、完全版は同一ソースをインライン展開してテストし、localStorageを模擬しました。印刷実機・長期保存は未検証です。MIT License。
