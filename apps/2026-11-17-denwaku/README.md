# でんわく / DENWAKU — 電源の時間割 ⚡

**小規模催事・マルシェ・展示ブース向け：複数機器の稼働時間を考慮して電源回路の同時消費電力を見える化するWebアプリ。**

## 使い方

`index.html` だけで起動する完全ローカル版（外部CDN/APIなし）。各「独立回路」の計画上限（W）と機器ごとの消費電力・台数・稼働開始/終了時刻を入力し、ピーク時間帯と超過を確認。「時間帯で自動割付」で近似的に分散し、必要に応じて回路割付を手動変更。JSON読込/保存、CSV、印刷、端末内保存が使用できます。

**注意：** 物理の電源容量の安全認定ではありません。ブレーカー・コンセント・配線などの独立性を会場に確認してください。突入電流、力率、ケーブル、上位回路、漏電保護、発電機を未計算。通電判断は会場責任者や有資格者に依頼してください。サンプルの1200Wは仮の計画値であり、安全基準ではありません。

## ターゲット・選定理由

日本のマルシェ/小規模イベント出店者や学校行事・展示会担当者。国内の[SS.Sound必要電源容量シミュレーター](https://ss-sound.jp/power-simulator.html)は機材のW計算と回路割付に対応し、[アイフィルムの電源計算](https://www.ifilm.co.jp/tools/power-ampere/)も存在します。実際の出展要項では機器のWを申請書に記入するよう求める事例があります。海外には[PowerSense](https://squaresmile.de/powersense)、[LVA Power Planner](https://www.lvapowerplanner.com/)、[NADJ Power Planner](https://www.nadj.org.uk/power-planner/)などがあり、電源計算そのものの新規性はありません。

## 差別化仮説

**小規模ブースに特化して、定格Wの単純な合計だけでなく、時間帯別ピーク・近似的な回路別分散・会場への確認事項を、登録不要の日本語画面に統合すること。** 実際の利用継続率・需要・課金意思はまだ未検証。

## 計算・テスト

ピーク算定は各機器の開始・終了時刻の全境界で半開区間として評価（開始を含み、終了を含まない）。自動割付は貪欲法＋局所再配置の近似で、最適解や安全性は保証しません。

- **GitHub単一HTML版**：2026年11月17日に公開ファイルを再取得し、DOMモック環境にて計算・操作 **10/10確認**（サンプルピーク1920W、初期2回路超過、割付で0回路超過、機器/回路追加、表示・保存呼出など）。
- **別構成のZIP拡張版**：Node単体テスト **21/21合格**、Chromium操作試験 **23/23合格**。GitHub単一HTML版と拡張版は**別実装**であり、テスト結果を同一視しません。
- ChromiumへのURL遷移が実行環境で遮断されているため、ZIP拡張版のブラウザ試験はHTML/JSを直接注入し、localStorageをメモリ模擬しました。実サイト配信・実端末での永続化・物理的な電気安全は未検証です。
