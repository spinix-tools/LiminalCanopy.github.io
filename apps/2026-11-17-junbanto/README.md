# 順番灯 / JUNBANTŌ

**制作日**: 2026-11-17  
**対象**: 小規模イベント・個人制作・小さな現場で、チェックリストの「実行結果」を正確に引き継ぎたい人。  
**形式**: HTML/CSS/JavaScript の静的Webアプリ。登録・クラウド・広告・外部API・追加課金なし。

## 課題と選定理由

マニュアルを配るだけでは、どこまで実行し、何が未解決かが残らない。現場の小さな定型作業について、作業開始時の手順を固定し、「実施済」「要対応」「未着手」「理由付き対象外」を区別できる、一台で使う無料ツールを試作した。

2026年11月17日に確認できた競合の公式情報：

- **日本：Teachme Biz**（https://biz.teachme.jp/ ） — AI支援でマニュアルの作成・共有・運用ができ、提供者によると2026年2月時点で国内外2,400社以上の導入。これは提供者自身の集計であり、当アプリの需要量や顧客獲得を直接示すものではない。
- **海外：Process Street**（https://www.process.st/help/docs/what-is-process-street/ ） — 動的なワークフローチェックリスト、担当者割当、進捗トラッキング、フォームの統合などがある。
- **海外：Process Street の条件分岐**（https://www.process.st/help/docs/conditional-logic/ ） — 2026年6月2日更新のヘルプによると条件付きでステップを表示する機能が既にある。**条件分岐そのものを独自機能だとは主張しない**。

## 差別化の仮説（未検証）

専任の管理者、チームアカウント、動画作成、連携自動化を必要としない**個人や小規模現場**では、「完了とみなす条件」「必須で飛ばせない項目」「対象外には理由必須」「問題は未完了として閉じる」「報告書を手元に書き出す」という小さな実行エンジンを、インターネットなし・個人情報不要で使えることに価値があるかもしれない。競合も高度なチェックリスト機能を持つため、独自性の独占や優位性は未実証。

## 実際の機能

1. サンプル2種類から開始、手順書の新規作成・複製・編集・並べ替え・削除
2. 項目ごとに判断条件と必須フラグを設定
3. 実行開始時点の手順を**スナップショット**として保存（後の手順書編集は進行中・過去の記録に反映しない）
4. 各項目を未着手・実施済・要対応・対象外で記録。必須項目は対象外不可、通常項目を対象外にするには理由必須
5. 未着手・要対応が残っていれば「完了」は不可。ただし「未完了として終了」して課題を保存できる
6. 実行記録の参照・削除、Markdownレポート、JSONのバックアップ・復元
7. ブラウザ内 localStorage のみに保存、外部通信なし

## 使い方

同じフォルダの `index.html`, `engine.js`, `app.js` を保ったまま、`index.html` をブラウザで開く。GitHub上では `hourly-app-lab` ブランチの `apps/2026-11-17-junbanto` に保存する想定。既存サイト・mainへの公開は行わない。

## 実施した検証

- Node.js v22: `node --test engine.test.cjs` **13/13 件成功**。重要項目の対象外禁止、理由なしスキップ拒否、ブロッカーがある場合の完了拒否、実行記録の不変化、JSON検証、Markdown出力など。
- Chromium + Playwright: `python browser_test.py` **12/12項目成功**。実行→完了・未完了、編集、JSON入出力、Markdownダウンロード、HTMLエスケープ、390px画面のはみ出しなしなど。
- **ブラウザ検証の境界**: この実行環境では `file://` とローカルHTTPへのページ遷移が管理ポリシーでブロックされるため、`about:blank` にHTMLを流し込み、JSを直接注入してテストした。`localStorage` はインメモリの模擬実装を使用。したがって、端末での実ファイル起動、永続化、外部サービスとの互換性は未検証。
- 外部の一般利用者によるユーザビリティ調査、継続利用率、売上、効果測定は未実施。

## 制限・注意

- チーム間のリアルタイム同期なし。データは使用端末・ブラウザに紐づき、閲覧履歴削除などで消える場合がある。適宜 JSON を書き出す。
- 手順の実行・完了は**操作者の自己申告**。実際の作業・安全性・第三者による確認・承認を保証しない。
- 本アプリは安全に関わる専門的な業務手順や法令要件を代替しない。サンプルは例示。
- 暗号化・ユーザー認証なし。機密情報、顧客の氏名等は入力しない運用を推奨。

## ファイル

- `index.html`: 画面・スタイル。外部ファイル参照は同梱の2つのJSだけ。
- `engine.js`: 判定ロジック。Nodeの単体テストが可能。
- `app.js`: ブラウザUI・localStorage・書き出し・復元。
- `engine.test.cjs`: ビジネスロジックの単体テスト。
- `browser_test.py`: Chromium操作試験（`playwright`, `/usr/bin/chromium` を使用）。

**先行アプリとの差**: 返信文作成、期限管理、時差公平化、不具合再現、梱包箱比較、防災食配分とは別の「手順実行・例外・未完了記録」を対象にしている。
