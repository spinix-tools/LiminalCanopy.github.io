# 電かさなり / DENKASA
**15分ごとの仮の電力負荷の重なりを見つける、登録不要のイベント準備ツール**（2026-11-22）。

## ターゲット・選定理由
小規模マルシェ、キッチンカー、学園祭、地域イベントの出店者・主催者。複数機器の使用が時間帯で重なり、単純なW合算だけではピークや混雑を把握しにくい。2026-04-06の[斉木電気設備による移動販売の電源解説](https://saikidenki.com/2026/04/06/移動販売の電気設備を解説｜電源確保4方法・必要/)は関連する国内の課題の参考。ただし本アプリ市場の大きさ、支払意思は不明。

国内競合：[デンゲンバン](https://apps.apple.com/jp/app/id6799537954)（キッチンカー向け電源計画）、[Elecalc仮設電源](https://apps.apple.com/jp/app/id6789530972)。海外競合：[PowerSense](https://squaresmile.de/powersense)、[PowerDistro](https://powerdistro.io/)、[NADJ Power Planner](https://www.nadj.org.uk/power-planner/)。既存ツールにも同時使用判定や電源分配機能があるので、独自性は限定的。

**差別化仮説：** 小規模用途に特化して、機器別の時刻を可視化→仮の系統自動割当→1台だけ時間をずらした際のピーク低減候補まで、無料・ログイン不要・端末内で完結できること。利用・収益仮説は未検証。

## 実装機能
- 最大40機器のW、台数、開始/終了時間、仮系統指定、自動割当、時刻変更可否を編集
- 15分単位の時間別負荷、系統別ヒートマップ、超過枠・ピーク・Wh・kWh参考値
- 最大4系統の仮容量を入力し、貪欲ヒューリスティックで割当。単一機器を±120分ずらす候補を計算・反映
- JSON入出力、CSVエクスポート、端末内保存、印刷、デモデータ

## 起動・成果物
このGitHubディレクトリの `index.html` と `payload-01.js`〜`payload-05.js` を**同一ディレクトリ**に置き、`index.html` を開く。5つのpayloadは可読な単一HTMLの圧縮配布形式で、indexがブラウザ内で復号して実行する。**編集しやすい完全な単一HTMLソース**、テストソース、テストログ、画面画像はこの実行で配布したZIPに同梱。外部CDN・API・課金・アカウント・個人情報送信なし。

## 検証
ZIP内の可読ソースに対し Node.js `node --test engine.test.cjs` **28/28合格**（固定シード400ケースのランダム条件を含む）。Playwright Chromium **27/27チェック合格**、デスクトップ・モバイル表示、例外0件、外部通信0件。GitHub配布版の圧縮ファイル5本の復号と操作可能な起動をローカルで確認。

**制限：** 実行環境の制限で通常の `file://` 直接アクセスが拒否されたため、Chromium検証は同一HTMLを `page.set_content` に展開し、端末保存は模擬した。GitHubから直接ダウンロードしてのファイル起動・長期保存・現場利用は未検証。

**安全上の注意：** これは消費電力の比較をする計画補助にすぎず、電気設備設計・安全性の判定はできない。起動電流、力率、電線・コンセントの許容電流、回路独立性、保護装置、接地、契約容量などは検証していない。実際の配線・運用は会場管理者と有資格者が判断する。時刻変更の実行可能性や割当の最適性も保証しない。
