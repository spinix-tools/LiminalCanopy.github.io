# 稽古パズル / KEIKO PUZZLE

出演者の出欠と場面ごとの必要稽古時間を組み合わせ、**15分単位で稽古枠を自動配分する**、アカウント不要・サーバー不要のブラウザアプリです。制作日：2026-11-20。

## ターゲットと選定理由

小劇場、学生劇団、地域劇団、演劇ワークショップの演出・舞台監督。出演者の欠席で稽古時間が分断される問題に着目。**需要の周辺指標**として、ぴあ総研の2026-06-17公表値では、2025年の日本のライブ・エンタテインメント市場の公演回数は100,820回。ただし音楽公演を含み、本アプリの利用者数ではない。

海外ではコミュニティシアター向けサービス市場が拡大するとする2026年の業界予測があるが、推計は幅広いサービスを含み、本製品の収益性は未検証。

## 競合と差別化仮説

- 国内：[GEKI TOCCA](https://geki.tocca.systems/) は公演・稽古カレンダー、日程調整、メンバー管理等を提供。
- 海外：[Quince](https://www.quince-app.com/) はシーン、役、欠席を考慮した自動計画や、急な欠席時に練習できるシーン候補まで提供。[Cast98](https://cast98.com/software/rehearsal-schedule) も出演者のコンフリクトと計画管理を提供。

**これらの機能自体は新規ではない。** 差別化仮説は、**登録なし・台本アップロードなしで、固定稽古の保持／実施可能性／未充足時間とその理由を一画面に可視化**し、JSON/CSVで持ち出せる「小規模座組の最短導入」にある。市場適合性・支払意欲・既存製品への優位性は未検証。

## 操作と機能

1. `index.html` を開く。出演者と出欠、稽古枠、場面の所要分数、優先度、必要な役を編集する。
2. 「自動で再編する」を押す。🔒固定枠を保持して、出席可能な場面を15分単位で割り当てる。
3. 枠ごとの手動追加、固定/変動切替、削除が可能。固定枠に矛盾があれば警告を表示。未割当には理由を表示。
4. 当日チェックで、対象枠で稽古できる場面を確認。CSV・JSON出力、JSON読込、印刷、ブラウザ内自動保存に対応。

外部API、アカウント、サードパーティSDK、外部通信、OpenAI API課金は不要。役名のみで利用でき、**データはユーザーのブラウザ内 `localStorage` に保存**され、外部送信されません。JSON/CSVを他者と共有する際は内容を確認してください。

## テストと制限

- `node --test engine.test.cjs`：制約検証・固定割当・例外・250ケースのランダム検証。
- `python browser_test.py`：Playwright Chromium がある環境でUI操作・読込・出力・端末保存と表示を確認（インライン展開で検証）。
- 自動再編は**優先度優先の貪欲近似**で、最適解・出演者の待ち時間最小化を保証しない。15分未満の時間は扱わず、複数部屋の並行稽古や移動時間は考慮しない。欠席と衝突する固定枠は勝手に消さず、警告する。
- 実利用の効果、利用者ニーズ・収益性、異なる端末間の同期は未検証。
