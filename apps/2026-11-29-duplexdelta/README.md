# DuplexDelta — 両面印刷の位置補正
2026-11-29 / MVP。`index.html` をブラウザで開く。依存ライブラリ・サーバー・外部APIなし。

## 対象と選定理由
自作トレカ・名刺・教材を家庭や小規模工房で両面印刷する人。表裏のずれは用紙の無駄と試し刷りを増やす。日本では Canon の画像位置調整、First CH Tools の自作トレカ寸法補正があり、海外にも Chitmunk や ToolSorcerer の表裏オフセット補正がある。需要の存在を示す定性的根拠であり、利用者数・収益性は未検証。
- 国内: https://oip.manual.canon/USRMA-7462-zz-PS-jaJP/contents/devu-mcn_mng-ptype_mng-img_posi.html
- 国内: https://tools.first-ch.com/toreka/
- 日本語対応競合（平行移動・回転）: https://apps.apple.com/jp/app/id6825743828
- 海外: https://chitmunk.com/tools/card-alignment-test
- 海外: https://toolsorcerer.com/duplex_print_alignment_corrector

## 差別化仮説
四隅の実測値から平行移動・倍率・傾きを含むアフィン変換を最小二乗推定し、推定に使わない中央点で不適合を検知。平行移動のみのモデルと残差を比較する。既存業務用機種に類似の補正があるため新規性は機能の組合せ・手軽さに限定。直近9案、GitHub比較結果300ファイル/51ディレクトリ、関連5語のコミット検索を確認（検索結果0、全履歴照合ではない）。

## 操作
1. 用紙と綴じ方向を選択し、未補正2ページを実寸100%で両面印刷。表のTOPを上に透かし、黒十字に対する赤円中心の差をmmで測定（右・下が正）。表の印刷寸法が正しいことが前提。
2. 5点を入力し、四隅と中央の残差を確認。用紙や給紙、綴じ方向を変更した場合は再計測。
3. 補正した2ページを再印刷し確認。JSON、裏面校正SVG、任意の全紙面PNG/JPEGを埋め込んだ補正SVGを出力できる。画像は裏面正立方向、用紙縦横比の1%以内、10MiB以下。画像はブラウザ内のみで処理。

## 計算・検証
表から見た観測座標を A、綴じ方向の鏡映を R とし、裏面に R A^-1 R を適用。四隅の直交配置による最小二乗推定。中央はホールドアウト。合成例では平行移動モデルの最大四隅残差1.414mm、アフィンモデル0mm。中央を(2,3)mmに変更すると中央残差3.606mm。
- `node test.cjs`: 400合成ケース（A4/Letter、長辺/短辺）で既知変換と逆補正を照合、固定検査も合格。
- `python test_browser.py`: Chromium（Playwright/Pillow、/usr/bin/chromium）で操作・3種のダウンロード・印刷用2ページDOM・無効入力・画像比率・390px表示を確認。JS例外と外部HTTP要求0件。環境制限によりfile://ではなく同一HTMLのインライン読込。実印刷は未検証。
- 制限: 実機の給紙変動、非線形歪み、紙伸縮、表面の絶対寸法誤差、SVG印刷時の実寸、PDF編集・他ブラウザは未検証。モデル残差は実際の補正後精度を保証しない。用紙端のクリッピングに注意。追加課金・入力収集なし。
