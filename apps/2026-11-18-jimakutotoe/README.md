# じまく整え / JIMAKU TOTOE

**字幕の公開前チェックと安全な一次補正を、ブラウザだけで。**（2026-11-18 作成）

## 対象と選定理由

YouTube・SNS動画・教材動画を作る個人クリエイター、広報担当者、少人数の制作チーム。自動生成した字幕の最終確認では、読み切れない字幕、行の詰まり、重複時刻の検出が必要です。

- **日本の関連市場**：サイバーエージェント／デジタルインファクトの2026年3月9日発表によれば、2025年の国内動画広告市場は8,855億円、2025年縦型動画広告市場は2,049億円。これは字幕校正ツールの売上・需要を直接示す数字ではありません。<https://www.cyberagent.co.jp/news/detail/id=33050>
- **海外の関連需要**：Wyzowl「State of Video Marketing 2026」では調査対象企業の91%が動画マーケティングを利用。字幕校正ツールの直接需要ではなく、動画制作の普及を示す参考値です。<https://wyzowl.com/video-marketing-statistics/>
- **海外競合**：SubtitleDesk、SRT Creator 等はSRT/VTT編集、CPS、重複検出を提供しており、字幕校正が独立したツールカテゴリーとして成立しています。市場規模や有料転換率は未調査です。<https://subtitledesk.com/subtitle-editor> / <https://www.srtcreator.com/>
- **国内競合**：VrewはAI文字起こしとSRTエクスポートを提供。<https://vrew.ai/ja/feature/srt-export/> / <https://vrew.ai/ja/feature/ai-video-subtitle/>
- **海外競合**：SRT Creatorは読み取り速度や重複の検査、自動修正、動画プレビューなど高度な機能を持ちます。これらを新機能とは主張しません。<https://www.srtcreator.com/>

## 差別化仮説

既存ツールの一部機能と競合するが、「日本語の句読点・禁則を意識した簡易改行」「読み切れる時間の診断」「安全な場合に限った重複解消」「SRT/VTTおよび検査CSV」を**ログイン・クラウドアップロード・従量課金なしの単体HTML構成**で、初心者にも理解しやすく提供すれば、字幕生成ツールからの仕上げ工程として価値を持つ、という仮説です。独自性・需要・収益性は未検証です。

## 実装機能

1. SRT / WebVTT のファイル読込（2MBまで）と直接貼り付け。時刻構文エラーの一部を通知。
2. 字幕ごとの文字速度（Unicode文字素単位）・表示時間・最大行数・最大行長・前後重複・順番・空白間隔の検査。閾値は変更可能。
3. 字幕本文と開始・終了時刻の直接編集、追加・削除、要確認フィルター、履歴からの元に戻す。
4. 自動補正：句読点・行頭/行末禁則に配慮した改行。重複時は前字幕が最短表示時間を守れる場合だけ短縮。自動延長や音声の意味改変はしない。
5. 時刻スライダーでの字幕プレビュー、端末上の任意動画ファイルの重ね合わせと再生。
6. SRT / WebVTT / BOM付きUTF-8検査CSVのダウンロード。

## 起動

ZIP展開後の `index.html` をダブルクリックして開きます。ネットワーク・Node.js・ビルド・APIキーは不要。最初は「サンプルで試す」を押してください。JavaScriptが有効な現代のブラウザを使用してください。読み込んだ字幕と動画はブラウザ内で処理され、送信・自動永続化・解析トラッキングを行いません。

## テスト結果（2026-11-18）

- `node --test engine.test.cjs`：**27 / 27 合格**（解析、SRT↔VTT、絵文字文字数、品質検査、禁則・自動修正・不変性等）。
- `python browser_test.py`：**Chromium 30 / 30 合格**（サンプル、診断、フィルター、編集、追加削除、履歴、補正、SRT/VTT/CSVダウンロード、スマホ横幅等）。
- JavaScript構文：`node --check engine.js`、`node --check app.js` 合格。
- **環境制限**：試験環境では Chromium の `file://` ページ遷移が `ERR_BLOCKED_BY_ADMINISTRATOR` で遮断されたため、`index.html` とそのCSS・JSを同じ内容でインライン化して `page.set_content()` から実ブラウザ試験。直接ファイル起動と外部配信のE2E試験は未実施。
- **限界**：改行は言語解析ではなくヒューリスティック。歌詞・ルビ・VTT装飾・位置指定・複雑なVTTメタデータの完全保持には非対応。原文に含まれる装飾タグや一部メタデータは変換時に失われる可能性があります。動画・音声と字幕の完全同期を保証しません。閾値は制作上の初期値であり公的規格ではありません。大きな字幕ファイルでの性能は未検証。
