# 訳幅ものさし / YAKU-HABA

**公開前の多言語表示崩れをローカルで確認する、登録不要のWebアプリ**。翻訳を自動生成するのではなく、既存の訳文が指定されたUI・案内表示ボックスに収まるかを検証する。2026-11-22試作。

## 対象・選定理由（2026-11-22調査）

- **ターゲット**：観光施設・地域店舗・自治体広報の案内表示担当者、Web制作・多言語UI翻訳の小規模チーム。日本語・英語・中国語・韓国語・ドイツ語・フランス語を扱う。
- **国内需要の間接指標**：JNTOが2026-11-18に公表した2026年10月の訪日外客数推計は3,912,500人で単月最高。案内の多言語化を考える背景にはなるが、翻訳QAアプリの利用者数・市場規模を示す数字ではない。[JNTO公式](https://www.jnto.go.jp/news/press/20261118_monthly.html)
- **国内競合**：[WOVN.io](https://wovn.io/ja/)はWeb・アプリの自動多言語化、翻訳管理等を包括的に提供している。
- **海外需要の参考**：CSA Researchが2020年に29カ国8,709人を調査したところ、回答者の76%が自分の言語での商品情報を好むと回答。ただし購買言語の選好に関する調査であり、**本アプリの直接需要や2026年現在の利用意向ではない**。[CSA Researchの調査解説](https://csa-research.com/l/blog/article/cant-read-wont-buy-consumer-language-preferences)
- **技術的な背景**：[W3C国際化記事](https://www.w3.org/International/articles/article-text-size.en)は言語間の訳文の文字幅・文字数の差、固定幅レイアウトのリスクを整理している。
- **海外競合**：[Lokalise Figma plugin](https://lokalise.com/product/apps/design-tools/figma/)はFigmaで訳文を確認し、文字の拡張によるレイアウト崩れを発見できる。この問題はすでに既存製品で解決が進んでおり、本アプリが最初の解決策ではない。
- **選定理由と仮説**：Figmaや翻訳管理プラットフォームを使わない小さな案件向けに、**文章・箱サイズ・言語を入力するだけで一括QA**できる軽量の単機能ツールを提供する。「現場で受け取ったCSVをその場で点検してCSVで返す」点を検証する。需要・売上・継続利用は未検証。

## 実装済みMVP

- HTML/CSS/JavaScriptのみ。データ送信なし、外部通信なし、外部CDN・AI APIなし。
- 初期サンプル5要素、6言語。最大100要素の追加・複製・削除・寸法編集。
- 幅/高さ（px）、文字サイズ、行間、余白、許容行数を変更するとブラウザCanvas.measureText + グラフェム分割で表示行数を再計算。
- はみ出し・翻訳未入力・余裕不足・収まる見込みの表示、言語切替・問題別フィルタ、必要な高さ/幅の提案・適用。
- 言語別の実寸風プレビュー、CSVとJSONのインポート、文字列表・QAレポートCSVのエクスポート、印刷、localStorageへの端末内保存。
- CSVの引用符・改行を取り扱い、Excel数式として解釈されそうな文字列の出力時にプレフィックスを追加。UI文字列をHTMLエスケープ。

## 起動とテスト

ZIPを展開し **`index.html`** を通常のブラウザで開く（同じディレクトリに `style.css`, `engine.js`, `app.js` を置く）。インストール・アカウント不要。

```bash
node --test engine.test.cjs
python browser_test.py
```

- Node.js単体テスト：**30/30合格**（グラフェム改行、幅・高さ、CSV、JSON、異常系、600件ランダム条件を含む）。
- Chromium操作テスト：**37/37合格**（編集・言語切替・追加/複製/削除・CSV/JSON出力と読込・XSS入力無害化・モバイル・外部通信0）。
- 管理環境で直接の`file://`アクセスが `ERR_BLOCKED_BY_ADMINISTRATOR` となったため、ブラウザテストは**同じ4ソースをインライン埋込**して実施。localStorageを模擬したため、通常のファイル直起動と長期端末保存は未検証。画像はブラウザテストのスクリーンショット。

## 制限・注意

これは**おおよその幅・行数の品質検査**。ブラウザのCanvasによる計測および文字単位の行折り返しを使う。実際のフォント（Webフォント・字間・カーニング）、CSS改行規則、右から左に書く言語、縦書き、端末差、校正、アクセシビリティ適合、サイン設置時の可読性は保証しない。翻訳品質を検査・生成するものでもない。原稿は自身で用意し、公開前に必ず対象実機と実フォントで最終確認すること。

## 前回案との非重複

字幕タイミング、印刷ラベル、色覚向けグラフ、香盤、在庫等の過去テーマとは異なり、**UI・サインの多言語文字列が表示領域に収まるか**を扱う。
