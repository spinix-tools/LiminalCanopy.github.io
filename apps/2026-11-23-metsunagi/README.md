# 目つなぎ / METSUNAGI 🧶

**2026-11-23 — 棒針編みの「段をまたぐ目数のつながり」を検算するオフラインWeb MVP。**

## ターゲットと選定理由
自作の棒針編み手順をテキスト化する人、編み物教室の講師、増減目をアレンジする人向け。特に一段ごとに前段の目数と整合するかを確かめたい場面を狙う。

日本：2026年3月8日付[ITmedia](https://www.itmedia.co.jp/business/articles/2603/08/news004.html)は、新宿オカダヤ本店の2025年毛糸売上が2023年比約6倍と報告。**特定店舗の売上でありアプリ市場規模ではない。** 2025年2月23日付[FNN](https://www.fnn.jp/articles/-/832619)も若年層の編み物人気を報告。

国内競合：[あみまる](https://apps.apple.com/jp/app/%E3%81%82%E3%81%BF%E3%81%BE%E3%82%8B/id6813901842)は編み図記号の目数検算、[KnitBuddy](https://apps.apple.com/jp/app/knitbuddy-%E7%B7%A8%E3%81%BF%E7%89%A9-%E5%A2%97%E6%B8%9B%E7%9B%AE%E8%A8%88%E7%AE%97/id6816652688)は増減目の配分計算を提供。海外競合：[Knit Toolbox](https://knittoolbox.com/)は並行カウンター・ゲージ計算、[Rowly](https://rowlyknit.com/)は計算ツール、[Slowspun](https://slowspun.app/)はゲージに合わせたパターン調整を提供。

**差別化仮説：** 手順を行単位のテキスト記号で入力し、*前段の結果目数 → 当該段の使用目数*を比較。最初の不一致以降は推測で目数を埋めず「保留」にして、点検表・グラフで問題行を見つける。類似検算機能は既にあり、需要・競争優位・収益性は未検証。

## できること
- `index.html` だけで起動する日本語UI。作り目、作品名、最大200段の編集、複製、削除、並び替え、Undo、ローカル自動保存。
- `K6`、`P6`、`KALL`、`YO`、`M1`、`KFB`、`K2TOG`、`SSK`、`K3TOG`、`SL1`、`[K2,P2]x6`（入れ子可）と一部の日本語表記。記述の使用／結果目数と停止後の未確定表示。
- JSON保存・読込、監査CSV、SVGグラフ、印刷。外部API/CDN・登録・有料機能・テレメトリはなし。

## 使い方・検証状況
`index.html` を開き、練習例の9段目 `K4 K2TOG K10 SSK K4` の `K10` を `K12` に変更すると、10段目までつながる。

完全版（配布ZIP）は **Node.js単体24/24・固定シード1,200系列・Chromium操作41/41** を合格。完全版はより詳細な解析・TXT出力等に対応。GitHub上のこの単一HTMLは**軽量な別実装**であり、同じ41件のブラウザテストを直接通したとは主張しない。GitHub版は構文・計数スモークチェックを実施（実施結果は報告文に記録）。

ブラウザテストは環境ポリシー上ローカルファイル直接遷移が遮断されるため、完全版HTMLをインライン注入し、端末保存はメモリ模擬で検証。通常のURL直起動、永続保存、印刷物と実編みでの確認は未検証。
