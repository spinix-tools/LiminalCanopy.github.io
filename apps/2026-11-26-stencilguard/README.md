# StencilGuard / つなぎ耐性ラボ
2026-11-26 | MVP

## 対象・選定理由
ステンシルを自作する工房、看板制作、DIY・工作教室。日本の中秀鉄工（2026-10-22）は漢字の囲まれた部分のつなぎ設計と反復使用時の破損を課題としている。豊栄産業（2026-05-19）もブリッジの必要性を解説。海外ではMaker3C、Islecut、Stencilyrなどが島の検出・自動接続を提供する。市場規模や支払意思は未確認。

## 差別化仮説
既存の図案生成器ではなく、接続済みの図案にも1セル破断を全数模擬し、追加脱落面積と弱点位置を可視化する事前監査に特化。補強前後を比較し、再制作の手間を減らせる可能性がある。競合全機能の網羅調査は未実施。

## 起動と操作
index.htmlをブラウザで開く。サンプルを選択、#（材料）と.（穴）の格子を入力、またはPNG/JPEG/WebP（5MB以下）を読み込む。最大40×40、外枠は固定。検査モードでセルを選択すると破断後に脱落する領域を表示。編集モードで材料を追加・除去して再検査。CSVと白黒PNGを出力。すべて端末内処理で外部API・依存ライブラリなし。

## 計算・検証
4近傍の幅優先探索で外枠と接続する材料を特定し、接続済みの各内部セルを一つずつ除去して追加脱落数を計算（破断セル自身・既存孤立片を除く）。サンプルは孤立例15セル、1本つなぎで弱点4セル・最大追加脱落17セル、2本で両方0。
- `node test.js`：固定10/10、独立した全格子反復探索との乱数200/200、40×40合格。
- `python browser_test.py`：Chromiumで破断、編集、入力エラー、画像読込、CSV/PNGダウンロード、390px幅を確認。JS例外・外部HTTP要求0件。環境のfile://制限のためインラインHTMLで実施。テストにはPlaywright、Pillow、Chromiumが必要。
- 制限：格子解像度依存、斜め接触は非接続。物理的強度、実寸、切断幅、複数セル同時破断、加工機互換性は評価しない。PNGは参照図案であり加工用ベクターではない。実需要・収益性は未検証。
