# TurnMargin / 譜めくり余白

既存の楽譜の段組を固定し、改ページ位置だけを調整する紙譜向け計画ツール。対象は伴奏者、室内楽奏者、編曲者、楽譜編集者。`index.html` をブラウザで開く。登録・通信・外部依存なし。

## 市場と仮説（2026-11-27）
- 日本：[ヤマハ ミューナビ](https://lms.school.jp.yamaha.com/help/new-lms_help_app_05.html) は演奏を中断しない譜めくりペダルを案内。[電子楽譜カノン](https://www.canon-score.com/usage/app) は自動譜めくりを提供。譜めくりの負担が製品機能になっている。
- 海外：[LilyPond](https://lilypond.org/doc/v2.24/Documentation/notation/page-breaking) は休止時間を考慮した改ページ最適化を実装済み。[SheetScroll](https://sheetscroll.com/ja/) は演奏追従型の譜めくりを提供。
- 差別化仮説：既存段組・既存改ページの維持を重視し、記譜ソフトを使わずに手入力した秒数で不足箇所と最小変更案を比較する。最適化自体は既存技術。紙譜編集の補助として需要を検証したい。市場規模・利用意向・収益性は未検証。
- 重複確認：直近の会話、mainとの差分300ファイル（51アプリディレクトリ）、コミット検索4語（page turn, 譜めくり, score, pagebreak）に明確な一致なし。全アプリの本文は未確認。

## 操作・計算
1行に1段の高さ（整数単位）、段末で実際に手を離せる秒数（小数1位まで）、改ページ状態（0なし/1既存/2固定/3禁止）をカンマ区切りで入力。最終段は状態0。最大100段、100ページ。見開きの開始側または単ページを選択する。紙譜の実際のページめくりが必要な境界だけを評価する。

動的計画法の状態は消費段数とページ数。容量・固定・禁止・ページ上限を守り、不足めくり数、総不足秒数、既存境界との対称差、ページ数、余白の二乗和の順に辞書式最小化する。秒数は0.1秒単位の整数。固定段モデルでの厳密解であり、紙面の自動生成やPDF編集ではない。反復、D.S.、持替、譜面の視認性は手動確認が必要。
