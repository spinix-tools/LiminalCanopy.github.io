# ぬきどり帳 / NUKIDORI-CHO

ロットの抜取検品を **計画 → 番号抽出 → 良否記録 → エクスポート** の順で扱う、登録不要・完全クライアントサイドのWebアプリ。2026-11-17制作。

## 想定利用者と選定理由

小規模製造業、工芸・雑貨メーカー、D2Cの入荷検品担当。2026年版中小企業白書は人手不足と生産性向上を重要課題としている（[中小企業庁](https://www.chusho.meti.go.jp/pamflet/hakusyo/index.html)）。ただし検品ツールの実需要や支払意思額を測ったものではない。

## 日本・海外競合／差別化仮説

- 国内： [Mahiro Apps 抜取検査計算](https://mahiroapps.com/sampling-inspection-calc) はJIS表の参照・OC曲線を提供。 [sampling-calc](https://github.com/kotaooka/sampling-calc) は抜取合格確率・AQL・OC曲線に対応。
- 海外： [AshToolbox Sampling Plan Designer](https://www.ashtoolbox.com/quality/sampling-plan-designer) と [MetricGate](https://metricgate.com/docs/acceptance-sampling/) は危険率やOC曲線・数理計画を扱う。
- 差別化仮説：計算だけで止めず、**小ロットの有限母集団モデル＋再現可能な抽出番号＋現場の良否記録＋判定・CSV** を同一画面に接続する。機能面の仮説であり独占性・市場優位性・収益性は未検証。

## 使い方・実装

`index.html` を開く（`engine.js` と `app.js` を同じフォルダに置く）。初期値はデモ。ロット数 N、良品/不良品の想定不適合率、許容 α/β、最大抜取数を設定し「計画を探す」。見つかった `(n,c)` で指定シードから重複しない抽出番号を生成し、各番号の良・不良を記録。不良数が `c+1` で即不合格、全 `n` 個確認後 `c` 以下なら合格。端末内に自動保存しCSV・JSONを出力。印刷対応。外部通信、トラッキング、API、ログイン不要。

計算は有限ロットの超幾何分布（真の不適合率を `round(N*p/100)` 個に丸める）。最小 `n` を最大500個、`c≤30`で探索。未達の場合は参考案と警告を表示する。番号抽出はFNV-1a + xorshift32に基づく**再現可能な擬似乱数**で、敵対的・監査上の公平抽選には不向き。初期値は240個、良品側1%、不良側9%、α15%、β20%、最大検査数160個。

**注意**：本ツールは統計学習・検査計画の補助であり、JIS Z 9015-1 / ISO 2859-1適合、製品安全、無欠陥、監査適合を保証しません。特に医療、航空、食品安全、法定検査、契約検査の代替には使わないでください。規定・専門家の判断を優先してください。

## テスト・制限

- `node --test engine.test.cjs`：数式と境界値、抽出の再現性、判定の単体テスト。
- `python browser_test.py`：Playwright/Chromiumを利用した入力→計画→番号抽出→結果記録→CSV・JSON・復元の操作試験。
- 実機・実ロットでの品質保証性能、暗号学的なランダム性、複数ブラウザや長期保存は未検証。ローカル保存データは端末・ブラウザの設定に依存。
