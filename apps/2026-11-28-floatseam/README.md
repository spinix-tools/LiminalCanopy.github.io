# FloatSeam / 織りの境界監査

2026-11-28 · MVP 1.0

**対象:** 手織り作家、織物教室、テキスタイル設計者。周期的な組織図の浮き糸検査を、試し織り前に行う。

**需要・選定理由:** 日本語の組織図編集アプリが存在し、海外では浮き糸の検査が既存製品の機能になっている。需要の存在を示す定性的証拠であり、市場規模・売上・利用意向は未検証。
- 日本: [Weave Designer](https://apps.apple.com/jp/app/weave-designer/id6757907705) — 組織図編集・PDF出力。
- 海外: [WeaveDraft](https://weavedraft.app/) — 組織図編集・最長浮き糸検査。[WeavePoint](https://www.weavepoint.com/feature.html) — 反復長・浮き糸解析と視覚化。[Treadl](https://treadl.com/) — WIF共有・編集。

**差別化仮説:** 単独の組織図と周期反復を並べ、境界で連結する浮き糸と無限に続く浮き糸を表裏・経緯別に特定する。既存の設計ツールを置き換えず補完する。競合が同様の周期判定を内部で行う可能性は未調査で、独占的な新規性は主張しない。今後、教室・作家に試用してもらい境界検査の有用性を検証する。

## 使い方
index.html をブラウザで開く。0/1の組織図（1=経糸が表、0=緯糸が表、左上を1）と経緯別の許容上限を入力し監査。最大64×64、2×2反復図で表裏・境界の強調切替、交点編集、JSON/CSV出力。JSONの len:null は無限、index/start は0始まり。CSVと画面は1始まり。単独図・周期図の超過件数はそれぞれの連続区間数であり、差分は新規件数ではない。

## 検証結果
- `node test.cjs`: 固定10アサーション合格、長さ2〜12の全二値列8,188件を独立の3周期連結法と照合（状態・長さ）。64×64全同値の無限浮き128件も確認。
- `python browser_test.py`: Chromiumでサンプル（単独0件・反復2件・各5本）、JSON/CSVダウンロード、強調切替、交点編集、旧結果無効化、不正入力、平織り、無限浮き、390px幅、JS例外・HTTP(S)要求0件を確認。環境のfile://制限により同じHTMLをインラインで読込。Python PlaywrightとChromiumが必要（アプリ自体は依存なし）。

**制約:** 完全周期の上下二値モデル。WIF取込、織機の綜絖・踏木制約、耳、糸の物理特性、実際の織布強度・仕上がりは未検証。図の交点編集が実機で可能とは限らない。許容上限は設計値であり規格ではない。登録・通信・有料API・個人情報収集なし。

**重複確認:** 会話内の既存案、mainとの差分に現れた51アプリ名、関連4語（float / weave / 織り / 織物）のコミット検索で明確な重複なし。全履歴・全ソースの網羅照合は未実施。
