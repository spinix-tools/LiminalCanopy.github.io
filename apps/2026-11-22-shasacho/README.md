# 写差帳 / SHASACHO

**写真を比較し、変化や未確認点をその位置に残す**。小規模修繕業者、学校・地域施設の担当者、地域景観の記録者向け。2026-11-22作成。

`index.html` をブラウザで開けば、外部依存なしで操作できます。サンプル画像内蔵。画像のサーバ送信、登録、API課金はありません。

## 調査・選定理由（2026-11-22確認）

- 日本：国土交通省は2026年4月1日に電子納品の要領・ガイドライン改定を案内。工事写真管理が継続的な業務である手がかりだが、これは本サービスの市場規模ではない。 https://www.cals-ed.go.jp/
- 日本の競合：[施工前後：ビフォーアフター比較写真](https://apps.apple.com/jp/app/id6802885092) は2026年8月26日公開。比較画像作成、ローカル処理などを提供。[ピタ撮り工事黒板](https://apps.apple.com/jp/app/id6826774916) は基準画像を透かして撮影位置を合わせる。
- 海外の競合：[Shotexa Compare](https://shotexa.com/compare-screenshots) は自動位置合わせ・差分抽出・レポート出力等があり、[Ybug Image Diff](https://ybug.io/tools/image-diff) もスワイプ・フェードをブラウザ内処理する。

**差別化仮説：** 差分検出の多機能化ではなく、観察者が付ける位置付き注釈（要確認／変化あり／問題なし）と、引き継ぎ用CSV・画像入りJSONを、登録不要の単一HTMLで一連の作業にする。既存競合が強いため需要・市場性・収益性は未検証。

## 操作できる機能

- PNG/JPEG/WebPの2枚の比較、重ね合わせ、境界スライド、並列、Before/After表示
- Afterのみの横・縦移動、拡大率、透過率調節
- クリックによる注釈の追加・編集・削除、状態分類と件数表示
- サンプル画像、PNG出力、CSV台帳、画像込みJSON保存・復元、印刷
- 外部CDN・外部APIなし、注釈のHTML非実行化、CSV数式対策

## 検証と制限

同一テーマの**完全版**は別途配布するZIPに同梱し、Chromium / Playwrightで操作32項目合格、JavaScript例外・外部リクエスト0件を確認した。管理環境ではローカルfile URLへの遷移が遮断されるため、テストでは完全版HTMLをブラウザへインライン挿入した。**このGitHub上の簡易単一HTML実装は完全版とは別のコードであり、その32項目テスト対象ではない。** GitHub版は保存・再取得とソース構造の確認のみ。実ブラウザ操作テストは未実施。

自動位置合わせ・自動損傷検知・原本改変防止・公的工事写真の規格適合は提供しない。画角、照明、影が異なると、画像差は物理的な変化を意味しない。JSONファイルには元画像の情報やEXIFが含まれる可能性があるため、共有前に内容を確認すること。
