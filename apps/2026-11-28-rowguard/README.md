# RowGuard / 模様を守る増減目計画
2026-11-28 — オフラインWeb MVP。index.htmlをブラウザで開く。追加ライブラリ・サーバー・登録不要。

**対象・選定理由:** 袖・身頃の増減目を行う編み手、編み図制作者。国内の[KnitBuddy](https://apps.apple.com/jp/app/knitbuddy-%E7%B7%A8%E3%81%BF%E7%89%A9-%E5%A2%97%E6%B8%9B%E7%9B%AE%E8%A8%88%E7%AE%97/id6816652688)は増減目・ゲージ計算を提供。海外の[Rowly](https://rowlyknit.com/calculators/shaping)は段の均等割付と表側指定、[Knit Toolbox](https://knittoolbox.com/)は模様と増減段の並行カウンターを提供。関連需要の存在を示すが、市場規模・売上・利用者数は未検証。

**差別化仮説:** 模様周期内の禁止段・個別禁止段・固定段・最低間隔を同時に守り、可能なら均等な増減段を求める。単純な均等割付・カウンターを補完する。競合すべてに同機能がないとは断定しない。

**機能:** 1〜300段、開始・終了目数、1回の変化量、奇偶制約、周期・固定・禁止段。段マップ、各段終了時目数、CSV、印刷。解なし・割り切れない目数差・禁止固定の衝突を通知する。イベント位置 r_i の理想値 (i-0.5)R/K+0.5 からの二乗偏差和を動的計画法で最小化（K=イベント数、R=総段数）。同点の解は一つ返す。模様の技法、左右の目の配置、ゲージ、フィットは検査しない。

**検証:** `node test.cjs` — 500件の小規模全列挙との最適値・実行可能性照合、固定7アサーション（最大300段含む）合格。`python test_browser.py` — Chromiumでサンプル、CSVダウンロード、編集時の結果無効化、解なし、リセット、固定段衝突、390px幅、JS例外・HTTP要求ゼロを確認。同一HTMLをインライン読み込み（file://は環境制限）。印刷出力そのもの、他ブラウザ、実際の編み地は未検証。サンプル: 48→60目、32段、3/7/11/19/23/31段で各+2目。

**重複:** 直近の制作履歴、mainとの比較で取得できた51ディレクトリ、関連5語のコミット検索を確認。appsディレクトリの全件取得はAPIが非対応で、網羅照合は未実施。入力データを外部送信せず、有料API・個人情報収集なし。
