# きりしろ / KIRISHIRO

**制作日:** 2026-11-17（日本時間）  
**分類:** DIY・小規模木工向けの1次元（長尺材）木取り計画MVP  
**アプリ:** `index.html` を開く（同じフォルダに `engine.js` と `app.js` が必要）。サーバー・アカウント・有料APIは不要。

## 誰の何を解決するか

DIY愛好家、小規模木工工房、学校・地域の工作活動が、必要な長さの部材を揃える際に**手持ち端材を先に使うと、どの規格材を何本買い足す必要があるか**を概算する。端材の長さ・本数、購入候補の長さ・単価、のこ刃厚、端面の余裕、カットサービス料を同時に扱う。

## 調査と市場仮説（2026-11-17時点のWeb確認）

日本では2026年の林野庁『令和7年度 森林・林業白書』概要に、2025年の木材価格が2021年のピークから下がっても2020年より高い状況にあると記されている。材料費を意識する動機の周辺情報にはなるが、**本アプリの顧客需要を直接裏づけるデータではない**。

- 国内競合: [木取り計算（App Store）](https://apps.apple.com/jp/app/%E6%9C%A8%E5%8F%96%E3%82%8A%E8%A8%88%E7%AE%97-%E6%9C%A8%E6%9D%90-%E3%83%99%E3%83%8B%E3%83%A4%E5%90%88%E6%9D%BF%E3%81%AE%E3%82%AB%E3%83%83%E3%83%88%E5%9B%B3%E9%9D%A2%E4%BD%9C%E6%88%90/id6832567947)は木材・合板の木取り図、刃厚、購入リストを扱う。さらに [CutPlan](https://apps.apple.com/jp/app/%E6%9D%BF%E5%8F%96%E3%82%8A%E6%9C%A8%E5%8F%96%E3%82%8A%E5%9B%B3-%E3%82%AB%E3%83%83%E3%83%88%E3%83%AA%E3%82%B9%E3%83%88%E6%9C%80%E9%81%A9%E5%8C%96/id6792293888)は端材の台帳やオフライン運用にも対応している。単に「端材活用・刃厚対応」だけでは独自性にならない。
- 海外競合: [Cut Wizard](https://cut-wizard.com/)は1D配置と価格・残材・印刷に対応。[NestSolver](https://nestsolver.com/optimize)は保存可能な端材と廃棄を区別する。[Cutlistor](https://www.cutlistor.com/)は2Dや図面読み取りを含む上位機能もある。
- 資料: [林野庁・木材需給と価格の概要](https://www.rinya.maff.go.jp/j/kikaku/hakusyo/r7hakusyo_h/summary/s_3.html) および [農林水産省・木材価格統計調査](https://www.maff.go.jp/j/tokei/kouhyou/mokuryu/kakaku/gaiyou/)。

**狭い差別化仮説:** 「手持ち端材＋店頭の規格材候補＋カット料金」を、価格入力済みの1画面で見積もってCSVの切断メモへ即変換する。高機能な2D最適化や外部図面取り込みでは競争しない。競合との機能重複は大きく、利用者による優位性検証は未実施。ビジネス機会は未確定。

## MVPの機能

- 必要部材（長さと本数）、手持ち端材（長さと本数）、購入候補（長さと税込想定単価）を自由に編集・追加・削除
- 刃厚を部材1本につき1カット分として**保守的に**加算。材料の両端の余裕も差し引いて判定
- 12パターンの逐次詰め込みヒューリスティックを比較し、まず購入＋加工費、次に捨てる短い残材量が小さい計画を採用
- 購入本数、利用する手持ち材、歩留まり、長さ別切断順、使える残材の図示
- JSON保存・読込、ブラウザ内への明示保存、Excel等でも開けるBOM付CSV出力、文章コピー、印刷用レイアウト
- タブレット／スマートフォン向けレスポンシブUI。外部ライブラリ・通信・アナリティクスなし

## 制約 / 安全上の注意

本ツールは**長さ方向の1D・同一断面材・直角切りのみ**を扱う。刃厚を部材ごとに1回計上する保守的な方式なので、最後の部材が無切断で取れる条件では残材を少なく見積もることがある。木目、節、欠け、反り、クランプ領域、刃の振れ、端部の利用不能領域、切断時の安全手順、斜め切り、材料寸法の実誤差は評価しない。アルゴリズムはヒューリスティックで、グローバルな最安・最少購入本数・最少ロスを保証しない。端材の保管基準は長さだけで、用途適合性や強度を保証しない。実際の作業前に安全な切断方法と寸法を必ず確認すること。

## 改善・撤回条件

3〜5名のDIY利用者に同じ部材表を渡し、手書き・競合アプリと比較した際に、作成時間・見積り誤差・必要購入本数で優位性を確認できなければ差別化仮説を撤回する。次の実装候補は、材種別グループ分離、店舗別の価格・加工上限、手持ち材の実在庫残量の更新、厳密ソルバーとの照合。
