# 星携 / STARPACK

観望リストに必要な倍率・実視界・ひとみ径を指定し、携帯本数・購入予算の制約内で接眼レンズの集合を選ぶオフラインWebアプリ。対象は天体観望愛好者、観望会主催者、天文部。`index.html` をブラウザで開くだけ。外部API、会員登録、個人情報の収集なし。

## 選定理由・市場調査（2026-11-25）
- 国内：胎内市公式発表（2026-03-27更新）によると2025年星まつり来場者は約25,000人。https://www.city.tainai.niigata.jp/sangyo/kanko/2025hoshimaturii.html
- 海外：Astronomical League はアマチュア向け観望プログラム等を提供。https://www.astroleague.org/memblarg/ 。需要の間接指標であり、このアプリへの支払意思の証明ではない。
- 競合：Vixen Eyepiece Book（2016年の発表、現行配信は未確認） https://www.vixen.co.jp/post/160531a/ 、astronomy.tools 視野比較 https://astronomy.tools/calculators/field_of_view/ 、StarStation Eyepiece Planner 複数機材比較 https://starstation.org/eyepiece-planner/ 。
- 差別化仮説：個別機材の見え方・仕様比較ではなく、複数の観望目標に対する機材集合を予算・携帯上限付きで選ぶ。手持ちのみの最適案との比較で追加購入の価値を説明する。競合の全機能・実需要・収益性は未検証。
- 重複：会話内の既制作案、専用ブランチとmainの差分一覧の一部、コミット検索（eyepiece/望遠鏡/アイピース/telescope、各0件）を確認。全アプリの精査は未実施。

## 使い方とモデル
1. 鏡筒の焦点距離・口径、携帯上限、予算を設定。候補の購入費は手持ちの場合0円。1行1件の区切り文字は `|`。
2. 目標の倍率範囲・最小実視界・ひとみ径範囲・優先度を指定。最大12本・40件。倍率=鏡筒焦点距離/接眼焦点距離、実視界=見掛視界/倍率（視野絞り径があれば径/鏡筒焦点距離×180/π）、ひとみ径=口径/倍率。
3. 全4096集合以下を探索し、優先度合計→達成件数→低費用→少本数を辞書式最大化。各目標は適合機材が1本以上あれば達成。完全同点は小さいビットマスク。CSV・印刷対応。
4. サンプル（架空条件）：携帯3本、予算12,000円、手持ちのみ4/5件、推奨5/5件（21/21点、9,000円、10/5/32mm）。

## 検証
- `node test.cjs`：固定9件、独立再帰列挙300件、最大12本40件すべて合格。目的値の照合（同点の選択自体は対象外）。
- `python browser_test.py`（Playwright・Chromiumがある環境）：HTMLインライン起動（環境によりfile://はブロック）、予算ゼロ、本数ゼロ、不正値、旧結果無効化、リセット、CSV実ダウンロード、HTMLエスケープ、390px幅すべて合格。JS例外・外部HTTP要求0件。
- 実機光学性能、光学的互換性、収差、天体の可視性、天候・位置、実機印刷、実ユーザー調査は対象外。太陽観測には使用しないこと。新規課金・有料サービスなし。
