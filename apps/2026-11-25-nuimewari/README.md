# 縫目割 / NUIMEWARI — クロスステッチ図案の印刷分割最適化
2026-11-25。自作図案・使用許可のある図案を、図柄をなるべく分断せずに複数ページへ割り付ける登録不要のWeb MVP。

## ターゲット・選定理由
クロスステッチ図案の制作者、刺繍教室、紙の図案を使う愛好者。DMC日本公式サイトには調査時にクロスステッチ図案706件が掲載され、印刷用図案を配布。海外のx stitch kitsは重複行の二重カウント防止を説明し、StitchThisはモチーフ途中の分割と重複の扱いに言及。関連する作業課題の存在を示すが、市場規模や支払意思ではない。

## 競合・差別化仮説
日本語対応のPixVix、Stitchmateは図案・PDF出力を提供。海外のCrosspicは用紙・行列数・重複・ページマップを設定可能、Stitch FiddleもPDF出力可能。既存機能との差は、図案自体を変更せず、同じ最少ページ数・目数上限で境界の隣接記号負荷を動的計画法で最小化し、固定幅分割と比較すること。競合の未公開機能や有料機能は未検証。既存apps一覧と関連READMEを確認し、既存の糸在庫・刺し子経路・ZINE面付けとは別用途と判断（全件コード比較は未実施）。

## 操作・制約
index.htmlをブラウザで開く。最大60×60の英数字記号図案（. は空白）、1ページの横・縦上限8〜40目、重複0〜3目を設定。推奨/固定割り切替、ページプレビュー、範囲CSV、全ページ印刷/PDF保存が可能。境界で両側が非空白なら異記号1、同記号2、空白を含む場合0とする。直交格子の最少ページ数を固定し、縦横独立に厳密最適化。重複は左・上のみで、灰色の目は本体ページで一度だけ刺す。サンプル28×18目では6ページのまま負荷46→0。実際の誤刺しや作業時間の削減は未検証。部分刺し、PDF取り込み、糸番号凡例、可変ページ格子、実プリンターの余白は対象外。印刷前に背景グラフィック・試し刷りを確認。外部通信・登録・個人情報収集・有料APIなし。

## テスト
node test.cjs：500軸の全列挙照合、400計画の本体重複なし・全セル被覆・容量検査、固定8項目合格。python browser_test.py（Playwright/Chromium）：初期値、分割切替、ページ選択、重複表示、CSV実ダウンロード、印刷DOMと6ページPDF出力、不正入力、リセット、390px幅、JS例外・外部HTTP要求0件を確認。環境のfile://制限のため同一HTMLをインライン実行。実機印刷・ユーザー需要・収益性は未検証。
