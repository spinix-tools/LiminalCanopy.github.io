# GrooveBound / 盤面割付ラボ

2026-11-27 MVP。インディーズレーベル、個人音楽制作者、レコード制作進行担当者向け。曲順を維持し、曲間の連続性を壊さずに面割りを計画する。音源不要、依存ライブラリなし、通信なし。index.html をブラウザで開く。

## 市場と選定理由
- 日本：日本レコード協会の2026-03-04公表資料では、2025年国内アナログディスク売上推計は88億4,700万円。https://www.riaj.or.jp/news/press/94d112e4-697a-4990-9f80-a721d1f5a921/
- 東洋化成は12インチ33回転で片面20分、45回転で11分を推奨し、実際の収録可能時間は音源内容に依存すると説明。https://www.toyokasei.co.jp/new/service/record/faq/
- 海外：2025年米国の新品レコード売上は10億ドル超（2026-03-16報道、RIAA資料に基づく）。https://www.theguardian.com/music/2026/mar/16/vinyl-record-sales-us-taylor-swift
- 直接競合 LISTN.TO Vinyl Side Timing Planner は曲順維持・2面の時間バランスを計算。https://listn.to/tools/vinyl-side-planner
- 関連サービス NoizePro は音源内容に応じた推奨時間とマスタリングを案内。https://noizepro.com/vinyl-pre-mastering/

差別化仮説：単純な2面均衡ではなく、連続曲の分割禁止・必須境界・希望境界・各面別目標・2/4面の選択・追加無音・代替候補3案を一つの事前確認フローに統合する。未発売音源のアップロード不要。市場規模は音楽商品の売上であり、本ツールの有料需要や競合に同等機能がないことは未確認。次は制作者5人程度に試用してもらい、面割り作成時間と修正回数を比較する。

## 使い方と計算
1. 面数（2/4）と各面目標（分:秒、1個または面数分）を入力。
2. 1行に `曲名 | 4:20 | 2 | free` のように記入。追加無音は次曲と同じ面の場合のみ加算。join=分割禁止、lock=必須分割、prefer=希望分割、free=自由。最終行は無音0・free。曲名に縦棒は使えない。既に音源にある無音は追加しない。
3. 全境界組合せを検査し、超過合計、最大超過、未採用prefer数、面間の目標使用率差（各面0.01%丸め）、境界順で辞書式に順位付け。上位3件を表示。JSON保存と印刷（展開中の候補）に対応。

サンプル：2面・各20:00では5候補中0件適合、最善は14:02と22:38（2:38超過）。4面・各13:00では10候補中1件適合、4:20 / 9:40 / 10:02 / 12:34。時間の適合はカッティング可能性を保証しない。音量・低域・溝・歪み・曲間実音・製造費は未評価。秒単位、非空面のみ、音源解析・ユーザー調査・実プレス・実印刷は未実施。
