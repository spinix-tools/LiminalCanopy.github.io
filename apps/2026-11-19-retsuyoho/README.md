# 列予報 / RETSU YOHŌ

登録不要・外部通信なしで、学園祭・模擬店・受付・マルシェ等の待機列を**事前**に試算する日本語Webアプリ（MVP）。

## 対象と選定理由
- **ターゲット**: 学園祭模擬店の責任者、小規模イベント受付、地域の出店運営者。イベント当日の配置を決める人。
- **国内の需要を示す状況**: 関西学院大学の2025年10月10日公表資料は2025年の大学祭で「過去最大数の模擬店」を告知した。国内の受付システム「Airウェイト」は来場受付・呼出し・分析を提供する。これはイベント市場の存在と現場課題の傍証で、**当アプリへの需要・市場規模の証明ではない**。
- **海外の競合**: Waitwhile（イベントの仮想待機列）、QueueSim（時間帯別の到着・スタッフ配置の無料シミュレーター。2026-11-04の製品説明を確認）、NextMe（イベント向け待ち時間計算）。QueueSimは近い機能を持つ重要な競合。
- **差別化仮説**: 「来場ペースを30分刻みで入力 → 行列が収容できる人数の超過を可視化 → スタッフ1人×30分だけ増員する枠を探索 → CSVで引き継ぐ」という**イベント前の単発運営判断**を日本語・無料・オフラインで完結させる。国内導入意思や有料転換は未検証。

## 実装済み機能
- 学園祭・マルシェ・受付の3プリセット。2〜12個の30分枠の来場ペース・スタッフ数を編集。平均対応時間、ばらつき、待ち時間目標、列スペース上限を設定。
- 先着順の離散イベント・モンテカルロ（ポアソン到着、有限の変動を持つ対応時間、40/80/160試行）。平均/P90待ち時間、P90ピーク待機人数、目標超過率、閉店後残務時間を表示。時系列グラフ（中央値・P90）。
- 各枠に1人だけ追加する比較を**同じ乱数系列**で実行し、おすすめ枠を反映可能。計算は平均待ち時間とP90の改善を使うヒューリスティックで、最適人員配置の保証はしない。
- CSV予測表、JSON設定保存・読込、ブラウザ内自動保存、印刷、スマホ表示。ネット接続・アカウント・有料API不要。

## 実行
`index.html`をブラウザで開く。CSS・JSは同じフォルダに置く。ローカルサーバーを使う場合は `python -m http.server 8000` でも起動可能。サンプル値は架空で、現場の実測で置き換えて使う。

## 検証結果（2026-11-19）
- `node --test engine.test.cjs` : **17/17 合格**。そのうち1テストは60種のパラメータ組み合わせを検査。
- `node --check engine.js` と `node --check app.js`: 合格。
- `python browser_test.py` : **34/34 Chromiumアサーション合格**（入力、時刻跨ぎ、提案反映、CSV/JSON入出力、リロード、モバイル等）。Chromium管理環境では `file://`への遷移が遮断されたため、同じ HTML/CSS/JS をページに直接注入し、localStorageを模擬して実施。**通常ブラウザの直接起動と実際の保存永続性は未検証**。
- 実イベントの実測との照合、印刷実機、会場の物理的な安全検証は未実施。予測モデルは顧客の途中離脱、優先受付、複数作業工程、設備のボトルネック、スタッフの休憩や習熟度を表現しない。安全管理には使わないこと。
