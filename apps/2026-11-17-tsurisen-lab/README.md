# つり銭ラボ / TSURISEN LAB

小規模イベント向けの、**釣銭の事前不足リスク試算 → 当日の商品会計 → 現金枚数照合**をつなぐオフラインWebアプリ。2026-11-17制作。Node.js/npm・サーバー・アカウント・外部APIは不要です。

## ターゲット / 選定理由

ハンドメイド作家、同人誌即売会・文化祭・バザー・マルシェの出店者。現金取引の機会がありながら、専用POSの導入コストやセットアップが見合わない単発出店を想定する。

日本市場の実在する活動例として、Creemaは**2026年4月15日**に、2026年7月開催のHandMade In Japan Fes'に出展するクリエイター約3,000名（2日間の延べ人数）を発表。**2026年7月23日**のオリコン記事では、同イベントがコロナ禍以降最多の入場者数を記録したと報告。これは現金会計アプリの支払意思・需要規模を直接示すものではない。

## 競合 / 差別化の仮説

- **日本:** [即売レジ](https://apps.apple.com/jp/app/id730021836) は販売・釣銭・在庫・CSVに対応。[ツール横丁「釣り銭準備・金種計算」](https://tool-yokocho.com/tsurisen) は準備金の金種内訳とレジ締めに対応。[BOOTH 釣銭準備シミュレーター](https://booth.pm/ko/items/8854120) は支払い比率による準備目安のExcelテンプレート（価格表示は調査時点）。これらの機能を「競合にない」とは言わない。
- **海外:** [Market Stall](https://apps.apple.com/jp/app/market-stall/id6821425215) はクラフトフェア向けのレジ・現金釣銭・終業集計、[Square POS](https://squareup.com/us/en/the-bottom-line/operating-your-business/free-pos-software) は無料POSと会計・レポート機能、[NexPOS](https://www.nexpos.co/it-ch/free-pos-system) は無料の現金販売とシフト締めを提供する。

**仮説:** 一般的なレジや単なる金種表ではなく、**「現在の金種枚数で実際にお釣りを出せるか」を売上ごとに更新し、その不足を出店前に繰り返し試せる**一連の体験に価値がある。先行競合にも類似の可能性があり、独自性・収益性は実ユーザー検証が必要。

## 実装機能

1. 10金種（10,000〜1円）の開店資金、商品の名前・価格・需要比重を登録・編集・削除。
2. 売上想定を重み付き乱数で抽選し、金種ごとの有限在庫から釣銭を返せるか試行。試算結果として全件無不足率、1試行当たり不足回数、不足しやすい釣銭額を表示。シード指定で再現可能。
3. 商品をカートに追加、単一金種の預かり金から釣銭内訳を算出し、在庫不足なら確定を禁止。取引履歴・最終会計の取消。
4. 帳簿上の枚数と実数を照合し、金種単位と合計金額の差異を表示。
5. `localStorage` に自動保存。JSONバックアップ・復元、売上CSV（Excel向けBOM）、全初期化。外部通信・課金・分析タグなし。

## 開き方

`index.html` をChrome/Edge/Safariなどのブラウザで開く。`engine.js` と `app.js` を同じフォルダに置く。操作は「準備する」→「不足を試算」→「販売・お釣り」→「現金照合」の順。

## 計算と限界

- お釣り探索は通常、手持ち金種の**大きい順に枚数を確保**し、それで作れない場合は**二進分割した有界ナップサックDP**で厳密な可否を求める。返却枚数の**大域最小性は保証しない**。
- 模擬会計は各回「商品を1種類」「預かり金種1枚」とする。支払い金種比率は `500円:6, 1,000円:62, 2,000円:3, 5,000円:20, 10,000円:9` という根拠のない仮定値（価格以上に限定して再正規化）。複数購入・キャッシュレス・顧客の実際の支払傾向・両替・返金・現金移動はモデル化していない。**成功率は市場の実確率ではない**。
- 試行1〜300回、1試行の会計1〜300件、合計20,000会計まで。価格1〜10,000円。最大100商品・2,000履歴。
- 会計機能の受け取りは**単一金種のみ**。実際の受け取り金種と画面を一致させて使う。物理の現金保護・税務会計・銀行両替の最適化は対象外。共有端末に入力するとその端末内に売上データが残るため、必要に応じてJSON保存後に消去する。
- デモの価格・金種・需要比重は架空。市場需要・有料化の可能性は未検証。
