# 盤棚 / BANTANA — レコード棚の最小移動計画
制作日：2026-11-25。`index.html` をブラウザで開く。登録・通信・外部API・課金不要。

## ターゲット・選定理由
レコード収集家、DJ、中古盤店。購入による棚の圧迫に対して、アーティスト順・ジャンル順などを保ちながら、動かす既存盤を少なくする。日本レコード協会の2026-03-04発表では2025年国内アナログディスク売上推計88億4,700万円。RIAAの2026-03-16発表では米国2025年のアナログ盤売上10億ドル超、前年比9.3%増。いずれも隣接市場の指標で、アプリ需要の実測ではない。
- 日本：https://www.riaj.or.jp/news/press/94d112e4-697a-4990-9f80-a721d1f5a921/
- 海外：https://www.recordoftheday.com/on-the-move/news-press/riaa-reports-us-recorded-music-annual-revenue-achieves-new-high-of-115-billion-in-2025

## 競合・差別化仮説
日本語対応DiggerPocketはコレクション・DJ支援、海外Shelfifyは実寸の棚マッピングと所在検索を提供。盤棚は個別盤の登録・同期をせず、任意順のグループの実測幅・現在棚・枚数から、各棚の余白を確保する移動枚数最小の連続区間分割を算出する。競合の全機能・市場優位性は未確認。既存ディレクトリ一覧と関連7件のREADME冒頭を確認し、確認範囲では用途重複なし。
- https://apps.apple.com/jp/app/diggerpocket-%E3%83%AC%E3%82%B3%E3%83%BC%E3%83%89%E7%AE%A1%E7%90%86/id6793334856
- https://shelfify.app/en/

## 実装・使用方法
最大12棚・120グループ。棚幅mm、余白0〜90%、グループ名,枚数,実測幅mm,現在棚番号（0は新規）を入力。入力行の順を保持し、グループを分割しない。動的計画法で棚間移動の枚数を厳密最小化（O(棚数×グループ数²)）。余白0%との比較、確保可能な最大の整数余白（90%上限）、棚図、移動表、CSV・印刷。入力変更時には古い計算結果を無効化。サンプルでは124枚のうち12枚を移し、最小空き率を20/300=6.7%から80/300=26.7%に改善、最大整数余白26%。

## テスト・限界
`node test.cjs`：固定9件、ランダム300件で独立全探索との最小移動・最大余白照合、157件の実行可能計画の制約照合、120グループケースに合格。`python browser-test.py`：Chromiumで同じHTMLをインライン実行（file://は環境制約で拒否）、初期表示・CSV・不正入力・収容不可・再計算・リセット・390px幅に合格、JS例外・HTTP要求0。ブラウザテストはPython/Playwrightと/usr/bin/chromiumが必要。
モデルは棚間移動枚数のみを評価。棚内の順序変更、個別盤の重量、耐荷重、仕切り、取り出し余裕、仮置きの作業順序は評価外。幅の実測と安全確認は利用者が行う。グループ内に複数の現棚がある場合は行を分ける。実地・収益性は未検証。
