# 問岐 MONKI — 早押し問題の冒頭監査

## 目的・対象
競技クイズの問題作成者、サークル、学校、英語圏のquizbowl編集者向け。自作問題集内で異なる答えの問題が何文字目まで同じ冒頭を持つかを全件比較し、改稿候補を発見する。読み上げや正解判定のアプリではない。

- 国内競合：SNStheAppは音声早押し・確定ポイントの練習、作って！早押しは問題セットの作成・練習・CSV取込を提供。 https://apps.apple.com/jp/app/id6753719073 https://apps.apple.com/jp/app/id6811375548

- 海外競合：QB Readerは問題読上げ型練習と検索DB、QBHubは手掛かりの検索、ACF qams²は解答欄・進捗・文字数管理を提供。 https://www.qbreader.org/ https://qbhub.io/about https://wiki.acf-quizbowl.com/sets/production/qams.html
- 差別化仮説：練習や問題収集でなく、公開前のローカルな冒頭衝突監査。異なる解答の候補が消える位置、短い問題の終了合図、同一文の分岐不能を区別する。需要・収益性・競合の未掲載機能は未検証。まず問題作成者に誤配信・改稿候補の発見数と作業時間を評価してもらう。
- 重複確認：直近の制作履歴、mainとの比較で返った既存ファイルの一部、コミット検索（クイズ、quiz、早押し）を確認。検索結果0件。全アプリ・全READMEの網羅照合ではない。

## 使用方法
`index.html`をブラウザで開く。サンプルは自作。1行 `答え｜問題文`、2〜200問、問題文300文字・答え100文字まで。解析後、問題選択、スライダー、±1文字、全文終了で候補を確認。CSV出力・印刷可能。入力変更後は再解析が必要。外部通信・永続保存・API・依存ライブラリなし。入力には自作または使用許諾済みの問題のみを用いる。

## 計算モデル・限界
Unicode NFKC、小文字化、空白・句読点除去後のコードポイント列を比較。同じ正規化答えの行は競合から除外。異答の最長共通接頭辞長を L とし、通常 L+1 で分岐、異答がなければ0、完全同一文なら分岐不能。短い側の全文終了は独立した合図。表記別名・読み・同義語・意味的手掛かり・問題の正誤は自動判定しない。正規化で区別が消えることもあるため、実際の確定ポイントとは異なる。英語も文字単位（単語単位ではない）。印刷はレイアウト指定のみ、実機出力未確認。
