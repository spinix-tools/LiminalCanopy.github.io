# 継ぎ目ゲージ / LoopGauge

ゲーム音響・環境音素材・サンプラー制作者向け。ループの長さを変えず、開始と終了を同時に移動して継ぎ目の局所不連続を減らすオフラインMVP。`index.html` をブラウザで開く。初期合成音で即操作可。自分が利用権を持つPCM 16-bit WAV（1–2ch、8–192kHz、20MB以下）も使用可能。開始・長さ・探索範囲を指定し、候補を選択、A/B試聴、WAV保存。アップロード・録音・外部APIなし。

- 差別化仮説：固定フレーム長と左右の悪い側の指標を明示し、加工なしで候補を比較できる軽量な事前検査。既存製品に同等機能がないとの断定はしない。無料の狭い用途で利用頻度を検証する。

## 方法・テスト
末尾から先頭への振幅差をJ、両側の1フレーム差をL,Rとし、各chの sqrt((J-(L+R)/2)^2+(R-L)^2)/32768 の最大値を最小化。±100msの範囲を1フレームずつ全探索（最大38,401候補）。同点は元に近い方を優先。表示上位5件は1ms以上離す。固定長のPCMをそのまま出力（元の付加メタデータは保持しない）。
- `node test.cjs`：固定アサーション合格、独立全列挙との200/200照合、WAVの全サンプル一致。
- `python browser_test.py`：Chromiumの候補変更、A/B再生状態、WAVダウンロード・再読込、不正入力、390px幅、JS例外・HTTP要求0件を確認。環境制限によりHTMLのインライン読込で実施。
- 合成例：20,800フレーム（1.3秒）を維持、961候補、スコア0.04985→0.01788、開始-216フレーム。
- 未検証：聴感、実音源・他ブラウザ・ゲームエンジンでのギャップレス再生、実需要・収益性。スコアは聴感やクリック消失の保証ではない。テンポ検出、クロスフェード、圧縮音源、smplチャンクは対象外。
