# 駐差 / CHUSA — 駐車料金の「境目」を確認する

**2026-11-23 / 操作可能なオフラインMVP。** 登録・位置情報・外部API・有料サービス不要。入庫・出庫日時と料金看板の条件を手入力して、複数候補の料金を比較します。

## ターゲットと選定理由
日本の時間貸し駐車場利用者、送迎・イベント訪問・出張などの利用者向け。日本の自動車保有台数は2026年8月末で約8,318万台（自動車検査登録情報協会）ですが、これは本アプリへの有料需要を示すものではありません。
https://www.airia.or.jp/publish/statistics/number.html

## 国内外の競合（2026-11-23調査）
- 国内：PPPark! は指定日時で駐車場の料金検索・比較に対応。https://apps.apple.com/jp/app/id673031121
- 国内：K3 Tools 駐車料金計算サイトは時間料金・最大料金などを試算。https://k3tools.com/parkingprice/
- 国内：「コインパーキング料金計算｜今いくら？」は夜間料金・最大料金・候補比較をうたう。https://apps.apple.com/jp/app/id6757843411
- 海外：Parkopedia は駐車場の場所・料金・空き情報を提供。https://www.parkopedia.com/faq/
- 海外：SpotAngels は路上駐車規則や料金・空き情報などを提供。https://www.spotangels.com/subscription

**差別化仮説：** 料金看板の「当日最大」「入庫から24時間ごと」「初回のみ」など**解釈の違いだけで見積額が変わること**を、区間別の計算内訳とともに横並びに示す。検索・予約よりも、現地看板の手入力による事前検算に集中する。需要・優位性・収益性は未検証で、既存競合とも機能の重複があります。

## Github版の機能
`index.html` は軽量版HTMLをgzip圧縮して内蔵した完全ローカルの起動ファイルです（標準 `DecompressionStream` を使います）。駐車日時編集、昼夜の単価・課金分数、暦日・24h反復・初回24hのみ・上限なし、複数候補比較、解釈4種の横並び、区間別内訳、JSON保存・復元を実装。

**注意：このGitHub版は軽量実装です。** 同じ日の本実行で作成したフル版には上昇時刻、SVG曲線、CSV書出、印刷、localStorageなどの追加機能があります。GitHub版とフル版は同一コードではありません。可読なGitHub版への復元は `python3 unpack.py` で行えます。

## テスト・制限
- フル版の料金計算：Node.js単体テスト **19/19**、固定シードランダム検証 **1,000ケース**合格。
- フル版のChromiumインラインUI操作：**26/26** 合格。外部HTTP要求・実行時JS例外は0件。
- Github版軽量HTMLはChromiumインラインDOMで初期表示・比較候補の追加を確認。圧縮ローダーは実装と合わせて画面起動を確認する。
- 管理環境で`file://`直接起動がブロックされるため、直接ファイル起動・実際の精算機での一致は未検証。
- **現地看板・精算機が優先。** 本モデルは時間帯と0時で分単位を区切り直す概算。夜間個別上限、無料時間、曜日・特別日料金、車種条件、複合上限、運営会社固有の端数処理には未対応。最大7日間。日本時間環境を想定。
- 秘密情報・個人情報は収集せず、API料金やサードパーティーの有料機能は発生しません。
