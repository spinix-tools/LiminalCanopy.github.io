# ひだまり窓 / HIDAMARI MADO ☀️

窓・ベランダに直射光が届く時間を、方位・庇の奥行き・正面の障害物の高さから概算する無料のブラウザアプリ。

## ターゲットと着眼点
賃貸住宅の居住者、ベランダ園芸・家庭菜園の愛好家、部屋を内見する人。矢野経済研究所（2024-12-25公表）は2023年度の国内ガーデニング・家庭菜園市場を2,321億円と推計（メーカー出荷額）。利用者需要や課金意向の証明ではない。

競合：国内の「日照チェッカー」（建物3Dデータを用いた日照予測）、Sun Seeker（太陽軌道/AR）、海外のShadeClock（遮蔽予測）とSunPeek（窓の季節比較）。基本的な太陽位置計算は成熟した領域。

**差別化仮説:** 住所・地図・アカウントなしで、庇の奥行き・観測点から庇までの高さ・遮蔽仰角を直接調整できる**断面形状ベースの手動シミュレーター**。優位性・需要・収益性はいずれも未検証。

## 機能
日本語、東京/札幌/大阪のプリセット、緯度経度とUTC時差、任意の日付・窓方位、庇の奥行き/高さ、正面の遮蔽仰角。24時間タイムライン、直射時間帯、年間12か月の比較、CSVエクスポート、印刷、ローカル設定保存。外部API・ログイン・個人情報の収集なし。

## 使用・計算の制約
`index.html`を開く（同じディレクトリに`engine.js`と`app.js`を置く）。ビルド不要。NOAAの近似式に基づいて太陽高度・方位を算出。窓面が鉛直、庇が水平の単純モデルで、太陽が窓の正面にあり、庇・遮蔽物に遮られなければ直射と判定。天気、窓ガラス、建物の実際の輪郭、手すり、室内到達や夏時間の自動判定は対象外。遮蔽仰角は窓前面の半球に一律適用する簡易仮定。これは晴天時の**幾何学的な目安**であり、植物の適性や実際の日照を保証しない。

## テスト
ローカル拡張版：`node --test engine.test.cjs` **15/15通過**。Chromium操作確認 **22/22通過**（画面描画、方位変更、プリセット、CSV、入力検証、狭幅表示など）。実行環境がlocalhost/file URLをブロックしたためHTMLとJavaScriptを直接注入、localStorageはモック。実URL配信と通常のブラウザストレージの永続性は未検証。
