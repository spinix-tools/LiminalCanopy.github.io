# PrintFit / 印刷倍率の許容範囲監査

## 対象と選定理由
型紙制作者、ペーパークラフト作家、小規模印刷・制作工房。実寸印刷の失敗を裁断・全ページ印刷前に発見する。国内向けの Metrico はテスト正方形の縦横の測定を案内している。海外の Sew Measure は倍率補正、Sewlore は縦横の差、MakerSizer は軸別の補正を提供する。需要の兆候はあるが、利用者数・支払意思・市場規模は未検証。

- 国内: https://www.metrico.studio/ja/help/printing
- 海外: https://sewmeasure.com/tools/pattern-print-scale/
- 海外: https://sewlore.com/pages/pdf-pattern-print-scale-checker
- 海外: https://makersizer.com/app

## 差別化仮説
単一のテスト正方形の補正ではなく、ページ・軸・位置ごとの目標、許容差、測定不確かさを同時に扱う。倍率設定刻みも考慮して合否を判定し、両端の制約要因を提示する。不合格なら最大超過を最小化する参考値（合格ではない）を表示する。独自性はこの機能の組合せについての仮説。

## 起動と計算
index.html をブラウザで開く。最大100行のタブ区切り（箇所名、目標mm、実測mm、許容差mm、不確かさmm）を入力する。測定倍率 B、実測 m±u、目標 t±d に対し、設定倍率 P の許容範囲は B(t-d)/(m-u) から B(t+d)/(m+u)。各区間の積集合を取り、指定刻みに合う設定を列挙する。合格なら現在倍率に最も近い設定、不合格なら最大超過最小、同点なら現在倍率に近い設定を表示する。JSON出力・印刷対応。外部API、通信、永続保存なし。PDFを加工する機能ではない。実際の印刷倍率が線形に効く仮定であり、歪み・紙変形・再現性・現場品質は未検証。必ず再印刷し確認すること。
