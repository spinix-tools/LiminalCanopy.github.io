# 種繰 / TANEGURI 🌾

**2026-11-23 — offline sourdough starter chain planner (MVP)**

家庭のサワードウベイカー向けに、最初の瓶の元種から、**複数のパンの種継ぎ・使用・次回保持量を順に計算**するWebアプリ。生地の粉・水に含まれる元種分も差し引きます。前工程で不足すれば後工程は推測せず「未計算」にします。

## 操作
`index.html` を新しいブラウザで開く。元種初期量、焼成別の「パンに使う種」「次に残す種」「1:r:rで加える粉水」「総粉量・水分率・塩」を編集（**値を確定/フォーカスを外すと反映**）。工程の追加・複製・移動・削除、元種の使い切りに近づく比率の提案、Undo、CSV・JSON・印刷、JSON復元、端末保存を搭載。

**前提：** 元種の水分率は常に100%、蒸発・付着損失なし。必要完成種 T=使用種+保持種。取り分け元種 S=T/(1+2r)。Sが手持ちを超えると「不足」で計算を停止。生地追加粉=総粉量-使用種/2。生地追加水=総粉量×水分率-使用種/2。配合矛盾も検出。発酵活性・衛生状態・完成時刻を予測しない。
