# いきすう / IKISUU — 空気の時間割

**人数・部屋の容積・外気換気量・強換気の時間帯から、CO₂濃度の推移を概算するオフラインWebアプリ。** 2026-11-18制作。

## 対象・選定理由

- **対象**: 会議室・小規模教室・ワークショップを運営する人、施設担当者。
- **日本**: 文部科学省の学校換気計画資料にはCO₂の目安1500 ppmと、換気設備に加え必要に応じて定期的な窓開けを行う考え方が記載される。換気の時間的な運用が課題であることを示す参考資料（法令・ガイドラインは最新原文を確認すること）。
- **海外**: 米国NISTのQICO2 Tool（2022年更新）は室内CO₂濃度の定常・一定時間後の計算を提供。Harvard Healthy BuildingsのCO₂ Calculatorも定常状態の予測を提供する。日本国内のパラダイム「換気量・CO₂目安シミュレーション」は面積と人数から定常濃度を概算。すなわち計算自体は既存。
- **差別化仮説**: 「時間枠ごとに人数と換気モードを編集」→「同じ人数で通常換気のみと比較」→「強換気を1枠追加した場合の改善候補」までを**日本語・登録なし・外部APIなし**の一画面で完結する。個別のアプリ需要、優位性、支払意思は未検証。

## 使い方・機能

`index.html` を開く（または `python -m http.server 8000` で配信）。会議室／教室／創作教室から選び、部屋寸法・通常と強換気の**屋外空気導入量 m³/h**、人のCO₂発生量（L/h/人）、比較濃度を指定する。15〜60分単位の時間枠を最大24件まで編集・追加・削除。各枠の人数と強換気を切り替え、通常換気のみと計画換気の2曲線、最大濃度、比較線超過時間・累積超過量、追加強換気の候補を表示。候補はボタンで適用できる。

CSV結果出力（UTF-8 BOM付き）、JSON設定保存・読込、印刷、ブラウザ内 `localStorage` 保存に対応。外部ライブラリ・ユーザー登録・APIキー・クラウド通信・個人情報入力は不要。

## モデルと限界

室容積 V [m³]、人数 n、1人の発生量 g [L/h]、外気換気 Q [m³/h]、外気濃度 Cout [ppm] の完全混合1室モデル。一定区間の解析解：

- Q > 0: `C(t) = Cout + (C0-Cout)*exp(-Q*t/V) + 1e6*(n*g/1000)/Q * (1-exp(-Q*t/V))`
- Q = 0: `C(t) = C0 + 1e6*(n*g/1000)*t/V`

区間ごとに人数とQを変更し、区間内12分割の数値サンプルで最大値と比較線超過時間を集計（濃度そのものは解析解）。提案は**各未設定枠を1枠だけ強換気にして累積超過量の低減を比較する局所的な順位付け**で、最適な全体計画を保証しない。比較線は法的適合・感染リスク・健康安全の判定を意味しない。

**必須の注意:** 実際の換気量、空気の混合度、CO₂発生量、外気変動、他の汚染物質、感染リスク、熱的快適性は未検証・未モデル化。空気清浄機の循環風量を外気換気量として入力しない。実測や専門判断に代わるものではない。
