# 余白シフト / YOHAKU SHIFT

**1日イベントのボランティア当番を、参加可能時間・役割・休憩・上限時間を守って割り当てるローカルWebアプリ**。静的なHTML/CSS/JSのみで起動できます。アカウント、APIキー、外部送信、追加課金は不要です。

## 対象・選定理由・市場調査（2026-11-20時点）

対象：小規模な地域の祭り、文化祭、非営利イベントを運営する担当者。参加者には氏名でなく **Aさん / Bさん** などの仮名を推奨します。

- **国内の需要の傍証**：大阪府の公表（2026-04-01更新）では2025年大阪・関西万博の「大阪まちボランティア」に約11,000人が184日間参加。大規模活動ではあるが、「限られた人手を時間帯・役割で組む」問題の存在を示す。これは小規模イベントのTAMや支払意欲の推計ではない。<https://www.pref.osaka.lg.jp/o020060/bampaku_suishin/volunteer/index.html>
- **国内競合**：2026-08-21にリリースされた「もちば」は非営利活動なら無償のボランティアシフト管理サービスで、希望収集と配置まで対応。<https://crssrds.jp/news/mochiba/>。また「当番表メーカー」は自動作成・通知・希望収集、whenlyは希望収集、ローテーション当番のToobanもある。<https://toban-maker.jp/> <https://whenly.paps.jp/use/shift> <https://tooban.net/>
- **海外競合**：VolunteerLocalは役割別シフト作成と参加枠管理（公式ヘルプ2026-10-01更新）、SignUpGeniusはボランティアの登録・イベント調整、WhenToHelpには時間帯希望に基づくAutoFillがある。<https://volunteerlocal.zendesk.com/hc/en-us/articles/5907745394203-How-to-Create-Manage-Shifts> <https://www.signupgenius.com/> <https://whentohelp.com/volunteer-scheduling.htm>

**差別化仮説**：参加者へのURL共有・メール通知・登録管理をあえて作らず、匿名・単一日の**「休憩や上限時間を破らない割当」**を端末内で最短操作に特化。重要な枠の欠員を可視化し、結果から任意の席を固定して残りを再探索できる。既存競合も自動配置に対応しているため、独占的な新機能とは主張しない。顧客インタビュー、実際の作業時間削減、支払意欲は未検証。

## 完成機能

1. 参加者の仮名、担当可能役割、複数の参加可能時間帯、上限勤務分数を編集。
2. 役割、開始・終了時刻、必要人数、重要度を持つ当番枠の追加・編集・削除。
3. 時間の完全包含、役割、重複禁止、最小休憩間隔、合計担当時間上限を**ハード制約**として配置を探索。重要枠の欠員は通常枠の5倍のペナルティ。
4. 小規模な場合（最大16未固定席・14名）は**上限85,000ノードの分枝探索**。探索上限に達した場合は非最適の可能性を警告。規模が大きい場合は貪欲法に切り替え、最適性を保証しない。欠員ペナルティ最小化を優先し、同点なら担当時間／各人上限の比率の分散を低減。
5. 配置結果、担当時間バー、欠員数、担当者固定・解除、固定条件が不正な場合の拒否。
6. CSV（UTF-8 BOM）、JSON入出力、手動localStorage保存と削除、印刷。CSV先頭の表計算式記号はエスケープ。

デモ起動時は7名・6枠・合計10席の例を初期表示します。

## 起動方法

ファイル4点（`index.html`、`style.css`、`engine.js`、`app.js`）を同じフォルダに配置し、`index.html`をブラウザで開いてください。ビルド手順・外部パッケージ・通信は不要です。GitHub Pagesへ公開するときは公開URLに移動すれば起動できます（このアプリのライブ公開は別途確認が必要です）。

## 制限とプライバシー

- **単一日**の計画のみ、同日内で完結する時間枠に対応。翌日への跨ぎ・夜勤・労務法適合の判定はしません。
- 休憩とは「連続した担当枠の間に最低N分の空白を置く」という単純な制約であり、法定休憩や安全性を保証しません。
- 固定担当が競合した場合は自動で破棄せずエラー表示。実際の参加確認、緊急連絡、参加者の同意収集等は別途運営者が行います。
- 参加可能時間や役割は入力したブラウザ内だけで処理されます。端末内保存はユーザーが「この端末に保存」を押した場合のみ。JSON/CSVの書き出し・読み込みは利用者の操作によります。個人情報・実名の入力は推奨しません。
