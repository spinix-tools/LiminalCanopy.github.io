# あみかえ / AMIKAE

編み図のゲージと手元の2つの試し編みゲージを照合し、**開始/終了目数・必要段数・左右対称の増減目を段単位に再計画する**登録不要の静的Webアプリ。

## 対象と選定理由（2026-11-18 確認）

対象：棒針/かぎ針編みで既存パターンを別糸・別針に換える人、ハンドメイド教室の講師。

日本ではITmedia（2026-03-08）がフェリシモ「クチュリエ」の編み物関連商品売上は2025年度に2023年度比約1.9倍と報道。若年層の編み物参加拡大が示唆されるが、**編み図換算ツール固有の需要・課金意向を直接測定した数字ではない**。海外ではGaugeGuru、Knit Toolboxなど実用品が存在し問題認識はあるが、競争も強い。

| 地域 | サービス | 確認した機能 / 相違 |
|---|---|---|
| 日本 | [Belicia ゲージ計算](https://belicia.jp/gauge/) | ゲージ・サイズ換算、増減目配分を提供。計算自体の新規性はない |
| 日本 | [KnitBuddy](https://apps.apple.com/jp/app/knitbuddy-%E7%B7%A8%E3%81%BF%E7%89%A9-%E5%A2%97%E6%B8%9B%E7%9B%AE%E8%A8%88%E7%AE%97/id6816652688) | 増減目・ゲージ換算。アプリ内購入あり |
| 海外 | [GaugeGuru](https://gaugeguru.app/) | ブラウザ内でゲージ換算・成形・プリセット保存まで提供 |
| 海外 | [Knit Toolbox](https://knittoolbox.com/) | 段数カウンタ、袖の成形、10cmゲージ計算を提供 |
| 海外 | [Stitchwise](https://kashiworks.com/projects/stitchwise) | 横縦のゲージを独立換算、模様の倍数も考慮 |

**仮説**：初心者〜中級者には「A/Bの試し編みを同一画面で比較 → 模様の倍数と左右対称制約を考慮 → 各段の実行指示と段カウンタまでつながる」日本語Web体験が有用。個々の数学機能は既に競合にあり、新規性はワークフローの統合・視覚化。競争優位・ヒット確率は未検証。

## 動作

`index.html` をブラウザで開く。ビルド・ネットワーク・アカウント不要。`engine.js` と `app.js`、`style.css` を同じフォルダに置く。

- 編み図の目数・段数、ゲージ、幅調整、模様の倍数＋余り、増減段の間隔を指定
- 試し編みA/Bの目数と段数を比較し、完成寸法誤差・増減回数を表示
- 段ごとに左右各何目増減するか出力し、進行カウンタとマップを連動
- 1段で複数増減が必要な場合、許容誤差0.5cm超の場合の警告
- 変更は端末ブラウザ内の `localStorage` に保存。JSON出力/読込、段割CSV、印刷対応

### 計算上の前提・注意

- 全目数は整数。開始・終了ともに「**模様倍数 × n + 余り**」を満たし、差を偶数に制限する。
- 1回の左右対称操作は左右に同数の増減をする。総目数差を段ごとに均等配分する。通常は左右各1目、段不足時は複数目/側を配し**警告**。
- 横ゲージと縦ゲージをそれぞれ10cmあたりの目/段で計算。幅調整は「開始・終了両方に同じcm」追加。
- 模様の編み方、輪編み/平編み、引き返し編み、拾い目、段間の柄位置、毛糸の伸縮、洗濯後変形、左右で異なる成形、増減可能な段の実現性は判断できない。
- 現物のパターンを自動解析するものではなく、入力数値に基づく**検討補助**。特に1段で複数目を処理する案は手動で見直す必要がある。
- 「推奨」は幅誤差と段の増減密度による参考点。着心地・デザイン品質の優劣ではない。

## テスト

- `node --test engine.test.cjs` → **21/21 pass** (Node v22)。誤差・制約・奇偶・左右対称・段数・入力拒否・減増パターンを確認。
- `python browser_test.py` → **32/32 pass** (Playwright + Chromium)。画面表示、A/B切替、段カウンタ、反応更新、エラー復帰、JSON・CSV出力/入力、保存復元、モバイルレイアウトを確認。
- **試験環境の制約**：Chromiumからの `file://` ナビゲーションは `ERR_BLOCKED_BY_ADMINISTRATOR`。HTML/CSS/JSをページに直接挿入、`localStorage` を模擬して試験。OSごとの実ローカルファイル起動、永続ストレージ、印刷実機は未検証。
