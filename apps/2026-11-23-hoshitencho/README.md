# 星点帳 / HOSHITENCHO ✧

**星景写真の露光予測・試写照合・連続撮影容量計画**。2026-11-23制作。MITライセンス、静的ブラウザアプリ、アカウント・API不要。

## ターゲットと選定理由

星景・天の川の固定三脚撮影を始めた写真愛好家、学校の天文部、小規模撮影会。画素密度や赤緯によって露光上限は変わり、撮影現場での予測と実写の差を確認する道具が必要だと考えた。CIPAが**2026年2月26日**に公表した2025年世界のデジタルカメラ出荷は**9,438,876台**。これはカメラ市場の間接指標であり**本アプリの潜在顧客数や課金意思を意味しない**。[CIPA 2026年2月26日](https://www.cipa.jp/documents/e/PRESSRELEASE20260226_e.pdf)、[CIPA 2026年9月実績（2026年11月2日更新）](https://www.cipa.jp/j/stats/dc.html)。

## 国内・海外競合と差別化仮説

- **国内**：[ポチカツ道具箱「星の点像シャッター」](https://tools.potikatsu.com/t/photo-star-shutter/) は500ルール/NPFルール/星像伸び表示を提供。
- **海外**：[PhotoPills Spot Stars](https://www.photopills.com/calculators/spotstars) はNPF等を提供。[ExposureTools StarCalc](https://exposuretools.net/star-calc) は無料・ブラウザオフラインでの撮影計算を提供。[NR Tech Studio](https://nrtechstudio.com/tools/star-trail-length-calculator/) は角秒とpxによる星像伸びを計算。

**差別化仮説**：単なる秒数計算ではなく、**幾何モデルの伸びpxとユーザーが試写から実測した伸びpxを照合**し、そのシャッター条件での**撮影枚数・カード容量・タイムラプス尺**までを一画面で判断できる小型ツール。既存ツールにも重複機能があり、差別化の有効性・需要・収益性は未検証。

## 使える機能

センサー例（フルサイズ/APS-C/M4/3）・実焦点距離・画素数・対象赤緯・許容px・露光の編集、上限秒数・リスク表示・SVGグラフ・14候補の露光比較、コマ間休止と撮影時間から枚数・GB・動画尺の計算、試写記録・メモ・削除と中央値からの参考上限、JSON保存/復元、CSV出力、印刷、端末内localStorageへの自動保存、スマートフォンレイアウト。試写pxの自動画像測定はない。

## 起動とコードの区別

**このGitHubフォルダの `index.html` は可読ソースの軽量・独立実装**で、単独保存して現代ブラウザで開ける。追加依存、ネットワーク要求なし。

**同時配布ZIPには、別の詳細UIの完全版**（`standalone.html` は単一ファイル起動、また `index.html` / `style.css` / `engine.js` / `app.js` は可読な分割ソース）がある。GitHubの軽量版とZIPの完全版は**別実装**。ZIPにのみ詳細テストコードと画面画像が含まれる。GitHub版のコードはgzip内包ではなくそのまま閲覧・編集できる。

## 検証と限界

- **ZIP完全版**：Node.js単体 **21/21合格**、固定シード1,600ケースの幾何・枚数不変条件、Chromium **43/43合格**（単独HTMLおよびZIP内のgzip再構成版）、JavaScript例外・外部HTTP通信は0件、JSON/CSV入出力とモバイル表示を確認。
- **GitHub版**：GitHubから再取得した17,381文字のHTMLで**JavaScript構文検証合格**、重要DOM ID **28/28存在**、外部CSS/JS参照なし、**DOM模擬操作14/14合格**（再計算、警告、センサー切替、試写追加削除、実測推定、JSON/CSV出力、入力回復など）。**GitHub版の実Chromium操作テストは未実施**。
- **環境制限**：完全版のChromiumテストは管理環境で `file://` 直接遷移が遮断されたため同じHTMLを `page.set_content` でインライン展開して実施。端末への永続保存、実星景写真での予測精度、通常ファイル起動は未検証。
- **モデル**：恒星日86,164.0905秒、角速度約15.041×cos(赤緯)角秒/秒、画素スケール約206.265×画素ピッチµm/実焦点距離mm。画像中心の小角・幾何近似。視野端・レンズ収差・大気の揺らぎ・手ぶれ・追尾・光害などは考慮しない。点像保証なし。

外部API・有料サービス・OpenAI API課金・秘密情報や個人情報の収集なし。
