# 種つなぎ / TANE TSUNAGI

**限られたプランター枠の中で、作物ごとの播種・育成・収穫を週単位でつなぐ、無料・完全ローカルの静的Webアプリ。** 2026年11月20日制作。

## ターゲット・市場選定

- **対象:** ベランダ菜園、キッチン菜園、小さな貸し農園で「収穫が一度に集中する／その後途切れる」「次を播けるプランターが分からない」人。作物・品種・地域ごとの適期は利用者自身が確認して入力する。
- **日本:** [タキイ種苗「2026年 家庭菜園に関する調査」（2026-03-04）](https://www.takii.co.jp/info/news_260304.html)は全国20～69歳の400人を対象にした調査で、省スペース・低コストの栽培への関心層が6割超と報告。未経験者の障壁として場所・時間・費用が挙げられた。小さなスペースを効率よく使いたい層の存在を示唆するが、ソフト購入需要や市場規模を直接測っていない。
- **国内競合:** [菜園ナビ記録ツール（App Store）](https://apps.apple.com/jp/app/id1112051462)は写真記録・栽培コミュニティとの連携、[にょきっと（App Store）](https://apps.apple.com/jp/app/id6801136964)は日当たり・水やり判断、[種ごよみ（App Store）](https://apps.apple.com/jp/app/id6816881926)は作業予定と記録に注力。国内にも栽培管理・カレンダー競合がある。
- **海外競合:** [Seedtime](https://seedtime.us/)は作付けカレンダー、ベッド配置、連続播種に対応し、サイト上で利用者57万超と表示（事業者による自己申告）。[Seedtime連続播種ガイド（2025-01-19）](https://help.seedtime.us/en/articles/5833547-succession-planting)も参照。[GrowVeg Garden Planner](https://www.growveg.com/guides/its-here-our-new-and-improved-garden-planner/)も連作・空き地確認・輪作に対応。**連続播種そのものは新規技術ではない。**
- **差別化仮説:** 既存の総合的な栽培管理に対して、**「枠数・播種からの育成週数・収穫期の毎週量・週ごとの食卓目標」を入力 → 何週目にいくつの枠が空くかを表示 → 固定済みの播種を保ったまま自動提案**までを1画面で完了。登録・位置情報・外部AIに依存しない。新規性・収益性・需要は未実証。

## 実装したMVP

1. 栽培開始日、6～24週の期間、使えるプランター枠（1～24）、毎週の収穫目標量（1～30）の編集。
2. 最大8作物の育成週・収穫週・必要枠・週当たり収穫量・播種可能期間・播種回数上限を編集。サンプル値は仮の計算値であり栽培適期・実際の収量ではない。
3. 容量上限と播種回数上限を守るヒューリスティック自動計画（複数の初期選択順序＋1件交換による局所改善）。「収穫をつなぐ／種まきを減らす」の2方式。
4. 特定作物の播種週を手動固定し、固定された種まきを壊さずに残りを再提案。容量超過・同週重複・範囲外は明示して拒否。
5. 週別の積み上げ収穫SVGグラフ、目標充足率、未達週、プランター使用量、作物別カレンダー、次の播種日一覧。
6. JSON保存・復元、Excel等で確認できるBOM付きCSV出力（CSV数式インジェクション対策あり）、印刷、localStorageへの自動保存、スマートフォン対応。

## 実行と検証（2026-11-20）

`index.html`をブラウザで開く。同じディレクトリに`style.css`、`engine.js`、`app.js`を置けばネットワークやパッケージインストールは不要。確認用コマンド：

```bash
node --test engine.test.cjs
python browser_test.py
```

- Node.js: **22/22単体テスト合格**。別途、固定seedの**250件のランダム条件**で枠数、収穫量の保存則などを照合。最大設定例（24週×8作物）も400 ms台で算出（単一実行時の参考値）。
- Chromium: **37件のGUIチェック合格**。入力編集、収穫グラフ、端末保存、CSV/JSON出力、JSON復元、種まき固定・削除、スマートフォン幅をテスト。画面画像は `desktop.png` と `mobile.png`。
- **制限:** 管理環境のブラウザでは `file://` が管理者ポリシーで遮断されたため、GUI試験は**実際の同一HTML/CSS/JSをインライン展開**し、localStorageを模擬した。通常ブラウザでの直接ファイル起動、保存永続性、印刷実機、実際の生育・収穫との一致は未検証。最適解保証はない。
- プライバシー: 利用者登録、APIアクセス、外部通信、個人情報収集、課金なし。作成した計画は端末のみで保持。JSON/CSVは利用者が手動ダウンロード。

## モデルの注意・検証課題

「枠」は同じサイズ・同じ条件の抽象化した栽培区画。1回の播種で必要枠を収穫最終週まで連続占有すると仮定する。各収穫週の予定量は一定で、天候、発芽率、間引き、土壌、病害、季節ごとの生長差、植え替え期は考慮しない。播種可能週や育成・収穫期間は**種袋・地域の公的な栽培指導を参照して設定**する。アプリから最適な播種日や食品安全性を保証するものではない。

実利用検証は、ベランダ栽培者5～10人に紙/表計算と比較してもらい、計画作成時間、播き忘れ・枠の取り合い、収穫空白週、翌月の継続利用を観察するのが次の段階。
