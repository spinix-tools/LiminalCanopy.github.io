# 木取り日和 / KIDORI BIYORI

**制作日:** 2026-11-20 / **対象:** 小規模DIY、木工初心者、工房の端材管理担当

## 選定理由と需要の手掛かり

過去の室内音響、水槽、結露、家庭菜園、電源計画、字幕、家具搬入、印刷分版、稽古編成、マルシェ採算とは異なる「板材の調達・切り出し」の課題を選んだ。経産省商業動態統計を紹介する流通ニュース（2026-10-30）では、2026年9月の国内ホームセンターDIY用具・素材売上が608億円、前年同月比3.5%増。これは関連物販の指標であり、アプリ利用・有料化の需要を証明しない。

## 国内・海外の競合

- 国内 [Cutting Planner](https://tubakurosoft.com/): 1D/2D板取り最適化。Windows向けソフト。
- 国内 [Sawgrid](https://apps.apple.com/jp/app/sawgrid-%E6%9C%A8%E5%8F%96%E3%82%8A-%E6%9D%BF%E5%8F%96%E3%82%8A%E6%9C%80%E9%81%A9%E5%8C%96/id6796387104): 木目、刃幅、端材管理等。Pro機能あり。
- 海外 [CutGrid](https://cutgrid.com/): 木目、刃幅、端材、購入原価などを備えるオンライン製品。
- 海外 [cutlistlab](https://cutlistlab.com/cut-list-optimizer-grain-direction.html): 無料・ログイン不要の木目固定・端材対応最適化。

**差別化仮説:** 最適化エンジンそのものは既に成熟した競争領域。初心者向けに、**「手持ち端材を先に使う」対「配置しやすさを優先」**を同条件で比較し、未割付部品、追加購入額、加工後に残しておく端材の寸法・面積をCSVに一気通貫で取り出す、完全オフラインの小さな判断ツールに価値がある可能性を検証する。競合より高精度・完全独自とは主張しない。

## MVP機能

- 手持ち端材と購入候補の材料を名前・mm寸法・枚数・価格で編集。部品の寸法・個数・木目方向固定を設定。
- 刃幅（カーフ）、四辺余白、再利用端材の最低寸法を指定。
- ２つの貪欲な矩形分割割付を比較。未割付は隠さず警告、購入金額は使用した新材のみ積算。
- SVG板取り図、各部品座標のCSV、再利用端材一覧CSV、先頭材料SVG、印刷、プロジェクトJSON入出力、localStorage自動保存。
- API・通信・アカウント登録・個人情報収集・追加課金は不要。`index.html` を直接開く構成（ただし管理環境では直接起動未確認）。

## 使い方

`index.html` をブラウザで開く。Node.jsでテストを実行するには `node --test engine.test.cjs`。Python Playwrightを使う画面テストは `python browser_test.py`（Chromiumが必要）。

## 検証（この実行）

- Node.js v22: **8/8 テスト合格**。320シナリオ × 2方針で、部品の欠落・重なり・材料外配置・数量整合性などを検証。
- Chromium / Playwright: **23操作・検査合格**。編集、削除、A/B、エラー復帰、JSON/CSV/SVG出力、モバイル画面を確認。
- Chromiumから `file://` へのアクセスは管理環境により `ERR_BLOCKED_BY_ADMINISTRATOR`。代わりに**実ファイルと同一のHTML/CSS/JSをインライン展開**して動作確認。ファイル直起動、localStorageの長期永続性、実機切断精度、最適解の達成度は未検証。

## 限界・安全性

ヒューリスティックなguillotine分割の一案。実際の**切断順・切断機の寸法制限・節・木目の材料間整合・厚み・材質・固定方法・安全性**は保証しない。材料間の材質混在も判定しない。再利用端材は幾何学的に残る矩形の推定。計算図に従う前に現物確認必須。
