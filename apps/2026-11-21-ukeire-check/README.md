# 受入前チェック / UKEIRE CHECK

小規模EC・NPO・学校事務・個人事業のCSV受入担当者向け、**文字コードの取り違えとデータ仕様違反を事前点検する、ブラウザだけのCSV検収デスク**。

## 選定理由・市場仮説（調査: 2026-11-21）

- **日本：** 中小機構が2026年2月に公表した「中小企業のDX推進に関する調査（2025年）」では、DXに取り組む／検討中の回答が39.1％。IT・DX人材と予算の不足が課題とされる。これは「CSV事前点検」固有の市場規模ではなく、軽量・無登録ツールを検討する背景指標。[中小機構 調査一覧](https://www.smrj.go.jp/research_case/questionnaire/) / [調査の概要](https://www.henmi-adm.jp/news/3758.html)
- **日米独：** IPA「DX動向2025」は日本・米国・ドイツの計2,500社を調査。小規模企業の社外連携活動には国差があり、複数システム間のデータ受け渡しは海外にも存在する。ただし、CSVでの失敗率や本アプリへの購買需要を直接実証する資料ではない。[IPA 2025-09-04](https://dx.ipa.go.jp/dx-trend-2025)
- **競合（国内）：** [サクプラCSVルール検証](https://www.norops.jp/tools/csv-rule-validator)は必須・型・重複チェックに対応。[CSV Dock](https://csvdock.com/ja)は文字化けとExcel変換に対応。後発のため単機能では競争が厳しい。
- **競合（海外）：** [CSVbox](https://csvbox.io/csv-importer/)は列マッピング、検証と修正を備える組込み型ツール。[Flatfile](https://support.flatfile.com/articles/7763163677-importing-data-with-flatfile-overview)もマッピング／バリデーションを提供。[CSVLint](https://csvlint.io/)は標準・スキーマ検証を提供。

**差別化仮説：** 競合との絶対的な新規性はない。業務非エンジニアに向け、**日本語＋CP932/EUC-JPの読込、取込列対応、型・必須・重複・先頭ゼロ・表計算式の事前点検、受入可能行だけの抽出、理由付きCSV検収レポート、再利用可能なJSON仕様**を**ログイン・送信・サーバーなし**でひとまとめにする。適合先固有の検査ルールを「仕様JSON」にして担当者間で共有できることが訴求点。需要・収益性は未検証。

## 操作

1. `index.html` を開く。サンプル（架空の商品マスタ）が自動で読み込まれ、検証結果が表示される。
2. 3MB以下のCSV/TSV/TXTを選択。自動判定またはUTF-8/CP932/EUC-JP/UTF-16LEを選ぶ。文字コード判定は推定であり、手動で変更できる。
3. 受入列名、入力列対応、型（文字列／整数／非負数／日付／列挙値）、必須、重複禁止、最大文字数を設定して「点検を実行」。
4. 指摘一覧から行番号と理由を確認。**見出しの不備がある場合は出力を禁止**、データ行のエラーはその行だけ除外、警告のみの行は残す。
5. CSV（UTF-8/BOM選択可）、指摘レポートCSV、検証ルールJSONを保存できる。式セル文字列化は任意設定で、既定では元データを改変しない。

## 実装・検証

- JavaScript単体テスト `node --test engine.test.cjs`：**38/38成功**。CSVクォート・改行・破損入力・ヘッダー重複・型検証・日付・数式・先頭ゼロ・JSON往復に加え、**500個のランダムCSV往復検証**を実施。
- Playwright + Chromium `python browser_test.py`：**29/29成功**。架空データ解析、入力変更後の再点検、CSV/BOMダウンロード、レポート、ルール編集、**CP932実ファイルのブラウザ復号とUTF-8変換**、誤エンコーディング警告、XSS文字列化、モバイル表示を確認。
- `node --check engine.js && node --check app.js` 実行成功。
- **制限：** 検証用Chromiumでは管理環境が `file://` をブロックしたため、`index.html`と同一のCSS/JSをインライン化した`about:blank`上でUI検証した。通常ブラウザの直接 `file://` 起動は未検証。3MB・100,000行・60列上限。超大容量CSV、独自の複合制約、送信先システムでの実インポート成功、Shift_JISでの出力、破損済みデータの復旧は対象外。自動文字コード推定は確率的で、最終確認が必要。
- 表計算式で始まる値は **警告だけ**で、標準出力は元値を保持する。Excelなどで開く際は、利用者が式として評価されない設定を選ぶ必要がある。`式として読まれる値に ' を付与`をオンにすれば、エクスポート時に該当値を明示的に変更する（受入先との適合性は未保証）。
