# 資金の谷 / SHIKIN NO YA

日本語で使える、登録不要の **入金遅延・資金ショート耐性シミュレーター**。 `index.html` をブラウザで開くと操作できます。依存ライブラリ、クラウド接続、APIキー、課金なし。MIT相当の自己利用は可能ですがライセンスは下記参照（LICENSEは未添付）。

## 想定ターゲットと選定理由
フリーランス、制作会社、受託開発の小規模事業者。請求書の入金予定が一定期間遅れた場合に、固定費・外注費が先に到来する「資金の谷」を直感的に確認したい人向け。

- **国内の課題**: 中小企業庁・2026年版白書の概要（2026年4月）は、資金繰り計画が資金不足時期の把握に寄与すると記載。経産省（2025年11月11日）は支払条件の改善が中小企業の資金繰り上の重点課題とし、2026年1月1日の取適法施行について説明。
- **国内競合**: freee会計の資金繰りレポートは将来の想定入出金も扱う。iOSアプリ「資金繰り予報」は90日予測と入金遅延比較まで提供。よって**入金遅延シミュレーション自体を独自機能とは主張しない**。
- **海外競合**: Floatは会計システム連携とシナリオ比較、Dryrunは日別予測や支払タイミングの変更を提供。いずれも既に高度な機能を備えている。

## 差別化仮説
日本語・JPY固定・ブラウザ内完結・会計サービス連携なしで、**「遅延0〜60日の通常/ストレスを一画面比較」+「目標残高を維持するための最大不足額」+「各入金を単独で予定日に戻した場合の最低残高改善額ランキング」**を一緒に見られる軽量な意思決定用ツール。競合優位性、実需要、価格受容性は未検証。

## 実装済み機能
- 開始日・資金残高・最低確保額・30/60/91/120日の期間設定
- 入金・出金予定の編集/追加/削除、月次繰り返し、入金ごとの遅延対象指定
- 入金遅延スライダー（0〜60日）、通常・ストレスの**日別**残高比較、SVGグラフ
- 期間中の最低残高、初回の確保額割れ/マイナス日、必要余力、個別入金の改善寄与
- BOM付き日別CSV、設定JSONエクスポート/インポート、印刷
- 明示保存時のみlocalStorageへ保存。サンプルデータ標準搭載
- 最大150明細、1件10億円、14〜120日、JSONは1MB以内の入力制限

## 動かし方
`index.html` を開く（ビルド・サーバー不要）。最初は架空のサンプルデータで動作します。JSON読み込みは本アプリ形式のみ。ブラウザのダウンロード設定に従ってCSVやJSONが保存されます。

## 計算の前提と限界
「開始日の朝の手元残高」に、入力された予定の当日入出金を加えた **日末残高** を使用。月次繰り返しは設定した日の各月同日（なければ月末）で発生。対象入金を指定日数だけ遅らせ、予測期間外は算入しません。確保額不足 = max(0, 確保額−期間最低日末残高)。必要余力は融資額の提案ではなく、与えられた仮定下の算術結果です。**入金確率予測、入金保証、支払猶予の法的判断、会計・税務・金融助言はしません**。

## 検証
自動テスト・実機検証の状況は実行レポートに別記。CSVやJSON生成、境界日付、DOMイベント、インポート、移動日を重点検証。通常のファイル直開き、印刷・実運用の実測精度は運用環境次第で追加検証が必要。

## 収集・課金の範囲
外部API呼び出しなし、会員登録なし、広告トラッカーなし、アプリによる個人情報収集・送信なし。localStorageは利用者の明示操作のみ。内容に取引先名や個別の金融機密を入力すると、共有端末内の保存や出力ファイルを扱う本人の管理責任が発生するため、架空の名称での使用を推奨。
