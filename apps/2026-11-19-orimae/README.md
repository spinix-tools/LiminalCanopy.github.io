# おりまえ / ORIMAE 📖

家庭用プリンターで中綴じコピー本を作る人のための**印刷前チェック・試し刷り台紙生成**アプリ。登録不要、無料、依存ライブラリなし、ローカル完結。

## 対象と選定理由

対象は文学フリマ・ZINE・同人誌の個人制作者、学校配布冊子や旅のしおりを作る人。文学フリマ東京42（2026-05-04）の公式開催報告は**3,509出店・4,082ブース、来場18,689人**と公表しており、少なくとも自主制作・頒布の場が存在する。ただし**本アプリの需要や有料転換率を証明する数字ではない**。

## 日本・海外競合と差別化仮説

- 日本: ナカバヤシ「コンビニでコピー本をつくろう」（2024-08-08発表）はPDFの自動面付けとコンビニ印刷予約を提供。PDFアップロード・対応機種が前提。
- 海外: [BookletMaker](https://bookletmaker.app/) は端末内PDF面付け、折丁・クリープ調整などに対応。
- 海外: [Booklet Imposer](https://bookletimposer.com/) も無料・ブラウザ内処理・見開きプレビュー・PDF出力に対応。

**差別化仮説:** 高機能なPDF面付けの代替を競うのでなく、印刷初心者の**「製本に失敗しないための実物の番号入り台紙・裏面の回転と出力順の調整・1冊あたりのコスト試算」**を右綴じ対応の日本語画面に集約する。PDF自体を読み込んで再配置する機能は**ない**。競合製品の既存機能も重複し、仮説は実利用者テストが必要。

## 操作機能

1. 1〜120ページ・1〜1,000部、右綴じ/左綴じ、A4/B4/A3/Letterの面付け順を計算。4の倍数への空白補完を表示。
2. シートごとの表裏2ページ配置と、検品チェックをインタラクティブに確認。
3. 用紙単価・面印刷単価・試し刷り枚数から紙枚数と概算コストを計算。
4. 印刷用の番号入り台紙HTML（全ページ・表面だけ・裏面だけ）とCSV面付け表を出力。裏面180°回転と裏面逆順にも対応。
5. ブラウザのlocalStorageへの設定・検品状態の自動保存。外部通信・アカウント登録なし。

**使い方:** フォルダをまとめてダウンロードし、`index.html`を開く。試し刷り台紙HTMLを保存してブラウザで開き、「100% / 実際のサイズ」「横向き」「両面短辺とじ」を出発点に印刷。プリンター側の「冊子印刷」を有効にしない。まず1枚で検証し、表裏の給紙方向が合わなければ設定を変えて試す。

## 動作確認（2026-11-19）

- `node --test engine.test.cjs`: **11/11 テスト合格**。1〜120ページ×左右綴じの計240組合せについてページの重複・脱落がないことも照合。
- `python browser_test.py`: **25/25 Chromium操作アサーション合格**。ページ数変更、左右反転、コスト、CSV・HTMLダウンロード、保存復元、モバイル表示、JSエラーなし等。
- `node --check engine.js && node --check app.js`: 合格。
- 制限: 管理環境の制約で`file://`とlocalhostの遷移が遮断され、Chromiumは**ソースをインライン展開**して、localStorageをメモリ模擬して試験。一般ブラウザの直接起動・実プリンターの両面設定・物理製本の精度は未検証。
- 印刷コストはユーザー入力の線形試算。余白、インク滲み、プリンターの印刷可能領域、紙の厚み・クリープ補正、冊子の厚みを考慮しない。生成物は**番号付きの検証台紙**であり、原稿PDFそのものを面付けするものではない。

## ソース構成

`index.html` UI、`style.css` スタイル、`engine.js` 純粋計算、`app.js` 操作、`engine.test.cjs` 単体・組合せテスト、`browser_test.py` Chromium試験、`LICENSE` MIT。依存パッケージのインストールは不要（テストにのみNode.jsおよびPlaywrightが必要）。
