# 席めぐり / SEKI MEGURI

**研修・交流会の複数回テーブル割を設計し、途中参加や欠席が発生しても確定済みの回を残して再計画する、登録不要・端末内完結のWeb MVP。**

## ターゲット・選定理由（調査日: 2026-11-17）
- ターゲット: 企業研修講師、地域交流会主催者、学校・ワークショップのファシリテーター。実名は不要で番号で運用できる。
- 日本: 矢野経済研究所（2026-08-24）は2025年度国内企業向け研修サービス市場を**6,075億円**、前年比**+3.7%**と推計。ただし**交流テーブル割りアプリの市場規模を示す数字ではない**。ヒューマンアカデミーの300名調査（2026-06-02掲載）ではコミュニケーション研修が2年連続で最も実施されたテーマとされる。
- 日本の競合: [Smart Group Maker](https://smartgroupmaker.com/ja) は属性に応じたグループ分け、登録不要を提供。
- 海外の競合: [GroupMixer](https://groupmixer.app/) は多回・接触重複低減・部分参加・同席制約を広く実装。[Speed Date Groups](https://speeddategroups.com/) は多回にわたり新規出会いを増やす。[Redmoon Breakout Room Assigner](https://redmoonrandomizers.com/tools/breakout-rooms) は端末内で過去の組合せも記憶。したがって**多回割付やオフライン性自体は新規ではない**。
- 差別化仮説: **現場で1回ずつ「確定」し、遅刻・欠席が入った時点で過去の席割を固定したまま未来だけ再計算する**ことに絞る。進行画面・卓別案内・CSV・JSONをひとつにし、交流会運営の当日オペレーションを短くする。需要・優位性・収益性は未実証。

## 実装機能
- 2〜64名、1〜16卓、1〜12ラウンド、ラウンド別の途中参加・途中退出（`名前,開始回,終了回`）。
- 同席禁止のペア入力、乱数シード再現、接触重複と卓偏りを抑える乱択貪欲法・入替局所探索。矛盾した制約の探索失敗は警告する（**数学的な不可能性の証明ではない**）。
- 進行済みラウンドの確定、未来ラウンドだけ再計算、卓カード・ラウンド切替・接触網羅率・新規対面グラフ。
- CSVエクスポート、状態を含むJSON保存・復元、印刷、レスポンシブ表示。外部API・アカウント・追跡スクリプト・追加課金なし。記入情報はブラウザからサーバーに送信せず、明示的なCSV/JSON出力のときだけ端末に保存する。

## 起動・操作
1. ZIP展開後 `index.html` をブラウザで開く（静的Webサーバーでも可）。外部依存なし。
2. 参加者を各行に入力し、ラウンド数・卓数・任意の同席禁止ペアを設定。「全ラウンドを作成」。
3. 実施した回を「この回を確定」。遅刻が発生したら `A13,2,4` のように入力して「未実施を再計算」。過去の回に影響する名簿変更は拒否される。
4. 卓割を印刷・CSV保存、JSONで運営状態をバックアップ。

## 検証
- Node 22 の `node --test engine.test.cjs`: **18 / 18 合格**。パース、重複名、参加期間、同席制約、乱数再現、空ラウンド、過去固定、統計・異常値を検査。
- Chromium + Playwright の `python browser_test.py`: **31 / 31 合格**。作成・確定・途中参加の未来のみ再計算・同席禁止・CSV/JSON出力と復元・エラー・画面遷移・モバイル横はみ出しを検査。ナビゲーション制約のため、実HTML/CSSを直接配置し、JSをインジェクションして評価。実配信環境は未検証。
- 最適割付は保証しない。複雑な同席禁止条件では解が存在しても探索が失敗しうる。出会いの深さや会話の質は測定しない。途中参加を過去に遡って追加することはできない。データを保存したJSONには入力した参加者名が入るため、共有時は匿名化すること。
