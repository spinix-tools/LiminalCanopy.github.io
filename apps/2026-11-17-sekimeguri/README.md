# 席めぐり / SEKI MEGURI

複数ラウンドの交流席割を作り、**途中参加・欠席に応じて確定済みの回を維持したまま未実施回だけ再計算**する、登録不要・静的Webアプリ。計算はブラウザ内で完結し、名簿の送信・外部API・課金はありません。

## 対象と選定根拠（2026-11-17）

企業研修講師、地域交流会主催者、学校のファシリテーター向け。矢野経済研究所の2026-08-24発表によると2025年度国内企業研修サービス市場は6,075億円（前年度比+3.7%）ですが、本アプリ独自の需要を裏づける数値ではありません。日本のSmart Group Makerは属性別グループ分け、海外のGroupMixerは複数回の接触重複低減・途中参加設定、Speed Date Groupsも公平な多回交流を提供しています。このため、単なるシャッフルではなく**ラウンド確定・当日の変更・接触状況の可視化・卓別出力を連結した運営フロー**を差別化仮説とします。需要・収益性は未検証です。

## 機能

2〜64名／1〜16卓／1〜12回。名前・開始回・終了回の入力、同席禁止ペア、シード再現可能な近似割付、確定済みの回を保持した未来再計算、新規／再会組数・カバレッジ、各卓案内、CSV・JSON保存と復元、印刷、スマホ対応。実名の代わりに番号を推奨します。外部API、追跡、アカウント、個人情報収集なし。

## 検証と限界

ローカル版: Node 22 単体18/18、Chromium + Playwright 操作31/31 合格。Chromiumはナビゲーション制約があるためHTMLを直接配置してJSを実行。配信環境・実端末保存は未検証。制約付き割付は乱択貪欲法＋局所探索の近似計算で、最適解を保証せず、解があっても探索に失敗する場合があります。

## 起動

`index.html` を開き、参加者を1行1名で入力。途中参加は `A13,2,4` の形式。作成→「この回を確定」→必要に応じて名簿修正→「未実施を再計算」。CSVで卓案内、JSONで状態保存。保存JSONには入力名簿が含まれるため共有時は匿名化してください。
