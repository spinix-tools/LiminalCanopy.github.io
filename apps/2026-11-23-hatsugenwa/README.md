# 発言輪 / HATSUGENWA — 録音せず話し合いを可視化

2026-11-23制作。学校のグループ討議・自治会・小規模ワークショップの進行役を対象にした、**静的・無料・登録不要**のWebアプリ。マイク・音声ファイル・外部API・ネットワーク通信・アカウント・端末内自動保存は使いません。

## 選定理由と競合調査

日本: 国立教育政策研究所は2026年8月3日に令和8年度全国学力・学習状況調査の結果資料と授業アイディア例を公表。これは授業改善の文脈を示すもので、アプリ需要を直接示す統計ではありません。
- 公式情報: https://www.nier.go.jp/kaihatsu/zenkokugakuryoku.html
- 国内の近接競合 **TalkMILL** は録画から会話・発話量をAI分析: https://talkmill.jp/
- 海外の直接競合 **Equity Maps** はiPadで発言のタップ記録、回数・時間・種別・再生・分析を提供: https://equitymaps.com/app-description/
- 国内ストアでも入手できる **Who Speaks: Talk Time** は許可を得て会話を録音し、端末内で話者別発話時間を推計: https://apps.apple.com/jp/app/who-speaks-talk-time/id6830642230

**差別化の仮説:** 発言席を手動タップし、匿名席・録音なし・日本語ブラウザ版・基本的な振り返りとCSV/JSON書き出しに絞ることで、小さなグループがすぐ使える。手動記録は既存競合にもあり、独自性・需要・収益性は未検証。

## 実装済み

- 2〜12席の匿名ラベル、テーマ、目標時間
- 発言席切替、発話種類（意見・質問・要約・橋渡し）、無発言、一時停止・再開・終了
- 発言秒数、回数、最長発言、発言シェア棒グラフ、最大−最小のシェア差（ポイント）、進行役向け振り返りヒント
- サンプル、直前取消、発話履歴、CSV/JSON保存、JSON読込、モバイル対応、印刷
- CSV数式インジェクション緩和、読込サイズ/形式検証。発言量を人格・貢献度の採点に使用しません。

## 実行とソース

このフォルダの **`index.html`をブラウザで開く**。完全版のHTMLをgzipでロスレス埋め込みしており、ブラウザの `DecompressionStream('gzip')` によりオフライン展開します。最新のChrome/Firefox/Edge推奨。可読なオリジナルHTMLは、同じフォルダで `python unpack.py` を実行すると `index-restored.html` として復元できます。外部のCDN・APIへのアクセスはありません。

## 検証（2026-11-23）

ローカル原本 `index.html` に対し Node.js単体テスト **22/22合格**（500系列のランダム検証を含む）、Chromiumインライン操作テスト **36/36合格**（編集、発話切替、停止、Undo、CSV/JSON実ファイル出力・復元、モバイル）。JavaScript例外0・外部HTTP要求0。原本ソース、テストと画面画像は配布ZIPに収録。GitHubの圧縮ランチャーは原本とFNV-1aでペイロード同一性を確認。ただしGitHub URLからの直接起動、実端末での計測精度、同時発話やスリープ復帰の挙動は未検証。管理環境では `file://` が遮断されたため、同一原本HTMLをChromiumの `set_content` で検証しました。

計測誤差・発話の重なり・沈黙や傾聴の意味は数値に反映しません。ラベルの本名入力は避けてください。必要なデータはセッション終了後に手動で書き出してください。
