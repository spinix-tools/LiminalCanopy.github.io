# サイン視界 / SIGN SIKAI

**2026-11-21｜毎時アプリ創作｜静的Webアプリ・登録不要・MIT License**

展示会・文化施設・学園祭の案内サインが「どの観察地点から」「立位と座位それぞれで」見えるかを**遮蔽物と文字の視角から簡易診断**するアプリ。`index.html` をブラウザで開くだけで動作。外部ライブラリ・API・アカウント・サーバーへの送信は一切なし。データは端末内の localStorage または手動保存したJSONのみ。

## 誰に・なぜ

- **ターゲット**：展示会運営者、小規模ギャラリー・博物館の展示担当、学校祭の会場設営者、臨時案内板を置く担当者。
- **日本側の兆候**：多摩市は公共サインの更新・標準化対応を課題とするガイドラインを公開（ページ更新 **2025-10-08**）。浜松市のユニバーサルデザイン指針はサインの設置位置と視認性に言及する。日本に案内設計上の課題がある根拠だが、**このアプリの購買需要を示す統計ではない**。
- **海外側の兆候**：米国National Park Serviceの展示アクセシビリティ・ガイドは、鑑賞距離に応じた文字の大きさ、遮蔽・反射等への配慮を記載。こうした実務ガイドの存在から事前点検の用途を推測。
- **競合（国内）**：ArtHang/ArtInstall Lite（展示作品の配置・寸法・取付位置）、Evento3D（2D/3D会場・サイン配置・見学モード）。
- **競合（海外）**：viewcone（図面上の視線と障害物）、ExpoFP（展示・イベントのインタラクティブ施設案内）。既に類似する機能は存在する。
- **差別化仮説**：大型3D会場ツールや案内マップの運用ではなく、サイン**1枚の設置前**に焦点を当て、複数観察地点×2種類の目線高さ×什器の高さ×文字の見かけの大きさを登録不要・オフラインで一括点検できること。移動候補の試算・根拠付きCSVがそのまま現場の確認表になる。**ヒット・継続率・収益性は未検証**。

## 実装機能

1. 会場寸法、観察地点、什器・間仕切りの平面位置と高さ、サイン位置・高さ・文字実寸の追加／修正／削除。
2. SVG平面図でサイン・地点・什器をドラッグ配置。サインの切替、目線表示・ラベル表示の切替。
3. **高さを含む直方体遮蔽判定**。2Dの線分と矩形が重なる区間を求め、3D視線の高度が障害物の上端以下なら「遮蔽」。最初に遮る什器名を記録。
4. 文字実寸と3D距離から**視角（分角）**を算出し、ユーザー指定しきい値に満たない場合に「文字が小さい」と分類。**30分角の初期値は便宜的な参考尺度であって法令・日本語可読性基準ではない**。
5. 選択サインを0.5mグリッド上に移動し、評価を改善する候補を最大3件表示。什器内部と会場外は候補から除外。物理的な固定方法・通路の安全・設置許可は審査しない。
6. プロジェクトJSONのエクスポート／インポート、診断CSV（UTF-8 BOM付き、数式注入対策）、図面SVG、印刷、端末内自動保存。

## 起動・テスト

サーバー不要：`index.html`, `style.css`, `engine.js`, `app.js` を同じフォルダーへ置き、`index.html` を開く。インターネット不要。

```sh
node --test engine.test.cjs
python browser_test.py
```

検証：**Node.js 34/34合格**。幾何交差・高さ遮蔽・視角・データ検査・CSV・再配置探索・600件の擬似乱数配置を含む。**Chromium + Playwright 32/32合格**：追加・編集・地図ドラッグ・出力3種・JSON復元・無効JSON拒否・画面サイズ・XSS表示・疑似保存を確認。JS構文検査も合格。

**検証上の制限**：テスト環境では `http://127.0.0.1` が管理者設定でブロックされたため、Chromium試験は**同一HTML/CSS/JSをインライン展開**して実行した。`localStorage` は同一文書内の模擬実装であり、実ブラウザでの再起動後の保存永続性、`file://` 直接起動、実機印刷、現場計測の一致は未検証。PDF・CAD取込、壁面の方向判定、サインの実寸幅、群衆・眩しさ・視力・読解などは未対応。視界と可読性は**概算**であり、バリアフリー認証・避難誘導・安全設計の根拠として使用しないでください。
