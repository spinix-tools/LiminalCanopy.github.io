# やさ札 / YASAFUDA

**伝える文から、動ける掲示へ。** 自治会・公共施設・学校・地域行事の掲示制作者向け、登録不要の日本語お知らせ検品ツール。HTML/CSS/JavaScript、サーバー・AI API・追跡通信なし。

## 使い方・機能
`index.html` をブラウザで開くと完成版が起動します。gzipにロスレス格納された単独HTMLをブラウザ内で展開します。可読な完全版ソースは同梱の `unpack.py` で復元できます（`python unpack.py`）。

原文と編集文の並行管理、難しい語句15項目・あいまい語句10項目・長い文の自動チェック、該当語句だけの修正候補、掲示種別に応じた日時・場所・行動・窓口の不足確認、ライブプレビュー・文字拡大・印刷。単独掲示HTML、検品TXT、JSONのエクスポートとインポート、端末内自動保存。事実・意味・体裁について人による3つの確認を明示し、編集すると確認印を自動解除します。
