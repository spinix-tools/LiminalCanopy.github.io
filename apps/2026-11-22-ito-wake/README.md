# 糸わけ手帖 / ITO-WAKE

一目刺しの図案の行・列の位相を選び、布の点間隔、糸の最長切断長、端糸、手持ち糸量から必要な糸取り本数を計算する、外部通信なしのブラウザアプリです。 `index.html` を開いて利用できます。

## ターゲット・選定理由・競合
刺し子初心者、ワークショップ講師、布小物作家。2026年6月17日の米沢刺し子体験の報告では海外参加者14人が紹介される（[出典](https://prtimes.jp/main/html/rd/p/000000115.000117892.html)）。需要の存在を示す一例であり、市場規模やヒット確率の証拠ではありません。国内・日本語対応の[Sashikoアプリ](https://apps.apple.com/jp/app/sashiko/id6820033503)、海外の[Sashiko Grid](https://sashikogrid.com/about)、[Hitomezashi Pattern Generator](https://github.com/kutay-serova/hitomezashi-pattern-generator)、隣接する[Stitchmate糸量計算](https://stitchmate.app/ja/tools/thread-usage-calculator)と比較。

差別化仮説: 図案作成だけでなく、表と裏の直線移動を含めた経路長を算出し、切断上限の範囲でステッチ間に分割、準備進捗と糸不足を一画面で扱う。需要・収益性は未検証。
