# 変速綴 / ShiftWeave

速度の順序を使って2種類の自転車駆動系を比較する、走行前・机上検討用のMVP。index.htmlをブラウザで開くだけで動作します（外部依存・API・アカウントなし）。

## 対象・選定理由（2026-11-26調査）
ロード・グラベル愛好家、1×/2×の交換を検討する人、ショップ。国内では自転車産業振興協会のJapan Bike Show第3回に2,081人来場との告知があり、ギア比計算サイトも存在する。米国ではPeopleForBikesが2024年に年1回以上乗った人を1.12億人と推計（2025-04-11公表）。いずれも本アプリ固有の需要や売上の証明ではない。

## 競合・差別化仮説
- 国内：ToolsAhuro（ギア比・速度一覧）、Cycle Gear Ratio Calculator（手動シフター）。
- 海外：Cyclists Hub（構成比較）、gearing.app（回転数帯・物理モデル）、ChainLab（仮想コース・自動変速）。
- 本案：ユーザーが指定した同じ速度列を入力し、回転数帯の維持と変速負担を全地点まとめて最適化。瞬時の最寄りギアを選ぶ基準案と比較し、リア移動段数とフロント変更回数を別表示する。類似機能の不存在は未確認。無料SEOツールからショップの比較支援へ展開する仮説。利用者インタビュー・収益性は未検証。

## 機能・計算
最大120地点、各構成最大28ギア（前1〜2枚、後1〜14枚）。歯数・実測周長・目標/許容rpm・変速負担点・両端除外を設定。rpm=速度×1000/(60×周長)×後歯/前歯。動的計画法 O(T×G²) で、範囲外地点数、累積範囲外差、目標差＋変速負担点の順に辞書式最小化（差・費用は百分の一点単位）。初期変速費なし。グラフ、地点別表、CSV、印刷、スマホ対応。各地点は等重みで時間加重しない。実走中の指示ではなく、負荷・勾配・惰行・適合性・操作時間は対象外。

## テスト結果
- `node test.cjs`：固定9件、独立全列挙240件、最大120地点×28ギア合格。
- `python browser_test.py`：Chromiumインライン読み込みで初期表示、編集後の結果無効化、再計算、CSV実ダウンロード、重複歯数エラー、リセット、390px幅を確認。JS例外・外部HTTP要求なし。環境の制限でfile://直接遷移は未確認。
- 架空例：Aは16/16地点が75〜95rpm、リア9段・前0回（基準案36段・8回）。Bは16/16地点、リア8段・前0回（基準案12段・0回）。実機・実走の検証なし。
