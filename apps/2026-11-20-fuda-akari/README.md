# 札あかり / FUDA AKARI — 日英併記の展示キャプション組版MVP

制作日: **2026-11-20（JST）** / 対象ブランチ: `hourly-app-lab` / データはブラウザ内だけ。ビルド・アカウント・APIキー・課金・外部CDN不要。

## 誰の何を解決するか

**対象:** 小規模美術館、大学の展示、個人ギャラリー、地域資料館の展示担当。作品札を複数作成するときに「日英の説明漏れ」「改行・字詰めの崩れ」「A4面付けの手戻り」が起きることを減らす。

**選定理由・関連市場の傍証:** 文化庁の[博物館総合サイト](https://museum.bunka.go.jp/museum/)は国内の博物館を **5,700以上** と説明。国立国会図書館の[2026年4月7日の紹介](https://current.ndl.go.jp/car/276977)によれば、2024年度日本の博物館総合調査は **4,368施設を対象に2,507施設が回答**。海外では米国博物館協会AAMの[2026年4月2日発表](https://www.aam-us.org/2026/04/02/aam-announces-latest-accreditation-awards-44-museums-achieve-this-distinction/)が国内推計**33,000館**を掲げ、英国DCMSの[2026年4月23日公表](https://www.gov.uk/government/statistics/dcms-sponsored-museums-and-galleries-annual-performance-indicators-202425/dcms-sponsored-museums-and-galleries-annual-performance-indicators-202425-headline-release)では対象施設への2024/25年度の訪問回数**4,200万回**。いずれも展示分野の活動規模に関する傍証で、**本アプリへの需要・利用率・支払意思を直接示さない**。

**既存競合**（2026-11-20確認）:
- 国内：DNPの[美術館・博物館での多言語情報配信サービス](https://www.dnp.co.jp/biz/products/detail/20172716_4986.html)はスマホへの多言語テキスト・音声配信。印刷札だけの同種競合ではなく周辺代替。
- 海外：[Art Wall Text](https://artwalltext.com/)はExcel等から多枚数のベクターラベルを作成、文字可読性チェックも訴求（ウェイトリスト/価格表記あり）。[GalleryCue](https://gallerycue.com/)は作品リストからA4ラベル・価格表作成、基本無料/有料パック。[art.industries](https://art.industries/tools/wall-label-generator)はブラウザ内で壁ラベルを作り印刷。[ArtFlow Pro](https://artflow-pro.com/tools/wall-label-maker)にも無料テンプレートがある。

**差別化の仮説:** 日本語＋英語を**別個の確定原稿**として保持し、未翻訳を警告しつつ、長文を黙って切り捨てず**「続き」札へ自動分割**、A4/mm面付け・コントラスト参考値・CSV/JSONバックアップ・SVG出力まで登録なしで行う「印刷前の校正」に絞る。類似機能は競合にも存在し、新規性・有料需要は未検証。既存の値札作成、字幕、翻訳UI検査アプリと用途を分けた。

## 使い方 / 実装済み

`index.html` をブラウザで開く（`style.css`, `engine.js`, `app.js` が同階層）。作品を選択して作者・タイトル・制作年・素材・日英解説を編集 → 札サイズ（標準・小型・横長）と言語・文字pt・紙色を指定 → A4の面付けを確認 → 「印刷する」またはページ単位SVG保存。作品の追加・削除、日英欠落・管理番号重複・文字色の対比警告、長文の自動継続札、CSV/JSON入出力、ローカル保存に対応。SVGと印刷ページは210×297mm、断裁目印付き。サンプル作品・作者はすべて架空。

**重要な制限:** 文字幅は軽量な推定モデルであり、ブラウザ・フォント・印刷機器によって実際の幅や改行は異なる。SVGはテキストをアウトライン化しない（受け手環境のフォントが必要）。編集原稿の削除は行わないが、予測した幅が実環境で収まる保証ではない。画面上の対比値はWCAG画面向け4.5:1を**参考**として表示するだけで、印刷や施設のアクセシビリティ適合を認証しない。本番前に必ず原寸試し刷りと翻訳文の人手校正をすること。PDF直出力・翻訳AIはなし（ブラウザのPDF印刷保存は可）。

## プライバシー・ライセンス

全処理クライアント側で完結。データはユーザーがJSON/CSVダウンロードした場合を除き外部送信しない。`localStorage`に編集状況を自動保存（保存拒否時はJSONバックアップを案内）。ネットワーク通信、追跡、API、翻訳サービス、個人情報入力フォームなし。作品説明は入力前に機密性を確認。オリジナル実装はMITライセンス。
