# BoxMend / 箱の再生計画（2026-11-27）

同一版のボードゲームの欠品箱から、完品候補を最大数復元するローカルWebアプリ。index.htmlをブラウザで開き、部品ごとの必要数と使用可能な実数を入力、箱を対象・提供専用・除外に分類し、計算する。最大12箱×30部品種。移動指示、移動後在庫、追加1箱に必要な不足数、JSON出力、印刷に対応。外部依存・通信・アカウント不要。

## 対象・市場・差別化仮説
中古ボードゲーム店、複数コピーを持つカフェ・図書館。国内の買取王国は欠品品も査定し、リゴレは使用に伴う損耗を交換対象外とする。海外のALAの図書館事例では欠品が貸出・除籍に関係する。GameShelfはコピー単位の在庫管理、Game Box Checkは単箱の内容物監査を扱う。BoxMendは複数箱を横断し、最大復元数と最小移動個数を同時に計算する点に特化。市場規模、利用意思、同等機能の不存在は未検証。

## 計算と限界
対象箱数と各部品の総在庫÷必要数（切り捨て）の最小値が最大復元数k。任意のk対象箱を満たすのに必要な移動個数の下界は各箱の不足個数の和で、全箱間で同種部品を自由に移せる仮定では達成できる。よって不足の少ないk箱を選ぶと厳密最適。除外箱は不変。箱の品質・カードの同一性・版の互換性・販売表示は人が確認する。移動指示行数の最小化や部品の購入は対象外。
