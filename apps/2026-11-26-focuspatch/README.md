# FocusPatch / 深度合成の再撮影計画 (2026-11-26)
`index.html` をブラウザで開く。依存・登録・外部API・通信なし。

## 対象・選定理由
マクロ・商品写真・標本撮影の制作者。国内ではニコンがフォーカスシフトの作例（101枚、10枚）を公開。海外では深度合成用の枚数・ステップ計算器が多数ある。撮影後に不足する鮮明範囲を埋める作業を対象に選んだ。市場規模・検索数・支払い意思は未検証。
- 国内: https://nij.nikon.com/support/manual/digitutor/d850/functions/focusshift.html
- 海外: https://www.josx.art/tools/focus-stacking-planner （撮影位置・重なりの計画）
- https://www.captd.app/tools/technical-calculators/focus-stacking-calculator （各撮影位置・鮮明範囲）
- https://geratools.com/macro-focus-stacking-interval （マクロのステップ計算）

## 差別化仮説・操作
撮影済みの実測鮮明範囲を再利用し、追加撮影候補から必要な最少枚数を選ぶ。各範囲の端を指定余裕分縮め、目標区間に切り詰める。右端を頂点とする有向非巡回グラフ上の最短路（撮影済みの辺費用0、追加候補1）で連続被覆を求める。候補の全使用でも残る抜けを表示。各200行、整数µm、接点での連続被覆を許す。光学計算・画像解析・合成なし。測定の妥当性、実画像、実需は未検証。競合の全機能・特許未調査。まず実撮影で再撮影枚数と合成結果を比較したい。

## テスト
`node test.cjs`: 固定6件・独立全列挙400ケース合格。`python browser_test.py`: Chromiumで操作、JSON実ダウンロード、入力変更時の無効化、不正入力、リセット、390px表示、JS例外・HTTP要求なしを検査し合格。環境制限でfile://が拒否されたためHTMLをインライン読み込み。実機未検証。初期サンプルは現在の抜け280µm、候補2の1枚で連続被覆可能。
