# 折章 / ORICHAPTER

手製本・ZINE・同人誌の編集者向けの折丁設計。2026-11-25 MVP。`index.html` をブラウザで開く（依存ライブラリ、サーバー、API、アカウント不要）。

## 市場・選定理由
- 国内：文学フリマ東京43（2026-11-08）は3,665出店、来場者19,641人。独立出版の潜在利用者層の指標であり、手製本需要そのものの計測ではない。https://t.co/Xjf4pcdXtQ
- 海外：LA Zine Fest（2026-11-07）は355出展枠に600超の応募（主催者への取材）。https://www.uscannenbergmedia.com/2026/11/12/los-angeles-zine-makers-find-power-in-self-publishing/
- 競合：国内企業のSignaPrintは固定サイズの折丁PDFと右綴じ・左綴じに対応。https://www.netflowers.co.jp/ios/signa-print/en-US/index.html ; 海外のImpはローカルPDF面付け、クリープ補正。https://github.com/lukaszlasek/imposition-imp ; Bookbinder's PDF Signature Makerは可変折丁による白紙削減を既に提供。https://github.com/ChimeraTato/bookbinders-PDF-Signature-maker/blob/main/README.md
- 差別化仮説：原稿PDF完成前に、章単位の開始位置・分割禁止・境界負担と白紙のトレードオフを扱う。PDF面付けの代替ではなく前工程。競合に同等機能がないことの網羅的証明や支払意思の検証は未実施。まずZINE制作者の試用と白紙数・計画時間の測定を行う価値がある。

## 操作・仕様
1行に「章名 | ページ数 | 任意/奇数/折丁 | 可/禁止」。1〜60章、合計400ページ以下。4〜32ページ（4の倍数）の許可折丁を選び、章途中の境界負担点を設定。計算後、ページ配置・両面の面付け番号・CSV・計画印刷を利用できる。奇数指定は物理ページの奇数側（右綴じなら左）。表紙は含まない。原稿ページ順序は維持する。

DPは原稿ページ位置を状態とし、次の折丁で消費する連続原稿ページ数・許可サイズを列挙する。必要な奇数開始用白紙だけを挿入し、残りは折丁末尾に置く。禁止分割と折丁開始制約を満たし、(白紙数＋重み×章途中境界数、白紙数、折丁数)を辞書式に最小化。全ての任意の白紙位置を探索するものではない。面付けは二つ折りの入れ子式折丁のみ。PDFファイル生成、紙厚・クリープ、実機両面印刷、紙の折り方向の確認は対象外。試し刷りを推奨。

- `python browser-test.py`：Chromium（Playwright、既存環境）で初期計算、面付け表示、CSV実ダウンロード、右綴じ、不正入力、解なし、旧結果無効化、再初期化、390px横幅を確認。JS例外・外部HTTP要求0。環境のfile://制限によりHTMLをインライン読み込み。
- サンプル30原稿頁、白紙6頁、章途中境界1回、折丁3組（16・8・12頁）、負担点4で評価10。
- 直近の制作履歴、mainとの比較で返った50アプリディレクトリ、および製本関連5語のコミット検索（該当なし）を確認。全履歴の網羅照合ではない。
- 個人情報収集・外部通信・新規有料サービスなし。実需要・収益・物理的製本品質は未検証。
