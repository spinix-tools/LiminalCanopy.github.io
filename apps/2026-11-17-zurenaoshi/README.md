# ずれなおし / ZURENAOSHI

**2026-11-17 / 静的Webアプリ / 完全ローカル / MIT**

印刷したラベルが上下左右にずれ、用紙の後半ほどずれが大きくなる問題に対し、用紙の2つの十字マークの実測位置から **X/Y独立の平行移動＋倍率の逆補正** を計算する、ミリメートル指定のシール面付けツールです。

## ターゲット・選定理由

ハンドメイド作家、フリマ・小規模EC事業者、店舗の値札やイベントのシールを家庭用プリンタで自作する人。国内ではGMOペパボが2025-11-13に発表した2025年のminne動向で、「デジタル素材・テンプレート」カテゴリーの注文金額が前年同期比**1.51倍**と報告された。ただし、これはラベル用紙の補正ツール固有の需要を証明しない。エーワン公式のサポートにも「印刷ずれ」「縮小」「位置調整」がFAQとして掲載され、明確な作業上の困りごとがあると判断した。

## 国内・海外競合と差別化仮説（2026-11-17 確認）

- **日本：** エーワン「ラベル屋さん10」は用紙対応・差し込み印刷・印刷位置の調整を提供。位置補正自体は既存機能。
- **米国：** Avery Design & Printは「Adjust Print Alignment」でmm/inch単位の左右上下位置調整を提供。既に高機能。
- **欧州：** HERMA LabelAssistant Onlineはテンプレート編集・PDF生成・X/Yの印刷位置調整を提供。
- **差別化仮説：** メーカーの型番カタログに依存せず、**テスト印刷したA/B二点の座標を4値で入力するだけで、ずれの平行移動だけでなく用紙後半に増大するX/Y別倍率誤差まで逆算**。登録・CDN・サーバー・有料API・個人情報送信なし。競合側に同等の補正機能が既にある可能性があり、本仮説の独占性・市場性・収益性は未検証。

## 実装済み機能

1. A4/US Letterの面付けプリセット4種、用紙/面サイズ、余白、間隔、行列をmm指定。はみ出し/面数/入力値の検証。
2. 1行1ラベル、`|`でラベル内改行。開始面をずらして一部使用済みの用紙に印刷。文字サイズ/内側余白/切取線を指定。CSV（各行1ラベル）取り込み。
3. 十字A/Bの試し刷り。実測4座標から出力位置を `(目標座標 - オフセット) / 印刷倍率` に変換。補正のON/OFFとずれ/倍率の表示。極端な誤入力を拒否。
4. SVG印刷プレビュー、ブラウザ印刷、SVG/CSV/JSONエクスポート、JSON復元、ブラウザ内の設定保存。レスポンシブ画面。

## 起動・検証

`index.html`, `engine.js`, `app.js` を同じフォルダに置き `index.html` を開く。環境によって `file://` を制限する場合は `python -m http.server 8000` で静的配信する。依存ライブラリ/ビルド工程なし。

```bash
node --test engine.test.cjs
python browser_test.py
```

- **Node.js 単体テスト：35/35 合格。** 面配置、座標逆補正、例外、CSV、SVG、エスケープを検査。
- **Chromium + Playwright 操作試験：53/53 合格。** 編集、入力検証、補正ON/OFF、SVG/CSV/JSONダウンロード、CSV/JSON復元、印刷アクション、モバイル表示など。
- この実行環境ではネットワーク・`file://` のナビゲーションが管理者ポリシーで禁止されたため、**ブラウザには実HTML/JSを直接注入し、localStorageのみモックして試験**。静的配信URLでの統合動作、実端末での保存持続、実プリンタの給紙精度、PDF印刷設定は未検証。`desktop.png` / `mobile.png` はこの試験で撮影。

## 計算の制約・注意

- X/Y独立の一次変換（倍率・平行移動）だけに対応。**回転、斜行、歪み、紙ごとのずれ、給紙揺らぎ**には非対応。印刷が再現性を持つ前提。機器設定で**倍率100%、ヘッダー・フッターなし、余白なし**を指定し、まず普通紙で試してから本用紙を使う。
- プリンタの非印字領域に掛かると十字やラベルが欠けることがある。プリンタ・用紙ごとの精度・メーカー互換性は保証しない。SVGの日本語表示は利用端末のフォントに依存する。
- 完全クライアント実装でネットワーク送信・ログイン・OpenAI API・有料サービスなし。ブラウザ内保存と明示的なファイル出力のみ。
