# ぱた箱 / PATABAKO — 紙製トレイ展開図ジェネレーター

実行日: 2026-11-18｜独立したブラウザ専用MVP｜ライセンス: MIT

## 誰に
小規模ネットショップの店主、ハンドメイド販売者、工作・学校の担当者。専用の型抜きソフトを導入せずに、試作箱の寸法・印刷枚数・材料費を素早く把握したい人。

## なぜ選んだか・市場検証
2026-10-21に経済産業省が公表した2025年の国内BtoC-EC市場は27.6兆円、うち物販系15.8兆円（2026-10-21付の報道）。これは関連市場の規模であり、本アプリの直接需要や購買意向を示す数字ではない。
海外ではEtsyの2025年末アクティブ出店者が560万人（2026-02-19公開のEtsy年次報告書）。手作り・ギフト市場の大きさを示す間接指標であり、箱生成ソフトの需要を直接測定した値ではない。海外には無料の箱展開図生成ツールが既に複数ある。日本国内についても「箱 展開図 作成 無料」などで競合領域を調査し、汎用ジェネレーターの競争があると認識した。

## 競合と差別化の仮説
- [Paper Box Designer](https://paperboxdesigner.com/)：リアルタイムの展開図・3Dプレビュー・SVG出力。
- [Foldly](https://foldly.site/)：多種の展開図とオフライン対応。
- [PudełkoTo](https://pudelkoto.podziel.pl/en/)：寸法指定・各種エクスポート・タイル分割も対応。
- [Box Template Lab](https://boxtemplatelab.com/)：A4・Letter向けの身ふた箱とSVG/PDF。

単一機能の独占性はない。日本語UIで「商品の外形＋ゆとり」→「ふたなしトレイののりしろ展開図」→「A4ページ分割・位置合わせ」→「必要個数の紙代」をひとつの画面で連続して扱う設計を差別化仮説とする。今後の検証指標は最初の印刷までの時間、寸法誤差、初回試作成功率、継続利用率。

## 使い方
ZIPを展開して`index.html`を開く。HTML/CSS/JSのみで動作。プリンタはA4縦、余白10mm、拡大縮小100%で出力。大きな箱は8mm重なった隣接ページを貼り合わせる。赤線で切り、青線で折り、緑のタブを接着。サイズ変更・サンプル・SVG・CSV・設定JSONの保存読込・ブラウザ内自動保存に対応。

## 技術・計算
- 対象は**ふたなしの紙製トレイ1形式**。商品幅・奥行には各方向で`2×ゆとり`、側面高さには`ゆとり`を加える。紙厚と折り半径は考慮しない。
- 展開寸法は`幅+2×高さ` × `奥行+2×高さ`。四隅に台形状ののりしろを配置。
- A4、上下左右10mmを除いた1ページの190×277mmを使用。ページ間8mm重ね。通常と90度回転のうちページ数が少ない方を採用。
- 費用は`1箱のページ数×予定箱数×用紙単価`。インク代・のり・作業時間・印刷ロス・強度は含めない。
- 入力はWebサービスへ送信せず、端末内localStorageと明示的なファイルダウンロードのみ。

## 検証
- `node --test engine.test.cjs`：**41/41 合格**。入力制約、A4敷き詰め・境界、枚数・費用、回転、SVG・CSV、のりしろなど。
- `python browser_test.py`：**35/35 合格**。Chromiumでプリセット選択、寸法変更、ページ分割、CSV/JSON/SVGダウンロード、JSON復元、印刷呼出、スマートフォン幅、コンソールエラーを確認。
- 実行環境の制限により`file://`の直接ナビゲーションが遮断されたため、ブラウザ試験は実際のHTML/CSS/JavaScriptを`about:blank`へ埋め込み、localStorageのみ模擬した。**実配信・端末保存の持続性・プリンタ実機・組み立て後の強度は未検証**。印刷アクションはモック化してページ生成まで確認。

## 注意・運用
実寸SVGは`mm`指定。一般プリンタの印刷ダイアログで「用紙に合わせる」を無効にすること。試作・定規による寸法確認が必須。寸法は数式上の参考値で、製造用の公差・紙厚・安全性の保証はない。外部サービス・個人情報・有料APIは利用しない。
