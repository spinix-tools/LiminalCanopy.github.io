# ひびき差 / HIBIKISA — Room Echo Lab

**制作:** 2026-11-20（JST）。ポッドキャスト・動画ナレーションを自宅で録音する個人、小規模な配信スタジオ、オンライン講座の制作者向けの、**6帯域RT60・吸音パネル検討**用Web MVP。Vanilla HTML/CSS/JavaScript、外部ライブラリ/サーバー不要。

## 日本・海外の需要と競合

- **国内の周辺需要:** オトナル×朝日新聞社の2026年3月公開「第6回ポッドキャスト国内利用実態調査」（2025年12月、15〜69歳の1万人を調査）では、国内月間利用率18.2%、15〜19歳40.5%。これは**聴取**の市場指標で、制作室音響ツールの直接需要・課金意向は示しません。［調査公表］(https://otonal.co.jp/news/50748) / ［朝日新聞 2026-03-12］(https://prtimes.jp/main/html/rd/p/000002123.000009214.html)
- **国内競合:** [Mahiro Apps「残響時間計算」](https://mahiroapps.com/reverberation-time) は部屋の寸法・材質・目標残響・必要な吸音材面積をすでに逆算。[計算ツールズ](https://ta5k.com/tools/tech/reverb-time) はSabine/Eyringの両方式に対応。計算や逆算そのものは新規ではありません。
- **海外競合 / 関連需要:** [Acouso Playground](https://www.acouso.com/playground/reverberation-time) は6帯域・両方式・処理前後のRT60比較に対応。[TYSTIQ](https://tystiq.eu/tools/calculator) は必要パネル数の提案を提供。音響計算に既存需要・先行製品があることを示しますが、本作の商業性・優位性を保証しません。
- **差別化の仮説:** 「既存の部屋→好きな素材の壁被覆面積を変更→会話中心の3帯域 / 全6帯域で目標を判定→**すべての選択帯域の制約を同時に満たす理論上の最小被覆面積**と、未達なら実行不能と表示」という短い操作線。素材変更で一部帯域が悪化する場合も半区間制約として計算し、平均値だけの合格表示を避けます。登録・カメラ・音声録音不要。競合が同等機能を持たないとは主張せず、利用者テストで検証すべきUX仮説です。

## 実装

- 奥行・幅・天井高、壁・床・天井の参考素材（6帯域吸音係数）を編集。壁面積と室容積を再計算。
- 吸音パネルの種類・壁被覆面積を数値とスライダーで変更。元の壁素材の吸音寄与を差し引いて計算。
- Sabine / Eyring 切替、500/1000/2000 Hz または全6帯域での目標判定。
- 125〜4000HzのA/Bグラフ、帯域別数値、平均短縮、達成判定、解析メッセージ。
- 両方式で目標値の制約を解く最小面積の逆算、壁全面で届かない／帯域間で衝突する場合の実行不能判定、提案のB案反映。
- 結果CSV、SVGグラフ、設定JSONの保存と復元、印刷、端末内localStorageによる保存。エクスポートはブラウザのBlobダウンロード。

### 起動

このフォルダの `index.html` をブラウザで開きます。5つの主要ファイル（`index.html`, `style.css`, `engine.js`, `app.js`, `README.md`）は相対参照で動作します。ネット接続やインストールは不要。プライベートモード等でlocalStorageが無効ならJSON書出しで保存してください。

## モデルの制約・安全

`RT60 = 0.161 V / A`（Sabine）。Eyringでは `RT60 = 0.161 V / [-S ln(1-A/S)]`。矩形空間の拡散音場の単純化であり、各素材の吸音係数はメーカー試験値ではなく**理解用の仮定**。壁面のパネルは壁素材を置換するものとして計算します。什器、家具、人数、低音の部屋モード、施工位置、音の漏れ・遮音、空気吸音、マイク距離はモデル化していません。**RT60短縮は防音性能の改善を意味しません。** 目標0.50秒は初期設定例で公的設計基準ではありません。実工事・材料購入前に製品の周波数別試験値と実測、必要に応じ専門家の検討が必要です。

データはブラウザ上に保存されるだけで、外部API・OpenAI API、有料サービス、ログイン、個人情報収集、アクセス解析・外部送信はありません。MIT License。
