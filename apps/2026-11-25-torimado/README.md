# 鳥間 / TORIMADO
野鳥観察・市民科学の活動時間配分を比較する、アカウント不要の単一HTML MVP（2026-11-25）。

## 対象・選定理由
地域の観察会、学校、市民調査の計画係。日本の全国鳥類繁殖分布調査（2016–2021）はボランティア2,106人、2,344地点で実施された。日本野鳥の会はeBird Japanを2021年に開設し学校向け教材も提供。海外のPatchBirdは固定地点の時間的継続性と空間的カバレッジの違いを明記している。これらは活動の存在を示すが、アプリへの支払意思は未検証。

## 競合と差別化仮説
- バードノート：観察記録データベース・年間出現表。
- eBird：記録・ホットスポット・チェックリスト・ターゲット種検索。
- PatchBird：定点の継続調査と未調査地域のカバーを目的別に分離。
- 本MVP：匿名の地点×時間帯ごとに、実施済み回数・目標・追加可能回数・1回の所要時間を入力。残時間の範囲で「空白解消優先」と「目標達成優先」の厳密最適案を並べ、どちらに時間を配分するか事前に判断する。競合に同一機能がないことは未証明。
- 検証仮説：次回観察会で計画係5組に試用してもらい、手作業との計画時間・選択変更・再利用意向を比較（未実施）。

## 使用法・計算
index.htmlをブラウザで開く。1〜24枠、残り0〜720分。目標を超える追加は行わない。時間を状態とする動的計画法で、2目的（新規観察枠、新規達成枠の優先順を逆転）を比較。第3基準は追加回数、第4基準は短い所要時間。結果切替・CSV・印刷。サンプル60分で空白優先は3枠を新規観察、達成優先は2枠を新規達成。全入力はメモリ内のみ、通信・GPS・登録・外部依存なし。

## テスト結果
- `node test.cjs`：固定10件、独立全列挙との600件比較と実行可能性確認、最大24枠・720分の両目的2件、すべて合格。
- `python browser-test.py`：Chromiumで同一HTMLをインライン実行（環境のfile://制限のため）。初期値・計画切替・CSV実ダウンロード・不正入力・編集時無効化・追加削除・リセット・390px横幅、合格。JS例外0、外部HTTP要求0。印刷実出力未検証。Playwright・Chromiumはテスト時のみ必要。
- 既存案照合：会話内の直近案、mainとの差分の取得上限300ファイル、直近コミット以降の差分、鳥・観察関連のコミット検索を確認。全206件の完全照合はできていない。
- 制約：具体的な日時重複、移動経路、天候、検出確率、標本設計、許可・生態影響はモデル外。空白は未実施を意味し、鳥の不在ではない。実地の有用性・収益性は未検証。
