# 停電配分室 / TEIDEN HAIBUN

家庭向け停電時の電池使用計画を比較する無料・オフラインWebアプリ（2026-11-20）。

## 想定ユーザーと選定理由
家庭の防災担当者、ポータブル電源の所有者。日本のNITEは2025-08-28に災害時のポータブル電源の事故を注意喚起した（https://www.nite.go.jp/jiko/chuikanki/press/2025fy/prs250828.html ）。海外の米EIAは2025-12-01に2024年の平均停電11時間と報告した（https://ebs.publicnow.com/view/1B29E57BEE5C28D6A94CD77A986C7360C3E72FF3 ）。関連需要はあるが本アプリの有料需要は未確認。

## 競合・仮説
Jackery日本の使用時間計算（https://www.jackery.jp/blogs/power-station/using-time-of-power-station ）や海外BackupCalc（https://backupcalc.com/power-station-runtime-calculator/ ）には稼働時間・定格出力を試算する競合機能がある。差別化仮説は、家電ごとの24時間の使用予定・必須/任意の優先度・電池予備を組み合わせ、通常案と省エネ案を比較すること。競合の網羅調査・収益性・ユーザー実証は未実施。

## 利用・留意点
`index.html`をブラウザで開く。専用ブランチのみへの保存で、mainは変更しない。電池の初期充電、残す予備、変換効率、家電の消費Wと予定を入力し、残量や未供給Whを比較。JSON設定、CSV出力をブラウザ内で行う。ネット通信・課金なし。

エネルギーの推計は平均W×時間÷効率の概算。予備残量より下での給電を止める。起動電流、電池劣化、温度、接続機器の安全性を保証しない。医療機器・生命維持用途には使用しない。エンジン式発電機は屋内で使わない。NITEやメーカーの注意事項を優先。
