# 字幕のりしろ / JIMAKU NORISHIRO

**2026-11-21｜静的・オフライン字幕検品MVP｜MIT License**

SRT / WebVTT字幕の読速、全角換算の行幅、改行禁則、タイムコード、字幕間隔を可視化し、**改行案・表示時間の延長・手動編集を同じ画面で実行する**日本語字幕の仕上げ台。`index.html` をブラウザで開く（`style.css`, `engine.js`, `app.js` は同階層）。サーバー・会員登録・外部API・広告タグ・課金は不要。データを自動送信・永続保存しない。

## 選定と市場仮説

- **ターゲット**：動画制作の個人事業主、学校・地域広報担当、字幕制作初心者、短尺動画の編集者。
- **日本市場の兆候**：サイバーエージェント／デジタルインファクトの2026年3月9日発表によれば、2025年国内動画広告市場は**8,855億円**、うち縦型動画広告は**2,049億円**。別途、矢野経済研究所は2025年9月26日に2024年度国内動画制作サービス市場を**4,238億円**と推計。いずれも**字幕検品ツールの購買需要や市場規模を直接示すものではない**。
- **海外需要の手掛かり**：WCAG 2.2の達成基準1.2.2は、例外を除き収録済み音声を含む同期メディアにキャプションを要求。字幕の品質管理は言語・視聴環境を超える課題とみられるが、購買意向は未検証。
- **競合**：国内の[Vrew](https://vrew.ai/ja/feature/srt-export/)（字幕作成・SRT出力）、[Editsub](https://editsub.com/ja)（字幕編集・変換）。海外の[Subtailor](https://subtailor.com/subtitle-line-breaker/)（自動改行・CPS等の検査）、[CueCheck](https://cuecheck.dpdns.org/)（SRT/VTT読速QC）、[QuickVeed](https://quickveed.com/subtitle-reading-speed-checker)（読速・間隔・重なり検出）。**ブラウザ内処理やQCは競合にもあるため、独占的な新機能とは主張しない**。
- **差別化仮説**：日本語に適した全角相当幅（通常の和文1、ASCII・半角カナ0.5）と行頭・行末禁則を使い、単なる警告リストで終わらず、**原文を短縮しない改行案、次の字幕と重ならない範囲の時間延長、手動修正、Undo、変更前後の比較、字幕だけの時間プレビュー**を1画面でつなぐ。試験的な基準値であり配信サービスの納品規格を保証しない。

## 動く機能

1. **ローカル読込**：SRT / VTT の貼り付け・ファイル選択、UTF-8 / Shift_JIS（2MB以下）。誤った時刻・未対応メタデータは警告。初期状態にサンプルデータ。
2. **検品**：全角相当/秒、行幅、行数、開始終了時刻、短すぎる/長すぎる表示時間、重なり、空き不足、禁則、空テキストを検出。基準は編集可能。
3. **修復**：1件／一括の禁則配慮改行案と、後続字幕を避けた表示時間延長。手動で本文・時刻を修正でき、最大30操作までUndo可能。字幕全体の時刻移動にも対応。
4. **検証と持ち出し**：初期状態との要確認件数比較、時間プレビュー、全件／要確認絞り込み、SRT・VTT・検品CSV出力。CSVは数式に見えるセルへアポストロフィを付ける。

**検証の境界**：テスト環境では管理制限により `file://` への遷移がブロックされるため、Chromium操作試験では **同一HTML/CSS/JSのテキストをインライン展開**して試した。一般ブラウザによる直接起動、ファイル選択からのShift_JIS読込の実機動作、動画／音声との同期、配信プラットフォームへの納品は未検証。VTTの `NOTE/STYLE/REGION` は警告のうえ出力では除外。改行はヒューリスティックで、言語表現・話者・読みやすさの正解を保証しない。テキストの自動省略・生成はしない。最終判断は制作担当者が行う。

## プライバシーと費用

すべてクライアント側のみで計算。アップロード・認証・Cookie・localStorage・外部HTTPリクエスト・AI API・第三者サービスなし。読み込んだ字幕はブラウザタブのメモリ内にのみ存在し、元ファイルに上書きしない。
