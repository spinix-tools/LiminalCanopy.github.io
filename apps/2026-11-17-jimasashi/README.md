# 字幕ものさし / JIMASASHI

**字幕は読める速度？** SRT / WebVTT の文字相当数・表示速度・字幕同士の時間重複を確認し、改行やタイミングをその場で直せる、日本語優先の完全ローカルWebアプリ（MVP）。

## ターゲットと需要仮説（2026-11-17調査）

個人YouTuber、講師・企業の教育動画担当、短編映像の字幕担当者。国内ではフィールドワークスの「映像メディアユーザー実態調査2026」（2025年11月調査、5,021人）で無料動画配信サービスの利用率が**71.3%**と報告。これは視聴側の規模を示すものであり、字幕QAツールの購入意向や需要を直接証明するものではない。日本語字幕の読みやすさの実務上の参考値として、Netflixの公開ガイドでは、日本語横書き字幕に **最大13全角相当/行・最大2行、最大4文字相当/秒**（ガイド内の映画などの区分）を示す。用途ごとに指針は異なる。

- 市場・需要資料: https://webtan.impress.co.jp/n/2026/03/09/52264 (2026-03-09)
- 日本語字幕参考値: https://partnerhelp.netflixstudios.com/hc/en-us/articles/215767517-Japanese-Timed-Text-Style-Guide
- 競合（日本）: Vrew — 字幕生成・編集・SRT出力 https://vrew.ai/ja/feature/srt-export/ ; CapCut — 自動キャプションとタイミング調整 https://www.capcut.com/ja-jp/help/how-to-recognise-subtitles
- 競合（海外）: Subtitle Edit — 無償の高度な字幕編集・行分割・速度調整（極めて強力な既存競合）https://subtitleedit.github.io/subtitleedit/overview.html と https://subtitleedit.github.io/subtitleedit/features/settings.html

## 選定・差別化仮説

字幕自動生成そのものは競争が激しい。そこで、**既に生成された字幕ファイルをアップロードせずに点検し、重なり・行長・読み速度の指摘から修正・再出力までを日本語UIの1画面で完結する**後工程の軽量QAに絞った。競合も速度・改行を扱うためアルゴリズムの独占性はない。日本語ワークフローの短さと無料・プライバシー保護に利用価値があるかは、実ユーザー調査が必要。

## 実装済み

- SRT / WebVTT 読込（UTF-8、BOM対応）、最大2MB・10,000行。壊れた時刻行はエラー表示して元データを保持。
- 各字幕の最長行の幅、文字相当数/秒、最大2行、短時間表示、隣接・包含を含む時間重複をチェック。日本語・半角英数字の表示幅を近似換算。
- 任意設定・参考プリセット（一般動画は本アプリ独自初期値18文字相当/行・7文字相当/秒、日本語配信参考値は13・4）。カスタム値の保存。
- QA一覧検索・要確認フィルター、時刻・テキスト修正、2行改行候補、改行結合、字幕追加・削除、全体時刻シフト（負の開始時刻は拒否）。
- 概算16:9プレビュー、SRT/VTT出力、指摘付きCSV書き出し、ブラウザ内 localStorage の自動保存。アカウント・外部API・通信・課金なし。
- DOMにはテキストとして字幕を表示し、読み込んだHTMLやJavaScriptは実行しない。

## 使い方

`index.html` を開くか、ディレクトリで `python -m http.server 8000` を実行して `http://localhost:8000` を開く。初回はデモ字幕が入っている。ファイル読込→「要確認」の行を選択→改行・時刻を手修正→SRT / VTTを書き出す。ファイルは端末側でのみ読み込む。

## テスト結果（2026-11-17）

- `node --test engine.test.cjs` : **30/30 合格**。SRT/VTT往復、時刻検証、半角・全角・絵文字、改行のテキスト保持、包含重複、CSV出力など。
- `python browser_test.py` : **25/25 合格**。ChromiumでのGUI選択・編集・読込・SRT/VTT/CSVダウンロード・検索・各種操作・XSS文字列の無害表示・レスポンシブ表示など。
- **制限**：試験環境で外部URLとlocalhostへのChromiumナビゲーションがブロックされたため、HTMLとJSを直接Chromiumへ読み込み、`localStorage`は模擬して保存・復元を試験した。実端末での永続化、URL配信、映像音声との同期、各動画プラットフォームでの互換性・字幕ガイド適合認定は未検証。実際の字幕は人が最終確認する必要がある。

## 既存アプリとの違いと未実装範囲

過去の「時差フェア」「再現地図」「箱棚」「くいきる」「順番灯」「きりしろ」「仕込みの天秤」「源流ノート」「値札あわせ」と異なり、**動画字幕品質の静的解析・修正**に特化。音声認識、自動翻訳、動画レンダリング、WebVTTの `STYLE/REGION` メタデータ保持、フォーマットタグの維持保証、タイムコードの自動音声同期、真の視認性測定は対象外。WebVTT の識別子・キュー設定を保存しないため、装飾情報が重要なファイルの往復編集には不向き。
