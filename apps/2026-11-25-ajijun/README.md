## 実行方法・実装
`index.html`をブラウザで開く。2〜6試料、1〜60人、固定済み順序を入力。全順列（最大720）から各追加行の二乗和増分を最小にする候補を選び、変更可能行を2巡再調整。位置別・有向隣接対の回数の二乗和を重み付きで評価する。理論下限との差を表示し、同じ固定行＋残り全員ABC…順より悪ければ比較案に戻す。大域最適性は一般には未保証。シードで共通3桁コードと候補の同点順を再現。実施済み行を固定し続ける際は同じ試料数・シードを使用する。
試飲者向けCSVと主催者用対応表CSV、印刷、ヒートマップ、固定欄への転記、入力検証。外部ライブラリ、アカウント、外部通信、個人情報入力なし。共通コードは強固な秘匿方式ではない。採点、温度、休憩、複数セッションの持越し、公式試験準拠、統計的有効性は対象外。
