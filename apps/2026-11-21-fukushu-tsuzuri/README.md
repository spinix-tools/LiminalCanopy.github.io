# 復習つづり / FUKUSHU TSUZURI 📚

**教員が「個人別の学習データを集めずに」クラス全体の正答傾向から次の復習プリントを選ぶ静的Webアプリ。** 制作・調査：2026-11-21。`index.html` と `style.css` `engine.js` `app.js` を同じ場所に置き `index.html` を開く。ビルド・会員・APIキー・追加料金不要。

## ターゲットと選定理由（国内／海外）

対象：少人数塾、補習教室、学校の教員、学習支援ボランティア。文部科学省はGIGAスクール構想で1人1台端末を推進している。2025年3月13日のデジタル庁資料では、授業で週3回以上の端末活用は小学校93.3%、中学校90.8%と報告。教員のデジタル教材運用環境があることの傍証であり、本アプリの市場規模や購入意向を示す数値ではない。

- 国内需要の背景： [文部科学省 GIGAスクール構想](https://www.mext.go.jp/a_menu/other/index_00011111.htm) / [2025-03-13 デジタル庁資料](https://www.digital.go.jp/assets/contents/node/basic_page/field_ref_resources/d5c4a630-e234-4e5e-b14d-f64ef8666415/62da155a/20250313_meeting_education-authentication_outline_03.pdf) （PDFは検索のテキスト要約を参照、原紙面検証はしていない）
- 日本の競合：[小テストジェネレーター](https://kengokosakai.com/printgenerator) は問題作成・印刷や成績管理等を提供し、同サイトには月間6万人利用・有料会員700人以上と記載（提供元の自己申告）。[MondAI](https://mond-ai.com/) はAI作問・採点・弱点分析等を提供。
- 海外の競合：[Quizlet for Teachers](https://quizlet.com/teachers) はカード・練習問題・授業用ゲームを、[AnkiDroid](https://docs.ankidroid.org/) は学習者の反応に応じた分散反復を提供。

**差別化仮説：** 大規模LMSや生徒アカウントを使わず、**問題ごとの匿名「受験数・正解数」だけ**を保持する。直近出題と弱点（累計正答率）と単元カバーを合わせ、時間制限のある **「配るための紙プリント＋別紙解答＋次回の再選定」** に絞る。印刷そのもの・間隔反復の先行例は多く、独占的な新規性は主張しない。実際の導入率・教育効果・課金意欲は未検証。

## 実装した操作

- 初期サンプル10問（分数・理科・国語）。単元、問題、解答、想定秒数、難易度を追加・編集・削除。問題検索。
- 出題日、単元、問数、総時間を指定して自動選定。履歴に基づく弱点重み付け、最近の出題抑制、単元の分散。選定は貪欲近似で、設定を満たせない場合は理由と不足件数を表示。
- 問題用紙と模範解答用紙を分けたブラウザ印刷。クラス全体の各問受験数・正解数を記録し、次回の優先度を再計算。氏名・個人別成績入力欄なし。
- UTF-8 BOM付き問題CSV・今回のプリントCSV・JSONバックアップ、JSON復元、localStorage保存、モバイル表示。表計算式の自動実行を避けるためCSV先頭の数式記号をエスケープ。

`node --test engine.test.cjs`：**22/22合格**、うち750件のランダム構成で問数・時間・単元・重複禁止を照合。`node --check engine.js` / `node --check app.js`：合格。`python browser_test.py`：**35/35合格**。Chromiumで追加・編集・削除、単元切替、時間制約、匿名結果記録、異常値拒否、JSON入出力、CSVダウンロード、印刷呼び出し、モバイル表示を検証。外向きネットワークリクエスト・JavaScript例外は試験中0件。

管理環境は `file://` ナビゲーションを遮断するため、ブラウザ試験は**同一HTML/CSS/JavaScriptをインライン展開**した。実機ブラウザでの直接起動、ローカル保存の永続性、プリンタ出力レイアウト、教材内容の妥当性、実学習効果は未検証。

## 注意点

これは**教育効果を保証する適応学習エンジンではありません**。累計正答率は問題の難しさ、教員の採点尺度、学級集団の変化の影響を受けます。直近出題と復習間隔（弱点により2/5/10日）は手作りの優先付けで、実証済みの学習科学アルゴリズムではありません。単元のカバー率と時間の両立も最適性を保証しません。著作権者の許諾がない問題の転載は避けてください。氏名・メールアドレス・児童生徒の個票や秘密情報を入力しないでください。ブラウザの保存領域削除に備え、JSONバックアップを推奨します。

**プライバシー・コスト：** フォント/CDN/分析タグ/外部APIなし。リクエスト送信処理なし。ローカルの匿名集計のみ。OpenAI API等の課金なし。
