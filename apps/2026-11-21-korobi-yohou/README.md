# ころび予報 / KOROBI YOHOU 🎲

**TRPG・ボードゲームの「何回も判定に失敗して進めない」を、シナリオ全体の連続失敗確率で検査するWebアプリ。** 登録不要、サーバー不要、外部依存なし。ブラウザだけで動作します。

## 対象・選定理由（2026-11-21調査）

- **ターゲット**：TRPGのゲームマスター、同人シナリオ作者、ボードゲームのルール設計者。判定の難易度と「詰まった感覚」を調整したい人。
- **日本の需要シグナル**：2026年5月23〜24日の「ゲームマーケット2026春」は延べ来場者3.2万人以上、出展1,000ブース以上と報道（[4Gamer、2026-09-28](https://www.4gamer.net/games/028/G102845/20260729002/)）。8月9日には体験イベントTGFF2026も開催（[roleplaying.jp、2026-07-18告知](https://www.roleplaying.jp/news/20260718-1500.html)）。アナログゲーム制作・体験のコミュニティが確認できる一方、**当アプリの購入意欲や市場規模を裏付ける統計ではない**。
- **日本の競合**：[CalcBEのTRPG判定・ダイス分布計算](https://calcbe.com/ja/tools/dice/)、[NanTooのダイス確率分布](https://www.nandemo-tools.com/entertainment/dice-probability)。単発成功率や分布の計算は既に提供されている。
- **海外の競合**：[AnyDice](https://www.anydice.com/docs/introduction/) は任意のダイス式の確率を計算できる強力な競合。[HARESEL Streak Simulator](https://haresel.com/en/calculators/streak-simulator) は同一確率の成功・失敗連続を扱う。両分野の先行ツールが存在する。
- **差別化仮説**：異なるDC・有利/不利・繰返し回数を持つ**時系列の判定列**について、連続失敗リスクを厳密計算し、「一律修正値を+何にすれば任意のリスク目標に達するか」をA/B比較・成功回数分布・即席ダイス実演と合わせて提示する。単発の確率ツールとルール調整の間にある体験を短縮できるか検証したい。**ユーザーテスト、継続率、収益性は未検証**。
- **既存アプリとの差**：既存 `hourly-app-lab/apps/` の116フォルダーを確認。直近の教材復習、字幕、木工、待ち行列、印刷、電源運用等とは異なる**TRPGルールの確率設計**であり、既存のダイス確率Webアプリは一覧に見当たらなかった。

## 動かし方・完成機能

1. このフォルダーの `index.html` を開く。`style.css`、`engine.js`、`app.js` を同じ場所に置く。ビルド不要。オフラインで使用可。
2. ダイス個数（1〜6）・面数（2〜100）・基本補正値、失敗連続の閾値と許容リスクを設定。
3. 判定のラベル／目標値DC／繰返し数／通常・有利・不利を追加・編集・削除。24種類、合計120判定まで。
4. **正確な確率分布**に基づく通常Aと追加補正Bの連続失敗確率、全成功確率、成功回数期待値、成功回数分布図、判定別の成功率を表示。
5. 許容リスク達成に必要な最小の追加補正（0〜12）を整数探索。達成できなければ不可能と明示。
6. 暗号学的乱数（`crypto.getRandomValues`、剰余バイアス回避）で実際にダイスを振り、1回分の判定列を試す。
7. CSV出力（UTF-8 BOM、表計算式インジェクション対策）、JSONエクスポート／インポート、端末内設定保存／削除、印刷、スマホ表示。

## モデルと限界

- `NdS+M` の合計分布は畳み込みDP（近似シミュレーションではなく、浮動小数での**厳密な組合せ確率計算**）。有利は独立な「合計値の2回判定」の最大、不利は最小。成功は `合計 >= DC`。
- 判定ごとの成功確率 `p_i` を求め、`0..k-1` 回の直近失敗を状態にするDPで、**列のどこかでk連続失敗が発生する確率**を計算。各判定の成功確率が異なっても対応。成功回数分布はポアソン二項のDP。
- すべてのダイス・判定は独立かつ公平と仮定する。技能レベルの変化、途中の打ち切り・リトライ、判定後の状況変化、対抗判定、クリティカル／ファンブル、ダイスの爆発、シナリオの分岐は含まない。**補正の推奨は統計モデル上の値で、実際のプレイの楽しさや公平性の保証ではない**。
- シナリオ名などの文字列は端末にのみ保存（個人情報を入力しないことを推奨）。ネットワークへの通信処理・API・計測SDK・広告・有料サービスなし。

## 検証結果（2026-11-21）

| 試験 | 結果 |
| --- | --- |
| `node --test engine.test.cjs` | **31/31合格**。既知の分布、連続失敗DP、独立全列挙との比較、確率保存則、境界値、乱数・CSV安全性を確認。 |
| ランダム500ケース（上記31テスト内） | **500/500合格**。確率分布の合計≈1、追加補正で成功期待値が低下しない・連続失敗リスクが増えないこと等を確認。 |
| `python browser_test.py` | **39/39合格**。Chromiumで編集、再計算、追加・削除、サンプルダイス、CSV/JSON保存と読込、入力拒否、HTML注入防止、印刷呼出、モバイルでの横幅、エラー0件。 |
