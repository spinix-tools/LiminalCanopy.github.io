# 異本スコープ / IBON SCOPE

**日本語の初稿・初出・改訂版などを最大3版まで比較し、異文への編集判断と根拠メモを残すブラウザーWebアプリ。** 2026-11-22制作。

対象：文学研究者、翻刻・編集担当者、教育現場、海外のデジタル人文学分野。

差別化仮説：既存のテキスト差分アプリ（国内 [DiffTool](https://difftool.net/ja/)・[nol.so](https://nol.so/ja/diff)）、高度な複数証本の校合（海外 [CollateX](https://collatex.net/)・[Juxta Commons](https://wiki.tei-c.org/index.php/JuxtaCommons)）の間に、**3版対照＋資料の確認水準＋行ごとの根拠メモ＋CSV／JSON書出**の小さな利用需要があると考えた。国文学研究資料館は2026-10-02に島崎藤村の自筆原稿の画像公開を発表（[情報源](https://school.nijl.ac.jp/db/)）。市場規模、顧客需要、収益性は未検証。

## 動かし方
`index.html`をブラウザーで開く。デモ本文は架空。日本語を含む3版を入力し対照・確認、メモを記録できる。通信不要、登録不要、外部APIなし。

## テスト
オリジナル完全版のNode.jsテスト **15/15**、固定シードランダム照合 **500ケース**、Chromium操作 **37/37** は合格。外部通信・JS例外0。管理環境ではローカルURLが遮断され、同一ソースをインライン展開し端末保存を模擬。通常ブラウザーの直接起動・永続保存は未検証。

**GitHub版の検証範囲は、完全版と異なる場合に別途明示する。**

## 限界
行単位の位置合わせは近似であり、異文の対応・真贋・時系列・作者帰属を確定しない。分割・移動・転倒等は目視照合が必要。本文・判断メモは端末内で処理し、ユーザーの指示なくサーバー送信しない。MIT License。
