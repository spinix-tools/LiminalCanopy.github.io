# ずらし畑 / ZURASHIBATA 🌿

**家庭菜園の「一度に採れすぎ」を減らす、登録不要・端末内完結のずらしまき比較ツール。**

## ターゲットと選定理由

ベランダ菜園・市民農園などで複数回に分けて野菜を育てる個人、家庭菜園講師。2026年3月4日公表のタキイ種苗「2026年 家庭菜園に関する調査」は全国20〜69歳の男女400人を対象とし、家庭菜園への関心と時間・場所・費用の障壁を報告。JAあつぎ（2025年11月更新）も狭い畑の作付けローテーションの必要性を解説。これらは関連ニーズの根拠であり、アプリ固有の需要・売上を証明するものではありません。

## 日本・海外の競合調査（2026-11-19確認）

- 日本向け: [Cultivy](https://apps.apple.com/jp/app/cultivy-%E5%AE%B6%E5%BA%AD%E8%8F%9C%E5%9C%92%E3%83%97%E3%83%A9%E3%83%B3%E3%83%8A%E3%83%BC/id6781305374) はオフラインで栽培時期や畝配置を案内。[Mebuki](https://apps.apple.com/jp/app/%E5%AE%B6%E5%BA%AD%E8%8F%9C%E5%9C%92%E3%81%AE%E6%A0%BD%E5%9F%B9%E8%A8%98%E9%8C%B2-%E7%AE%A1%E7%90%86-mebuki-%E9%87%8E%E8%8F%9C%E3%82%92%E8%82%B2%E3%81%A6%E3%82%8B/id6759305787) は水やり・追肥等の栽培記録を提供。
- 海外: [Seedtime](https://seedtime.us/) には種まきの反復（succession planting）、畝レイアウト、収穫カレンダーが既に存在し、2025-01-19更新の[ヘルプ](https://help.seedtime.us/en/articles/5833547-succession-planting)で操作も説明されている。**ずらしまき自体を新発明とは主張しない。**
- **差別化仮説:** 入力された「食べ切れる週間食分」を基準に、**5つの種まき間隔（＋任意値）の収穫ピーク、目標超過・不足、畝の占有重複、表示範囲外**を同一条件で並べ、登録や気候位置データの入力なしに調整できること。ユーザーインタビューによる優位性は未検証。

参考: [タキイ種苗 2026-03-04](https://www.takii.co.jp/info/news_260304.html)、[JAあつぎ 2025-11](https://www.ja-atsugi.or.jp/learn/garden/kateisaien/2025/11.html)、[Seedtime](https://seedtime.us/)

## 実装済みMVP機能

- 作物・播種日・区画・播種間隔・回数・収穫開始までの日数・収穫期間・収穫見込み食分・片付け日数の設定
- 区画を順番に割り当てる反復作付けの生成、1件単位の追加・修正・削除
- 7/10/14/21/28日＋任意の種まき間隔を比較し、衝突・収穫偏りを見ながら候補を追加
- 週別収穫チャート、目標線、超過分、区画二重使用の警告、表示範囲外の警告
- 最大12区画・300作付け、8〜32週（エンジン上限52週）の表示、ブラウザ内自動保存
- JSONエクスポート/復元、2種類のCSV、グラフSVG、印刷向けCSS、初回サンプル
- 入力を文字列として安全に表示（HTMLエスケープ）、JSON形式と数値の検証、CSV式先頭記号の保護

## 起動方法

このフォルダの `index.html` をブラウザで開きます。`engine.js`、`app.js`、`style.css` を同じフォルダに置いてください。外部API、npm、ビルド、会員登録、利用料は不要。データはブラウザの `localStorage` に保存されます。プライベートモードやブラウザの設定によって保持されない場合があるため、JSONでバックアップを取ってください。アプリは送信処理やアクセス解析を含みません。

## ロジックと限界

- 収穫開始は `種まき日 + 入力した日数`、収穫見込みは収穫期間の各日に均等配分して週（月曜始まり）ごとに合算します。
- 区画占有期間は `種まき日〜収穫終了日+片付け日数` の半開区間。区画が同じで区間が交わる組を警告します。
- 候補の順序は `3 × 週間目標超過累計 + 目標不足累計 + 3 × 表示範囲外見込み + 10,000 × 区画衝突組数` が小さい順。**試した候補内の順位**であり、全間隔・現実の生産性における最適解ではありません。
- **実際の生育予測ではありません。** 品種の適期、地域の気象、温度、日照、病害虫、連作障害、収量変動、区画内の混植と成長差は推定しません。播種や収穫の判断は種袋・地域の栽培情報・実測に従ってください。
