# LocalePath — 翻訳フォールバック比較

## 対象・選定理由（2026-11-27）
日本語・英語などを提供する小規模SaaS、アプリ開発者、ローカライズQA担当。辞書の欠落が代替言語で覆われるため、探索順の変更が表示内容に与える影響は単純なキー比較だけでは分からない。日本の開発事例と国内向けQA製品、海外のi18next・QA製品から課題の存在を確認。売上規模・支払意思は未検証。

## 競合・差別化仮説
- 日本の実装例: https://zenn.dev/mtea/articles/react-i18next
- 日本向けLocaleQA（キー・プレースホルダー比較）: https://localeqa.com/ja
- i18nextのフォールバック仕様: https://www.i18next.com/principles/fallback
- 海外のi18next CLI（翻訳状態検査）: https://github.com/i18next/i18next-cli/blob/main/README.md
- Crowdin QA（構文・翻訳チェック）: https://support.crowdin.com/project-settings/qa-checks/

辞書の不足検査に加え、同じ辞書に対して二つの明示的探索順を比較し、キー×ロケール単位で表示文字列と採用元の変化、新規未解決、改善を特定する。探索順の変更レビューに特化する仮説であり、競合に同等機能がないとの断定ではない。過去の会話内アプリ、専用ブランチ差分の51ディレクトリ、4語のコミット検索で明確な重複なし。全履歴・全ソースの網羅検査は未実施。

## 操作
index.htmlをブラウザで開き、サンプルを編集。「比較する」で集計・出典差分を表示、フィルターとJSON出力を利用できる。最大30言語×2000必須キー、入力合計200万文字。画面は先頭500件、JSONは全件。対象言語を先頭とする明示的な順序で最初の有効な文字列を採用する。空文字の欠落扱いは選択可能。再帰探索、複数形、補間、名前空間、実ライブラリ完全互換、翻訳の正しさは対象外。外部API・依存ライブラリ・永続保存なし。秘密情報や個人情報は入力しないこと。

## 検証
`node test.cjs`: 640生成ケースと7固定検査合格。`python browser_test.py`: Chromiumで初期値、フィルター、JSON実ダウンロード、不正入力、旧結果無効化、空文字設定、390px幅を検査し合格。JS例外・HTTP要求0件。環境制限でfile://起動が拒否されたため、同一HTMLをset_contentで検査。実プロジェクトでの実行・収益性は未検証。
サンプル8件: 新規未解決2、変更後未解決2、採用元または値の変化5、変更後代替言語3。
