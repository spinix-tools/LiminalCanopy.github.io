# SpoolFit / 残糸割付ラボ

## 対象・選定理由（2026-11-28）
3Dプリント愛好家、小規模工房、学校・メイカースペース。少量残った互換フィラメントを複数の印刷ジョブに割り付け、造形途中の交換を避ける計画を作る。

国内向け競合： [Filament Genius](https://filamentgenius.app/ja/) は在庫・スライサー連携、[フィラメント台帳](https://apps.apple.com/jp/app/%E3%83%95%E3%82%A3%E3%83%A9%E3%83%A1%E3%83%B3%E3%83%88%E5%8F%B0%E5%B8%B3/id6796057602) は残量・使用量の記録。 [Raise3D国内代理店](https://www.raise3d.jp/news/112) は長時間造形での交換リスクを説明。海外： [Spoolroom](https://spoolroom.app/) は印刷前の在庫適合確認・余裕、[3DPrint.Tools](https://3dprint.tools/tools/filament-remaining-calculator/) は単一スプール残量とジョブの適合計算。これらは需要の間接証拠であり、販売数・検索量・収益性は未検証。

差別化仮説：在庫台帳ではなく、空スプール重量の不確実性を含めた複数ジョブの一括割付。下限案と上限案を比較し、入力順の割付より多くのジョブを完了できる条件を示す。競合の全機能を確認したわけではない。日本語の残糸活用・造形前チェックを入口に、英語版を将来検証する。既存の直近8案とは用途が異なる。リポジトリのmainとの差分取得およびコミット検索（filament、spool、フィラメント）で明確な重複は発見せず、全ソースの網羅照合は未実施。

## 使用法・モデル
`index.html` をブラウザで開く。スプール最大8本、ジョブ最大12件。CSV風入力（引用符なし、整数g、IDは各表で一意）。互換性が確認済みの材料に限定。各ジョブに指定割合の余裕を加え整数gに切り上げる。総重量から空重量上限／下限を引いて残量下限／上限を算出。部分集合DPで完了件数、同数なら割付重量を最大化する。ジョブ分割・途中交換なし。下限は仮定した範囲内での条件付き保証であり、実消費を保証しない。ファイルや個人情報の送信、外部API、永続ストレージなし。JSON出力・印刷対応。

## テスト結果
- `node test.cjs`：固定7アサーション、乱数300ケース×上下限の独立全列挙照合、最大8本/12件、すべて合格。
- `python browser_test.py`：Chromiumで同一HTMLをインライン読み込み（環境のfile://制限）。初期値、余裕変更、JSONダウンロード、入力不正、旧結果無効化、HTML文字列の安全表示、リセット、390px幅を検査。JS例外・外部HTTP要求0件。全合格。印刷実出力は未検証。
- サンプル：下限100g・70g、ジョブ70/60/40g、余裕0%。入力順2件、最適3件。余裕10%では下限2件・上限3件。

制限：スライサーファイル解析、異種材料の混在、重量測定誤差（空重量の範囲以外）、造形品質、実プリンター接続、実機テストなし。印刷成功や材料の適合性を保証しない。
