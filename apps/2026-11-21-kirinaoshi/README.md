# 切り直し / KIRINAOSHI

木材・角材・パイプなど**同じ断面の長尺材**について、切断計画と切り損ね後の再計算をつなぐ、登録不要・オフラインのMVP（2026-11-21）。`index.html` を開いて使用。Node.js 22+ で `node --test engine.test.cjs`。

## 想定利用者と選定理由

日本のDIY愛好者、工房、学校工作室。2026年10月30日付の経産省統計紹介によると、2026年9月のホームセンターの「DIY用具・素材」販売額は608億円、前年同月比3.5%増。ただし**この金額から切断計画アプリの利用意欲は推定できない**。海外でも長尺材の木取り最適化サービスが複数提供され、類似の作業需要が存在する。

## 競合と差別化仮説

- 国内：Cutting Planner（長尺材／板材の木取り）、iOS CutPlan（木取り図・刃厚対応）。
- 海外：LinearCutting（端材・刃厚・切断計画）、Cut Wizard（1D切断最適化）、NestSolver（欠陥・端材対応）。

**新規性は最適化そのものではない。** 現物を1カットするごとに完了数と材料の**実測残り**を確定させ、切り損じで予定より短くなっても、未切断分を手元の材料へ割り当て直す「現場での復旧ループ」に絞る。実際の利用需要・競争優位・収益性は未検証。

## 実装機能

1. 材料1本ずつの長さ・種類（購入材／端材）、必要部材の名称・長さ・本数を入力。
2. 刃厚・再利用長を設定し、3通りの貪欲法候補から未配置数→使用購入材数→廃棄長の順に選ぶ。材料別の切断図と順番を表示。
3. 各材料の最初の部材を切り、実測残りを入力して「完了」または「失敗」を記録。失敗時は完成数を増やさず在庫長を消費し、未完成の部材を再配置。1手Undo可能。
4. ブラウザ内自動保存、JSON入出力、Excel向けBOM付CSV、印刷。
5. サンプルデータ同梱。外部通信、アカウント、秘密情報、OpenAI APIを使わない。

## 検証と限界

- Node.js単体テスト（保存則、完了処理、Undo、刃厚、不足、JSON、CSV）と250件の乱数ケースを実施。
- Chromiumの主要UI操作テスト23/23合格（制限環境のためインライン実行・localStorageモック）。
- **最適解の保証なし**。材の寸法以外（断面の違い、木目、欠陥、反り、角度、刃物の仕様、固定代、端面処理）は考慮しない。すべて直角・単純1次元、毎切断の刃厚を消費する保守的モデル。実物切断前に作業者が必ず確認する。
- 完了した部材は部材数を保存するが、どの完成部材をどこに保管したかの追跡・加工取り消しは未対応。
