# 切り直し / KIRINAOSHI

木材・角材・パイプなど**同じ断面の長尺材**について、切断計画と切り損ね後の再計算をつなぐ、登録不要・オフラインMVP（2026-11-21）。`index.html` を開いて使用。Node.js 22+で `node --test engine.test.cjs`。

## 想定利用者と選定理由

日本のDIY愛好者、工房、学校工作室。経産省統計の2026年9月ホームセンター「DIY用具・素材」販売額は608億円、前年同月比3.5%増（流通ニュース2026年10月30日）。ただしこの統計だけでは切断計画ソフトの需要規模は推定できない。

## 競合と差別化

- 国内 Cutting Planner（長尺材／板材の木取り）、CutPlan（木取り図・刃厚対応）
- 海外 LinearCutting、Cut Wizard、NestSolver（それぞれ刃厚・端材・木取り最適化機能あり）

**新規性は最適化そのものではない。** 現物を1カットするごとに部材の完了数と**実測残り**を確定させ、切り損じで短くなっても、未切断分を即時に割り当て直す「現場の復旧ループ」に絞る。需要・競争優位・収益性は未検証。

## 機能とテスト

材料1本ごとの長さ・種別、部材の寸法・必要本数、刃厚・残材保管目安、3通りの貪欲法による割当候補、切断図、1カット完了＋実測残り再計算、1手Undo、端末内保存、JSON入出力、CSV、印刷。単体テスト10/10合格、ランダム250ケース合格、Chromium操作21/21合格（セキュリティ制限で同一コードをインライン展開しlocalStorageを模擬）。

**限界：** 1次元・直角切断のみ。毎切断の刃厚を消費する保守的近似で最適解保証なし。木目・傷・断面・安全な固定寸法を扱わない。実機切断は要再確認。ブラウザでの `file://` 起動は未検証。
