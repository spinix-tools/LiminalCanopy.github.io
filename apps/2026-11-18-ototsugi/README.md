# 音つぎ / OTO-TSUGI — 対バン回線転換プランナー

> 小さな会場の複数アクトについて、共用入力チャンネルを割り当て、組間の変更を視覚化する完全オフラインのWeb MVP。

## 対象・選定理由

対象：ライブハウス、学校音楽祭、地域の小規模音楽イベントのPA担当・出演者。2026年6月17日のぴあ総研公表によると、2025年の国内ライブ・エンタテインメント市場は8,564億円・公演回数は100,820回。ただし大規模公演も含む広範な市場値で、本ツールの直接需要・商業性は未実証。国内では「セット図くん」が登録不要でセット図・インプットリストを提供。海外ではPluggedIn、AUDIOPATCHなどがフェス向けマスターパッチや複数アクトの運用を実装済み。したがって「複数アクトの入力表が作れること」自体は新規性ではない。

## 差別化仮説

**無料・登録不要・通信不要の1画面で、「出演順を入れ替えた場合」と「物理チャンネルを固定した場合」を比較し、切替注意箇所を印刷用チェック表として出せること**を優先する。クラウド上の包括的ライダー管理ではなく、その日の小規模公演での転換チェックに特化。現場ヒアリングによる評価は今後必要。

## 実装機能

- 出演枠12組・各組32入力まで登録、変更、複製、並び替え、削除
- 音源名・種別・ファンタム48V・固定チャンネルを編集
- 8/16/24/32chを対象に最小費用割当（ハンガリアン法）、容量超過・固定ch衝突を検出
- 組ごとの共用パッチマトリクス、回線変更・取り外し・新規・48V差の可視化
- 3〜7組の場合、出演順変更による参考コスト低下候補を探索（参考スコアに限る）
- 組間転換チェックメモ、コピー・テキスト保存、CSV出力、JSONバックアップ・復元、印刷
- localStorage自動保存。外部JS・外部API・会員登録・課金・個人情報送信はなし

## 起動・検証

ZIPを展開して `index.html` を開く。依存関係とビルド不要。手動で試す際はサンプルを読み、別組の入力を変更し、共用パッチと変更点を確認。CSV/JSONダウンロードが可能。

- `node --test engine.test.cjs`: **37/37 合格**（入力正規化、容量と固定ch競合、割当、電源差の表示、CSV、再現性等）
- `python browser_test.py`: **24/24 合格**（Chromiumで編集・入力追加/削除・順番変更・複製・CSV/JSON入出力・レスポンシブを確認）
- **ブラウザ制限：** 管理Chromiumの `file://` / local HTTP ナビゲーションが遮断されたため、実HTML/CSS/JSを `set_content` / `add_script_tag` で直接読み込み、`localStorage` のみ模擬した。実配信でのJS実行・端末間移行・自動保存の持続性・印刷実機は未検証。
- コストは**手作業の便宜的重み**で、音響上の安全、ケーブル長、ステージ箱位置、物理パッチの現状、FOH/Monitor分岐等は最適化しない。出演順提案は総当たりの近似的な事前選別後に比較し、網羅最適ではない。
- **安全：** 48V表示は注意喚起のみ。機器接続・ミュート・ファンタムの切替手順・ゲインはPA担当者が機材取扱説明書と現場ルールで確認すること。アプリは機器制御を行わない。
