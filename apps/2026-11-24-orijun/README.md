# 折順 / ORIJUN — ZINE 面付け・折り順ラボ

2026-11-24 新規制作。対象：ZINE作者、学校の小冊子制作、文芸サークル、イベント出展者。過去の釣銭・展示・パン・育苗・舞台・駐車・鉄道模型・発送・本交換・自転車ギア分野とは非重複。

## 市場と競合
- 日本：ZINEZ「ZINE白書2026」（2026-11-11時点）はBOOTH掲載のZINE 3,505点、1,651作者を収録。業界全体の代表統計ではない。https://zinez.org/report/2026
- 日本：「MORIMICHI ZINE'S FAIR 2026」は出展枠の約3倍の応募、56組出展（運営公表）。https://insec2.com/morimichi-zines-fair-2026/
- 海外：Portland Zine Symposium は2026-10-17〜18日に開催。https://www.portlandzinesymposium.org/
- 競合：折本制作支援ツール orie（テキスト・画像の折本）https://orie.comilab.net/ 、ainew のPDF中綴じ https://tools.ainew.jp/pdf-booklet-maker 、PDF24 https://tools.pdf24.org/ja/create-pdf-booklet 、BookletMaker https://bookletmaker.app/ （折丁・クリープ補正）。

**差別化仮説：** PDFにする前の文章入力から、1枚の表裏の面付け・折丁の分割・白紙挿入・試し刷り・用紙代見積りまでを一画面で行う。少部数のコピー本でミスの削減につながる可能性がある。既存サービスとの機能重複はあり、需要・優位性・収益性は未検証。

## 機能
64ページまでの本文・見出しの編集、ページ追加・削除・移動、左右綴じの中綴じ面付け、4〜64ページ単位の折丁計算、白紙自動補完、表裏プレビュー、用紙枚数・単価計算、A4横のブラウザ印刷（全表裏・表のみ・裏のみ・1枚試し刷り）、JSON入出力、CSV出力、端末内自動保存。外部API、アカウント、課金、内容送信なし。

GitHub配布の `index.html` は完全版HTMLをgzipでロスレス格納したローダー。直接ブラウザで開けるほか、同梱の `unpack.py` で可読な `standalone.html` に復元できます（SHA-256確認）。

## 検証
- Node.js単体テスト **18/18合格**。1〜64ページ×6折丁設定×両綴じの全組合せ、およびランダム **2,500ケース**の面付け監査。
- Chromium画面操作 **45/45合格**。編集、計算、JSON/CSV出力、JSON復元、XSS無害化、モバイル画面。JS例外・外部HTTP要求0件。
- Chromium印刷レンダリング：A4横のPDF **6ページ**を作成、ページ数・用紙寸法・1ページ目を目視検査。
- GitHub用gzipローダーの展開・画面描画を確認。
- **制限:** 管理環境で `file://` 直接起動が遮断されたため、同一HTMLをChromiumへインライン挿入、localStorageはメモリで代替してテスト。実プリンター・継続的保存・紙の仕上がりは未検証。右綴じでも文字は横組み。画像/PDF読込、クリープ補正、長文の自動流し込みには非対応。

印刷はA4横・倍率100％・余白/ヘッダーなし。プリンタ側の「小冊子」「2ページ/枚」をOFF。自動両面は通常「短辺とじ」だが機種差があるため、必ず最初の1枚で試し折りしてください。
