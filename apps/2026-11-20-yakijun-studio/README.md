# 焼き順スタジオ / YAKIJUN STUDIO

2026-11-20 制作。家庭の複数種類のパンを1台のオーブンで焼くための、日本語・無料・オフラインWebアプリ。

## 起動方法

このディレクトリにある **[index.html](index.html)** は外部ファイル不要の単一HTML版です。ローカルへ保存し、一般的なブラウザで開くと利用できます（動作の直接検証は後述）。配合計算、最終焼き上がり時刻からの逆算、重複しない焼成枠、全順列での混合作業重複最小化、工程図、計量表、JSON・CSV入出力、印刷、端末内保存が利用可能です。ログイン、外部API、追加課金、個人情報の外部送信はありません。

開発時の**分割ソース版**は index.html + style.css + engine.js + app.js + Node/Chromiumテストから構成され、同実行の成果物ZIPとして利用可能です。GitHubの単一HTML版と分割版は異なるビルドであり、完全一致・同一テスト結果を主張しません。

## ターゲットと選定理由

家庭のパン愛好家、少人数のパン教室、試作を行うマイクロベーカリー。クックパッドの2025年10月3日発表では「初めて」つくれぽの上位30レシピのうちパンが2025年に26.1%を占めた。対象は人気30レシピに限られ、日本の製パン趣味人口・本アプリ需要を直接表す値ではない。英国AHDBは2026年3月19日に、2025年の家庭ベーキング回数が前年比7%減と報告しているため、一律に成長市場と断じない。

## 競合と差別化仮説

- [Flourwise](https://flourwise.com/) — 配合・ルヴァン・温度・タイマー
- [SourdoughGuru](https://sourdough.guru/) — 焼きたい時刻からの工程逆算、発酵時間調整
- [Sourdough and Bread](https://sourdoughandbread.com/sourdough-bake-planner) — 無料の計量・予定・記録

単なる配合・逆算は既存機能。**複数生地を1台のオーブンで焼くときに、混合作業の重複を最小化する順番を同時比較する**ことに特化する仮説。実利用率・収益化・競合に対する優位性は未検証。

## 計算仕様／限界

総粉量 F = 合計生地重量 / (1 + 加水率/100 + 塩率/100) 。総水 W = F×加水率/100、ルヴァン質量 L = F×ルヴァン率/100 。ルヴァン内の粉 Lf = L / (1 + ルヴァン含水率/100) なので、追加粉 F−Lf、追加水 W−(L−Lf)、塩 F×塩率/100 を表示。「ルヴァン%」は総粉重量比のルヴァン質量で、PFFとは別。負の追加材料は警告。各バッチはオーブン一回分を占有し、投入・取り出しの隙間を挿入。最大7バッチで最大5,040通りを比較。発酵所要時間は**手入力**であり、温度・発酵速度・実オーブン容量・予熱・食品衛生・焼成結果を保証しません。
