# 穴合わせ / AnaPair

## 対象・市場・選定理由（2026-11-26）
手縫い革小物・バッグの製作者、レザークラフト教室、型紙作家。別裁ちしたパーツの縫い穴が角や目印でずれ、穴開け後に修正しにくい問題を対象とする。国内では手縫い教室や多ピッチの工具が存在し、海外の愛好者掲示板にもマチの角や縫い穴数を合わせる悩みがある。市場規模・支払意思は未計測。

- 国内の教室: https://atelierhanada.com/
- 国内の工具・ピッチ解説: https://leather-craft.net/leather157
- 海外の課題例: https://www.reddit.com/r/Leathercraft/comments/t1smpx
- 競合: [LeatherDraft](https://www.leatherdraft.com/guide/stitch) は輪郭への穴配置、[ToolHuts](https://toolhuts.com/leathercraft/stitch-hole-spacing-calculator) は単一縫い線の穴位置、[Countfolk](https://countfolk.com/leather-bag-gusset-stitch-calculator/) は対称な閉じた角丸長方形のマチ穴数を計算する。

差別化仮説：任意の対応目印で区切った二つの開いた縫い線について、区間ごとに同じ間隔数を求め、既定の穴数・総穴数・両辺の許容ピッチを同時に扱う。全穴の対照位置を出力する。単独計算や型紙CADに対する補助ツール。初期顧客候補は教室・型紙作家。試用後の修正時間と穴数不一致率を検証する。独自性・収益性は仮説。

## 起動・入力
index.htmlをブラウザで開く。依存ライブラリ、サーバー、ログイン不要。A/Bを同じ縫い進行方向で、縫い線上の対応目印間の長さを `A長さ,B長さ,固定間隔数` 形式で各行に入力（0は自動、最大12区間、各0.5〜300mm）。希望ピッチ2〜10mm、偏差0〜30%、総穴数0（自動）または2〜3601を指定。計算、対応図、累積位置、CSV、印刷を利用できる。外部送信・保存なし。

## 計算
区間長a,bに対して間隔数n（1〜300）を共有し、両ピッチa/n,b/nを制約内に収める。各区間のコスト n×[(a/n−p)^2+(b/n−p)^2] の和を最小化。総穴数指定時は動的計画法、自動時は各区間の最小候補を選ぶ。境界穴は重複計上しない。サンプルは各辺を別々に丸めると35穴/36穴、共同計画では35穴ずつ、間隔数11/8/15、最大偏差6.25%、全長差4mm。

## テスト結果
- `node test.cjs`: 固定10アサーション、独立全列挙300ケース、12区間1801穴、すべて合格。
- `python browser_test.py`: Chromiumで初期表示、CSV実ダウンロード、総穴数変更、結果無効化、解なし、不正入力、リセット、390px表示に合格。JS例外・外部HTTP要求0件。環境のfile URL制限によりHTMLをインライン実行。再実行にはPython PlaywrightとChromium（スクリプト内の実行パスを調整可）が必要。

## 限界
開いた縫い線のみ。長さ差、曲率、材料の厚みや伸び、穴形状、工具の固定ピッチ、縫合強度、印刷実寸は保証しない。対応する穴数が得られても物理的に縫える保証はない。端材での実測・試作が必要。実ユーザーによる需要・効果・収益性は未検証。
