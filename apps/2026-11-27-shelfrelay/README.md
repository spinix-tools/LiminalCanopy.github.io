# ShelfRelay / 配架修正ナビ

図書館・学級文庫・小規模資料室向け。台帳順と現物順の個体IDを貼り付け、確認済み資料を最少の移動で並べ直す。`index.html` をブラウザで開く。外部依存・通信・登録なし。個人情報は入力しない。

## 市場と差別化（2026-11-27調査）
- 日本: [DNP](https://www.dnp.co.jp/news/detail/20169899_1587.html) は蔵書点検を効率化するRFIDサービスを2023年10月に発表。[SHELF EYE](https://biz.kccs.co.jp/service/shelfeye/) は画像による点検支援を提供。設備を導入できない小規模施設にも点検需要があるとの仮説。
- 海外: [OCLC Digby](https://help.oclc.org/Library_Management/WorldShare_Circulation/Digby/Get_started/Digby%C2%AE_app_FAQ) は請求記号順の点検と問題資料の報告に対応。[Shelf](https://github.com/dgahagan/shelf) は蔵書監査と棚の並び管理を提供。
- 差別化仮説: 専用台帳や分類体系に依存せず、順序付きIDの2リストだけから最少の抜き差し手順を出す。既存製品の補完を狙う。市場規模・有償需要・独自性の網羅検証は未実施。
- 重複確認: 直近の会話履歴、mainとの差分に含まれる51アプリディレクトリ、shelf/配架/書架/蔵書/ShelfRelay のコミット検索で明確な重複なし。全ソース照合は未実施。

## 実装と制約
各5,000行まで。IDは前後空白を除き厳密一致、固有個体IDを使用。重複IDでは計画を停止。未確認と台帳外を別表示し、台帳外を除いた確認済み列だけを最適化。最長増加部分列を残し、残りを目標順の右から左へ移す。移動数は n−LIS 長で最小（任意位置へ1冊を移すモデル）。棚容量・移動距離・貸出状況・分類規則は扱わない。カメラや専用機器との連携は未実装。JSON保存・印刷用表示あり。
