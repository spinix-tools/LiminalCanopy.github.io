# かえり箱 / KAERIBAKO

**2026-11-21制作 / 登録不要・無課金・ブラウザ完結のリターナブル物流容器循環プランナー。**

配送に使う通い箱が「出荷 → 客先での滞留 → 回収 → 洗浄 → 再出荷可能」になるまでの時間差から、欠品が発生する日、配送先別の出荷未達、必要な初期箱数を計算します。現状と「追加調達／回収短縮／洗浄短縮」の改善案を比較できます。

## 想定ユーザー・選定理由

惣菜・青果の小規模工房、生産者グループ、地域配送・共同物流の担当者。少数の固定配送先に繰り返し箱を貸し出すとき、個別トラッキングシステムを導入する前に「何個持てば回るか」を試算したい人を想定しています。**市場全体の動向は、このアプリへの実需要や購入意向の直接証明ではありません。**

- **日本:** 国土交通省は2024-04-23、国際間リターナブル物流容器（RTI）の利用促進に向けた実証輸送と手引き改訂を公表。2026-04から物流効率化法に伴う一部大規模事業者の計画・報告義務が開始。小規模事業者向けの需要は別途検証が必要です。 [国土交通省 RTI実証](https://www.mlit.go.jp/report/press/tokatsu01_hh_000778.html) / [物流効率化法](https://www.mlit.go.jp/seisakutokatsu/freight/seisakutokatsu_freight_mn1_000034.html)
- **海外:** 欧州委員会は2026-08-11、EUの包装・包装廃棄物規則（PPWR）が2026-08-12から段階的に適用され、再使用に関する具体的な目標等は2030年以降適用されると説明。これは規制対応ニーズの背景であり、本アプリが法令適合を保証するものではありません。 [European Commission 2026-08-11](https://environment.ec.europa.eu/news/new-eu-rules-packaging-enter-application-2026-08-11_en)

## 競合と差別化の仮説

- **国内:** 日新の [ハコループ](https://www.nissin-tw.com/news/hacoloop202502.html)（2025-02-26公開）は国際物流の容器種別ごとの費用・CO2比較を提供。目的は導入時の費用対効果検討で、当MVPの「曜日別の循環在庫と日別欠品計算」と焦点が異なります。
- **海外:** [Tosca Hub](https://www.toscaltd.com/tosca-ordering-hub/) は発注・追跡・返品管理、[MyIFCO](https://www.ifco.com/food-supply-chain-innovation/smartcycle/ordering/) はリユース容器の注文・返品を管理。既存の商用システムは高機能であり、容器の在庫管理それ自体に新規性はありません。
- **狭い差別化仮説:** 「一枚の配車表のように、曜日 × 箱数 × 回収日数 × 洗浄 × 想定損失だけを編集し、日別欠品の発生と**予定を全部出すために必要な最小初期在庫**を即時比較できる」こと。実際の継続利用率・競合に対する優位・収益性は未検証。

## 操作

1. `index.html` を同じフォルダの `style.css`, `engine.js`, `app.js` とともに開く。ビルド・サーバー・APIキー不要。
2. 開始日、7〜120日の期間、手元の箱数、配送先ごとの曜日・箱数・回収日数・洗浄日数・回収不能率を編集する。配送先は上下で優先順位を変更できる（最大16件）。臨時の追加便は日付で登録（最大120件）。
3. 現状と改善案の合計欠品・出荷達成率・在庫推移・日別明細を比較する。「改善案を欠品ゼロにする」で、設定した回収条件の下での必要な追加箱数を自動セット。
4. CSV出力・JSON保存／読込・印刷が可能。設定はブラウザ内 `localStorage` に自動保存。外部送信なし。

## 計算の前提と制限

- 毎日**朝に回収・洗浄完了済み箱を受け取った後、その日の予定を出荷**。欠品時は上の配送先から先に配る。配送可能数だけを出荷し、未出荷分の後日繰越はしない。
- 各ロットの回収数量は `Math.round(出荷数量 × (100-回収不能率)/100)`。損失は計算上出荷時に織り込みます。回収日数は**出荷後から返却が戻るまで**、洗浄日数はその後に要する日数。洗浄0日なら帰着当日の朝から使用可能と仮定。
- 必要な最小初期在庫は、**全予定を欠品なく出荷した場合**の「その日までの累積出荷数 − その日までに使用可能になる回収予定数」の最大値。需要・日数・回収率が固定なら、完全充足できる初期在庫の厳密値です。
- これは確定的な計画モデルです。連休・洗浄機の処理能力・返却遅延の確率・箱の破損差・多拠点間移送・実際の安全在庫・輸送費・環境影響は考慮しません。回収率はロットごとの整数丸めを伴います。**実運用には余裕と現場確認が必要**です。
