## 競合と差別化仮説
- **日本：** [KAESU](https://apps.apple.com/jp/app/kaesu-%E3%82%B3%E3%83%B3%E3%83%9D%E3%82%B9%E3%83%88%E8%A8%98%E9%8C%B2%E3%82%A2%E3%83%97%E3%83%AA/id6775872570) は生ごみの投入記録・推定栄養の可視化を提供。[GardenMetric](https://gardenmetric.com/ja/compost-cn-ratio) は C:N 比計算を提供。
- **海外：** [CarbonBalance](https://solveitlocal.com/compost-cn-calculator/) は乾物ベースの C:N・水分と単素材の追加量の逆算に対応。[InfyCalculator](https://infycalculator.com/calculator/compost-ratio-calculator) は C:N・水分に基づく多素材の評価に対応。**既に十分な競合が存在**する。
- **仮説：** 2つの追加素材を任意に選び、**C:Nと含水率の2目標を同時に満たす正の分量が存在するか**を一度で判定し、前後比較→材料リストへ反映→材料CSV・プロジェクトJSON保存までつなぐ日本語の実験道具に需要があるか。優位性、利用意向、収益性は未検証。アプリの独自性を数学手法そのものには求めない。

## 使える機能
材料名、湿重量kg、含水率%、乾燥物中N%、C:N比を追加・編集・削除。炭素・窒素の質量収支から混合C:Nを計算し、水分量・乾物量・材料別の炭素寄与を表示。C:Nと水分の目標、追加材2種類を選び、**2元1次連立方程式**で必要重量を求める。負の追加量または特異行列なら**実行不能と表示**。正の解をリストに反映でき、CSV（数式注入対策）、JSONの保存・読込、印刷、localStorageへの自動保存に対応。

初期値と素材ライブラリ値は**教育用の仮定**であり測定値ではない。乾物炭素Cと窒素Nのバランスから算出するもので、単純な C:N 平均値ではない。例: `乾物=湿重量×(1−水分率)`, `N=乾物×N%`, `C=N×(C:N)`。水を加えたときもC・Nは増加しない。二軸の方程式は `Σ(C−R×N)=0` と `Σ(水−M×湿重量)=0` から求める。小数表示は2桁に丸めるが、計算内部は丸めない。

**重要な限界：** 発酵の進行、温度、通気、悪臭、害虫、病原リスク、乾燥や分解による質量変化、かさ密度、完成日、肥効、食物安全を評価しない。計算値が目標範囲でも良質・安全な堆肥になる保証はない。使う前に現物と自治体の指針を確認。初期素材の代表値や推奨範囲は目安のみ。
