入換尺 IREKAEJAKU

線路を延ばす前に、手持ちの貨車で入換が成立するか確かめる。

Offline · no account · no external API

01 / 条件を入力

全長は同じ単位（例：mm）。引上線は機関車・余裕分を差し引いた貨車用有効長。

貨車は A から順に最大6両（2〜6両）。空線は空欄のまま / で区切る。目標はA線に指定車だけが並び、引上線が空になること。

02 / 入換操作

分岐側 ← 各線の車両順 → 車止め側（引上線は分岐から機関車側）

目標（車止め側から）：

実行した移送0
現在からの最短移送—

03 / 初期配置からの延長比較

各線を一つずつ延長したときの最短移送数を比較。数字は操作回数のモデル値で実際の運転時間ではない。

04 / 現在からの最短手順

模型用の抽象モデル。線路の実形状・連結器・勾配・機関車の移動距離・実車の運転安全性は扱いません。
