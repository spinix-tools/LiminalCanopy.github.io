# 電波ふた案 / DENPA FUTAAN 📶

2つの自宅Wi-Fi配置案について、**壁越しの概算受信強度と、仕事部屋など優先したいエリアの達成率**をブラウザで比較する、登録不要のローカルWebアプリ。2026-11-20制作。対象：日本の家庭・在宅勤務者・小規模店舗。

## 使い方

`index.html` を同じフォルダの `style.css`、`engine.js`、`app.js` とともに開く。サンプルが最初から入っています。現状A/移設Bの各ルーターは、ツールを選んで図面をクリック・ドラッグするか、数値入力で移動。壁と「重要な部屋」はドラッグで追加。周波数・壁材・目標dBm・部屋の優先度を変更すると、電波予測図、2案の達成率、部屋別比較が更新されます。JSON保存/読込、CSVレポート、SVG図面保存、印刷、ブラウザ内保存が可能です。

## 市場・競合を調べて選んだ理由

- **日本の周辺需要**：総務省が2026-05-29に公表した「2025年通信利用動向調査」では、国内のスマートフォン保有世帯は**91.8%**。Wi-Fi利用世帯やプランニング需要を直接示す統計ではありませんが、家庭ネットワーク環境の広い関連母集団を示します。出典：[総務省](https://200.180.31.150.static.iijgio.jp/main_sosiki/joho_tsusin/eng/pressrelease/2026/5/29_2.html)。
- **日本の競合**：[WaveHunt](https://wavehunt.app/) はスマホでの実測・サイトサーベイ、PCでのマップ統合を提供。[NetSpot日本語版](https://www.netspotapp.com/jp/wifi-planning/) は壁材等を考慮した予測ヒートマップを提供します。
- **海外の競合**：[NetSpot](https://www.netspotapp.com/wifi-planning/) はAPや壁材の予測設計に対応し、[wifiheatmap.app](https://wifiheatmap.app/) は登録不要のブラウザ上で類似した予測ヒートマップを提供。高機能分野では [Ekahau Plan](https://www.ibsjapan.co.jp/eka05) も存在。**電波予測という機能自体には新規性がありません**。
- **差別化仮説**：技術計測値ではなく「現状Aと移設B」の同一画面比較を基本に、リモート会議室・寝室といった**優先エリアの面積×重み付き達成率**に絞り、専門知識なしに比較する。測定器・アカウント・課金は不要。ただし利用意向、正確さ、優位性、継続率、収益性はいずれも未検証です。

## 実装仕様

- 横幅3〜40m / 縦3〜30mの矩形フロア。複数APは各案最大5台、壁50本、優先エリア20件。
- 1m自由空間損失を起点とした対数距離損失（距離減衰指数2.7、距離下限1m）と、見通し線が壁を横切る場合の一律材質損失を合算。複数APは受信強度が最大の1台のみ評価。
- 設定したしきい値を超えた格子点の割合を床面達成率とする。部屋の達成率は室内25点で判定し、`面積 × 優先度` で重み付き平均。移設案とのポイント差を表示。
- 石膏5dB、コンクリート15dBなどは**教材用の仮定**。実住宅・周波数別の透過損失を忠実に再現しません。反射・回折・マルチパス、天井・階層、干渉、チャネル混雑、速度、機種別送信出力、端末感度、ビームフォーミングを除外。各AP電力の入力は概算値であり法定出力・安全性を保証しません。比較結果を通信品質保証や工事判断に使わないでください。

## テスト結果（2026-11-20）

`node --test engine.test.cjs` → **28/28 合格**。壁交差・減衰方向・帯域差・重み付き達成率・JSON構造検査等。ランダム500回の壁減衰性質試験、300回のAP追加単調性試験を含む。

`python browser_test.py` → Chromiumで **30/30 合格**。壁/エリアの作成・編集・削除、AP配置、各帯域・寸法の更新、JSON読込、JSON/CSV/SVGダウンロード、モバイル表示、JS例外なし等を確認。

**環境制限**：この実行のChromiumは `file://` URL遷移を管理ポリシーで拒否したため、同一HTML・CSS・JSを**インライン読み込み**して操作検証。`localStorage` はメモリで模擬した呼出確認のみで、通常ブラウザでの直接起動・永続化・印刷実機・無線実測との精度比較は**未検証**。`desktop.png` / `mobile.png` はテスト環境のスクリーンショット。
