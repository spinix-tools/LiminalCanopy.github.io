# 綜絖割 / SOKOWARI
2026-11-25制作。手織り愛好者・染織教室向け。手持ちの綜絖枚数に合わせ、組織図の変更交点数を厳密に最小化する。`index.html` を開けばオフラインで動作。

## 実装と制限
2〜32段×2〜32本、異なる経糸列は12種類まで、綜絖1〜12枚。各列を上昇パターンとして同一列を集約し、重み付き多数決で各部分集合の最小変更数を計算。部分集合分割DPで最大指定枚数の全分割を比較し、同点なら少ない枚数を選ぶ。同一列を分割しても最良の代表列に集約し直せるので最適値は失われない。交点数のみを目的とする。差分表示・綜絖通し・上昇表・CSV・印刷。上昇式の独立操作モデルであり、踏木数・浮き糸・織りの品質・実機適合は保証しない。
