# 版ずれラボ / BANZURE LAB 🖨️

**画像１枚から２色のリソグラフ風版下を作り、見当ずれの見え方と版の重なりを比較する日本語Webアプリ。** 静的HTML + JavaScriptのみ。アカウント、外部通信、依存ライブラリ、API課金なし。

## 対象と選定理由（2026-11-20調査）

- **対象**: ZINE・小部数ポスターの個人制作者、美術学校の学生、小規模RISO印刷工房の入門者。
- **日本市場の周辺需要**: 東京・蔵前の[RISO ART STUDIO @ ONTEN](https://risoart.onten.jp/) は2026-08-27付のZINE制作告知を掲載し、2024-07-26にはオンライン印刷の開始を案内。東京の[Hand Saw Press](https://handsawpresstokyo.com/workshop.html) もリソ印刷・ZINEのワークショップを継続案内。印刷文化・サービスが存在する証拠であり、需要量や課金意欲の測定ではない。
- **海外の周辺需要**: [The Guardian（2026-04-07）](https://www.theguardian.com/artanddesign/2026/apr/07/nifty-japanese-printing-gadget-risograph-riso-club-gabriella-marcella) は国際的なRISO制作者コミュニティと展示活動を報じた。市場規模の数字ではない。
- **国内の競合・代替**: ONTENなどの印刷所が入稿手順・確認を案内。Adobe Photoshop / Illustratorなどでの手動分版は高機能な代替手段。
- **海外の直接競合**: [Fuser two-color](https://fuser.studio/tools/risograph-two-color) は2色変換・濃度・ノイズ・見当ずれ操作にすでに対応。[hafacc/color-separation](https://github.com/hafacc/color-separation) は選択インクへのグレースケール分版を提供。[Super Collage](https://supercollage.art/) も印刷色別の版書き出しに対応。**二色化や版ずれの機能自体は新規ではない。**

**差別化仮説**: 写真から作業を始める日本語の印刷初心者に、(1) 簡易光学濃度モデルによる分版、(2) 版ごとの平均濃度と重なりの数値診断、(3) 見当ずれをさせない白黒版PNGの同時書き出し、(4) 画像込みの端末内プロジェクト保存を、迷いにくい4ステップに統合すると手戻りが減る。**競合との差別化の実効性、利用意思、収益性は未検証。**

## 操作可能なMVP

1. **PNG/JPEG/WebP入力**（25MB以下）または内蔵サンプル。画像を外部送信しない。
2. ７色パレットから２インク選択。総濃度・各版の強度・出力解像度を変更。
3. 原稿と分版後の合成、版１、版２、版の重なりを切替表示。版２の見当ずれを水平・垂直に調整（プレビューだけ）。
4. **各版のグレースケールPNG**、見本の合成PNG、画像を含むJSONプロジェクトのエクスポート／復元。
5. 版の平均濃度・加重重なり率・元原稿との平均RGB差を算出。設定はブラウザのlocalStorageにも保存。

## 計算と制約

インクのRGBを光学濃度 `-ln(c/255)` に近似変換し、元画像の光学濃度に近い２版の非負係数（各0～1）を求め、RGB各成分の透過率の積で合成する。**インク吸収スペクトル、紙色、蛍光、網点形成、印刷機の位置ずれ精度は模擬していない。** グレースケール出力は印刷所によって入稿要件（実寸、解像度、色調、面付け、塗り足し、網点）が異なり、そのまま印刷に利用できるとは限らない。重なり率は出力２マスクの加重積の平均。平均RGB差は標準0～255の概算値であり色差ΔEではない。

## テスト（2026-11-20）

- `node --test engine.test.cjs` → **13/13件合格**。白の無インク、単色復元、同色インク、オフセット、グレー版、透過・不正サイズ、決定性、**乱数300条件**を検証。
- `python browser_test.py` → **Chromium 18項目合格**。色・濃度・版ずれ・表示切替・3種類のPNGダウンロード・JSON保存/復元・ローカル画像入力・モバイル横スクロール・エラーなし・画像キャプチャ。検査用デスクトップ・モバイルPNGも同梱。
- 管理環境で `file://` ナビゲーションが拒否されたため、ブラウザ試験では**同一HTMLとengine.jsをインライン展開して表示**。実際のローカルファイル直接起動・保存設定のブラウザ再起動後永続性・印刷所の出力精度は未検証。

## 実行方法

ダウンロードしたZIPを解凍し、同一フォルダの `index.html` を通常のブラウザで開く。`engine.js` が同じフォルダに必要。外部依存なし。Node.jsがあれば `node --test engine.test.cjs` で検証できる。ブラウザE2EにはPlaywright、PillowとChromiumが必要。
