# MatRelay / 額装共通窓ラボ

2026-11-27 MVP。`index.html` をブラウザで開く。依存ライブラリ・サーバー・登録・外部通信なし。作品名には匿名の管理番号を推奨。

## ターゲットと選定理由
写真展・版画展の企画者、ギャラリー、額装工房。作品交換時に共通のマットを再利用したいが、署名や絵柄を覆わずに用紙端を隠せるかが課題。国内の任意窓寸・偏心窓の販売と海外の寸法計算サービスを需要の間接証拠とした。市場規模や支払意思は未確認。

- 日本：額縁のタカハシ https://www.gakubuti.net/product/mat （任意寸法・偏心窓・シミュレーター）／アトリエフォロン https://www.folon.jp/item/額装用マット/ （重ね代・マット幅の案内）
- 海外：FramingMath https://framingmath.com/mat-opening-calculator/ （窓と重ね代の計算）／Dorkroom https://dorkroom.art/docs/dorkroom-tools/mat-calculator （窓とカッター設定）
- 差別化仮説：一作品の寸法計算ではなく、最大50作品×50窓を共通規格として比較。保護矩形・最低重ね代・施工位置ずれを同時に保証する整数mm配置域を算出。適合作品数を最大化し、同数では面積を最小化する（狭い窓を優先する独自の方針で、審美上の最適性ではない）。

## 使い方・計算
外寸、重ね代、貼付ずれ、マット幅、下辺追加幅、窓候補、作品寸法と保護矩形を入力し比較する。各候補の適合数、作品ごとの左上位置と許容域、図を確認。JSON・印刷に対応。窓は固定、作品は平行移動のみ。各軸で用紙がボード内に収まる、窓の両端を覆う、保護範囲が窓内に残る、という三条件を±tの両端で交差させ、整数区間に変換する。候補の全比較は O(作品数×候補数)（順位整列を除く）。

## テスト結果
- `node test.cjs`：独立の整数全列挙との比較3000件、固定5アサーション合格。サンプルは200×280mmが3/4作品で首位（190×270と210×290は2/4、180×260は0/4）。
- `python browser_test.py`：Chromiumで選択・再計算・入力エラー・初期化・JSON実ダウンロード・390px幅・JS例外0・外部HTTP要求0を確認。環境のfile URL制限のため同一HTMLをインライン読み込み。
- 実物の額装、印刷、ベベル、固定方法、保存性、窓自体の寸法誤差、回転、非矩形、収益性は未検証。施工保証ではない。
- 重複確認：直近の会話の制作履歴、mainとの差分300ファイル（51アプリディレクトリ）、関連コミット検索5語で明確な重複なし。全ソースの網羅照合は未実施。
