# 折丁譜 / ORICHOFU

糸かがり製本・ZINE・小部数の作品集向け。見開きや図版を折丁の境界で分断したくない制作者を想定した、本文の折丁割りと面付け指示のブラウザツールです。index.html を開くだけで利用可能。入力は端末内で処理し、通信・課金・アカウントは不要です。

## 選定理由・競合（2026-11-25 調査）
- 国内：手紙社の製本ワークショップは2026年3月31日の記事時点で約80回・延べ約800人参加。https://tegamisha.com/news/kamibungu202604/
- 海外：米 Center for Book Arts は2026年11月10日〜12月8日の小部数上製本講座を掲載。https://shop.centerforbookarts.org/products/26fbb300i
- 競合：国内の小冊子メーカー（SignaPrint）は固定折丁・両方向・PDF面付けに対応。https://apps.apple.com/jp/app/id6794354522 ／ 海外 Book Signature Lab は面付け・折丁計画を提供。https://nrtechstudio.com/tools/book-signature-lab/ ／ 折丁のコレーション計画も既存。https://supreminders.com/woodworking/bookbinding-sewn-signature-collation-planner
- 差別化仮説：PDF処理ではなく、守りたい見開きの指定から可変長の折丁境界を逆算。禁止境界を厳守し、回避重み→折丁数→基準サイズとの差の順に最小化する。市場規模・購買意向・実製本での改善は未検証。
- 過去案：直近の履歴、main と専用ブランチの差分300ファイル、製本・折丁・bookbinding・signature・面付けのコミット検索を確認。該当なし。ただし全既存アプリとの完全照合ではない。

## 利用・計算
1〜1200ページ、許可折丁4〜64ページ（4の倍数）、禁止境界、回避境界と重み、基準サイズ、綴じ方向を指定。末尾だけ白紙追加。動的計画法で厳密に最適化し、制約なし比較案・ページ範囲・面付け指示を表示。CSV・印刷対応。48ページ例では 16+16+16 から 12+12+16+8 へ変更し、禁止境界2→0、折丁3→4、白紙0。
