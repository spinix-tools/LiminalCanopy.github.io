# 目地割 / MEJIWARI
2026-11-24 — DIY・小規模リフォームの直交タイル割付を、実測寸法のばらつきに対して比較するローカルWeb MVP。`index.html` をブラウザで開く。登録・外部API・有料サービスなし。

## ターゲット・選定理由
DIY施工者、タイル販売店の相談担当、小規模リフォーム業者。壁の上下などの幅が異なると、中央寸法だけで決めた割付の端が細くなることがある。国内ではLIXILが割付の目的・手順を解説（2025-10-07）。日本DIY・ホームセンター協会の2025年調査は26社で売上2兆6719億円。米国ではTCNAの2025年陶磁器タイル消費量は25.7億平方フィート、前年比4.9%減（2026-03-31公表）。これらは関連市場の指標であり、アプリ需要・課金意欲を示さない。

## 競合・差別化仮説
日本語対応のTileFitは割付図・カットリスト・購入数。海外のTilePlan、SetoutLab、Layometryは割付・端部・材料計算等を提供し、Layometryは不均一な壁にも対応。今回の仮説は、同じ基準辺からの最小〜最大実測寸法を入力し、固定した格子の全整数mm条件を検査して、許容片幅を満たす条件数、目地終端でない条件数、最悪端部幅の順に最大化すること。競合に同等機能がないとは断定しない。初期案の木材切断・布裁断とは異なる。既存apps一覧と関連8件のREADMEを確認（全件ソース照合は未実施）。

## 機能・制限
タイル縦横20–1200mm、目地0–20mm、各方向寸法差200mm以内。外周の施工指定クリアランスを除いた有効寸法を入力。全基準端幅1mm刻みを探索。名目中央寸法の最小片幅を最大化し左右差を小さくする案と比較。SVG図、寸法別判定・CSV、縦横交換、印刷、端末保存（利用可能時）。終端が目地内または目地末端なら不適合。連続値・斜め張り・開口・実際の曲がりや下地・接着剤・目地材・切断再利用・購入枚数は対象外。施工保証ではない。サンプル横方向の最悪幅は中央寄せ146mm→最適151mm、縦173→177mm。

## テスト
`node test.cjs`：固定6、独立逐次配置との比較2000、独立全探索との比較300、全合格。`python browser_test.py`：Chromiumで初期描画、案切替、CSV内容、縦横交換、模擬保存復元、不正入力、リセット、390px幅、JS例外・外部HTTPゼロを確認。環境のfile://制限により同一HTMLをインライン実行、保存はメモリ模擬。実ブラウザの永続保存・実施工・印刷実機・有料需要は未検証。
