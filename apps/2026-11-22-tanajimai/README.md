# 棚じまい / TANAJIMAI

**委託品の棚卸しと精算前の照合に特化した、無料・登録不要・オフラインの静的Webアプリ**。2026-11-22制作。対象：ZINE・雑貨の委託販売を短期間で行う小規模書店、展示会、ポップアップ主催者、ハンドメイド委託店。委託元には本名でなく任意の呼称を使えます。

## 選定理由・需要と競合（2026-11-22確認）

- **日本の実例:** 大阪の「ええもんみっけてなぁ！ 秋のハンドメイド市」は2026-10-29〜11-02に「委託販売」で開催され、作品10点・30点の区分を公表。終了時の受領・売上・返却の照合が発生しうる具体的な市場例だが、本アプリの需要規模は示さない。 [イベント主催者の掲載](https://mamanoyume.net/marche/detail/80)
- **国内の比較対象:** [委託販売ノート（App Store）](https://apps.apple.com/jp/app/%E5%A7%94%E8%A8%97%E8%B2%A9%E5%A3%B2%E3%83%8E%E3%83%BC%E3%83%88/id6800209010) は残数からの売上推計と精算管理。[おあずかり（App Store）](https://apps.apple.com/jp/app/%E3%81%8A%E3%81%82%E3%81%9A%E3%81%8B%E3%82%8A-%E5%A7%94%E8%A8%97%E8%B2%A9%E5%A3%B2%E3%81%AE%E6%98%8E%E7%B4%B0%E6%9B%B8-%E4%BD%9C%E5%93%81%E3%82%84%E9%AA%A8%E8%91%A3%E3%81%AE%E9%A0%90%E3%81%8B%E3%82%8A%E5%8F%B0%E5%B8%B3%E3%81%A8%E7%B2%BE%E7%AE%97/id6794990152) は入庫・販売・精算、オフライン運用に対応。一般的な在庫・精算管理は既に競合がある。
- **海外の比較対象:** [ConsignCloud](https://consigncloud.com/) は委託者別在庫・POS・支払・レポートを、[SimpleConsign](https://www.simpleconsign.com/) は委託品登録・精算・会計連携を提供。いずれも当アプリより総合機能が多い。
- **差別化仮説:** 店舗運営全体や実際の支払を管理せず、終了時の「納品 − 販売 − 返却 − 破損 − 保管 = 0」を品目ごとに独立照合し、未照合品が1つでもある委託元を**精算保留**として表示。販売数を現物から逆算する操作は明示的確認後にのみ反映。短期イベント終了時の監査・引き渡し用途に絞った日本語Web版。競合の優位性やヒット確率の確証はなく、ユーザーインタビューと実業務での検証が必要。

## 実装機能

- 商品の追加・変更・削除、委託元・SKU・単価・歩率・数量（納品、販売、返却、破損、保管）の編集。上限120品目。
- 品目別に数量差、不正入力、売上、手数料（1円未満切捨）、受取予定額を計算。委託元を個別集計し、差異がある委託元のみ「要照合・保留」。
- 現物数量から販売数候補を逆算し、確認ダイアログを経て反映。勝手に販売実績を補完しない。
- CSV明細・CSV精算候補、JSONバックアップ・復元、端末内自動保存、印刷、デモデータ、モバイル用レイアウト。API・ログイン・クッキー送信・解析SDK・新規課金なし。

## 起動・操作

`index.html` を同じディレクトリの `style.css`、`engine.js`、`app.js` と一緒に開くか、配布ZIP内の **`standalone.html`** を開く。サーバー不要。デモには意図的な1品目の差異があり、保留の動作を確認できる。販売数は実際の売上記録と突合し、返却・破損・保管は実物に基づいて入力する。「差異0」は証拠の正しさを保証しない。ブラウザ保存は削除される場合があるので、随時JSONを書き出す。

- **検証範囲の制限:** 実行環境は `http://localhost` が管理者により遮断されたため、テストでは**本配布の4ソースを内容変更せずインライン埋込み**してブラウザ操作しました。`localStorage` は `about:blank` の制限により模擬実装で永続性を確認。一般のブラウザでの `file://` 直接起動、実機間の永続保持、実売上・税務書類との整合は未検証。

## 前提・非対象

整数円建て。原則、行単位の販売金額 × 手数料率を1円未満切捨、税・内税/外税・割引・送料・振込手数料・返品返金・複合契約・非円通貨を扱わない。精算候補は**実際の送金・支払・会計確定ではない**。入力した委託元呼称・商品の情報は当該ブラウザ内のみで処理（ユーザーが明示してファイルに書き出す場合を除く）。名前、連絡先、決済情報の収集は求めない。著作権はMIT License。
