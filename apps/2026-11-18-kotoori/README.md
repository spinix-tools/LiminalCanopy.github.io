# こと折 / KOTOORI — A4一枚の8ページ折本スタジオ

**制作日:** 2026-11-18 / **対象:** 日本語で短文・詩・日記・ZINEを作りたい個人、文学フリマや学校工作の参加者。海外のzine作家にも横書きで対応。

## 選定理由・市場観察

- **日本:** 2026年11月8日開催の文学フリマ東京43の来場者は約19,641人と報道（11月12日記事）。2025年10月のZINEフェス東京は出展申込500組超を告知。小部数自主出版の創作機会が確認できる。ただしイベント動員数は本アプリへの需要の実証ではない。
- **海外:** 2026年11月7日のLA Zine Festは出展355枠に対して応募600超と報道。2026年9月のSF Zine Festも210超の出展者を案内。潜在利用者層は存在するが、有料転換は未検証。
- **競合:** 国内の「折本制作支援ツール orie」は画像・テキストの8/16p面付けに対応し、ZINE-KENはブラウザ編集と印刷案内を提供。海外のsnipzine / Dirty Little Zine / Foldpicも8p面付け、写真、PDFなどを提供する。ゆえに「オフライン」や「面付け」自体は独自機能ではない。

**差別化仮説:** 日本語の「縦書きの本文・見出し」から「読み順の編集→実際の折り位置を考慮した面付け→文字はみ出し警告→A4原寸印刷」まで、初学者が一画面で完結できること。写真を混在させる際もローカルで縮小し、JSONで端末間の移動ができる。現時点で優位性・市場適合を証明するものではない。

## できること

- 8ページそれぞれの見出し・本文を編集、読み順と面付けを切り替え
- 縦書き / 横書き、文字サイズ、紙色、折り・切れ目ガイド
- 各ページの背景写真（PNG/JPEG/WebP、最大12MB、長辺900pxにブラウザ内で縮小）
- 文字のDOM表示領域に基づく「はみ出し可能性」警告
- 印刷用面付けをA4横・片面で印刷（上段7,6,5,4は180°回転、下段8,1,2,3）
- ブラウザ内自動保存、JSON書出し・読み込み、空の新規作成、見本の復元

## 起動 / 操作

サーバー・ビルド・APIキー不要。`index.html`を同じフォルダの`engine.js`、`app.js`と一緒に開く。8ページを読み順で編集したら「面付けプレビュー」に戻し、「A4印刷」を押す。プリンタ設定は**A4、横、片面、倍率100%、余白なし、背景グラフィックON**を推奨。印刷後、8区画を折り、**中央の横線の真ん中2区画の境界だけ**に切れ目を入れ、両端を押して一冊に折る。試し刷りで実際の向き・印字領域を必ず確認すること。

## 検証（この実行）

- `node --test engine.test.cjs` : **13/13 合格**。面付け8マスの全対応、入力形式とサニタイズ、保存復元、文字計数、文字サイズ境界など。
- `python browser_test.py` : **38/38 合格**。システムChromiumの実DOMを操作し、編集・選択・設定変更・JSON入出力・画像追加削除・文字はみ出し・印刷CSS・モバイルを検証。デスクトップ、モバイル画面を同梱。
- 環境のローカルHTTPナビゲーションが管理ポリシーにより遮断されたため、ブラウザ試験ではHTML/CSS/JavaScriptをChromium DOMへ直接配置し、localStorageだけを模擬した。**実配信・OS間の印刷再現性・実機プリント・ストレージ永続化は未検証**。文字はみ出しは警告であり、すべてのフォント・プリンタでの防止保証ではない。

## プライバシーと制限

外部API・認証・広告・計測・有料サービスを使用しない。作品データは端末に留まる。取り込む写真はダウンロードするJSONに埋め込まれるので、JSONの共有先には注意。端末の保存容量が不足すると自動保存できない場合があり、その際は画面にメッセージを表示する。PDFの直接生成ではなくブラウザの**印刷→PDFに保存**を利用する。見開きイラストの自動分割、16ページ折本、プリンタ非印字領域に応じた個別補正は未対応。
