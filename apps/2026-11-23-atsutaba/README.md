# 厚束 / ATSUTABA — 平物の積層梱包・封筒比較

2026-11-23 開発。フリマ・小規模ハンドメイド出品者向け、**複数品目を一緒に封筒発送するときの寸法・厚さ・重量・仮料金を事前比較**する、通信不要のWebアプリです。

## 市場と競合（調査日：2026-11-23）

日本の2024年CtoC-EC市場は **2兆5,269億円**（経済産業省、2025-08-26発表）。海外Etsyマーケットプレイスは2025年末で**560万のアクティブセラー**（2026-02-19付年次報告）。これらは近接市場の規模であり、本サービスへの有料需要を示すものではありません。

- 日本：[MercaFee](https://www.mercafee.com/) は発送方法・梱包コスト・送料を比較。[MerCalc](https://apps.apple.com/jp/app/id1241372281) も送料・利益計算に対応。
- 海外：[Looty Tools](https://lootytools.com/tools/poly-mailer-size-calculator) は袋と厚さの回り込みを検算。[Etsy Calculated Shipping](https://help.etsy.com/hc/en-us/articles/115013946647-How-to-Set-Up-Calculated-Shipping) は包装設定から配送条件を推定。

**差別化仮説**：複数種類・複数量の「平たい品物」を重ね、品物ごとに90°回転して袋に収める条件を試算し、厚み＋1mm時の最安候補の変化まで確認できれば、発送前の試行錯誤を減らせる。競合との重複はあり、利用需要・収益性は未実証。

## 実装

品目の追加・編集・複製・削除、最大40品目／30配送候補、緩衝材の厚さと重量、封筒の幅・長さ・厚み上限・重量上限、仮料金による適合判定、SVG重なり図、＋1mm感度分析、JSON入出力、CSV、端末内保存、印刷を実装。外部API、位置情報、購入者の氏名・住所、課金処理は使いません。

**計算モデル**：総厚＝Σ(厚×個数)＋緩衝材、総重＝Σ(重×個数)＋資材。袋の有効幅＝袋幅−2×回込み係数×総厚−側面余白。有効長＝袋長−回込み係数×総厚−封口余白。各品目は2方向のいずれかで収まること、総厚・総重が上限内であることを同時検査します。これは**平積みが可能な柔らかい平物向けの概算**で、厚み圧縮・縫い目・硬物・防水・破損、配送会社の実際の規約を保証しません。

**料金・上限の初期値はすべて架空のデモ値**です。必ず実寸と最新の配送事業者規約に置き換えてください。

## 起動・復元

ブラウザで `index.html` を開きます。完全版HTMLは `payload.js` にgzipでロスレス格納しており、対応ブラウザで自動展開。Python 3があれば `python3 unpack.py` で `standalone.html` に復元できます。可読な分割ソースとテストコードはこの実行のZIP成果物内に入っています。

## 検証

- Node.js単体テスト **20/20合格**。うち独立した全90°方向列挙とランダム **3,000件** を照合。
- Chromium 144／Playwright ブラウザ操作 **25/25合格**：品目、候補、緩衝材の編集、SVG、JSON／CSV、再計算、リセット。外部HTTP要求とJS例外は0件。
- **制約**：管理ブラウザは `file://` 遷移を禁止しているため、操作試験は**同じフル版ソースをインライン実行**。実機での保存継続、印刷、袋への物理的封入、実送料との一致は未検証。GitHubから直接のページ公開も未検証。
