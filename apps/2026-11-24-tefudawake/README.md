# 手札分け / TEFUDAWAKE
2026-11-24制作。TCGプレイヤー・カードゲーム設計者向けの、兼任カードを含む初手成立率比較。`index.html` をブラウザで開く。ビルド、登録、通信、API課金なし。

## 選定理由・競合（2026-11-24確認）
- 日本：[矢野経済研究所（2025-12-23）](https://www.yano.co.jp/press-release/show/press_id/3946) は2023年度TCG国内出荷額が前年比26.1%増、アナログゲーム市場の89.9%と報告。[PokeDeckLab](https://poke-deck-lab.com/) は初動のモンテカルロ分析、[ポケカタイムズ](https://pokecatimes.jp/probability-calculator/) は複数コンボ等の厳密計算を提供。
- 海外：[ICv2（2026-04-03）](https://icv2.com/articles/markets/view/62035/big-growth-hobby-games-2025) は2025年の米加ホビーゲーム市場全体を36.6億ドル、前年比40%増と推計。[Deck Optimize](https://deckoptimize.com/) は複数グループ条件と採用枚数感度を提供。[TradeMatches](https://tradematches.app/en/tools/opening-hand-probability) は超幾何分布で対象カードのドロー確率を計算。
- 差別化仮説：兼任できるカードの同時使用可否を別々に計算し、その差を示す。固定分類を守った1枚交換の全候補を順位付けし、即適用・取消できる。確率計算自体は既存機能。調査範囲での仮説であり独占性、直接需要、収益性は未検証。次はプレイヤー5人で入力負担と交換案の実用性を確認する。
- 専用ブランチの apps 一覧、会話履歴、関連5件のREADMEを確認。袖割はスリーブ購入であり用途が異なる。全既存ソースの精査は未実施。

## 使用方法と計算
A/B/Cの3役割の組合せ8分類にカードを重複なく割り振る。合計1〜100枚、ドロー1〜12枚、各役割の必要数0〜3。兼任可は同じカードが複数役割を満たせる。専任は1枚1役に限定し、7つの非空役割部分集合の必要数と対応可能カード数を比較する（Hallの定理）。分類ごとの引き枚数の組合せを多変量超幾何分布で重み付け集計。C(100,12)以下の整数なのでJSの安全整数範囲内。百分率は小数2桁表示。ロック分類の増減は禁止。最大56交換、改善上位8案、全候補CSV、適用/Undo、サンプル。再読込で入力は消える。

## 検証
`node test.cjs`：固定6件、独立した個別カード組合せ列挙・割当バックトラックとの照合400件、交換順位の照合30件、全合格。`python browser_test.py`：Chromiumで初期表示、適用、Undo、ロック、目的変更、CSV、無効入力、リセット、390px幅を確認。JS例外・外部HTTP要求0件。file URLが管理環境で遮断されたためインライン実行。実対戦、各ゲームの採用制限、マリガン、サーチ、カードコスト、妨害、勝率は対象外。サンプルは架空の60枚デッキで専任60.67%→65.37%、兼任可65.83%（交換前）。
