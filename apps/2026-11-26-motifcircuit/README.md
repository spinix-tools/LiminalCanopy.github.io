# 柄環 / MotifCircuit
2026-11-26 | 裁断前の横縞・周期柄の合印整合性検査

## 対象・選定理由
洋裁愛好家、洋裁教室、小規模縫製工房。日本のラ・スーラ（2026-10-30）は柄合わせに関する利用者の質問と裁断前の準備を紹介し、心あがるソーイングは脇線・袖の合印での柄合わせを解説する。海外には柄合わせ用尺計算・配置ツールがある。これは課題の存在を示す傍証であり、市場規模、実需要、有料転換率は未検証。

## 競合・差別化仮説
- 日本: [ラ・スーラ](https://la-suila.jp/apps/note/archives/12193)、[心あがるソーイング](https://shichibusode.com/how-to-match-patterns/) は手順を解説（直接のアプリ競合ではない）。
- 海外: [SewCalcs](https://sewcalcs.uk/fabric-and-yardage/pattern-matching-calculator/) は柄合わせ用の追加用尺を概算。[PatternNest](https://madegrain.com/patternnest/) は型紙配置と柄基準点の指定。[Workroom Tools](https://workroomtools.com/fabric-pattern-matching-planner/) はカーテンの柄合わせ・継ぎ目確認。
- 仮説: 用尺・配置計算の前に、複数の合印の制約が**数学的に同時成立するか**を判定し、矛盾の閉路と1件解除での解消候補を提示する独立した検査に価値がある。既存ツールで十分、または入力負担が裁断ミスの削減を上回るなら仮説を撤回する。競合調査は公開機能説明の範囲（2026-11-26確認）。

## 起動・機能
`index.html` を現代的ブラウザで開く。登録・ビルド不要。初期例は矛盾あり。「成立例」や解除候補を押すと比較できる。周期1〜10000mm（整数）、40パーツ、100合印、40固定条件まで。パーツ基準点の位相 x と合印オフセット a の和が周期 R で一致する条件をグラフで検査。探索木で位相を伝播し全辺を照合するため、このモデル内の成立判定は厳密。固定なしの連結成分は相対位相。矛盾を構成する条件ID、各合印の最短周期差、全ての単一合印解除候補、位相図、JSON出力、印刷。固定条件は解除候補に含めない。解除時に合印IDは再採番される。

## 限界・費用
同一方向・1軸・整数mmの周期柄のみ。布の伸び、反転、曲線、縫い代、柄の対称性、布幅、用尺、裁断の物理的実現可能性は対象外。不一致数は仮位相での数で最小違反数ではない。解除候補は数学的条件の除外であり縫い目の省略を勧めるものではない。画像・秘密情報・個人情報の入力要求、外部送信、永続保存、追加API課金、有料サービスなし。
