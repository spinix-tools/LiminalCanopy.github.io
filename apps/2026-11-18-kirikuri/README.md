# きりくり / KIRIKURI — 長尺材の端材優先・切断計画 MVP

**制作日:** 2026-11-18（JST） / **分野:** DIY・小規模製作 / **公開形態:** MIT License、外部通信なし、登録不要。

## 誰のためのアプリか／選定理由

DIY愛好家、小規模木工工房、学校の工作室・地域工房が対象。棚柱・横桟など同一断面・同一材質の木材、パイプ、棒材を切り出す前に、倉庫の端材を使えるか、規格材を何本買うかを見積もる。日本の2025年7月のホームセンター販売額は3,006億円、そのうちDIY用具・素材が684億円（前年同月比1.8%増、経産省速報の紹介）。**DIY関連の支出が存在する根拠ではあるが、カット最適化アプリの市場規模を示すものではない。**

## 日本・海外の競合と仮説（2026-11-18に公開情報を確認）

- **国内：** [Cutting Planner](https://tubakurosoft.com/) は長尺材1D・板材2Dの材料取りを支援するWindowsソフト。[CutPlan（App Store）](https://apps.apple.com/jp/app/cutplan-%E6%9D%BF%E5%8F%96%E3%82%8A%E6%9C%80%E9%81%A9%E5%8C%96-%E6%9C%A8%E5%8F%96%E3%82%8A%E5%9B%B3/id6792293888) も刃幅・板取り・端材を扱う。
- **海外：** [CutWize](https://cutwize.com/) は長尺・板・ロールと端材台帳に対応。[Cutlist Evolution](https://cutlistevo.com/free-cutlist-optimizer) は無料ブラウザ版で刃幅・トリム・端材の再利用を提供。[Linear Cutting](https://linearcutting.com/) も無料の長尺材割付と端材管理に対応する。
- **差別化仮説：** 既存競合にも高機能な最適化・端材管理がある。「世界初」ではない。本MVPは **端材を使う／使わない場合の購入費差額を並べ、実際の切断位置・残材の残り方を見せ、作業終了時に次案件の端材へ引き継ぐ** という小規模現場の意思決定に絞る。日本語、mm・円、無登録・オフライン、ローカルで完結する点を試す。定量的な顧客需要と競争優位性は未検証。

市場資料: [流通ニュース／経産省のホームセンター2025年7月速報（2025-08-29）](https://www.ryutsuu.biz/sales/r20250829007.html)。競合機能は上記公式ページの記載から把握し、料金・仕様は変更される可能性がある。

## MVPでできること

1. 部品名・長さ(mm)・数量、手持ち端材の本数、購入可能な定尺材と単価を編集。サンプル入力ですぐ体験できる。
2. **刃幅（部品1個につき1回）＋両端落とし（母材1本につき両端各1回）** を控除して、1D切断計画を計算。4種類の並び替え×4種類の選択基準を比較する近似探索。
3. 材料ごとの切り順、部品別の切断位置、残り長・再利用対象/廃棄相当を可視化。部品数・刃幅・材料長・費用の整合性を独立チェック。
4. 端材を使う計画と、購入材だけで切る計画の購入費を比較。端材が有利でない場合は購入のみの計画を選ぶことがある。
5. 部品CSV取込、切断指示CSV・残材CSV・設定JSON出力、設定JSON読込、明示操作によるブラウザ保存、印刷/PDF、残材から次案件への引継ぎ。

**使い方:** ダウンロード後 `index.html` をブラウザで開く。Node・APIキー・ビルド・外部サービスは不要。`python3 -m http.server 8000` でも利用可能。CSV取込は `品名,長さ,数量` の3列。ファイルは端末内で処理し、設定の保存は「この端末に保存」押下時だけ行う（ブラウザの localStorage）。

## テスト結果

- `node --test engine.test.cjs`: **37件すべて合格**。入力検証、数量・刃幅・端落とし・長さ保存、購入費、残材、CSV引用符・数式インジェクション対策、45件の疑似乱数案件の不変条件を検査。
- `python browser_test.py`: **36件すべて合格**（Chromium）。入力・計算・編集・CSV/JSONの実ダウンロード/インポート、保存API呼出、端材引継ぎ、エラー表示、レスポンシブ表示、JS例外なしを検査。画面画像は `desktop.png` と `mobile.png`。
- **試験上の制約:** 実行環境ではブラウザからローカルHTTP/ファイルURLへの遷移が管理者設定で遮断されたため、HTMLと本物の `engine.js`/`app.js` をChromiumへ直接読み込んだ。**localStorageのみモック**で保存・復元を検査。実ホスティングと実端末での保存継続性は未検証。

## 制約・安全

- 対応は**同一断面・同材質の直線的な長尺材の1D割付のみ**。合板2D、材質混合、斜めカット、木目・節・欠損・クランプ・材長公差、のこぎりごとの具体的な施工方法は対象外。
- すべての部品に刃幅分を1回ずつ確保する安全側の単純モデル。実際の切断順・施工安全・寸法取りは作業者が必ず確認すること。切断位置は母材の前端からの概算(mm)で、物理的なマーク位置を保証しない。
- 最適化は**近似解**であり最小費用・最小廃棄量の証明はできない。購入費差額は入力単価に基づく参考値で、労務費・送料・持ち帰り・材料品質は含まない。「廃棄相当」に刃幅と端落としを含める。
- 計画の「次案件引継ぎ」は**実際に切断したことを検知しない**。作業済みの場合だけ操作する。実在庫の自動更新や複数端末同期はない。
- 外部APIアクセス、外部ライブラリ、有料サービス、課金、アカウント、秘密情報・個人情報の外部収集は一切なし。
