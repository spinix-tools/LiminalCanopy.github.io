# 源流ノート / GENRYU NOTE

**引用数と独立した根拠の数を混同しない、ローカル完結の出典系譜ノート。**

- 制作日: 2026-11-17 (JST)
- 主な対象: 日本語で資料を調べる学生・編集者・ライター・ファクトチェックを学ぶ人
- 形式: HTML + JavaScript の静的Webアプリ。サーバー・ログイン・外部API・課金・分析SDK不要。

## 選定理由と市場・競合の確認

日本では[日本ファクトチェックセンターと電通総研の2026年4月の情報インテグリティ調査](https://www.factcheckcenter.jp/explainer/others/info-integrity-2026-1/)が、情報検証の実践に課題が残ることを報告。2025年の[総務省ICTリテラシー調査の報道](https://internet.watch.impress.co.jp/docs/news/2013682.html)でも誤情報の拡散経験が指摘されている。これは情報確認への社会的ニーズの傍証であり、本アプリの顧客需要や収益性を証明するものではない。

海外の隣接競合として[Source.io](https://identity.source.io/portal)は版・記録を固定した出典チェーンと共有ボードを提供。[Full Fact AI](https://fullfact.org/ai/)はファクトチェック担当者向けの主張抽出・監視を提供。[sourcecheck](https://github.com/aberaio/sourcecheck)は研究引用の検証を支援する。独立資料の自動判定や引用系譜の整理は既存領域であり、機能そのものが新発明という意味ではない。

**差別化仮説:** 日本語・会員登録なし・外部送信なしで、短時間で「原資料の一致」「独立起点として仮置きした数」「支持／反証の混在」「出所不明」を同じ画面に示し、透明なMarkdown点検メモとして書き出せる。実利用者による需要検証・比較評価は未実施。

## 実装済み機能

1. 複数論点の新規作成・編集・削除、検証段階・注記の管理
2. 資料名、URL、支持／反証／参考、原資料／引用・転載／出所不明、メモの登録・編集・削除
3. 直接引用元を指定し、引用を何段かさかのぼって同一の起点へ集約。循環や別論点への不正リンクを拒否
4. 原資料としてユーザーが登録した独立起点を**1系統1件**として集計。1系統に支持と反証が共存すれば「混在」に分類。出所不明の系統は独立件数に含めない
5. 架空のデモデータ、JSONバックアップ／復元、Markdownレポート／コピー、ブラウザ内の自動保存
6. モバイル対応、文字列をHTMLとして評価しないDOM構築、URLのhttp/https制限

## 利用方法

`index.html`を`engine.js`と`app.js`と同じディレクトリに配置し、ブラウザで開く。ローカルでHTTP配信する場合は `python3 -m http.server 8000` のあと `http://localhost:8000/` を開く。最初は「架空デモを見る」で挙動を確認できる。

保存先はブラウザ内 `localStorage`。ブラウザのプライベートモードや保存制限、キャッシュ削除、端末変更では消える場合がある。必要に応じてJSONをダウンロード。自動同期・通知・アカウント・情報の外部送信は行わない。任意で入力した外部URLをクリックした場合は、そのリンク先へ遷移する。

## 安全性と限界

本ツールは**利用者が入力した出典のつながりと立場を集計するだけ**で、実在性、記述内容の真偽、独立性、証拠能力、引用文脈を自動検証しない。「独立起点」として入力された複数資料が実際には同一情報源に依存する可能性もある。複数の独立した根拠を使った一つの合成記事や、複雑な多対多の引用関係はMVPの単一親モデルでは表現できない。重要な判断では元資料を必ず確認し、結果を自動的な信頼度スコアとして利用しないこと。
