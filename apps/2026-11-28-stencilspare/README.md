# StencilSpare / ステンシル破断監査

2026-11-28 | MVP v1.0

## 対象・選定理由
ステンシルを繰り返し使う看板・工房・DIY制作者。国内では中秀鉄工が日本語文字のつなぎと耐久性の課題を解説（2026-10-22）。海外では Makerfern の自動最短ブリッジ、StencilVector の安定性評価、Stencil Lab の加工性チェックなどが存在する。需要の兆候であって市場規模や売上の証明ではない。
- https://www.nakahide.co.jp/news/stencil-plate-bridge-design/
- https://www.carverdesign.jp/sutenshiru.html
- https://makerfern.com/stencil-maker
- https://stencilvector.com/
- https://stencil-lab.com/

## 差別化仮説・操作
単なる孤立領域の検出ではなく、接続済みの型紙について単一マスを失った場合の追加脱落数を全マスで評価する。3〜32行・列の #（材料）と .（穴）で編集、または図をクリックして変更。外周は固定。監査後、破断マスを選ぶと追加脱落が青色で表示される。補強探索は横・縦の全連続穴区間（幅1マス）を比較し、孤立マス数、最大追加脱落数、弱点マス数、追加材料数の順で優先する。適用後の再監査、JSONおよび実寸SVGマスクの出力が可能。SVGは黒が残す材料、白が穴。切断輪郭データではない。index.html をブラウザで開くだけ。外部依存なし。

## 検証（実行済み）
- `node test.cjs`：300ランダム格子、6469個の破断影響比較（独立BFS）、固定7件合格。提案適用後の再監査も照合。
- `python test_browser.py`：Chromiumでサンプル、破断選択、補強探索・適用、JSON/SVGダウンロード、入力エラー、390px表示を確認。JS例外・外部HTTP要求なし。環境制限により同じHTMLをインライン読込。
- 初期例：孤立0、弱点5、最大追加脱落18。1マス補強後：いずれも0。

## 限界
4近傍、外周不破断、単一マス除去の離散モデル。強度・加工公差・複数同時破断・実機加工・画像入力・市場規模は未検証。補強候補の範囲内での最適化であり、任意形状の大域最適化ではない。既存案の全ソース照合は未実施。入力を外部送信しない。
