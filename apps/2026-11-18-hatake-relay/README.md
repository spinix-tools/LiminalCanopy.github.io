# 畑リレー / HATAKE RELAY 🌱

**家庭菜園の作付け履歴を使い、次季の野菜の植え場所を自動割当するオフラインWebアプリ。**

## 対象・選定理由

市民農園、ベランダの複数プランター、学校菜園などで、毎年の作物の場所を忘れがちな小規模利用者向け。国内のガーデニング・家庭菜園市場は2023年度2,321億円（矢野経済研究所、2024-12-25公表）。タキイ種苗の2025-03-04公表調査は600人を対象にし、初心者・中級者に「継続3年目の壁」があると報告。ただし、これらはアプリ固有の購買需要を示さない。

## 競合・差別化仮説

- 日本 **菜園工房**（App Store掲載）：畑の図、作業、連作の注意表示まで提供。
- 海外 **Gardentasia**：3年の科履歴・無料ブラウザ計画に対応。
- 海外 **Seedtime**：区画レイアウトと作付けカレンダーに対応。

競合が強いことを前提に、**過去3年の「科」の履歴と今年植えたい作物を入力し、固定した区画を守りながら、他の作物の割当を正確に最小スコア化する**という狭い作業に特化。優れた履歴管理そのものや病害予測の独自性は主張しない。

## 実装機能

- 最大10区画・10作物を登録。区画名、面積、前年・2年前・3年前の科を編集。
- 20品目／8グループの作物ライブラリ。同一科の再作付けと参考面積の不足を点数化。
- **ビットマスクDPによる厳密な最小費用割当**。固定区画を維持し、現在の点数と最適化後を比較。提案は承認後に反映。
- 重複配置の拒否、区画ごとの簡易マップ、注意表示。
- 自動localStorage保存、JSONのエクスポート／インポート、CSV（BOM付き）、印刷、初期化。
- 外部依存ライブラリ・外部API・ユーザー登録・個人情報収集なし。

**使い方**：同じディレクトリの `index.html` を通常のブラウザで開く。例データが入っているので「最小リスク配置を提案する」を押して動作確認。入力はこの端末内で処理する。

**評価の限界**：同一科が1/2/3年前にあればそれぞれ100/42/16点、参考面積不足にも加点する**説明用のヒューリスティクス**。感染率・収穫量・推奨輪作年限を算出するものではない。個々の作物、品種、土壌、病害、肥培管理で注意点は変わる。記録なしを安全と断定しない。DPの「最適」はこの定義されたスコアと1区画1作物モデルの範囲内でのみ成立する。

## テスト（2026-11-18）

- `node --test engine.test.cjs`：**38/38 合格**。計算例、固定割当、総当たりオラクルとの一致、10区画、CSV・JSON、不正入力を検査。
- `python browser_test.py`：**38/38 合格**（Chromium）。入力編集、割当・ロック、提案適用、エラーパス、CSV/JSON、再表示、モバイル幅、初期化を検査。
- 環境のナビゲーション制約により、Chromiumに実HTML・JSを注入してlocalStorageをメモリ実装に置き換えて検証。**実ファイル起動・GitHub Pages配信・ブラウザ実保存の持続性・農学的精度は未検証**。
